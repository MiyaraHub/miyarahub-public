الميزات

وحدة تحكم UniFi في جيبك.

يتحدث Network Deck مباشرةً مع واجهة API المحلية لوحدة تحكم UniFi - سواء كانت UniFi OS (UDM Pro أو Cloud Gateway أو Dream Machine) أو وحدة تحكم UniFi Network مستقلة. العملاء وWiFi وجدار الحماية والمنافذ وVPN والإحصاءات، دون فتح المتصفح.

رقم 01

◉ لوحة معلومات مباشرة

حالة ISP (مزوّد الإنترنت)، ومخطط نطاق ترددي لحظي بنافذة متحركة من 60 عينة، وبطاقات قابلة للتخصيص - معلومات النظام، وحركة DPI، والتنبيهات، والأحداث، وأبرز العملاء، وسجل اختبارات السرعة، واختصارات سريعة. تخطيط بعلامات تبويب يمكنك إعادة ترتيبها.

رقم 02

▣ العملاء والأجهزة

قائمة كاملة بالعملاء مع عوامل تصفية WiFi / سلكي / الكل وقوة الإشارة بوحدة dBm بنظرة واحدة. احظر أو ارفع الحظر أو اطرد أو انسَ عدة عملاء دفعة واحدة. تفاصيل لكل عميل تشمل السجل وتوزيع DPI وعنوان IP ثابت ومجموعة المستخدم ومصادقة الضيوف.

حظر / طردإشارة dBmIP ثابتإجراءات جماعية
رقم 03

◎ WiFi وVLAN والتحكم في المنافذ

أنشئ شبكات SSID وعدّلها واحذفها (الأمان، والنطاق، والضيوف، وVLAN، وPMF، والتجوال السريع). أدِر شبكات VLAN مع DHCP وIPv6 وmDNS والبث المتعدد وخيارات العزل. تحكّم في PoE لكل منفذ وفي إعدادات راديو نقطة الوصول AP (القناة، وقوة الإرسال TX، والعرض، وتوجيه النطاق، والحد الأدنى لـ RSSI).

◈ جدار الحماية وقواعد حركة البيانات

السياسات (سماح / حظر / فحص)، وإعادة توجيه المنافذ، وقواعد حركة البيانات والمسارات، ومجموعات جدار الحماية، ومناطق جدار الحماية مع مصفوفة سياسات v2، وعناصر تحكم تطبيقات / مجموعات DPI - وكلها مع مفاتيح تفعيل / تعطيل مباشرة. دون الحاجة إلى المتصفح.

فعّل IPS / IDS واختر الوضع، وفلتر المحتوى لكل شبكة (عمل / عائلة / مخصص)، وفحص SSL، وحظر الموقع الجغرافي لعناوين IP مع قائمة سماح وحظر للدول، وفحص نقاط الوصول AP المارقة، وسجل التهديدات المستمد من تنبيهات وحدة التحكم.

▤ اختبار السرعة ومسح الموقع

شغّل اختبار السرعة المدمج في وحدة التحكم مع استطلاع كل ثانيتين وسجل كامل. ومسح محلي لموقع WiFi (على Android): القناة والإشارة والأمان، إضافةً إلى قياس زمن الاستجابة (ping) والارتجاف (jitter) وفقد الحزم مقابل نقاط Cloudflare.

التوافق

يعمل مع وحدة تحكم UniFi لديك.

يدعم Network Deck أجهزة UniFi OS ووحدات تحكم UniFi Network المستقلة. فهو يكتشف تلقائيًا نقاط الاتصال التي يوفرها البرنامج الثابت لديك ويكيّف واجهة UI وفقها - فالميزات غير المتاحة لك لا تظهر ببساطة.

◉ أجهزة UniFi OS

  • UDM Pro SE (تم التحقق)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ وحدات التحكم المستقلة

  • UniFi Network 10.x (تم التحقق)
  • مُستضاف ذاتيًا على Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ المصادقة

  • اسم مستخدم وكلمة مرور للمشرف المحلي
  • المصادقة الثنائية (TOTP)
  • X-API-KEY للوصول البرمجي
  • لا حاجة إلى حساب UniFi Cloud

◆ منصات الجوال

  • iOS 13 فأحدث
  • Android 5.0 (API 21) فأحدث
  • تخطيطات الهاتف واللوحي
  • سمات فاتحة وداكنة

التوافق مع البرامج الثابتة: يكتشف Network Deck تلقائيًا نقاط الاتصال التي توفرها وحدة التحكم ويتكيّف مع اختلافات JSON الخاصة بكل برنامج ثابت (تغيّر أسماء الحقول، وتحويل الأنواع، وتعدد أشكال واجهة API التكاملية). قد تلاحظ حسابات المشرفين الفرعيين أن بعض نقاط الاتصال تُرجع الخطأ 401 - وهذا قيد في صلاحيات وحدة التحكم وليس قيدًا في التطبيق.

كيف يعمل

مباشرةً إلى وحدة التحكم. بلا وسيط سحابي.

يتصل Network Deck مباشرةً بوحدة تحكم UniFi عبر شبكتك المحلية (أو VPN). ولا تمر بيانات اعتمادك وبيانات شبكتك عبر أي خادم تابع لـ MiyaraHub.

1

أضف وحدة التحكم

أدخل اسم المضيف أو عنوان IP لوحدة التحكم، والمنفذ (الافتراضي 443 لـ UniFi OS و8443 للوحدات المستقلة)، وبيانات اعتماد المشرف المحلي. يكتشف Network Deck تلقائيًا ما إذا كنت تستخدم UniFi OS أم وحدة تحكم مستقلة.

2

سجّل الدخول محليًا

سجّل الدخول باسم مستخدم وكلمة مرور المشرف المحلي. والمصادقة الثنائية مدعومة بالكامل. تفضّل مفاتيح API؟ استخدم X-API-KEY للوصول البرمجي وتجاوز مسار ملفات تعريف الارتباط تمامًا.

3

أدِر كل شيء بنظرة واحدة

راقب مخطط النطاق الترددي المباشر، أو اطرد عميلًا مزعجًا، أو بدّل قاعدة في جدار الحماية، أو أعد تشغيل منفذ PoE، أو ادعُ ضيفًا عبر Teleport، أو انتقل إلى موقع آخر - وكل إجراء يصل إلى وحدة التحكم ويتحدّث بثّ الأحداث المباشر.
