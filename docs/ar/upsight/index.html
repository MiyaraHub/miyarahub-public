ما الذي تحتاج إليه

جهاز UPS على شبكتك.

يتحدث UPSight مع جهاز UPS لديك عبر الشبكة، من خلال بطاقة الشبكة فيه أو من خلال خادم NUT.

◉

جهاز UPS ببطاقة شبكة

APC Network Management Card وCyberPower RMCARD وEaton Network-M2 وNetwork-M3 وTripp Lite WEBCARDLX وVertiv Liebert IntelliSlot وأي بطاقة شبكة UPS أخرى تدعم SNMP. فعّل SNMP في صفحة الويب الخاصة بالبطاقة، ثم أضف عنوان IP الخاص بها في UPSight.

▣

أو جهاز UPS مشارَك عبر NUT

إذا كان جهاز UPS موصولًا بخادم أو NAS أو Raspberry Pi عبر USB وكان ذلك الجهاز يشغّل خادم Network UPS Tools (NUT)، فأضف خادم NUT في UPSight لمراقبة UPS من أي مكان على شبكتك.

◎

ليس إعدادًا عبر USB فقط

جهاز UPS الموصول بحاسوب واحد فقط عبر USB، دون بطاقة شبكة ودون خادم NUT، لا يمكن الوصول إليه عبر الشبكة، ولذلك لا يستطيع UPSight رؤيته.

الأسئلة الشائعة.

هل يحتاج جهاز UPS لدي إلى اتصال بالإنترنت؟ +
لا. يتواصل UPSight عبر شبكتك المحلية فقط. يكفي أن يكون جهاز UPS على الشبكة نفسها (أو متاحًا عبر VPN/Tailscale) التي يتصل بها هاتفك. لا حاجة إلى الوصول إلى الإنترنت لجهاز UPS نفسه.
هل يمكنني مراقبة عدة أجهزة UPS؟ +
نعم! يدعم UPSight عددًا غير محدود من أجهزة UPS. وتعرض لوحة المعلومات جميع وحداتك ببطاقات حالة تُرى بنظرة واحدة. المس أي جهاز لعرض التفاصيل الكاملة عبر ستة تبويبات: نظرة عامة، والطاقة، والبطارية، والمنافذ، والأحداث، والمعلومات.
هل يمكنني التحكم في منافذ UPS من التطبيق؟ +
نعم، لطرازات UPS التي تدعم التحكم في المنافذ عبر SNMP (مثل سلسلة CyberPower PR ذات المنافذ القابلة للتحكم). يمكنك تشغيل كل منفذ على حدة أو إيقافه وإعادة تسميته لسهولة التعرف عليه. أما المنافذ للقراءة فقط فتعرض الحالة دون عناصر تحكم للتبديل.
كم تبلغ تكلفة UPSight؟ +
UPSight عملية شراء لمرة واحدة بسعر $4.99. بلا اشتراكات، وبلا عمليات شراء داخل التطبيق، وبلا إعلانات. اشتره مرة واحدة واستخدمه إلى الأبد. وجميع التحديثات المستقبلية مشمولة.
ما إصدارات SNMP المدعومة؟ +
يدعم UPSight إصدارات SNMP v1 وv2c وv3. ويمكنك اختيار الإصدار لكل جهاز أثناء الإعداد. تستخدم معظم أجهزة UPS الاستهلاكية وشبه الاحترافية الإصدار v2c مع سلسلة مجتمع «public». أما v3 فمتاح للبيئات المؤسسية التي تتطلب المصادقة والتشفير.
هل يمكنني استخدام UPSight عن بُعد (خارج شبكة منزلي)؟ +
نعم، إذا كان جهاز UPS متاحًا عبر VPN أو Tailscale أو WireGuard أو ما شابه. يتصل UPSight بأي عنوان IP تضبطه. وننصح بالوصول عبر VPN بدلًا من تعريض منافذ SNMP مباشرةً للإنترنت.
هل يعمل UPSight مع بطاقة شبكة UPS لديّ؟ +
نعم، إذا كانت البطاقة تدعم SNMP. ويشمل ذلك APC Network Management Card وCyberPower RMCARD وEaton Network-M2 وNetwork-M3 وTripp Lite WEBCARDLX وبطاقات Vertiv Liebert IntelliSlot. فعّل SNMP في 'واجهة الويب' الخاصة بالبطاقة، ثم أضف عنوان IP الخاص بها في UPSight.
جهاز UPS لدي يحتوي على منفذ USB فقط. هل يمكنني استخدام UPSight؟ +
نعم، عبر NUT. وصّل جهاز UPS بخادم أو NAS أو Raspberry Pi يشغّل خادم Network UPS Tools (NUT) وأضف ذلك الخادم في UPSight. أما جهاز UPS المتصل بحاسوب واحد عبر USB فقط، دون NUT، فلا يمكن الوصول إليه عبر الشبكة.
العلامة التجارية لجهاز UPS لدي غير مدرجة. هل سيعمل؟ +
على الأرجح! إذا كان جهاز UPS يدعم SNMP وينفّذ معيار RFC 1628 UPS-MIB القياسي، فسيعمل برنامج التشغيل العام في UPSight. وتلتزم معظم أجهزة UPS القادرة على العمل الشبكي بهذا المعيار. وإذا واجهت مشكلات، فتواصل معنا وسنبحث إضافة برنامج تشغيل مخصص لعلامتك التجارية.
