Funkce

Váš řadič UniFi v kapse.

Network Deck komunikuje přímo s místním API vašeho řadiče UniFi - ať už jde o UniFi OS (UDM Pro, Cloud Gateway, Dream Machine), nebo samostatný řadič UniFi Network. Klienti, WiFi, firewall, porty, VPN a přehledy bez otevírání prohlížeče.

Kompatibilita

Funguje s vaším řadičem UniFi.

Network Deck podporuje konzole UniFi OS i samostatné řadiče UniFi Network. Automaticky zjistí, které koncové body váš firmware nabízí, a přizpůsobí tomu rozhraní - funkce, které nemáte, se prostě nezobrazí.

◉ Konzole UniFi OS

  • UDM Pro SE (ověřeno)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Samostatné řadiče

  • UniFi Network 10.x (ověřeno)
  • Vlastní hosting na Linuxu / v Dockeru
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Ověřování

  • Místní administrátorské jméno + heslo
  • Dvoufázové ověření (TOTP)
  • X-API-KEY pro programový přístup
  • Cloudový účet UniFi není potřeba

◆ Mobilní platformy

  • iOS 13 a novější
  • Android 5.0 (API 21) a novější
  • Rozvržení pro telefony i tablety
  • Světlý a tmavý motiv

Tolerance firmwaru: Network Deck automaticky zjišťuje koncové body, které váš řadič nabízí, a přizpůsobuje se variantám JSON specifickým pro daný firmware (změny názvů polí, převody typů, více tvarů integračního API). Účty sub-administrátorů mohou u některých koncových bodů dostat chybu 401 - jde o omezení oprávnění řadiče, ne aplikace.

Jak to funguje

Přímo k vašemu řadiči. Žádný cloudový přenos.

Network Deck komunikuje přímo s vaším řadičem UniFi přes místní síť (nebo VPN). Vaše přihlašovací údaje ani data o síti se nikdy nedostanou na server MiyaraHub.

1

Přidejte svůj řadič

Zadejte název hostitele nebo IP adresu řadiče, port (výchozí 443 pro UniFi OS, 8443 pro samostatný řadič) a své místní administrátorské údaje. Network Deck automaticky rozpozná, zda používáte UniFi OS, nebo samostatný řadič.

2

Přihlaste se lokálně

Přihlaste se místním administrátorským jménem a heslem. Dvoufázové ověření je podporováno od začátku do konce. Dáváte přednost klíčům API? Použijte X-API-KEY pro programový přístup a vynechte přihlášení přes cookies úplně.

3

Spravujte na první pohled

Sledujte živý graf šířky pásma, odpojte zlobícího klienta, přepněte pravidlo firewallu, restartujte port PoE, pozvěte hosta přes Teleport nebo přepněte na jinou lokalitu - každá akce proběhne přes řadič a promítne se do živého proudu událostí.

Zabezpečení & soukromí

Jen lokálně. Bez účtu. Bez cloudového přenosu.

Network Deck je navržen s architekturou zaměřenou na soukromí a pouze lokální. Žádný účet MiyaraHub, žádný cloudový přenos, žádný sběr dat kromě hlášení pádů.

◉

Žádný cloudový přenos

Všechny příkazy a živé proudy dat probíhají přímo mezi vaším telefonem a řadičem přes místní Wi-Fi nebo VPN. Nic nejde přes externí servery.

▣

Standardní ověřování UniFi

Používá stejné místní administrátorské údaje (nebo klíč API) jako webové rozhraní UniFi Network. Údaje jsou uloženy v iOS Keychain / Android Keystore na zařízení a nikdy se neodesílají mimo zařízení, kromě vašeho řadiče.

◎

Bez účtu MiyaraHub

Žádná registrace, žádný e-mail, žádný účet MiyaraHub. Nainstalujte, nasměrujte na svůj řadič a jste uvnitř.

◈

Minimální analytika

Firebase Crashlytics pouze pro hlášení chyb. Žádné sledování používání, žádné reklamy, žádný prodej dat. Síťové chyby se zaznamenávají jako nekritické, aby nám pomohly zlepšit kompatibilitu s firmwarem, aniž bychom sbírali rozvržení vaší sítě.

◆

Respektování oprávnění

Aplikace pracuje v rámci oprávnění vašeho administrátorského účtu UniFi. Sub-administrátoři vidí jen to, co jim řadič dovolí. Žádné zvyšování oprávnění, žádná zadní vrátka.

◐

Pouze oprávnění k síti

Jediné oprávnění zařízení, které Network Deck vyžaduje, je přístup k síti, používaný výhradně k připojení k vašemu řadiči UniFi v místní síti (nebo přes VPN).

Které řadiče UniFi jsou podporovány? +
Network Deck podporuje jak konzole UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus), tak samostatné řadiče UniFi Network s verzí v10.x na Linuxu, v Dockeru nebo na Windows. Aplikace při připojení automaticky rozpozná vaši platformu a přizpůsobí rozhraní koncovým bodům, které váš firmware skutečně nabízí - funkce, které nemáte, se prostě nezobrazí. Otestováno naživo na UDM Pro SE (UniFi OS 5.0.16) a samostatném Network 10.2.105.
Jak Network Deck komunikuje s mým řadičem? +
Network Deck používá stejné místní API jako webové rozhraní UniFi Network - kombinaci klasických koncových bodů /rest a /cmd (s ověřováním relace pomocí cookies) a novějšího integračního API v2. K řadiči také otevírá WebSocket pro přenos živých událostí. Veškerá komunikace probíhá přímo mezi vaším telefonem a řadičem přes místní síť nebo VPN.
Potřebuji cloudový účet UniFi? +
Ne. Network Deck používá pouze místní ověřování. Přihlaste se místním administrátorským jménem a heslem UniFi (nebo klíčem API). Pokud je váš řadič zatím dostupný jen přes cloudové přihlášení ui.com, budete si muset pro použití Network Deck zapnout místní administrátorský účet v Settings → Admins. Řadič s námi nikdy nekomunikuje a my nikdy nekomunikujeme s cloudem Ubiquiti vaším jménem.
Mohu spravovat pravidla firewallu a přesměrování portů? +
Ano. Network Deck má kompletní firewall: zásady (povolit / blokovat / kontrolovat), přesměrování portů s plnou správou (CRUD), pravidla provozu a trasy, skupiny firewallu, zóny firewallu (matice zásad v2) a aplikace / skupiny DPI. Vše se přepíná přímo v seznamu - žádné proklikávání dialogů.
Podporuje více lokalit? +
Ano. Pokud váš řadič spravuje více lokalit, Network Deck nahoře zobrazí přepínač lokalit. Každá funkce - přehled, klienti, firewall, VPN - se vztahuje k aktuálně vybrané lokalitě. Přepnete jedním klepnutím.
Kolik bude Network Deck stát? +
Network Deck bude jednorázový nákup za $4.99 v App Store, Google Play a Microsoft Store. Bez předplatného, bez reklam, bez nákupů v aplikaci. Cena se může před veřejným spuštěním změnit.
Mohu ho používat na dálku (mimo domov / kancelář)? +
Network Deck se připojí k jakémukoli názvu hostitele nebo IP adrese, kterou nastavíte. Pokud je váš řadič dostupný přes VPN, Tailscale, WireGuard nebo přesměrovaný port, aplikace bude fungovat i na dálku. Doporučujeme použít VPN nebo Tailscale místo přímého vystavení řadiče UniFi do internetu.
Které platformy jsou podporovány? +
Network Deck běží na iOS (13 a novější) i Android (5.0 / API 21 a novější). Podporována jsou rozvržení pro telefony i tablety. Aplikace vyjde současně v App Store, Google Play a Microsoft Store.
