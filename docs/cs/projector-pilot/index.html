Funkce

Kompletní ovládání projektoru ve vaší ruce.

Projector Pilot se k projektoru Epson připojí přes Wi-Fi a dává vám plnou kontrolu nad každým nastavením - od napájení a obrazu po objektiv a geometrii - bez doteku projektoru a bez hledání fyzického dálkového ovladače.

Jak to funguje

Přímé síťové připojení. Žádný cloud.

Projector Pilot komunikuje s vaším projektorem přímo přes Wi-Fi pomocí standardních síťových protokolů. Vaše data se nikdy nedostanou na externí server.

1

Přidejte svůj projektor

Zadejte IP adresu svého projektoru Epson. Projector Pilot otestuje připojení přes PJLink a Web Control, rozpozná model a automaticky zjistí všechny dostupné funkce.

2

Připojte se přes Wi-Fi

Projector Pilot používá PJLink ke zjištění pohotovostního režimu a ovládání napájení a Epson Web Control API k plnému ovládání obrazu, objektivu a nastavení po zapnutí. Vše zůstává ve vaší místní síti.

3

Převezměte plnou kontrolu

Upravujte nastavení obrazu, přepínejte vstupy, ovládejte motorizovaný objektiv, spravujte korekci lichoběžníkového zkreslení, sledujte hodiny lampy a procházejte nabídku OSD - vše v jedné elegantní aplikaci.

Zabezpečení & soukromí

Jen lokálně. Bez účtu. Bez cloudu.

Projector Pilot je navržen s architekturou zaměřenou na soukromí a pouze lokální. Žádná závislost na cloudu, žádný uživatelský účet, žádný sběr dat kromě hlášení pádů.

◉

Žádný cloudový přenos

Všechny příkazy a dotazování stavu probíhají přímo mezi telefonem a projektorem přes vaši místní Wi-Fi. Nic neopustí vaši síť.

◎

Účet není potřeba

Žádná registrace, žádný e-mail, žádný účet MiyaraHub. Otevřete aplikaci, zadejte IP adresu projektoru a máte ho pod kontrolou.

▣

Minimální analytika

Firebase Crashlytics pouze pro hlášení chyb. Žádné osobní údaje, žádné sledování používání, žádné reklamy. Data vašeho projektoru nikdy neopustí váš telefon.

◆

Jen místní úložiště

IP adresy projektorů, přihlašovací údaje a předvolby aplikace se ukládají lokálně ve vašem zařízení pomocí SharedPreferences. Nic se nesynchronizuje na server.

▢

Jen akce vyvolané uživatelem

Aplikace posílá příkazy projektoru pouze na vaši výslovnou akci. Nic se neděje automaticky ani na pozadí bez vašeho vědomí.

Vše, co potřebujete vědět o Projector Pilot.

Je Projector Pilot spojen se společností Epson? +

Tento název používáme výhradně k popisu kompatibility (nominativní fair use).
Které projektory jsou podporovány? +
Projector Pilot funguje se všemi síťovými projektory Epson, které podporují PJLink a/nebo Web Control. To zahrnuje většinu modelů z posledních více než 10 let - od vlajkových QB1000 a LS12000 po střední třídu Home Cinema a profesionální instalační modely. Aplikace při připojení automaticky zjistí dostupné funkce, takže každý uživatel uvidí přesně to, co jeho projektor podporuje. Základní ovládání přes PJLink funguje i u projektorů jiných výrobců než Epson, například NEC, Panasonic, Sony a dalších.
Jak Projector Pilot komunikuje s mým projektorem? +
Projector Pilot používá dva protokoly: PJLink (port 4352) pro univerzální ovládání projektoru včetně zapnutí z pohotovostního režimu, přepínání vstupů a stavu lampy, a Epson Web Control API (port 80) s ověřováním Digest pro rozšířené ovládání nastavení včetně obrazu, objektivu, lichoběžníkového zkreslení, HDR a dalších. Veškerá komunikace probíhá přímo ve vaší místní síti Wi-Fi.
Mohu ovládat motorizovaný objektiv? +
Ano, u projektorů s motorizovaným objektivem. Projector Pilot nabízí úplné ovládání posunu objektivu (vodorovného i svislého), zaostření a zoomu se zpětnou vazbou pozice v reálném čase. Můžete také ukládat a vyvolávat předvolby paměti objektivu pro různé poměry stran, pozice plátna nebo způsoby sledování. U modelů bez motorizovaného objektivu se ovládání objektivu automaticky skryje.
Podporuje HDR a široký barevný gamut? +
Ano. Projector Pilot umožňuje ovládat nastavení dynamického rozsahu (Auto, HDR10, HLG, SDR), barevný prostor (Auto, BT.709, BT.2020) a nabízí úpravy zisku a posunu RGB pro každý kanál pro přesnou kalibraci barev. Funkce HDR se zobrazují jen u modelů, které je podporují.
Mohu projektor zapnout z pohotovostního režimu? +
Ano. Projector Pilot používá PJLink k zapnutí projektoru, i když je v pohotovostním režimu. Pokud je projektor připojen k síti (pro probuzení z pohotovostního režimu doporučujeme kabelovou síť LAN), můžete ho zapínat a vypínat z telefonu.
Kolik Projector Pilot stojí? +
Projector Pilot je ke stažení zdarma, základní ovládání je součástí. Pro je jednorázové odemčení za $9.99, Domácí automatizace stojí $2.99, nebo si pořiďte obojí jako balíček za $11.99. Bez předplatného, bez reklam. Koupíte jednou a vlastníte navždy. Cena se může před spuštěním změnit.
Jaká verze Android je potřeba? +
Projector Pilot vyžaduje Android 5.0 (API 21) nebo novější. Zatím je to aplikace pouze pro Android. Podpora iOS může přibýt v budoucí verzi.
