En førsteklasses, målrettet brugerflade til UniFi-administratorer. Mørkt tema, livedata, intuitiv navigation - ingen browserfaner nødvendige. Tryk på et billede for at zoome.

Funktioner

Din UniFi-controller i lommen.

Network Deck taler direkte med din UniFi-controllers lokale API - uanset om det er UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) eller en selvstændig UniFi Network-controller. Klienter, WiFi, firewall, porte, VPN og indsigt uden at åbne en browser.

Nr. 01

◉ Live dashboard

ISP-sundhed, båndbreddegraf i realtid med rullende 60-samples vindue og tilpasselige kort - systemoplysninger, DPI-trafik, alarmer, hændelser, top-klienter, historik for hastighedstest og hurtige genveje. Layout med faner, som du kan omarrangere.

BåndbreddeISP-sundhedDPI-trafikTop-klienter
Nr. 02

▣ Klienter & enheder

Komplet klientliste med filtre for WiFi / kablet / alle og signalstyrke i dBm med et blik. Bloker, fjern blokering, smid ud eller glem i bulk. Detaljer pr. klient med historik, DPI-fordeling, fast IP, brugergruppe og gæstegodkendelse.

Bloker / Smid udSignal dBmFast IPMassehandlinger
Nr. 03

◎ WiFi, VLAN & portstyring

Opret, redigér og slet SSID'er (sikkerhed, bånd, gæst, VLAN, PMF, hurtig roaming). Administrer VLAN med DHCP, IPv6, mDNS, multicast og isolation. PoE-styring pr. port og AP-radiokonfiguration (kanal, TX-effekt, bredde, band steering, min. RSSI).

SSID CRUDVLANPoE-styringAP-radioer
Nr. 04

◈ Firewall & trafikregler

Politikker (tillad / blokér / inspicer), portvideresendelser, trafikregler og ruter, firewallgrupper, firewallzoner med v2-politikmatrixen og styring af DPI-apps / -grupper - alt sammen med til/fra-kontakter direkte i listen. Ingen browser nødvendig.

PolitikkerPortvideresendelserZoner v2DPI
Nr. 05

◆ Sikkerhed & indsigt

Slå IPS / IDS til og vælg tilstand, indholdsfilter pr. netværk (arbejde / familie / brugerdefineret), SSL-inspektion, geo-IP-blokering med land-hvidliste / -sortliste, scanning efter uautoriserede AP'er og trusselshistorik hentet fra din controllers alarmer.

Opret Teleport-gæsteinvitationer med 24 timers udløb. Opret site-til-site-tunneler med IPsec, OpenVPN eller WireGuard med en pre-shared key. Slå peer-to-peer og enhedsopdagelse til og fra med et tryk.

▤ Hastighedstest & site survey

Kør controllerens indbyggede hastighedstest med 2 sekunders polling og fuld historik. Lokal WiFi site survey (Android): kanal, signal, sikkerhed samt måling af ping, jitter og pakketab mod Cloudflare-endpoints.

Kompatibilitet

Virker med din UniFi-controller.

Network Deck understøtter både UniFi OS-konsoller og selvstændige UniFi Network-controllere. Appen registrerer automatisk, hvilke endpoints din firmware udstiller, og tilpasser brugerfladen - funktioner, du ikke har, vises simpelthen ikke.

◉ UniFi OS-konsoller

  • UDM Pro SE (verificeret)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Selvstændige controllere

  • UniFi Network 10.x (verificeret)
  • Selvhostet på Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Godkendelse

  • Lokalt administratorbrugernavn + adgangskode
  • Tofaktorgodkendelse (TOTP)
  • X-API-KEY til programmatisk adgang
  • Ingen UniFi Cloud-konto påkrævet

◆ Mobile platforme

  • iOS 13 og nyere
  • Android 5.0 (API 21) og nyere
  • Telefon- og tabletlayout
  • Lyse og mørke temaer

Tolerance over for firmware: Network Deck registrerer automatisk, hvilke endpoints din controller udstiller, og tilpasser sig firmwarespecifikke JSON-varianter (ændrede feltnavne, typekonvertering, flere strukturer i integrations-API'et). Underadministratorkonti kan opleve, at nogle endpoints returnerer 401 - det er en begrænsning i controllerens rettigheder, ikke i appen.

Sådan fungerer det

Direkte til din controller. Ingen cloud-relay.

Network Deck taler direkte med din UniFi-controller over dit lokale netværk (eller din VPN). Dine loginoplysninger og netværksdata rører aldrig en MiyaraHub-server.

1

Tilføj din controller

Indtast din controllers værtsnavn eller IP, port (standard 443 for UniFi OS, 8443 for selvstændig) og dine lokale administratoroplysninger. Network Deck registrerer automatisk, om du bruger UniFi OS eller en selvstændig controller.

2

Log ind lokalt

Log ind med dit lokale administratorbrugernavn og din adgangskode. Tofaktorgodkendelse understøttes hele vejen. Foretrækker du API-nøgler? Brug X-API-KEY til programmatisk adgang og spring cookieflowet helt over.

3

Styr det hele med et blik

Følg den levende båndbreddegraf, smid en driller af nettet, slå en firewallregel til eller fra, genstart en PoE-port, inviter en Teleport-gæst eller skift til et andet site - hver handling går til controlleren og opdaterer live-hændelsesstrømmen.

Sikkerhed & privatliv

Kun lokalt. Ingen konto. Intet skyrelæ.

Network Deck er designet med en privatlivsfokuseret, kun lokal arkitektur. Ingen MiyaraHub-konto, ingen cloud-relay, ingen dataindsamling ud over nedbrudsrapportering.

◉

Intet skyrelæ

Alle kommandoer og live-strømme går direkte mellem din telefon og din controller over dit lokale Wi-Fi eller din VPN. Intet sendes via eksterne servere.

▣

Standard UniFi-godkendelse

Bruger de samme lokale administratoroplysninger (eller API-nøgle) som UniFi Networks webgrænseflade. Oplysningerne gemmes i iOS Keychain / Android Keystore på enheden og sendes aldrig fra enheden bortset fra til din controller.

◎

Ingen MiyaraHub-konto

Ingen tilmelding, ingen e-mail, ingen MiyaraHub-konto nødvendig. Installér, peg appen på din controller, og så er du i gang.

◈

Minimal analyse

Firebase Crashlytics kun til fejlrapporter. Ingen sporing af brug, ingen reklamer, intet salg af data. Netværksfejl logges som ikke-fatale for at hjælpe os med at forbedre firmwarekompatibiliteten uden at indsamle dit netværkslayout.

◆

Rettigheder respekteres

Appen arbejder inden for de rettigheder, din UniFi-administratorkonto har. Underadministratorer ser kun det, controlleren tillader. Ingen rettighedseskalering, ingen bagdør.

◐

Kun netværkstilladelse

Den eneste enhedstilladelse, Network Deck kræver, er netværksadgang, som udelukkende bruges til at forbinde til din UniFi-controller på dit lokale netværk (eller via VPN).

Ofte stillede spørgsmål.

Alt, hvad du behøver at vide om Network Deck.

Er Network Deck tilknyttet Ubiquiti eller UniFi? +
Nej. Network Deck er en uafhængig tredjepartsapp udviklet af MiyaraHub Technologies LLC. Den er ikke udviklet af, godkendt af, sponsoreret af eller tilknyttet Ubiquiti Inc. på nogen måde. »Ubiquiti«, »UniFi«, »UniFi OS«, »UniFi Network«, »UDM«, »UDR«, »UCG«, »Teleport« og alle relaterede produktnavne er varemærker tilhørende Ubiquiti Inc. Vi bruger navnene udelukkende til at beskrive kompatibilitet (nominativ brug).
Hvilke UniFi-controllere understøttes? +
Network Deck understøtter både UniFi OS-konsoller (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) og selvstændige UniFi Network-controllere med v10.x på Linux, Docker eller Windows. Appen registrerer automatisk din platform ved tilslutning og tilpasser brugerfladen til de endpoints, din firmware faktisk udstiller - funktioner, du ikke har, vises simpelthen ikke. Testet live mod UDM Pro SE (UniFi OS 5.0.16) og selvstændig Network 10.2.105.
Hvordan kommunikerer Network Deck med min controller? +
Network Deck bruger det samme lokale API som UniFi Networks webgrænseflade - en kombination af de klassiske /rest- og /cmd-endpoints (med cookiebaseret sessionsgodkendelse) samt det nyere v2-integrations-API. Appen åbner også en WebSocket til din controller for at streame live-hændelser. Al kommunikation foregår direkte mellem din telefon og din controller over dit lokale netværk eller VPN.
Skal jeg have en UniFi-cloudkonto? +
Nej. Network Deck bruger kun lokal godkendelse. Log ind med dit lokale UniFi-administratorbrugernavn og din adgangskode (eller en API-nøgle). Hvis din controller i dag kun kan nås via ui.com-cloudlogin, skal du aktivere en lokal administratorkonto under Settings → Admins for at bruge Network Deck. Controlleren taler aldrig med os, og vi taler aldrig med Ubiquitis cloud på dine vegne.
Kan jeg administrere firewallregler og portvideresendelser? +
Ja. Network Deck har en komplet firewall-pakke: politikker (tillad / blokér / inspicer), portvideresendelser med fuld CRUD, trafikregler og ruter, firewallgrupper, firewallzoner (v2-politikmatrix) samt DPI-apps / -grupper. Alt kan slås til og fra direkte i listevisningen - ingen dialog-tryk-dialog-forløb.
Understøtter den flere sites? +
Ja. Hvis din controller administrerer flere sites, viser Network Deck en site-vælger øverst. Alle funktioner - dashboard, klienter, firewall, VPN - gælder for det aktuelt valgte site. Skift med ét tryk.
Hvad kommer Network Deck til at koste? +
Network Deck bliver et engangskøb til $4.99 på App Store, Google Play og Microsoft Store. Intet abonnement, ingen reklamer, ingen køb i appen. Prisen kan ændres før den offentlige lancering.
Kan jeg bruge den på afstand (uden for hjemmet / kontoret)? +
Network Deck forbinder til det værtsnavn eller den IP, du angiver. Hvis din controller kan nås via VPN, Tailscale, WireGuard eller en videresendt port, virker appen også på afstand. Vi anbefaler at bruge en VPN eller Tailscale frem for at udsætte din UniFi-controller direkte for internettet.
Hvilke platforme understøttes? +
Network Deck kører på både iOS (13 og nyere) og Android (5.0 / API 21 og nyere). Både telefon- og tabletlayout understøttes. Appen lanceres samtidig på App Store, Google Play og Microsoft Store.
