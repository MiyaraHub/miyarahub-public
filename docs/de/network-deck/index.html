Funktionen

Dein UniFi-Controller in deiner Hosentasche.

Network Deck spricht direkt mit der lokalen API deines UniFi-Controllers - egal ob UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) oder eigenständiger UniFi Network-Controller. Clients, WLAN, Firewall, Ports, VPN und Insights, ohne einen Browser zu öffnen.

ISP-Zustand, Echtzeit-Bandbreitendiagramm mit gleitendem 60-Messwerte-Fenster und anpassbare Karten - Systeminfo, DPI-Traffic, Alarme, Ereignisse, Top-Clients, Speedtest-Verlauf und schnelle Shortcuts. Ein Tab-Layout, dessen Reihenfolge du ändern kannst.

Kompatibilität

Funktioniert mit deinem UniFi-Controller.

Network Deck unterstützt sowohl UniFi OS-Konsolen als auch eigenständige UniFi Network-Controller. Die App erkennt automatisch, welche Endpunkte deine Firmware bereitstellt, und passt die Oberfläche entsprechend an - Funktionen, die du nicht hast, werden einfach nicht angezeigt.

◉ UniFi OS-Konsolen

  • UDM Pro SE (verifiziert)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Eigenständige Controller

  • UniFi Network 10.x (verifiziert)
  • Selbst gehostet unter Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Authentifizierung

  • Lokaler Admin-Benutzername + Passwort
  • Zwei-Faktor-Authentifizierung (TOTP)
  • X-API-KEY für den programmatischen Zugriff
  • Kein UniFi-Cloud-Konto erforderlich

◆ Mobile Plattformen

  • iOS 13 und höher
  • Android 5.0 (API 21) und höher
  • Smartphone- und Tablet-Layouts
  • Helle und dunkle Designs

Firmware-Toleranz: Network Deck erkennt automatisch die Endpunkte, die dein Controller bereitstellt, und passt sich an firmwarespezifische JSON-Varianten an (abweichende Feldnamen, Typumwandlung, mehrere Formate der Integrations-API). Bei Sub-Admin-Konten können einige Endpunkte 401 zurückgeben - das ist eine Berechtigungsgrenze des Controllers, keine Einschränkung der App.

So funktioniert es

Direkt zu deinem Controller. Kein Cloud-Relay.

Network Deck spricht direkt mit deinem UniFi-Controller über dein lokales Netzwerk (oder dein VPN). Deine Zugangsdaten und Netzwerkdaten berühren nie einen MiyaraHub-Server.

1

Controller hinzufügen

Gib Hostnamen oder IP deines Controllers, den Port (Standard 443 für UniFi OS, 8443 für eigenständige Controller) und deine lokalen Admin-Zugangsdaten ein. Network Deck erkennt automatisch, ob du UniFi OS oder einen eigenständigen Controller nutzt.

2

Lokal anmelden

Melde dich mit deinem lokalen Admin-Benutzernamen und Passwort an. Die Zwei-Faktor-Authentifizierung wird durchgängig unterstützt. Lieber API-Schlüssel? Nutze X-API-KEY für den programmatischen Zugriff und überspringe den Cookie-Ablauf komplett.

3

Alles auf einen Blick

Beobachte das Live-Bandbreitendiagramm, wirf einen störenden Client raus, schalte eine Firewall-Regel um, starte einen PoE-Port neu, lade einen Teleport-Gast ein oder wechsle zu einem anderen Standort - jede Aktion geht zum Controller und zurück und aktualisiert den Live-Ereignisstream.

Sicherheit & Datenschutz

Nur lokal. Kein Konto. Kein Cloud-Relay.

Network Deck wurde mit einer datenschutzorientierten, rein lokalen Architektur entwickelt. Kein MiyaraHub-Konto, kein Cloud-Relay, keine Datenerhebung außer Absturzberichten.

◉

Kein Cloud-Relay

Alle Befehle und Live-Streams laufen direkt zwischen deinem Smartphone und deinem Controller über dein lokales WLAN oder VPN. Nichts wird über externe Server geleitet.

▣

Standard-UniFi-Authentifizierung

Verwendet dieselben lokalen Admin-Zugangsdaten (oder denselben API-Schlüssel) wie die Weboberfläche von UniFi Network. Zugangsdaten werden im iOS Keychain / Android Keystore auf dem Gerät gespeichert und nie vom Gerät übertragen - außer an deinen Controller.

◎

Kein MiyaraHub-Konto

Keine Registrierung, keine E-Mail, kein MiyaraHub-Konto nötig. Installieren, auf deinen Controller zeigen, fertig.

◈

Minimale Analysen

Firebase Crashlytics nur für Fehlerberichte. Kein Nutzungs-Tracking, keine Werbung, kein Datenverkauf. Netzwerkfehler werden als nicht schwerwiegend protokolliert, damit wir die Firmware-Kompatibilität verbessern können, ohne dein Netzwerklayout zu erfassen.

◆

Berechtigungen werden respektiert

Die App arbeitet innerhalb der Berechtigungen, die dein UniFi-Admin-Konto hat. Sub-Admins sehen nur, was der Controller ihnen erlaubt. Keine Rechteausweitung, keine Hintertür.

◐

Nur Netzwerkberechtigung

Die einzige Geräteberechtigung, die Network Deck benötigt, ist der Netzwerkzugriff - ausschließlich, um sich in deinem lokalen Netzwerk (oder per VPN) mit deinem UniFi-Controller zu verbinden.

Welche UniFi-Controller werden unterstützt? +
Network Deck unterstützt sowohl UniFi OS-Konsolen (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) als auch eigenständige UniFi Network-Controller ab v10.x unter Linux, Docker oder Windows. Die App erkennt deine Plattform beim Verbinden automatisch und passt die Oberfläche an die Endpunkte an, die deine Firmware tatsächlich bereitstellt - Funktionen, die du nicht hast, werden einfach nicht angezeigt. Live getestet mit UDM Pro SE (UniFi OS 5.0.16) und eigenständigem Network 10.2.105.
Wie kommuniziert Network Deck mit meinem Controller? +
Network Deck nutzt dieselbe lokale API wie die Weboberfläche von UniFi Network - eine Kombination aus den klassischen Endpunkten /rest und /cmd (mit cookiebasierter Sitzungsauthentifizierung) sowie der neueren v2-Integrations-API. Zusätzlich öffnet die App einen WebSocket zu deinem Controller, um Live-Ereignisse zu streamen. Die gesamte Kommunikation läuft direkt zwischen deinem Smartphone und deinem Controller über dein lokales Netzwerk oder VPN.
Brauche ich ein UniFi-Cloud-Konto? +
Nein. Network Deck verwendet ausschließlich lokale Authentifizierung. Melde dich mit deinem lokalen UniFi-Admin-Benutzernamen und Passwort an (oder mit einem API-Schlüssel). Wenn dein Controller bisher nur über den ui.com-Cloud-Login erreichbar ist, solltest du unter Settings → Admins ein lokales Admin-Konto aktivieren, um Network Deck zu nutzen. Der Controller kommuniziert nie mit uns, und wir kommunizieren nie in deinem Namen mit der Cloud von Ubiquiti.
Kann ich Firewall-Regeln und Portweiterleitungen verwalten? +
Ja. Network Deck bietet einen vollständigen Firewall-Bereich: Richtlinien (erlauben / blockieren / prüfen), Portweiterleitungen mit CRUD, Traffic-Regeln und Routen, Firewall-Gruppen, Firewall-Zonen (v2-Richtlinienmatrix) sowie DPI-Apps / -Gruppen. Alles lässt sich direkt in der Listenansicht umschalten - ohne Dialog-Tippen-Dialog-Ablauf.
Wird Multi-Site unterstützt? +
Ja. Verwaltet dein Controller mehrere Standorte, zeigt Network Deck oben einen Standort-Umschalter an. Jede Funktion - Dashboard, Clients, Firewall, VPN - bezieht sich auf den aktuell gewählten Standort. Gewechselt wird mit einem Tipp.
Was wird Network Deck kosten? +
Network Deck wird ein Einmalkauf für $4.99 im App Store, bei Google Play und im Microsoft Store. Kein Abo, keine Werbung, keine In-App-Käufe. Der Preis kann sich vor dem öffentlichen Start noch ändern.
Kann ich die App aus der Ferne nutzen (außerhalb von Zuhause / Büro)? +
Network Deck verbindet sich mit dem Hostnamen oder der IP, die du einrichtest. Ist dein Controller per VPN, Tailscale, WireGuard oder weitergeleitetem Port erreichbar, funktioniert die App auch von unterwegs. Wir empfehlen ein VPN oder Tailscale, statt deinen UniFi-Controller direkt ins Internet zu stellen.
Welche Plattformen werden unterstützt? +
Network Deck läuft sowohl auf iOS (ab 13) als auch auf Android (ab 5.0 / API 21). Smartphone- und Tablet-Layouts werden beide unterstützt. Die App erscheint gleichzeitig im App Store, bei Google Play und im Microsoft Store.
