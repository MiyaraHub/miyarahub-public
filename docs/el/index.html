Μικρό στούντιο. Προσεκτική δουλειά.

Η MiyaraHub Technologies είναι μια μικρή, ανεξάρτητη LLC στο Van Alstyne του Τέξας, που ανήκει και διευθύνεται από τον Meir Miyara.

Δεν είμαστε εργοστάσιο και δεν προσποιούμαστε ότι είμαστε. Είμαστε μια μικρή ομάδα που νοιάζεται να πετυχαίνει τις λεπτομέρειες - το είδος λογισμικού που θα θέλατε στις δικές σας συσκευές, να ελέγχει τον δικό σας εξοπλισμό.

Χτίζουμε με διαφάνεια, ακούμε όσους χρησιμοποιούν τις εφαρμογές μας και διορθώνουμε γρήγορα. Μεγάλο μέρος αυτού που κυκλοφορεί σε μια έκδοση ξεκίνησε ως μήνυμα από κάποιον στην κοινότητα - και προτιμούμε να παραμείνει έτσι.

Δεν θα υπερβάλουμε. Κάποιες από τις εφαρμογές μας είναι άρτιες και κυκλοφορούν σε χιλιάδες ανθρώπους· μερικές είναι ακόμα στον πάγκο εργασίας, και θα σας πούμε ποιες. Αυτό που υποσχόμαστε είναι έντιμη προσπάθεια, native λογισμικό, στη συσκευή από προεπιλογή και χωρίς συνδρομές για πράγματα που τρέχουν σε υλικό που ήδη κατέχετε.
