Λειτουργίες

Ο controller UniFi σας, στην τσέπη σας.

Το Network Deck επικοινωνεί απευθείας με το τοπικό API του controller UniFi σας - είτε πρόκειται για UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) είτε για αυτόνομο controller UniFi Network. Πελάτες, WiFi, firewall, θύρες, VPN και αναλυτικά στοιχεία, χωρίς να ανοίξετε πρόγραμμα περιήγησης.

Συμβατότητα

Λειτουργεί με τον controller UniFi σας.

Το Network Deck υποστηρίζει τόσο κονσόλες UniFi OS όσο και αυτόνομους controllers UniFi Network. Εντοπίζει αυτόματα ποια endpoints εκθέτει το firmware σας και προσαρμόζει τη διεπαφή - οι λειτουργίες που δεν διαθέτετε απλώς δεν εμφανίζονται.

◉ Κονσόλες UniFi OS

  • UDM Pro SE (επαληθευμένο)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Αυτόνομοι Controllers

  • UniFi Network 10.x (επαληθευμένο)
  • Αυτο-φιλοξενούμενο σε Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Έλεγχος Ταυτότητας

  • Τοπικό όνομα χρήστη + κωδικός διαχειριστή
  • Έλεγχος ταυτότητας δύο παραγόντων (TOTP)
  • X-API-KEY για προγραμματιστική πρόσβαση
  • Δεν απαιτείται λογαριασμός UniFi Cloud

◆ Πλατφόρμες για Κινητά

  • iOS 13 και νεότερο
  • Android 5.0 (API 21) και νεότερο
  • Διατάξεις για κινητά και tablet
  • Θέματα Light και Dark

Ανοχή στο firmware: Το Network Deck εντοπίζει αυτόματα τα endpoints που εκθέτει ο controller σας και προσαρμόζεται σε παραλλαγές JSON ανά firmware (αλλαγές ονομάτων πεδίων, μετατροπές τύπων, πολλαπλές μορφές για το integration API). Οι λογαριασμοί υποδιαχειριστών ενδέχεται να λαμβάνουν 401 από ορισμένα endpoints - αυτό είναι όριο δικαιωμάτων του controller, όχι περιορισμός της εφαρμογής.

Πώς λειτουργεί

Απευθείας στον controller σας. Χωρίς cloud relay.

Το Network Deck επικοινωνεί απευθείας με τον controller UniFi σας μέσω του τοπικού δικτύου (ή του VPN σας). Τα διαπιστευτήριά σας και τα δεδομένα του δικτύου σας δεν περνούν ποτέ από διακομιστή της MiyaraHub.

1

Προσθέστε τον Controller σας

Εισαγάγετε το hostname ή την IP του controller σας, τη θύρα (προεπιλογή 443 για UniFi OS, 8443 για αυτόνομο) και τα τοπικά διαπιστευτήρια διαχειριστή. Το Network Deck εντοπίζει αυτόματα αν χρησιμοποιείτε UniFi OS ή αυτόνομο controller.

2

Συνδεθείτε Τοπικά

Συνδεθείτε με το τοπικό όνομα χρήστη και κωδικό διαχειριστή. Ο έλεγχος ταυτότητας δύο παραγόντων υποστηρίζεται πλήρως. Προτιμάτε API keys; Χρησιμοποιήστε το X-API-KEY για προγραμματιστική πρόσβαση και παραλείψτε εντελώς τη ροή με cookie.

3

Διαχείριση με μια Ματιά

Παρακολουθήστε το ζωντανό γράφημα εύρους ζώνης, αποσυνδέστε έναν προβληματικό πελάτη, αλλάξτε έναν κανόνα firewall, επανεκκινήστε μια θύρα PoE, προσκαλέστε έναν επισκέπτη Teleport ή περάστε σε άλλο site - κάθε ενέργεια περνά από τον controller και ενημερώνει τη ζωντανή ροή συμβάντων.

Ασφάλεια & Απόρρητο

Μόνο τοπικά. Χωρίς λογαριασμό. Χωρίς ενδιάμεσο cloud.

Το Network Deck σχεδιάστηκε με αρχιτεκτονική που προτάσσει το απόρρητο και λειτουργεί μόνο τοπικά. Χωρίς λογαριασμό MiyaraHub, χωρίς cloud relay, χωρίς συλλογή δεδομένων πέρα από αναφορές σφαλμάτων.

◉

Χωρίς ενδιάμεσο cloud

Όλες οι εντολές και οι ζωντανές ροές διεξάγονται απευθείας ανάμεσα στο τηλέφωνό σας και τον controller σας μέσω του τοπικού Wi-Fi ή VPN. Τίποτα δεν δρομολογείται μέσω εξωτερικών διακομιστών.

▣

Τυπικός Έλεγχος Ταυτότητας UniFi

Χρησιμοποιεί τα ίδια τοπικά διαπιστευτήρια διαχειριστή (ή API key) με το web UI του UniFi Network. Τα διαπιστευτήρια αποθηκεύονται στο iOS Keychain / Android Keystore της συσκευής και δεν μεταδίδονται εκτός συσκευής, παρά μόνο στον controller σας.

◎

Χωρίς Λογαριασμό MiyaraHub

Χωρίς εγγραφή, χωρίς email, χωρίς λογαριασμό MiyaraHub. Εγκαταστήστε, δείξτε στην εφαρμογή τον controller σας και είστε μέσα.

◈

Ελάχιστα analytics

Το Firebase Crashlytics χρησιμοποιείται μόνο για αναφορές σφαλμάτων. Χωρίς παρακολούθηση χρήσης, χωρίς διαφημίσεις, χωρίς πώληση δεδομένων. Τα σφάλματα δικτύου καταγράφονται ως μη μοιραία για να βελτιώνουμε τη συμβατότητα με το firmware, χωρίς να συλλέγουμε τη διάταξη του δικτύου σας.

◆

Σεβασμός στα Δικαιώματα

Η εφαρμογή λειτουργεί εντός των δικαιωμάτων που έχει ο λογαριασμός διαχειριστή UniFi σας. Οι υποδιαχειριστές βλέπουν μόνο όσα τους επιτρέπει ο controller. Χωρίς κλιμάκωση προνομίων, χωρίς κερκόπορτες.

◐

Μόνο άδεια δικτύου

Η μόνη άδεια συσκευής που απαιτεί το Network Deck είναι η πρόσβαση στο δίκτυο, που χρησιμοποιείται αποκλειστικά για τη σύνδεση με τον controller UniFi σας στο τοπικό δίκτυο (ή μέσω VPN).
