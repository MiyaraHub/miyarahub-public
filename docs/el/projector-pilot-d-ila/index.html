Projector Pilot D-ILA · για προβολείς JVC D-ILAΟ D-ILA σας, στα χέρια σας.✦

Ένα χειριστήριο τοπικού δικτύου για προβολείς JVC D-ILA, από το τηλέφωνο, το tablet ή τον υπολογιστή σας.

Το Projector Pilot D-ILA μιλά απευθείας με τον προβολέα σας, στη θύρα δικτυακού ελέγχου του (TCP 20554), με τον κωδικό δικτύου που ορίσατε σε αυτόν. Τροφοδοσία, είσοδοι, πλοήγηση στο μενού, λειτουργία εικόνας, επίπεδο HDR, χρώμα, κίνηση, φακός, εγκατάσταση και λόγος διαστάσεων, με σκηνές, συντήρηση και Αυτοματισμό Σπιτιού από πάνω. Κανένας λογαριασμός και καμία υπηρεσία cloud δεν παρεμβάλλονται.

Συμβατότητα

Λειτουργεί με προβολείς JVC D-ILA με δικτυακή σύνδεση.

Η εφαρμογή γνωρίζει κάθε μοντέλο που κατονομάζουν τα έγγραφα δικτυακών εντολών της JVC, ομαδοποιημένα παρακάτω όπως τα ομαδοποιεί η βάση μοντέλων της. Τα ονόματα σε μία γραμμή αντιστοιχούν στον ίδιο προβολέα που πωλείται με διαφορετικές περιφερειακές ονομασίες.

Γενιά 2025

  • DLA-NZ900
  • DLA-NZ800

Γενιά 2024

  • DLA-NZ700 / RS2200 / N899 / N888 / N800 / Z7
  • DLA-NZ500 / RS1200 / N799 / N788 / N700 / Z5 (επαληθευμένο σε πραγματικό NZ500)

Γενιά 2021

  • DLA-NZ9 / RS4100 / N11 / V90R
  • DLA-NZ8 / RS3100 / N98 / V80R
  • DLA-NZ7 / RS2100 / N88 / V70R
  • DLA-NP5 / RS1100 / V50

Γενιά 2018

  • DLA-NX9 / RS3000 / NX11 / V9R
  • DLA-NX7 / RS2000 / N8 / V7
  • DLA-NX5 / RS1000 / N5 / N6 / V5

Παλαιότερα μοντέλα με δικτυακή σύνδεση

  • DLA-X7 / X9 / RS50 / RS60
  • DLA-X30 / RS45
  • DLA-X70R / X90R / RS55 / RS65

Δεν υποστηρίζονται: χωρίς δικτυακό έλεγχο

  • DLA-HD350, HD550, HD750, HD950, HD990
  • DLA-RS10, RS15, RS20, RS25, RS35, RS40
  • DLA-X3

Πόσο βέβαιη είναι κάθε γραμμή; Ο DLA-NZ500 έχει διαβαστεί και γραφτεί μέσω δικτύου σε πραγματικό προβολέα. Κάθε άλλο μοντέλο ακολουθεί τα δημοσιευμένα έγγραφα εντολών της ίδιας της JVC γι' αυτό. Η εφαρμογή διαβάζει το μοντέλο κατά τη σύνδεση και εμφανίζει μόνο τις εντολές του. Χρησιμοποιείτε προβολέα Epson; Το Projector Pilot PJLink & VP21 ελέγχει προβολείς Epson και διατίθεται τώρα.

Πώς λειτουργεί

Άμεση σύνδεση δικτύου. Χωρίς cloud ενδιάμεσα.

Το Projector Pilot D-ILA συνδέεται απευθείας με τον προβολέα σας στο τοπικό σας δίκτυο. Δεν υπάρχει διακομιστής MiyaraHub ούτε λογαριασμός.

1

Βρείτε τον προβολέα σας

Σαρώστε το δίκτυό σας, που δοκιμάζει τη θύρα 20554 σε κάθε διεύθυνση του υποδικτύου σας, ή προσθέστε έναν προβολέα με τη διεύθυνση IP του.

2

Συνδεθείτε με τον κωδικό του

Εισαγάγετε τον κωδικό δικτύου που ορίσατε στον προβολέα. Η εφαρμογή συνδέεται στο TCP 20554, διαβάζει το μοντέλο και φυλάσσει τον κωδικό στην ασφαλή αποθήκευση της συσκευής σας.

3

Αναλάβετε τον έλεγχο

Χρησιμοποιήστε τις οθόνες χειριστηρίου, εικόνας, φακού και ρυθμίσεων που υποστηρίζει το μοντέλο σας, αποθηκεύστε σκηνές και συνδέστε τον Αυτοματισμό Σπιτιού αν τον θέλετε.

Ασφάλεια & Απόρρητο

Πρώτα το τοπικό. Χωρίς λογαριασμό. Χωρίς διαφημίσεις.

Η εφαρμογή μιλά με τους προβολείς σας στο τοπικό σας δίκτυο και με το κατάστημα για τις αγορές εντός εφαρμογής. Τι άλλο στέλνει, και πότε, αναφέρεται εδώ.

◉

Κατευθείαν στον προβολέα

Οι εντολές και οι αναγνώσεις κατάστασης γίνονται απευθείας ανάμεσα στη συσκευή σας και στον προβολέα σας, στο τοπικό σας δίκτυο, χωρίς καμία υπηρεσία cloud ενδιάμεσα.

◎

Δεν απαιτείται λογαριασμός

Χωρίς εγγραφή και χωρίς λογαριασμό MiyaraHub. Σαρώστε ή εισαγάγετε τη διεύθυνση του προβολέα και συνδεθείτε.

▣

Αναφορές σφαλμάτων και ανάλυση χρήσης

Οι αναφορές σφαλμάτων είναι ενεργές από προεπιλογή σε Android, iPhone και iPad ώστε να διορθώνονται τα σφάλματα, και οι Ρυθμίσεις τις απενεργοποιούν. Μια αναφορά σφάλματος μπορεί να περιλαμβάνει το κείμενο του σφάλματος που σταμάτησε την εφαρμογή, το οποίο σε σπάνιες περιπτώσεις αναφέρει μια διεύθυνση δικτύου. Οι εφαρμογές macOS και Windows δεν στέλνουν καμία. Η ανώνυμη ανάλυση χρήσης είναι ανενεργή μέχρι να τη δεχτείτε και περιέχει μόνο αριθμούς και αποτελέσματα, ποτέ όνομα, διεύθυνση ή κωδικό προβολέα ούτε διεύθυνση κόμβου.

◆

Κωδικοί σε ασφαλή αποθήκευση

Ο κωδικός δικτύου κάθε προβολέα φυλάσσεται στην ασφαλή αποθήκευση της συσκευής σας. Δεν πηγαίνει πουθενά αλλού, ούτε σε αρχεία καταγραφής ή αντίγραφα ασφαλείας, παρά μόνο στο Home Assistant στο οποίο προσθέτετε τον προβολέα.

▢

Τίποτα δεν στέλνεται χωρίς Αυτοματισμό Σπιτιού

Με την αγορά του Αυτοματισμού Σπιτιού, η εφαρμογή στέλνει τα εναύσματά σας μόνο στις διευθύνσεις web που εισαγάγετε, την τροφοδοσία και την είσοδο μόνο στον κόμβο Hubitat που συνδέετε, και την κατάσταση του προβολέα στο Home Assistant στο οποίο συνδέεστε. Χωρίς αυτήν, και πάντα για τον επιδεικτικό προβολέα, τίποτα δεν στέλνεται.
