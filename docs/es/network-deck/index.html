Tu controlador UniFi, en tu bolsillo.

Compatibilidad

Funciona con tu controlador UniFi.

Network Deck es compatible tanto con consolas UniFi OS como con controladores UniFi Network independientes. Detecta automáticamente qué endpoints expone tu firmware y adapta la interfaz: las funciones que no tienes, simplemente no aparecen.

◉ Consolas UniFi OS

  • UDM Pro SE (verificada)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Controladores independientes

  • UniFi Network 10.x (verificado)
  • Autoalojado en Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Autenticación

  • Usuario y contraseña de administrador local
  • Autenticación en dos pasos (TOTP)
  • X-API-KEY para acceso programático
  • No requiere cuenta de UniFi Cloud

◆ Plataformas móviles

  • iOS 13 y posteriores
  • Android 5.0 (API 21) y posteriores
  • Diseños para teléfono y tableta
  • Temas claro y oscuro

Tolerancia al firmware: Network Deck detecta automáticamente los endpoints que expone tu controlador y se adapta a las variantes JSON propias de cada firmware (cambios en nombres de campos, conversión de tipos, múltiples formatos de la API de integración). Las cuentas de subadministrador pueden recibir un 401 en algunos endpoints: es una limitación de permisos del controlador, no de la app.

Cómo funciona

Directo a tu controlador. Sin relé en la nube.

Network Deck habla directamente con tu controlador UniFi a través de tu red local (o tu VPN). Tus credenciales y los datos de tu red nunca pasan por un servidor de MiyaraHub.

1

Añade tu controlador

Introduce el nombre de host o IP de tu controlador, el puerto (443 por defecto para UniFi OS, 8443 para independiente) y tus credenciales de administrador local. Network Deck detecta automáticamente si usas UniFi OS o un controlador independiente.

2

Autentícate localmente

Inicia sesión con tu usuario y contraseña de administrador local. La autenticación en dos pasos es compatible de principio a fin. ¿Prefieres claves API? Usa X-API-KEY para el acceso programático y olvídate por completo del flujo de cookies.

3

Gestiona de un vistazo

Mira el gráfico de ancho de banda en vivo, expulsa a un cliente problemático, activa una regla de firewall, reinicia un puerto PoE, invita a un invitado por Teleport o cambia a otro sitio: cada acción se envía al controlador y actualiza el flujo de eventos en vivo.

Seguridad & privacidad

Solo local. Sin cuenta. Sin relé en la nube.

Network Deck está diseñada con una arquitectura que prioriza la privacidad y funciona solo en local. Sin cuenta de MiyaraHub, sin relé en la nube y sin recopilación de datos más allá de los informes de fallos.

◉

Sin relé en la nube

Todos los comandos y flujos en vivo ocurren directamente entre tu teléfono y tu controlador, a través de tu Wi-Fi local o VPN. Nada pasa por servidores externos.

▣

Autenticación estándar de UniFi

Usa las mismas credenciales de administrador local (o clave API) que la interfaz web de UniFi Network. Las credenciales se guardan en el llavero de iOS / Android Keystore del dispositivo y nunca salen de él, salvo hacia tu controlador.

◎

Sin cuenta de MiyaraHub

Sin registro, sin correo electrónico, sin necesidad de cuenta de MiyaraHub. Instala, apunta a tu controlador y listo.

◈

Analíticas mínimas

Firebase Crashlytics solo para informes de errores. Sin seguimiento de uso, sin anuncios, sin venta de datos. Los errores de red se registran como no fatales para ayudarnos a mejorar la compatibilidad con el firmware, sin recopilar el diseño de tu red.

◆

Permisos respetados

La app opera dentro de los permisos que tenga tu cuenta de administrador de UniFi. Los subadministradores solo ven lo que el controlador les permite ver. Sin escalada de privilegios, sin puertas traseras.

◐

Solo permiso de red

El único permiso de dispositivo que necesita Network Deck es el acceso a la red, usado exclusivamente para conectarse a tu controlador UniFi en tu red local (o mediante VPN).

Todo lo que necesitas saber sobre Network Deck.

¿Network Deck está afiliada a Ubiquiti o UniFi? +
No. Network Deck es una aplicación independiente de terceros desarrollada por MiyaraHub Technologies LLC. No ha sido creada, respaldada ni patrocinada por Ubiquiti Inc., ni está afiliada a ella de ninguna manera. «Ubiquiti», «UniFi», «UniFi OS», «UniFi Network», «UDM», «UDR», «UCG», «Teleport» y todos los nombres de productos relacionados son marcas comerciales de Ubiquiti Inc. Usamos estos nombres únicamente para describir la compatibilidad (uso nominativo legítimo).
¿Qué controladores UniFi son compatibles? +
Network Deck es compatible tanto con las consolas UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) como con controladores UniFi Network independientes con v10.x en Linux, Docker o Windows. La app detecta tu plataforma automáticamente al conectar y adapta la interfaz a los endpoints que tu firmware realmente expone: las funciones que no tienes, simplemente no aparecen. Probada en vivo con UDM Pro SE (UniFi OS 5.0.16) y Network 10.2.105 independiente.
¿Cómo se comunica Network Deck con mi controlador? +
Network Deck usa la misma API local que la interfaz web de UniFi Network: una combinación de los endpoints clásicos /rest y /cmd (con autenticación de sesión basada en cookies) más la nueva API de integración v2. También abre un WebSocket con tu controlador para recibir eventos en vivo. Toda la comunicación ocurre directamente entre tu teléfono y tu controlador, a través de tu red local o VPN.
¿Necesito una cuenta en la nube de UniFi? +
No. Network Deck usa únicamente autenticación local. Inicia sesión con tu usuario y contraseña de administrador local de UniFi (o una clave API). Si hoy solo puedes acceder a tu controlador mediante el inicio de sesión en la nube de ui.com, tendrás que activar una cuenta de administrador local en Settings → Admins para usar Network Deck. El controlador nunca habla con nosotros, y nosotros nunca hablamos con la nube de Ubiquiti en tu nombre.
¿Puedo gestionar reglas de firewall y redirecciones de puertos? +
Sí. Network Deck incluye un firewall completo: políticas (permitir / bloquear / inspeccionar), redirecciones de puertos con CRUD, reglas y rutas de tráfico, grupos de firewall, zonas de firewall (matriz de políticas v2) y apps / grupos DPI. Todo se activa o desactiva directamente desde la vista de lista, sin tener que ir de diálogo en diálogo.
¿Admite multisitio? +
Sí. Si tu controlador gestiona varios sitios, Network Deck muestra un selector de sitio en la parte superior. Cada función (panel, clientes, firewall, VPN) se aplica al sitio seleccionado en ese momento. Cambia con un solo toque.
¿Cuánto costará Network Deck? +
Network Deck será una compra única de $4.99 en App Store, Google Play y Microsoft Store. Sin suscripción, sin anuncios, sin compras dentro de la app. El precio puede cambiar antes del lanzamiento público.
¿Puedo usarla de forma remota (fuera de casa / de la oficina)? +
Network Deck se conecta al nombre de host o IP que configures. Si tu controlador es accesible mediante VPN, Tailscale, WireGuard o un puerto redirigido, la app funcionará de forma remota. Te recomendamos usar una VPN o Tailscale en lugar de exponer tu controlador UniFi directamente a internet.
¿Qué plataformas son compatibles? +
Network Deck funciona tanto en iOS (13 y posteriores) como en Android (5.0 / API 21 y posteriores). Admite diseños tanto para teléfono como para tableta. La app se lanzará de forma simultánea en App Store, Google Play y Microsoft Store.
