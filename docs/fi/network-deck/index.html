Ominaisuudet

UniFi-kontrollerisi taskussasi.

Network Deck keskustelee suoraan UniFi-kontrollerisi paikallisen API:n kanssa - olipa kyseessä UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) tai itsenäinen UniFi Network -kontrolleri. Asiakkaat, WiFi, palomuuri, portit, VPN ja analytiikka ilman selaimen avaamista.

◉ Reaaliaikainen kojelauta

Internet-yhteyden terveys, reaaliaikainen kaistanleveyskaavio 60 näytteen liukuvalla ikkunalla ja muokattavat kortit - järjestelmätiedot, DPI-liikenne, hälytykset, tapahtumat, aktiivisimmat asiakkaat, nopeustestihistoria ja pikakuvakkeet. Välilehtinäkymä, jonka järjestyksen voit muuttaa.

Yhteensopivuus

Toimii UniFi-kontrollerisi kanssa.

Network Deck tukee sekä UniFi OS -konsoleita että itsenäisiä UniFi Network -kontrollereita. Se tunnistaa automaattisesti, mitä rajapintoja laiteohjelmistosi tarjoaa, ja mukauttaa käyttöliittymän sen mukaan - ominaisuudet, joita sinulla ei ole, eivät yksinkertaisesti näy.

◉ UniFi OS -konsolit

  • UDM Pro SE (varmennettu)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Itsenäiset kontrollerit

  • UniFi Network 10.x (varmennettu)
  • Itse ylläpidetty Linuxissa / Dockerissa
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Tunnistautuminen

  • Paikallinen ylläpitäjän käyttäjätunnus + salasana
  • Kaksivaiheinen tunnistautuminen (TOTP)
  • X-API-KEY ohjelmalliseen käyttöön
  • UniFi-pilvitiliä ei vaadita

◆ Mobiilialustat

  • iOS 13 ja uudemmat
  • Android 5.0 (API 21) ja uudemmat
  • Puhelin- ja tablettinäkymät
  • Vaaleat ja tummat teemat

Laiteohjelmiston joustavuus: Network Deck tunnistaa automaattisesti kontrollerisi tarjoamat rajapinnat ja mukautuu laiteohjelmistokohtaisiin JSON-muunnelmiin (kenttänimien vaihtelu, tyyppimuunnokset, integraatio-API:n useat rakenteet). Alaylläpitäjien tilit saattavat saada joistakin rajapinnoista 401-vastauksen - kyse on kontrollerin käyttöoikeusrajoituksesta, ei sovelluksen puutteesta.

Näin se toimii

Suoraan kontrolleriisi. Ei pilvivälitystä.

Network Deck keskustelee suoraan UniFi-kontrollerisi kanssa paikallisverkossasi (tai VPN:n kautta). Tunnuksesi ja verkkotietosi eivät koskaan kulje MiyaraHubin palvelimien kautta.

1

Lisää kontrollerisi

Anna kontrollerisi isäntänimi tai IP-osoite, portti (oletus 443 UniFi OS:lle, 8443 itsenäiselle) ja paikalliset ylläpitäjän tunnuksesi. Network Deck tunnistaa automaattisesti, käytätkö UniFi OS:ää vai itsenäistä kontrolleria.

2

Tunnistaudu paikallisesti

Kirjaudu sisään paikallisella ylläpitäjän käyttäjätunnuksella ja salasanalla. Kaksivaiheinen tunnistautuminen on tuettu kauttaaltaan. Haluatko mieluummin API-avaimet? Käytä X-API-KEY -avainta ohjelmalliseen käyttöön ja ohita evästepohjainen kirjautuminen kokonaan.

3

Hallitse yhdellä silmäyksellä

Seuraa reaaliaikaista kaistanleveyskaaviota, potkaise häiriköivä asiakas pois, kytke palomuurisääntö, käynnistä PoE-portti uudelleen, kutsu Teleport-vieras tai vaihda toiselle sivustolle - jokainen toiminto kulkee kontrollerin kautta ja päivittyy reaaliaikaiseen tapahtumavirtaan.

Turvallisuus & tietosuoja

Vain paikallisesti. Ei tiliä. Ei pilvivälitystä.

Network Deck on suunniteltu yksityisyys edellä ja vain paikallisella arkkitehtuurilla. Ei MiyaraHub-tiliä, ei pilvivälitystä, ei tiedonkeruuta kaatumisraportointia lukuun ottamatta.

◉

Ei pilvivälitystä

Kaikki komennot ja reaaliaikaiset virrat kulkevat suoraan puhelimesi ja kontrollerisi välillä paikallisen Wi-Fi-verkon tai VPN:n kautta. Mitään ei reititetä ulkoisten palvelimien kautta.

▣

Tavallinen UniFi-tunnistautuminen

Käyttää samoja paikallisia ylläpitäjän tunnuksia (tai API-avainta) kuin UniFi Networkin verkkokäyttöliittymä. Tunnukset tallennetaan laitteen iOS Keychainiin / Android Keystoreen, eikä niitä koskaan lähetetä laitteelta muualle kuin kontrolleriisi.

◎

Ei MiyaraHub-tiliä

Ei rekisteröitymistä, ei sähköpostia, ei MiyaraHub-tiliä. Asenna, osoita sovellus kontrolleriisi, ja olet sisällä.

◈

Minimaalinen analytiikka

Firebase Crashlytics vain virheraportteja varten. Ei käytön seurantaa, ei mainoksia, ei tietojen myyntiä. Verkkovirheet kirjataan ei-vakavina, jotta voimme parantaa laiteohjelmistoyhteensopivuutta keräämättä verkkosi rakennetta.

◆

Käyttöoikeuksia kunnioitetaan

Sovellus toimii UniFi-ylläpitäjätilisi käyttöoikeuksien rajoissa. Alaylläpitäjät näkevät vain sen, minkä kontrolleri sallii. Ei oikeuksien laajentamista, ei takaovea.

◐

Vain verkkokäyttöoikeus

Ainoa laiteoikeus, jota Network Deck tarvitsee, on verkkoyhteys, jota käytetään yksinomaan UniFi-kontrolleriisi yhdistämiseen paikallisverkossa (tai VPN:n kautta).

Mitä UniFi-kontrollereita tuetaan? +
Network Deck tukee sekä UniFi OS -konsoleita (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) että itsenäisiä UniFi Network -kontrollereita, jotka toimivat v10.x:llä Linuxissa, Dockerissa tai Windowsissa. Sovellus tunnistaa alustasi automaattisesti yhdistettäessä ja mukauttaa käyttöliittymän niihin rajapintoihin, joita laiteohjelmistosi todella tarjoaa - ominaisuudet, joita sinulla ei ole, eivät yksinkertaisesti näy. Testattu livenä UDM Pro SE:llä (UniFi OS 5.0.16) ja itsenäisellä Network 10.2.105:llä.
Miten Network Deck keskustelee kontrollerini kanssa? +
Network Deck käyttää samaa paikallista API:a kuin UniFi Networkin verkkokäyttöliittymä - yhdistelmää perinteisistä /rest- ja /cmd-päätepisteistä (evästepohjaisella istuntotunnistautumisella) sekä uudemmasta v2-integraatio-API:sta. Se avaa myös WebSocket-yhteyden kontrolleriisi reaaliaikaisten tapahtumien suoratoistoa varten. Kaikki liikenne kulkee suoraan puhelimesi ja kontrollerisi välillä paikallisverkossa tai VPN:n kautta.
Tarvitsenko UniFi-pilvitilin? +
Ei. Network Deck käyttää vain paikallista tunnistautumista. Kirjaudu sisään UniFin paikallisella ylläpitäjän käyttäjätunnuksella ja salasanalla (tai API-avaimella). Jos kontrolleriisi pääsee tällä hetkellä vain ui.com-pilvikirjautumisella, ota Network Deckin käyttöä varten käyttöön paikallinen ylläpitäjätili kohdassa Settings → Admins. Kontrolleri ei koskaan keskustele kanssamme, emmekä me koskaan keskustele Ubiquitin pilven kanssa puolestasi.
Voinko hallita palomuurisääntöjä ja porttiohjauksia? +
Kyllä. Network Deckissä on täysi palomuuripaketti: käytännöt (salli / estä / tarkasta), porttiohjaukset täydellä CRUD-hallinnalla, liikennesäännöt ja reitit, palomuuriryhmät, palomuurivyöhykkeet (v2-käytäntömatriisi) sekä DPI-sovellukset ja -ryhmät. Kaikki kytketään päälle ja pois suoraan listanäkymästä - ei dialogi-napautus-dialogi-säätöä.
Tukeeko se usean sivuston hallintaa? +
Kyllä. Jos kontrolleri hallitsee useita sivustoja, Network Deck näyttää sivustonvaihtajan ylhäällä. Jokainen ominaisuus - kojelauta, asiakkaat, palomuuri, VPN - rajautuu parhaillaan valittuun sivustoon. Vaihto onnistuu yhdellä napautuksella.
Paljonko Network Deck tulee maksamaan? +
Network Deck on kertaostos hintaan 4,99 $ App Storessa, Google Playssa ja Microsoft Storessa. Ei tilausta, ei mainoksia, ei sovelluksen sisäisiä ostoksia. Hinta voi muuttua ennen julkista julkaisua.
Voinko käyttää sitä etänä (kodin / toimiston ulkopuolelta)? +
Network Deck yhdistää mihin tahansa isäntänimeen tai IP-osoitteeseen, jonka määrität. Jos kontrolleriisi pääsee VPN:n, Tailscalen, WireGuardin tai edelleenohjatun portin kautta, sovellus toimii etänä. Suosittelemme käyttämään VPN:ää tai Tailscalea sen sijaan, että UniFi-kontrolleri avattaisiin suoraan internetiin.
Mitä alustoja tuetaan? +
Network Deck toimii sekä iOS:llä (13 ja uudemmat) että Androidilla (5.0 / API 21 ja uudemmat). Sekä puhelin- että tablettinäkymät on tuettu. Sovellus julkaistaan samanaikaisesti App Storessa, Google Playssa ja Microsoft Storessa.
