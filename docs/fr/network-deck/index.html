Fonctionnalités

Votre contrôleur UniFi, dans votre poche.

Network Deck dialogue directement avec l'API locale de votre contrôleur UniFi, qu'il s'agisse d'UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) ou d'un contrôleur UniFi Network autonome. Clients, WiFi, pare-feu, ports, VPN et statistiques, sans ouvrir de navigateur.

Une disposition par onglets que vous pouvez réorganiser.

Compatibilité

Compatible avec votre contrôleur UniFi.

Network Deck prend en charge aussi bien les consoles UniFi OS que les contrôleurs UniFi Network autonomes. Il détecte automatiquement les points d'accès exposés par votre firmware et adapte l'UI en conséquence : les fonctions que vous n'avez pas n'apparaissent tout simplement pas.

◉ Consoles UniFi OS

  • UDM Pro SE (vérifié)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Contrôleurs autonomes

  • UniFi Network 10.x (vérifié)
  • Auto-hébergé sous Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Authentification

  • Nom d'utilisateur + mot de passe d'administrateur local
  • Authentification à deux facteurs (TOTP)
  • X-API-KEY pour l'accès programmatique
  • Aucun compte cloud UniFi requis

◆ Plateformes mobiles

  • iOS 13 et versions ultérieures
  • Android 5.0 (API 21) et versions ultérieures
  • Mises en page téléphone et tablette
  • Thèmes clair et sombre

Tolérance aux firmwares : Network Deck détecte automatiquement les points d'accès exposés par votre contrôleur et s'adapte aux variantes JSON propres à chaque firmware (noms de champs qui changent, conversion de types, formes multiples de l'API d'intégration). Les comptes sous-administrateurs peuvent voir certains points d'accès renvoyer une erreur 401 : il s'agit d'une limite de permissions du contrôleur, pas de l'application.

Comment ça marche

En direct avec votre contrôleur. Sans relais cloud.

Network Deck dialogue directement avec votre contrôleur UniFi via votre réseau local (ou votre VPN). Vos identifiants et vos données réseau ne transitent jamais par un serveur MiyaraHub.

1

Ajoutez votre contrôleur

Saisissez le nom d'hôte ou l'IP de votre contrôleur, le port (443 par défaut pour UniFi OS, 8443 pour un contrôleur autonome) et vos identifiants d'administrateur local. Network Deck détecte automatiquement si vous utilisez UniFi OS ou un contrôleur autonome.

2

Authentifiez-vous en local

Connectez-vous avec votre nom d'utilisateur et votre mot de passe d'administrateur local. L'authentification à deux facteurs est prise en charge de bout en bout. Vous préférez les clés API ? Utilisez X-API-KEY pour l'accès programmatique et évitez complètement le flux par cookie.

3

Gérez d'un coup d'œil

Suivez le graphique de bande passante en direct, déconnectez un client récalcitrant, activez une règle de pare-feu, redémarrez un port PoE, invitez un invité Teleport ou passez à un autre site : chaque action est transmise au contrôleur et mise à jour dans le flux d'événements en direct.

Sécurité & confidentialité

Local uniquement. Sans compte. Sans relais cloud.

Network Deck repose sur une architecture locale qui place la confidentialité en premier. Pas de compte MiyaraHub, pas de relais cloud, aucune collecte de données hormis les rapports de plantage.

◉

Aucun relais cloud

Toutes les commandes et tous les flux en direct passent directement entre votre téléphone et votre contrôleur, via votre WiFi local ou votre VPN. Rien n'est acheminé par des serveurs externes.

▣

Authentification UniFi standard

Utilise les mêmes identifiants d'administrateur local (ou la même clé API) que l'UI web d'UniFi Network. Les identifiants sont stockés dans le Keychain iOS / Keystore Android de l'appareil et ne quittent jamais l'appareil, sauf pour être envoyés à votre contrôleur.

◎

Aucun compte MiyaraHub

Pas d'inscription, pas d'e-mail, pas de compte MiyaraHub. Installez l'application, indiquez votre contrôleur, et c'est parti.

◈

Statistiques minimales

Firebase Crashlytics uniquement pour les rapports de bugs. Aucun suivi d'utilisation, aucune publicité, aucune revente de données. Les erreurs réseau sont consignées comme non fatales pour nous aider à améliorer la compatibilité avec les firmwares, sans collecter l'architecture de votre réseau.

◆

Permissions respectées

L'application fonctionne dans la limite des permissions de votre compte administrateur UniFi. Les sous-administrateurs ne voient que ce que le contrôleur leur permet de voir. Aucune élévation de privilèges, aucune porte dérobée.

◐

Autorisation réseau uniquement

La seule autorisation d'appareil requise par Network Deck est l'accès au réseau, utilisé uniquement pour se connecter à votre contrôleur UniFi sur votre réseau local (ou via un VPN).

FAQ

Questions fréquentes.

Tout ce qu'il faut savoir sur Network Deck.

Network Deck est-il affilié à Ubiquiti ou à UniFi ? +
Non. Network Deck est une application tierce indépendante, développée par MiyaraHub Technologies LLC. Elle n'est ni créée, ni approuvée, ni sponsorisée par Ubiquiti Inc., et n'y est affiliée d'aucune manière. « Ubiquiti », « UniFi », « UniFi OS », « UniFi Network », « UDM », « UDR », « UCG », « Teleport » et tous les noms de produits associés sont des marques commerciales d'Ubiquiti Inc. Nous utilisons ces noms uniquement pour décrire la compatibilité (usage nominatif).
Quels contrôleurs UniFi sont pris en charge ? +
Network Deck prend en charge les consoles UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) ainsi que les contrôleurs UniFi Network autonomes en version v10.x sous Linux, Docker ou Windows. L'application détecte automatiquement votre plateforme à la connexion et adapte l'UI aux points d'accès réellement exposés par votre firmware : les fonctions que vous n'avez pas n'apparaissent tout simplement pas. Testé en conditions réelles sur un UDM Pro SE (UniFi OS 5.0.16) et sur UniFi Network 10.2.105 autonome.
Comment Network Deck communique-t-il avec mon contrôleur ? +
Network Deck utilise la même API locale que l'UI web d'UniFi Network : les points d'accès classiques /rest et /cmd (avec authentification par session et cookie), ainsi que la nouvelle API d'intégration v2. Il ouvre aussi un WebSocket vers votre contrôleur pour diffuser les événements en direct. Toute la communication passe directement entre votre téléphone et votre contrôleur, via votre réseau local ou votre VPN.
Ai-je besoin d'un compte cloud UniFi ? +
Non. Network Deck utilise uniquement l'authentification locale. Connectez-vous avec votre nom d'utilisateur et votre mot de passe d'administrateur local UniFi (ou une clé API). Si votre contrôleur n'est aujourd'hui accessible que via la connexion cloud ui.com, il faudra activer un compte administrateur local dans Settings → Admins pour utiliser Network Deck. Le contrôleur ne communique jamais avec nous, et nous ne communiquons jamais avec le cloud d'Ubiquiti en votre nom.
Puis-je gérer les règles de pare-feu et les redirections de ports ? +
Oui. Network Deck propose une pile pare-feu complète : politiques (autoriser / bloquer / inspecter), redirections de ports avec CRUD, règles et routes de trafic, groupes de pare-feu, zones de pare-feu (matrice de politiques v2) et applications / groupes DPI. Tout s'active ou se désactive directement depuis la liste, sans enchaîner les boîtes de dialogue.
Le multi-sites est-il pris en charge ? +
Oui. Si votre contrôleur gère plusieurs sites, Network Deck affiche un sélecteur de site en haut de l'écran. Chaque fonction (tableau de bord, clients, pare-feu, VPN) s'applique au site actuellement sélectionné. Changez de site d'une simple pression.
Combien coûtera Network Deck ? +
Network Deck sera proposé en achat unique à $4.99 sur l'App Store, Google Play et le Microsoft Store. Sans abonnement, sans publicité, sans achats intégrés. Le prix peut évoluer avant le lancement public.
Puis-je l'utiliser à distance (hors de chez moi / du bureau) ? +
Network Deck se connecte au nom d'hôte ou à l'IP que vous configurez. Si votre contrôleur est accessible via un VPN, Tailscale, WireGuard ou un port redirigé, l'application fonctionne à distance. Nous vous recommandons d'utiliser un VPN ou Tailscale plutôt que d'exposer directement votre contrôleur UniFi à Internet.
Quelles plateformes sont prises en charge ? +
Network Deck fonctionne à la fois sur iOS (13 et versions ultérieures) et sur Android (5.0 / API 21 et versions ultérieures). Les mises en page pour téléphone et pour tablette sont toutes deux prises en charge. L'application sortira simultanément sur l'App Store, Google Play et le Microsoft Store.
