Politique de confidentialité

Date d'entrée en vigueur : 15 novembre 2026. Version 3.0.

Cette politique indique quelles données personnelles MiyaraHub Technologies LLC traite, pourquoi, qui les reçoit, combien de temps elles sont conservées et ce que vous pouvez nous demander de faire. Si cette page et le texte d'une application diffèrent, écrivez-nous et nous corrigerons celui qui est erroné.

  • La boutique Elan Audio Lab gère des comptes clients, des commandes et des paiements. Elle est décrite dans son propre bloc de l'Annexe A et à la section 14.

4. Les données que nous traitons, par source

4.1 E-mails que vous nous envoyez

Lorsque vous nous écrivez, nous recevons votre adresse e-mail, votre nom si vous l'indiquez, votre message et les éventuelles pièces jointes. Nous les utilisons pour vous répondre.

4.2 Rapports de diagnostic que vous choisissez d'envoyer

De nombreuses applications ont un bouton qui prépare un e-mail ou un fichier de diagnostic. Il ouvre votre propre application de messagerie ou la feuille de partage, et rien n'est envoyé tant que vous n'appuyez pas sur envoyer. Selon l'application, le rapport peut contenir le modèle de votre appareil et la version du système, les réglages de l'application, des journaux, ainsi que les adresses réseau, les adresses matérielles (MAC), les noms d'hôte, les noms de modèle et les numéros de série des appareils que vous contrôlez. Certaines applications en suppriment une partie au préalable ; beaucoup ne le font pas. L'Annexe A indique ce que chaque application inclut. Relisez le rapport avant de l'envoyer et retirez tout ce que vous ne souhaitez pas partager.

4.3 Rapports de plantage (Firebase Crashlytics)

Lorsqu'une application plante ou rencontre une erreur grave, Crashlytics envoie à Google un rapport contenant l'erreur et l'emplacement dans le code, la version de l'application, le modèle de l'appareil, la version du système, la mémoire et le stockage disponibles, un identifiant d'installation Crashlytics aléatoire et un identifiant d'installation Firebase. Google reçoit votre adresse IP lors de l'envoi du rapport. Dans de nombreuses applications, le texte de l'erreur peut contenir l'adresse réseau ou le nom d'un appareil que vous contrôlez. L'Annexe A indique, pour chaque application, si les rapports de plantage sont activés par défaut, où se trouve le commutateur et ce qui est supprimé avant l'envoi.

4.4 Statistiques d'utilisation (Firebase Analytics)

Dans les applications où il est actif, Firebase Analytics envoie à Google des événements tels que la première ouverture, le début de session, les affichages d'écran, les achats intégrés et les événements d'application que liste l'Annexe A. Chaque événement comporte un identifiant d'instance d'application aléatoire, un identifiant d'installation Firebase, le modèle de l'appareil, la version du système, la langue, la version de l'application et une position approximative (pays ou région) que Google déduit de votre adresse IP. Sur iOS, il peut aussi utiliser l'identifiant de fournisseur. Dans les applications où l'Annexe A le précise, il collecte également l'identifiant publicitaire Android. Nous utilisons les statistiques pour voir quelles fonctions sont utilisées et où les applications échouent. Nous ne les utilisons pas pour afficher des publicités.

4.5 Rapports d'achats et de boutiques

Lorsque vous achetez une application ou une mise à niveau intégrée, Apple, Google ou Microsoft traite le paiement. Ils nous envoient des rapports de ventes avec les dates, les pays, les produits, les prix et les numéros de commande. Nous ne recevons pas vos données de carte. Les applications conservent un enregistrement de votre achat sur votre appareil afin de débloquer des fonctions ; l'Annexe A indique où.

4.6 La boutique Elan Audio Lab

La boutique gère les comptes, les commandes, les paiements, les adresses de livraison, les avis, les inscriptions à la newsletter, les formulaires de contact, les demandes de devis, les enregistrements de garantie, les concours et les candidatures d'artistes. Voir la section 14 et le bloc Elan Audio Lab de l'Annexe A.

4.7 Ce site web

GitHub Pages héberge miyarahub.com. GitHub reçoit votre adresse IP et les informations de votre navigateur lorsque vous chargez une page, et conserve des journaux pour des raisons de sécurité. Certaines pages chargent des polices depuis Google Fonts ; Google reçoit donc votre adresse IP et les informations de votre navigateur. Nos pages ne déposent aucun cookie et n'exécutent aucune statistique. Si vous choisissez une langue, votre choix est enregistré dans le stockage local de votre navigateur sous la clé « lang » et ne nous est jamais envoyé.

4.8 Données qui restent sur votre appareil

Les adresses d'appareils, les réglages, les mots de passe et les jetons que vous saisissez sont stockés sur votre appareil. Nous ne les recevons pas, sauf si vous nous les envoyez dans un rapport de diagnostic. La sauvegarde propre à votre appareil (iCloud, Google ou un autre outil de sauvegarde) peut les copier ; l'Annexe A indique quelles applications excluent quoi de la sauvegarde.
