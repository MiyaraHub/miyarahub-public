השיטה

הכול במכשיר שלכם, כלום בענן

Almanox מריץ מנוע אסטרונומיה מלא מקומית. בלי חשבון, בלי הרשמה, והוא עובד גם כשהקליטה כבויה - השמיים זהים בין אם יש לכם קווי קליטה ובין אם לא.

1

בחרו את המקום

השתמשו במיקום הנוכחי שלכם או שמרו את המקומות שבהם אתם מצלמים. Almanox מחשב את השמש, הירח והשמיים בדיוק למקום שבו אתם עומדים.

2

קראו את פסק הדין

ציון אחד עונה על השאלה היחידה שחשובה - האם הלילה שווה את זה? ראו את חלון שמי החושך הטוב ביותר, את ליבת שביל החלב ועד כמה הירח מפריע.

3

תכננו את הצילום

מצאו את הימים המדויקים שבהם השמש או הירח המלא מסתדרים עם הכיוון שלכם, תפסו את השעה הזהובה וקבלו התראה לפני שהשמיים מוכנים.
