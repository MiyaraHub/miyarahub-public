מיקומים שמורים

כל מספר ב-Almanox - אירועי השמש, פסק הדין, ליבת שביל החלב, זמני הירח - מחושב לנקודה אחת על פני כדור הארץ. במסך המיקומים בוחרים את הנקודה הזו: ה-GPS שלכם, עיר לפי שם או קואורדינטות מדויקות, שמורים כדי שתוכלו לעבור בין המקומות שבהם אתם באמת מצלמים.

איך מגיעים

למה מחושבים השמיים

פותחים את המיקומים בנגיעה בשם המקום בראש מסך היום או הלילה.

שם המיקום נמצא בראש שני המסכים, היום והלילה. נוגעים בו ונפתח מסך המיקומים, עם רשימת כל המקומות ששמרתם והפעיל מסומן. המעבר הוא נגיעה אחת - בוחרים אריח וכל האפליקציה מחושבת מחדש לאותו מקום, ו-Almanox זוכר את הבחירה לפעם הבאה.

יש שלוש דרכים להגדיר עבור איזה מקום אתם מתכננים:

  • שימוש במיקום הנוכחי - מבקש שוב את מיקום ה-GPS שלכם. בזמן העבודה מוצג דיאלוג ״מאתר את המיקום שלכם״. אם לא מתקבל קיבוע - ההרשאה נדחתה, שירותי המיקום כבויים או כל שגיאה אחרת - Almanox מודיע שהמיקום אינו זמין וחוזר למיקום ברירת המחדל המובנה בניו יורק במקום להציג לכם כלום.
  • חיפוש עיר - מקלידים שם מקום ומחפשים; התאמות קרובות מוצגות עם הקואורדינטות שלהן, ונגיעה באחת שומרת אותה. הוא לוקח את השם שהקלדתם, או את הקואורדינטות שלו אם השארתם את התיבה ריקה.
  • קואורדינטות - מקלידים קו רוחב וקו אורך ישירות, עם אימות לטווחים האמיתיים (-90 עד 90, -180 עד 180), ועם שם מותאם אופציונלי. משאירים את השם ריק ו-Almanox הופך את הקואורדינטות לשם מקום עבורכם.

סדר וניקיון

מעבר, מחיקה וברירת המחדל

הרשימה שלכם לעריכה כרצונכם - עם מעקה בטיחות אחד כדי שלא תישארו לעולם בלי מקום.

  • מעבר - נוגעים בכל אריח שמור כדי להפוך אותו לפעיל. המקום הפעיל מניע כל מסך עד שתשנו אותו.
  • מחיקה - מחליקים אריח שמאלה כדי להסיר אותו. אי אפשר למחוק את המיקום היחיד שנותר; תמיד חייב להיות לפחות אחד, כדי שלאפליקציה לא יישאר מקום לחשב עבורו.
  • התווית DEFAULT - מסמנת את ברירת המחדל המובנית בניו יורק כשהיא אחת מהרשומות השמורות שלכם, כך שתמיד ברור איזו מהן היא רשת הביטחון.

הגרסה החינמית כוללת שלושה מיקומים שמורים, מספיק לבית, לאתר חושך קרוב ולמקום נסיעה. Pro מסיר את המגבלה, למי שמתכנן בהרבה מקומות.

חיפוש עיר והמרת קואורדינטות לשם דורשים חיבור; אחרי ששומרים מקום, כל מדידות השמש, הירח ומפת הכוכבים שלו מחושבות במכשיר גם בלי קליטה.
