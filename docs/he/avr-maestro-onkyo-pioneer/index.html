ללא חשבון וללא פרסומות. AVR Maestro מתקשרת עם המקלט שלכם ישירות דרך הרשת המקומית שלכם, ללא שירות ענן באמצע. דוחות קריסה וסטטיסטיקות שימוש נשלחים אל Firebase, מקושרים למזהה אקראי ולא לשמכם, כדי לעזור לתקן באגים ולשפר את האפליקציה.
