ראו כל מסך.

תכונות

בקר ה-UniFi שלכם, בכיס.

Network Deck מדברת ישירות עם ה-API המקומי של בקר ה-UniFi שלכם - בין אם זו קונסולת UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) ובין אם בקר UniFi Network עצמאי. לקוחות, Wi-Fi, חומת אש, יציאות, VPN ותובנות, בלי לפתוח דפדפן.

◉ לוח מחוונים חי

מצב ה-ISP, גרף רוחב פס בזמן אמת עם חלון נע של 60 דגימות, וכרטיסים להתאמה אישית - מידע על המערכת, תעבורת DPI, התראות, אירועים, לקוחות מובילים, היסטוריית בדיקות מהירות וקיצורי דרך. פריסה בלשוניות שאפשר לסדר מחדש.

איך זה עובד

ישירות אל הבקר שלכם. בלי ממסר ענן.

Network Deck מדברת ישירות עם בקר ה-UniFi שלכם דרך הרשת המקומית (או ה-VPN). פרטי הכניסה ונתוני הרשת שלכם לא נוגעים אף פעם בשרת של MiyaraHub.

1

הוסיפו את הבקר שלכם

הזינו את שם המארח או כתובת ה-IP של הבקר, את היציאה (ברירת מחדל 443 ל-UniFi OS, 8443 לבקר עצמאי) ואת פרטי המנהל המקומי שלכם. Network Deck מזהה אוטומטית אם אתם על UniFi OS או על בקר עצמאי.

2

התחברו מקומית

התחברו עם שם המשתמש והסיסמה של המנהל המקומי. אימות דו-שלבי נתמך מקצה לקצה. מעדיפים מפתחות API? השתמשו ב-X-API-KEY לגישה תכנותית ודלגו לגמרי על זרימת העוגיות.

3

ניהול במבט אחד

צפו בגרף רוחב הפס החי, נתקו לקוח שמתנהג לא יפה, הפעילו או כבו חוק בחומת האש, אתחלו יציאת PoE, הזמינו אורח דרך Teleport או עברו לאתר אחר - כל פעולה עוברת אל הבקר ומתעדכנת בזרם האירועים החי.

האם אני צריך חשבון ענן של UniFi? +
לא.
