איך זה עובד

חיבור רשת ישיר. בלי צורך בענן.

Projector Pilot מתקשרת ישירות עם המקרן שלכם דרך Wi-Fi באמצעות פרוטוקולי רשת סטנדרטיים. הנתונים שלכם לא נוגעים אף פעם בשרת חיצוני.

1

הוספת המקרן

הזינו את כתובת ה-IP של מקרן ה-Epson שלכם. Projector Pilot בודקת קישוריות PJLink ו-Web Control, מזהה את הדגם ומגלה אוטומטית את כל התכונות הזמינות.

2

התחברו דרך Wi-Fi

Projector Pilot משתמשת ב-PJLink לזיהוי מצב המתנה ולשליטה בהפעלה, ובנוסף ב-Epson Web Control API לשליטה מלאה בתמונה, בעדשה ובהגדרות כשהמקרן דלוק. הכול נשאר ברשת המקומית שלכם.

3

קחו שליטה מלאה

כווננו הגדרות תמונה, החליפו כניסות, שלטו בעדשה המנועית, נהלו תיקון keystone, עקבו אחר שעות המנורה ונווטו ב-OSD - הכול מאפליקציה אחת ואלגנטית.

אבטחה & פרטיות

מקומי בלבד. בלי חשבון. בלי ענן.

Projector Pilot תוכננה עם ארכיטקטורה שמעמידה את הפרטיות במרכז ופועלת באופן מקומי בלבד. בלי תלות בענן, בלי חשבון משתמש, ובלי איסוף נתונים מעבר לדיווחי קריסה.

◉

בלי ממסר ענן

כל הפקודות ובדיקות המצב מתבצעות ישירות בין הטלפון למקרן דרך ה-Wi-Fi המקומי שלכם. שום דבר לא יוצא מהרשת שלכם.

◎

לא נדרש חשבון

בלי הרשמה, בלי אימייל, בלי חשבון MiyaraHub. פותחים את האפליקציה, מזינים את כתובת ה-IP של המקרן, ואתם בשליטה.

▣

ניתוח מינימלי

Firebase Crashlytics לדיווחי באגים בלבד. בלי נתונים אישיים, בלי מעקב שימוש, בלי פרסומות. נתוני המקרן שלכם לא עוזבים את הטלפון.

◆

אחסון מקומי בלבד

כתובות IP של מקרנים, פרטי הזדהות והעדפות האפליקציה נשמרים מקומית על ההתקן באמצעות SharedPreferences. שום דבר לא מסונכרן לשרת.

▢

פעולות ביוזמת המשתמש בלבד

האפליקציה שולחת פקודות למקרן רק בעקבות פעולה מפורשת שלכם. שום דבר לא קורה אוטומטית או ברקע בלי ידיעתכם.

☼

הרשאת רשת בלבד

ההרשאה היחידה ש-Projector Pilot דורשת מההתקן היא גישה לאינטרנט / לרשת, והיא משמשת אך ורק להתחברות למקרן שלכם ב-Wi-Fi המקומי.

שאלות נפוצות.

כל מה שצריך לדעת על Projector Pilot.

האם Projector Pilot קשורה ל-Epson? +
לא. Projector Pilot היא אפליקציה עצמאית של צד שלישי שפותחה על ידי MiyaraHub Technologies LLC. היא אינה נוצרת, מאושרת, ממומנת או קשורה ל-Seiko Epson Corporation או לאף אחת מחברות הבת או החברות הקשורות שלה בשום צורה. “Epson” הוא סימן מסחרי רשום של Seiko Epson Corporation. אנו משתמשים בשם אך ורק כדי לתאר תאימות (שימוש הוגן שמי).
אילו מקרנים נתמכים? +
Projector Pilot עובדת עם כל מקרני Epson המחוברים לרשת שתומכים ב-PJLink ו/או ב-Web Control. זה כולל את רוב הדגמים מ-10 השנים האחרונות ויותר - מדגמי הדגל QB1000 ו-LS12000 ועד דגמי Home Cinema בטווח הביניים ודגמי התקנה מקצועיים. האפליקציה מזהה אוטומטית את התכונות הזמינות בעת ההתחברות, כך שכל משתמש רואה בדיוק את מה שהמקרן שלו תומך בו. שליטה בסיסית ב-PJLink עובדת גם עם מקרנים שאינם של Epson מבית NEC, Panasonic, Sony ואחרים.
איך Projector Pilot מתקשרת עם המקרן שלי? +
Projector Pilot משתמשת בשני פרוטוקולים: PJLink (יציאה 4352) לשליטה אוניברסלית במקרן, כולל הדלקה ממצב המתנה, החלפת כניסות ומצב מנורה; ו-Epson Web Control API (יציאה 80) עם אימות Digest לשליטה עשירה בהגדרות, כולל תמונה, עדשה, keystone, HDR ועוד. כל התקשורת מתבצעת ישירות ברשת ה-Wi-Fi המקומית שלכם.
האם אפשר לשלוט בעדשה המנועית? +
כן, במקרנים עם מערכות עדשה מנועיות. Projector Pilot מספקת שליטה מלאה בהזזת עדשה (אופקית ואנכית), בפוקוס ובזום, עם משוב מיקום בזמן אמת. אפשר גם לשמור ולהחזיר פריסטים של זיכרון עדשה ליחסי תצוגה, מיקומי מסך או הגדרות צפייה שונים. פקדי העדשה מוסתרים אוטומטית בדגמים ללא עדשה מנועית.
האם יש תמיכה ב-HDR ובטווח צבעים רחב? +
כן. Projector Pilot מאפשרת לשלוט בהגדרות הטווח הדינמי (Auto, HDR10, HLG, SDR) ובמרחב הצבע (Auto, BT.709, BT.2020), ומספקת כוונון gain ו-offset לכל ערוץ RGB לכיול צבע מדויק. תכונות HDR מוצגות רק בדגמים שתומכים בהן.
האם אפשר להדליק את המקרן ממצב המתנה? +
כן. Projector Pilot משתמשת ב-PJLink כדי להדליק את המקרן גם כשהוא במצב המתנה. כל עוד המקרן מחובר לרשת (מומלץ LAN קווי להדלקה ממצב המתנה), אפשר להדליק ולכבות אותו מהטלפון.
כמה עולה Projector Pilot? +
Projector Pilot להורדה חינם, כולל שליטה בסיסית. Pro הוא שדרוג חד-פעמי ב-$9.99, Home Automation עולה $2.99, או שניהם יחד בחבילה ב-$11.99. בלי מנוי, בלי פרסומות. קונים פעם אחת והיא שלכם. המחיר עשוי להשתנות לפני ההשקה.
איזו גרסת Android נדרשת? +
Projector Pilot דורשת Android 5.0 (API 21) ומעלה. בינתיים זו אפליקציה ל-Android בלבד. תמיכה ב-iOS עשויה להתווסף בגרסה עתידית.

הצהרה משפטית & הודעה על סימנים מסחריים

Projector Pilot היא אפליקציה עצמאית של צד שלישי שפותחה ופורסמה על ידי MiyaraHub Technologies LLC. היא אינה נוצרת על ידי Seiko Epson Corporation, אינה קשורה אליה, אינה מאושרת על ידה, אינה ממומנת על ידה ואינה מחוברת אליה רשמית בשום אופן, ולא לאף אחת מחברות הבת או החברות הקשורות שלה.

“Epson” הוא סימן מסחרי רשום של Seiko Epson Corporation. “PJLink” הוא סימן מסחרי רשום של Japan Business Machine and Information System Industries Association (JBMIA). כל שאר הסימנים המסחריים המוזכרים כאן הם רכוש בעליהם.

ההתייחסות למוצרים האלה בעמוד זה ובתוך האפליקציה נעשית אך ורק לצורך זיהוי תאימות ותיאור הפונקציונליות של האפליקציה (שימוש הוגן שמי). בעלי הסימנים המסחריים אינם קשורים ל-MiyaraHub Technologies LLC ואינם מאשרים את המוצר הזה.

Projector Pilot מתקשרת עם מקרני Epson באמצעות ממשקי בקרת הרשת שלהם (PJLink, Web Control API). השימוש באפליקציה הוא על אחריותכם בלבד. MiyaraHub Technologies LLC אינה אחראית לתצורה שגויה, לבעיות באיכות התמונה או לבעיות אחרות הנובעות מהשימוש באפליקציה.
