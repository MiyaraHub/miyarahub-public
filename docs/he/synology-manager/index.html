ראו את זה בפעולה

כל ה-NAS שלכם, במבט אחד.

צילומי מסך אמיתיים מ-Syno Manager - לוח מחוונים, מוניטור מערכת, אחסון, משימות, קבצים, ערכות נושא ועוד. הקישו על כל תמונה להגדלה.

תכונות

שליטה מלאה ב-NAS, בכף היד.

כל מה ש-DSM מציג לכם, בגרסת מובייל - והיא מסתירה בחן את מה שהחשבון שלכם לא יכול לראות.

מס׳ 01

◉ לוח מחוונים בזמן אמת

CPU, RAM, טמפרטורה וזמן פעולה חיים במבט אחד. כרטיסים להתאמה אישית מאפשרים לראות בדיוק את מה שחשוב - בריאות המערכת, ניצול אחסון, תפוקת רשת ועוד.

מס׳ 02

▣ ניהול Docker

צפו בכל הקונטיינרים הפועלים עם שימוש ב-CPU ובזיכרון בזמן אמת. הפעילו, עצרו והפעילו מחדש קונטיינרים וגשו ליומנים - שליטה מלאה ב-Docker מהטלפון.

מס׳ 03

◎ מצלמות אבטחה

שידורי מצלמות חיים בפריסת רשת נקייה. הקישו למעבר למסך מלא, ראו את מצב ההקלטה ועקבו אחר כל מצלמות Surveillance Station שלכם במקום אחד.

מס׳ 04

▢ אחסון & בריאות כוננים

ניצול נפחים, מצב RAID, טמפרטורות כוננים בודדים ונתוני בריאות SMART לכל דיסק. תמיד תדעו מה מצב האחסון שלכם.

מס׳ 05

╿ ניטור רשת

גרפי רוחב פס חיים לכל ממשק רשת. עקבו אחר מהירויות הורדה / העלאה, חיבורים פעילים, ממשקים מאוגדים ותצורת DNS.

מס׳ 06

⚙ ניהול חבילות

ראו את כל חבילות DSM המותקנות ואת מצבן. נטרו שירותים פועלים, משימות מתוזמנות, מצב סוללת UPS, רשומות יומן ותיקיות משותפות.

מס׳ 07

☼ ניתן להתאמה מלאה

הגדירו את קטגוריות לוח המחוונים, התאימו את סרגל הניווט, בחרו ערכת נושא וקבעו מרווחי דגימה. גרמו לאפליקציה לעבוד בדיוק כמו שאתם רוצים.

מס׳ 08

✦ ווידג'טים למסך הבית

ווידג'טים של Quick Actions, Storage Overview ו-System Status למסך הבית. הציצו במצב ה-NAS בלי אפילו לפתוח את האפליקציה.

3

לוחות מחוונים, Docker, מצלמות, אחסון, רשת, חבילות ומשימות - ישירות מהטלפון, מהטאבלט או משולחן העבודה.

ה-NAS שלכם, הנתונים שלכם, השליטה שלכם.

Syno Manager תוכננה עם ארכיטקטורה שמעמידה את הפרטיות במרכז. איסוף נתונים מינימלי, בלי מעקב אחר משתמשים, בלי תלות בענן.

◉

בלי ממסר ענן

שאלות נפוצות (FAQ)

שאלות נפוצות.

איך האפליקציה מתחברת ל-NAS שלי? +
Syno Manager משתמשת בנקודות הקצה המתועדות של Synology DSM API כדי לתקשר עם ה-NAS שלכם דרך הרשת המקומית. האפליקציה שולחת בקשות ישירות ל-NAS - אין שרתי ביניים, פרוקסי או ממסרי ענן. אתם מזינים את כתובת ה-IP / שם המארח והיציאה של ה-NAS, מתחברים עם פרטי ה-DSM שלכם, והאפליקציה מתקשרת ישירות עם DSM.
אילו הרשאות האפליקציה צריכה ב-NAS שלי? +
האפליקציה פועלת במסגרת ההרשאות שיש לחשבון המשתמש שלכם ב-DSM. לפונקציונליות מלאה של לוח המחוונים מומלץ חשבון מנהל. עם זאת, האפליקציה מתדרדרת בצורה חיננית - אם לחשבון שלכם אין הרשאות Docker, מקטע Docker פשוט לא יציג נתונים. כך גם ב-Surveillance Station, בתיקיות משותפות וכן הלאה. אין צורך להתקין חבילות DSM מיוחדות.
האם האפליקציה שומרת את פרטי ההזדהות של ה-NAS שלי? +
פרטי החיבור נשמרים מקומית על ההתקן באמצעות אחסון מאובטח של הפלטפורמה (iOS Keychain / Android Keystore). פרטי ההזדהות לא נשלחים לעולם אל MiyaraHub Technologies או לכל צד שלישי. הם משמשים אך ורק להזדהות מול ה-NAS שלכם.
אילו דגמי Synology נתמכים? +
Syno Manager עובדת עם כל Synology NAS שמריץ DSM 7.0 ומעלה. זה כולל את כל דגמי DiskStation (DS), RackStation (RS) ו-FlashStation (FS) הנוכחיים. בדגמים ישנים יותר עם DSM 6.x ייתכנו מגבלות בפונקציונליות בגלל הבדלי API.
האם אפשר לנהל קונטיינרים של Docker מרחוק? +
כן. אפשר לראות את מצב הקונטיינרים, שימוש ב-CPU / בזיכרון, לגשת ליומנים ולבצע פעולות עצירה / הפעלה מחדש ישירות מהאפליקציה. יצירת קונטיינרים ושינויי תצורה אינם נתמכים כרגע - הדגש הוא על ניטור ופעולות ניהול מהירות.
כמה עולה Syno Manager? +
Syno Manager היא רכישה חד-פעמית ב-$9.99. בלי מנוי, בלי פרסומות, בלי רכישות בתוך האפליקציה. קונים פעם אחת ב-App Store או ב-Google Play והיא שלכם.
האם אפשר לגשת ל-NAS מרחוק (מחוץ לרשת הביתית)? +
Syno Manager מתחברת לכל כתובת IP / שם מארח שתגדירו. אם ה-NAS שלכם נגיש דרך VPN, Tailscale או יציאה מועברת, האפליקציה תעבוד גם מרחוק. אנו ממליצים להשתמש ב-VPN או ב-Tailscale ולא לחשוף את DSM ישירות לאינטרנט.
