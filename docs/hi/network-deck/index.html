यह कैसे काम करता है

सीधे आपके कंट्रोलर तक। कोई क्लाउड रिले नहीं।

Network Deck आपके लोकल नेटवर्क (या आपके VPN) पर सीधे आपके UniFi कंट्रोलर से बात करता है। आपके क्रेडेंशियल और नेटवर्क डेटा कभी किसी MiyaraHub सर्वर तक नहीं पहुँचते।

1

अपना कंट्रोलर जोड़ें

अपने कंट्रोलर का होस्टनेम या IP, पोर्ट (UniFi OS के लिए डिफ़ॉल्ट 443, स्टैंडअलोन के लिए 8443) और अपने लोकल एडमिन क्रेडेंशियल डालें। Network Deck अपने-आप पहचान लेता है कि आप UniFi OS पर हैं या स्टैंडअलोन कंट्रोलर पर।

2

लोकल तौर पर ऑथेंटिकेट करें

अपने लोकल एडमिन यूज़रनेम और पासवर्ड से साइन इन करें। टू-फ़ैक्टर ऑथेंटिकेशन शुरू से अंत तक समर्थित है। API key पसंद है? प्रोग्रामैटिक एक्सेस के लिए X-API-KEY इस्तेमाल करें और कुकी वाला पूरा फ़्लो छोड़ दें।

3

एक नज़र में मैनेज करें

लाइव बैंडविड्थ चार्ट देखिए, शरारती क्लाइंट को किक कीजिए, फ़ायरवॉल रूल टॉगल कीजिए, PoE पोर्ट बाउंस कीजिए, Teleport गेस्ट को इनवाइट कीजिए या दूसरी साइट पर स्विच कीजिए - हर ऐक्शन कंट्रोलर तक जाकर लौटता है और लाइव इवेंट स्ट्रीम को अपडेट करता है।

सुरक्षा & गोपनीयता

सिर्फ़ स्थानीय। कोई अकाउंट नहीं। कोई क्लाउड रिले नहीं।

Network Deck को प्राइवेसी-फ़र्स्ट, सिर्फ़ लोकल आर्किटेक्चर के साथ डिज़ाइन किया गया है। कोई MiyaraHub अकाउंट नहीं, कोई क्लाउड रिले नहीं, क्रैश रिपोर्टिंग के अलावा कोई डेटा संग्रह नहीं।

◉

कोई क्लाउड रिले नहीं

सारे कमांड और लाइव स्ट्रीम सीधे आपके फ़ोन और आपके कंट्रोलर के बीच, आपके लोकल Wi-Fi या VPN पर होते हैं। कुछ भी बाहरी सर्वर से होकर नहीं गुज़रता।

▣

मानक UniFi ऑथ

आपके UniFi Network वेब UI वाले ही लोकल एडमिन क्रेडेंशियल (या API key) इस्तेमाल होते हैं। क्रेडेंशियल डिवाइस पर iOS Keychain / Android Keystore में सुरक्षित रहते हैं और आपके कंट्रोलर के अलावा कहीं और डिवाइस से बाहर नहीं भेजे जाते।

◎

◈

न्यूनतम एनालिटिक्स

Firebase Crashlytics सिर्फ़ बग रिपोर्ट के लिए। कोई उपयोग ट्रैकिंग नहीं, कोई विज्ञापन नहीं, कोई डेटा बिक्री नहीं। नेटवर्क एरर नॉन-फ़ेटल के रूप में लॉग होते हैं ताकि आपका नेटवर्क लेआउट जुटाए बिना हम फ़र्मवेयर संगतता सुधार सकें।

◆

अनुमतियों का सम्मान

ऐप उन्हीं अनुमतियों के दायरे में काम करता है जो आपके UniFi एडमिन अकाउंट के पास हैं। सब-एडमिन को वही दिखता है जो कंट्रोलर उन्हें देखने देता है। न कोई विशेषाधिकार बढ़ाना, न कोई बैकडोर।

◐

क्या Network Deck का Ubiquiti या UniFi से कोई संबंध है? +
नहीं। Network Deck MiyaraHub Technologies LLC द्वारा विकसित एक स्वतंत्र, थर्ड-पार्टी ऐप्लिकेशन है। इसे Ubiquiti Inc. ने नहीं बनाया है, न ही यह किसी भी रूप में उससे संबद्ध, उसके द्वारा समर्थित या प्रायोजित है। "Ubiquiti," "UniFi," "UniFi OS," "UniFi Network," "UDM," "UDR," "UCG," "Teleport" और सभी संबंधित उत्पादों के नाम Ubiquiti Inc. के ट्रेडमार्क हैं। इन नामों का उपयोग केवल संगतता बताने के लिए किया गया है (नामात्मक उचित उपयोग)।
कौन-से UniFi कंट्रोलर समर्थित हैं? +
Network Deck UniFi OS कंसोल (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) और Linux, Docker या Windows पर चलने वाले स्टैंडअलोन UniFi Network कंट्रोलर (v10.x) दोनों को सपोर्ट करता है। कनेक्ट होते समय ऐप आपका प्लेटफ़ॉर्म अपने-आप पहचान लेता है और UI को आपके फ़र्मवेयर के उपलब्ध एंडपॉइंट के हिसाब से ढाल देता है - जो फ़ीचर आपके पास नहीं हैं, वे बस दिखते ही नहीं। UDM Pro SE (UniFi OS 5.0.16) और स्टैंडअलोन Network 10.2.105 पर लाइव टेस्ट किया गया है।
Network Deck मेरे कंट्रोलर से कैसे संवाद करता है? +
Network Deck वही लोकल API इस्तेमाल करता है जो UniFi Network का वेब UI करता है - क्लासिक /rest और /cmd एंडपॉइंट (कुकी-आधारित सेशन ऑथेंटिकेशन के साथ) और नई v2 इंटीग्रेशन API का मेल। लाइव इवेंट स्ट्रीम करने के लिए यह आपके कंट्रोलर से एक WebSocket भी खोलता है। सारा संवाद सीधे आपके फ़ोन और कंट्रोलर के बीच, आपके लोकल नेटवर्क या VPN पर होता है।
क्या मुझे UniFi क्लाउड अकाउंट चाहिए? +
नहीं। Network Deck सिर्फ़ लोकल ऑथेंटिकेशन इस्तेमाल करता है। अपने UniFi लोकल एडमिन यूज़रनेम और पासवर्ड (या API key) से साइन इन करें। अगर आपका कंट्रोलर फ़िलहाल सिर्फ़ ui.com क्लाउड लॉगिन से पहुँच में है, तो Network Deck इस्तेमाल करने के लिए Settings → Admins में लोकल एडमिन अकाउंट चालू करना होगा। कंट्रोलर कभी हमसे बात नहीं करता, और हम आपकी ओर से कभी Ubiquiti के क्लाउड से बात नहीं करते।
