यह कैसे काम करता है

सीधा नेटवर्क कनेक्शन। क्लाउड की ज़रूरत नहीं।

Projector Pilot मानक नेटवर्क प्रोटोकॉल का उपयोग करके Wi-Fi पर सीधे आपके प्रोजेक्टर से संवाद करता है। आपका डेटा कभी किसी बाहरी सर्वर तक नहीं पहुँचता।

1

अपना प्रोजेक्टर जोड़ें

अपने Epson प्रोजेक्टर का IP पता डालिए। Projector Pilot PJLink और Web Control कनेक्टिविटी जाँचता है, मॉडल पहचानता है और सभी उपलब्ध फ़ीचर अपने-आप खोज लेता है।

2

Wi-Fi से कनेक्ट करें

Projector Pilot स्टैंडबाय पहचानने और पावर कंट्रोल के लिए PJLink इस्तेमाल करता है, और चालू होने पर पिक्चर, लेंस और सेटिंग के पूरे कंट्रोल के लिए Epson Web Control API। सब कुछ आपके लोकल नेटवर्क पर रहता है।

3

पूरा नियंत्रण लें

पिक्चर सेटिंग बदलिए, इनपुट स्विच कीजिए, मोटराइज़्ड लेंस कंट्रोल कीजिए, कीस्टोन करेक्शन संभालिए, लैंप आवर्स देखिए और OSD में नेविगेट कीजिए - सब कुछ एक ही शानदार ऐप से।

क्या Projector Pilot का Epson से कोई संबंध है? +
नहीं। Projector Pilot MiyaraHub Technologies LLC द्वारा विकसित एक स्वतंत्र, थर्ड-पार्टी ऐप्लिकेशन है। इसे Seiko Epson Corporation या उसकी किसी सहायक या संबद्ध कंपनी ने नहीं बनाया है, न ही यह किसी भी रूप में उनसे संबद्ध, उनके द्वारा समर्थित या प्रायोजित है। "Epson" Seiko Epson Corporation का पंजीकृत ट्रेडमार्क है। इस नाम का उपयोग केवल संगतता बताने के लिए किया गया है (नामात्मक उचित उपयोग)।
कौन-से प्रोजेक्टर समर्थित हैं? +
Projector Pilot उन सभी नेटवर्क वाले Epson प्रोजेक्टर के साथ काम करता है जो PJLink और/या Web Control सपोर्ट करते हैं। इसमें पिछले 10+ वर्षों के ज़्यादातर मॉडल शामिल हैं - फ़्लैगशिप QB1000 और LS12000 से लेकर मिड-रेंज Home Cinema और प्रोफ़ेशनल इंस्टॉलेशन मॉडल तक। ऐप कनेक्ट होते समय उपलब्ध फ़ीचर अपने-आप पहचान लेता है, इसलिए हर उपयोगकर्ता को ठीक वही दिखता है जो उसका प्रोजेक्टर सपोर्ट करता है। बुनियादी PJLink कंट्रोल NEC, Panasonic, Sony और अन्य के गैर-Epson प्रोजेक्टर के साथ भी काम करता है।
Projector Pilot मेरे प्रोजेक्टर से कैसे संवाद करता है? +
Projector Pilot दो प्रोटोकॉल इस्तेमाल करता है: सार्वभौमिक प्रोजेक्टर कंट्रोल के लिए PJLink (पोर्ट 4352), जिसमें स्टैंडबाय से पावर-ऑन, इनपुट स्विचिंग और लैंप की स्थिति शामिल है; और पिक्चर, लेंस, कीस्टोन, HDR आदि जैसे विस्तृत सेटिंग कंट्रोल के लिए Digest ऑथेंटिकेशन वाला Epson Web Control API (पोर्ट 80)। सारा संवाद सीधे आपके लोकल Wi-Fi नेटवर्क पर होता है।
क्या मैं मोटराइज़्ड लेंस कंट्रोल कर सकता हूँ? +
हाँ, मोटराइज़्ड लेंस सिस्टम वाले प्रोजेक्टर पर। Projector Pilot रीयल-टाइम पोज़िशन फ़ीडबैक के साथ पूरा लेंस शिफ़्ट (क्षैतिज और ऊर्ध्वाधर), फ़ोकस और ज़ूम कंट्रोल देता है। आप अलग-अलग ऐस्पेक्ट रेशियो, स्क्रीन पोज़िशन या देखने के सेटअप के लिए लेंस मेमोरी प्रीसेट सेव और रिकॉल भी कर सकते हैं। मोटराइज़्ड लेंस के बिना वाले मॉडल के लिए लेंस कंट्रोल अपने-आप छिप जाते हैं।
क्या यह HDR और वाइड कलर गैमट को सपोर्ट करता है? +
हाँ। Projector Pilot आपको डायनैमिक रेंज सेटिंग (Auto, HDR10, HLG, SDR), कलर स्पेस (Auto, BT.709, BT.2020) कंट्रोल करने देता है, और सटीक कलर कैलिब्रेशन के लिए हर चैनल का RGB गेन और ऑफ़सेट एडजस्टमेंट देता है। HDR फ़ीचर केवल उन मॉडल पर दिखते हैं जो उन्हें सपोर्ट करते हैं।
क्या मैं स्टैंडबाय से प्रोजेक्टर चालू कर सकता हूँ? +
हाँ। Projector Pilot आपके प्रोजेक्टर को स्टैंडबाय मोड में होने पर भी चालू करने के लिए PJLink इस्तेमाल करता है। जब तक आपका प्रोजेक्टर आपके नेटवर्क से जुड़ा है (स्टैंडबाय से जगाने के लिए वायर्ड LAN की सलाह है), आप उसे अपने फ़ोन से चालू और बंद कर सकते हैं।
