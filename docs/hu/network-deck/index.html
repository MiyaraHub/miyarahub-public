Network Deck · UniFi hálózati vezérlőkhözA UniFi hálózata, kézben.✦

UniFi hálózatának teljes irányítása a telefonjáról.

Prémium mobilalkalmazás Ubiquiti UniFi hálózati vezérlőkhöz. Élő vezérlőpultok, kliens- és eszközkezelés, WiFi- és VLAN-vezérlés, tűzfalszabályok, portvezérlés, VPN, sebességteszt és többtelephelyes váltás - mindez a telefonjáról, közvetlenül a vezérlőjéhez csatlakozva.

Képernyőképek

Nézze meg az összes képernyőt.

Prémium, kifejezetten UniFi-adminisztrátoroknak épített felület. Sötét téma, élő adatok, átlátható navigáció - böngészőfülek nélkül. Bármelyikre koppintva nagyíthat.

Funkciók

UniFi vezérlője a zsebében.

A Network Deck közvetlenül a UniFi vezérlő helyi API-jával kommunikál - legyen az UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) vagy önálló UniFi Network vezérlő. Kliensek, WiFi, tűzfal, portok, VPN és elemzések böngésző megnyitása nélkül.

◉ Élő vezérlőpult

Internetszolgáltatói állapot, valós idejű sávszélesség-diagram 60 mintás gördülő ablakkal, valamint testreszabható kártyák - rendszerinformációk, DPI-forgalom, riasztások, események, legaktívabb kliensek, sebességteszt-előzmények és gyorsparancsok. Átrendezhető, füles elrendezés.

Kompatibilitás

UniFi vezérlőjével együttműködik.

A Network Deck egyaránt támogatja a UniFi OS konzolokat és az önálló UniFi Network vezérlőket. Automatikusan felismeri, mely végpontokat kínálja a firmware, és ahhoz igazítja a felületet - ami nem érhető el, az egyszerűen nem jelenik meg.

◉ UniFi OS konzolok

  • UDM Pro SE (ellenőrizve)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Önálló vezérlők

  • UniFi Network 10.x (ellenőrizve)
  • Saját üzemeltetésű Linux / Docker rendszeren
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Hitelesítés

  • Helyi adminisztrátori felhasználónév + jelszó
  • Kétfaktoros hitelesítés (TOTP)
  • X-API-KEY programozott hozzáféréshez
  • UniFi felhőfiók nem szükséges

◆ Mobil platformok

  • iOS 13 vagy újabb
  • Android 5.0 (API 21) vagy újabb
  • Telefonos és táblagépes elrendezés
  • Világos és sötét témák

Firmware-tűrés: A Network Deck automatikusan felismeri a vezérlő által kínált végpontokat, és alkalmazkodik a firmware-specifikus JSON-változatokhoz (mezőnév-eltérések, típuskonverzió, az integrációs API többféle formája). Az al-adminisztrátori fiókoknál egyes végpontok 401 hibát adhatnak - ez a vezérlő jogosultsági korlátja, nem az alkalmazásé.

Hogyan működik

Közvetlenül a vezérlőhöz. Felhős közvetítő nélkül.

A Network Deck közvetlenül a UniFi vezérlővel kommunikál a helyi hálózaton (vagy VPN-en) keresztül. A hitelesítő adatai és a hálózati adatai soha nem érintenek MiyaraHub szervert.

1

Adja hozzá a vezérlőjét

Adja meg a vezérlő gépnevét vagy IP-címét, a portot (alapértelmezés: 443 UniFi OS esetén, 8443 önálló vezérlőnél) és a helyi adminisztrátori hitelesítő adatokat. A Network Deck automatikusan felismeri, hogy UniFi OS-t vagy önálló vezérlőt használ-e.

2

Helyi hitelesítés

Jelentkezzen be a helyi adminisztrátori felhasználónevével és jelszavával. A kétfaktoros hitelesítés teljes körűen támogatott. Inkább API-kulcsot használna? Az X-API-KEY programozott hozzáférést tesz lehetővé, és teljesen kihagyhatja a cookie-alapú folyamatot.

3

Mindent egy pillantással

Kövesse az élő sávszélesség-diagramot, dobjon ki egy rakoncátlan klienst, kapcsoljon át egy tűzfalszabályt, indítsa újra egy PoE-port tápellátását, hívjon meg egy Teleport-vendéget, vagy váltson másik telephelyre - minden művelet végigmegy a vezérlőn, és frissíti az élő eseményfolyamot.

Biztonság & adatvédelem

Csak helyi. Fiók nélkül. Felhős közvetítés nélkül.

A Network Deck adatvédelmi szemléletű, kizárólag helyi architektúrára épül. Nincs MiyaraHub-fiók, nincs felhős közvetítő, és az összeomlás-jelentésen túl nincs adatgyűjtés.

◉

Nincs felhős közvetítés

Minden parancs és élő adatfolyam közvetlenül a telefonja és a vezérlője között zajlik a helyi Wi-Fi-n vagy VPN-en. Semmi nem halad át külső szervereken.

▣

Szabványos UniFi hitelesítés

Ugyanazokat a helyi adminisztrátori hitelesítő adatokat (vagy API-kulcsot) használja, mint a UniFi Network webes felülete. A hitelesítő adatokat az iOS Keychain / Android Keystore tárolja az eszközön, és az eszközről csak a vezérlője felé kerülnek továbbításra.

◎

Nincs MiyaraHub-fiók

Nincs regisztráció, nincs e-mail, nincs szükség MiyaraHub-fiókra. Telepítse, irányítsa a vezérlőjére, és már használhatja is.

◈

Minimális elemzés

A Firebase Crashlytics kizárólag hibajelentésekhez. Nincs használatkövetés, nincs reklám, nincs adateladás. A hálózati hibákat nem végzetes eseményként naplózzuk, hogy javíthassuk a firmware-kompatibilitást anélkül, hogy a hálózata felépítését gyűjtenénk.

◆

Jogosultságok tiszteletben tartása

Az alkalmazás azokon a jogosultságokon belül működik, amelyekkel a UniFi adminisztrátori fiókja rendelkezik. Az al-adminisztrátorok csak azt látják, amit a vezérlő megenged nekik. Nincs jogosultság-emelés, nincs hátsó ajtó.

◐

Csak hálózati engedély

A Network Deck egyetlen eszközjogosultságot igényel: a hálózati hozzáférést, amelyet kizárólag a UniFi vezérlőhöz való csatlakozásra használ a helyi hálózaton (vagy VPN-en keresztül).

Mely UniFi vezérlők támogatottak? +
A Network Deck egyaránt támogatja az UniFi OS konzolokat (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) és az önálló, v10.x verziójú UniFi Network vezérlőket Linuxon, Dockeren vagy Windows-on. Élesben tesztelve UDM Pro SE (UniFi OS 5.0.16) és önálló Network 10.2.105 mellett.
Hogyan kommunikál a Network Deck a vezérlőmmel? +
A Network Deck ugyanazt a helyi API-t használja, mint a UniFi Network webes felülete - a klasszikus /rest és /cmd végpontokat (cookie-alapú munkamenet-hitelesítéssel), valamint az újabb v2 integrációs API-t. Emellett WebSocket-kapcsolatot nyit a vezérlőhöz az élő események streameléséhez. Minden kommunikáció közvetlenül a telefonja és a vezérlője között zajlik a helyi hálózaton vagy VPN-en keresztül.
Szükségem van UniFi felhőfiókra? +
Nem. A Network Deck kizárólag helyi hitelesítést használ. Jelentkezzen be a UniFi helyi adminisztrátori felhasználónevével és jelszavával (vagy API-kulccsal). Ha a vezérlője jelenleg csak a ui.com felhős bejelentkezésen keresztül érhető el, a Network Deck használatához engedélyeznie kell egy helyi adminisztrátori fiókot a Beállítások → Adminisztrátorok menüben. A vezérlő soha nem kommunikál velünk, mi pedig soha nem lépünk kapcsolatba az Ubiquiti felhőjével az Ön nevében.
Kezelhetem a tűzfalszabályokat és a porttovábbításokat? +
Igen. A Network Deck teljes tűzfalcsomagot kínál: szabályzatok (engedélyezés / tiltás / vizsgálat), porttovábbítások teljes CRUD-kezeléssel, forgalmi szabályok és útvonalak, tűzfalcsoportok, tűzfalzónák (v2 szabályzatmátrix), valamint DPI-alkalmazások / -csoportok. Minden közvetlenül a listanézetből kapcsolható - nincs párbeszédablakról párbeszédablakra lépkedés.
Támogatja a több telephelyet? +
Igen. Ha a vezérlője több telephelyet kezel, a Network Deck felül telephelyváltót jelenít meg. Minden funkció - vezérlőpult, kliensek, tűzfal, VPN - az éppen kiválasztott telephelyre vonatkozik. Egyetlen koppintással válthat.
Mennyibe fog kerülni a Network Deck? +
A Network Deck egyszeri vásárlás lesz $4.99 áron az App Store-ban, a Google Play-en és a Microsoft Store-ban. Nincs előfizetés, nincs reklám, nincsenek alkalmazáson belüli vásárlások. Az ár a nyilvános indulás előtt változhat.
Használhatom távolról is (otthonomon / irodámon kívül)? +
A Network Deck bármilyen megadott gépnévhez vagy IP-címhez csatlakozik. Ha a vezérlője elérhető VPN-en, Tailscale-en, WireGuard-on vagy továbbított porton keresztül, az alkalmazás távolról is működik. Javasoljuk VPN vagy Tailscale használatát ahelyett, hogy a UniFi vezérlőt közvetlenül kitenné az internetre.
Mely platformokat támogatja? +
A Network Deck egyaránt fut iOS (13 vagy újabb) és Android (5.0 / API 21 vagy újabb) rendszeren. Telefonos és táblagépes elrendezés egyaránt támogatott. Az alkalmazás egyszerre indul az App Store-ban, a Google Play-en és a Microsoft Store-ban.
