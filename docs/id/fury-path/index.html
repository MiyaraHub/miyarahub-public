Fitur

Seluruh antarmuka web HDFury, di tangan Anda.

Aplikasi mendeteksi perangkat Anda secara otomatis dan mengaktifkan kumpulan fitur untuk model Anda.

No. 01

◉ Info sinyal real-time

Ikhtisar langsung sinyal input, output video/audio, detail EDID sink, status eARC, dan mode operasi, semua dalam satu tampilan yang bisa digulir, diperbarui secara real-time.

No. 02

▣ Manajemen EDID

Pilih mode EDID, atur pengaturan Automix, dan setel kemampuan video termasuk laju FRL, VRR, ALLM, dan injeksi HDR. Kontrol mendalam atas setiap parameter EDID.

No. 03

◎ HDR / Dolby Vision

Injeksi atau hapus metadata HDR kustom per format (HDR10, HLG, LLDV). Aktifkan injeksi flag DV, pilih profil mode DV, dan alihkan passthrough Low-Latency Dolby Vision.

No. 04

▢ CEC / eARC / audio

Atur komunikasi HDMI-CEC, setel mode eARC/ARC, sesuaikan baud rate RS232, dan bisukan output audio satu per satu. Kontrol passthrough codec audio penuh termasuk TrueHD, DTS-HDMA, DD+.

No. 05

◆ Sistem makro JVC Model tertentu

Atur perintah proyektor JVC otomatis yang dipicu oleh perubahan metadata HDR. Setel aktifkan makro, sync-on-event, dan pengaturan waktu tunda. Tersedia di VRRooM, VERTEX2, DIVA, dan Maestro.

No. 06

⚙ Konfigurasi perangkat penuh

Atur pergantian input otomatis, mode HDCP, mode latensi rendah HTPC per input, volume/bass/treble audio analog, pengaturan remote IR, paksa TX +5V, dan konfigurasi jaringan/TCP.

No. 07

☼ Tampilan OSD / OLED

Kendalikan layar OLED bawaan perangkat: aktifkan/nonaktifkan, pilih halaman info, setel batas waktu memudar otomatis, dan sesuaikan opsi lanjutan seperti rotasi dan inversi warna.

No. 08

✦ Navigasi kustom & multi-perangkat

Pilih tab mana yang ada di bilah bawah per perangkat: Home plus hingga 6 lainnya, dengan minimum 2. Kelola banyak perangkat HDFury dari satu aplikasi, masing-masing dengan pengaturan, navigasi, dan status koneksinya sendiri.

No. 09

FAQ

Pertanyaan yang sering diajukan.

Bagaimana FuryPath berkomunikasi dengan perangkat HDFury saya? +
FuryPath mengirim permintaan HTTP GET langsung ke perangkat HDFury Anda di jaringan Wi-Fi lokal, memakai protokol yang sama dengan antarmuka web bawaan HDFury. Perintah dikirim ke GET /cmd?key=value dan polling status membaca dari endpoint GET /ssi/*.ssi. Tidak ada server eksternal yang terlibat. Perangkat Anda harus berada di jaringan Wi-Fi yang sama dengan ponsel Anda.
Versi sistem operasi apa saja yang didukung? +
FuryPath tersedia di iPhone, iPad, Android, Mac, dan Windows. iOS memerlukan iOS 16.0 atau lebih baru. macOS memerlukan macOS 11.0 atau lebih baru. Android memerlukan Android 7.0 (API 24) atau lebih tinggi.
Bisakah saya mengendalikan perangkat HDFury dari luar rumah? +
FuryPath terhubung ke alamat IP apa pun yang Anda atur. Jika perangkat HDFury Anda dapat diakses lewat VPN atau Tailscale, aplikasi akan bekerja dari jarak jauh. Kami menyarankan memakai VPN atau Tailscale daripada membuka perangkat Anda langsung ke internet.
Apakah mendukung semua model HDFury? +
FuryPath mendukung VRRooM, VERTEX2, VERTEX, DIVA, Maestro, ARCANA2, Arcana, dan Dr.HDMI 8K. Aplikasi mendeteksi perangkat Anda secara otomatis saat terhubung dan mengaktifkan kumpulan fitur yang relevan untuk model Anda. Tidak semua model mendukung semua fitur. Makro JVC, misalnya, hanya tersedia di VRRooM, VERTEX2, DIVA, dan Maestro.
Apakah saya perlu dongle Bluetooth atau perangkat keras tambahan? +
Tidak. FuryPath berbicara dengan perangkat HDFury Anda lewat jaringan rumah memakai antarmuka web bawaan perangkat, jadi tidak ada dongle Bluetooth (seperti GO2) atau perangkat keras lain yang perlu dibeli. Perangkat HDFury Anda cukup terhubung ke jaringan yang sama dengan ponsel, tablet, atau komputer Anda.
Apakah FuryPath aplikasi resmi HDFury? +
Tidak. FuryPath adalah aplikasi independen buatan MiyaraHub Technologies LLC untuk mengendalikan perangkat HDFury. Aplikasi ini tidak dibuat, didukung, atau disokong oleh HDFury. Untuk produk, firmware, dan dukungan resmi HDFury, kunjungi hdfury.com.
Berapa harga FuryPath? +
FuryPath adalah pembelian sekali bayar seharga $9.99. Tanpa langganan, tanpa iklan, tanpa pembelian dalam aplikasi. Beli sekali dan miliki.
Bisakah saya mengelola beberapa perangkat HDFury? +
Ya. FuryPath mendukung banyak perangkat, masing-masing dengan pengaturan, tab navigasi, dan status koneksinya sendiri. Berpindah antar perangkat dari dasbor utama dengan satu ketukan.
Bisakah saya menyesuaikan navigasi dan layar Home? +
Setiap perangkat punya layar Home plus tab fitur (INFO, EDID, HDR/AVI, DV, CEC/eARC, MACROS, OSD, OLED, CONFIG), ditampilkan sesuai model Anda. Anda memilih tab mana yang muncul di bilah navigasi bawah per perangkat (Home plus hingga 6 lainnya, minimum 2), dan Anda bisa menyeret untuk mengurutkan ulang dan menghapus kartu di Home. Setiap perangkat mengingat tata letaknya sendiri secara independen.
