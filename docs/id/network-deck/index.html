Lihat setiap layar.

Antarmuka premium yang dirancang khusus untuk administrator UniFi. Tema gelap, data langsung, navigasi intuitif - tanpa perlu tab browser. Ketuk gambar mana pun untuk memperbesar.

Fitur

Kontroler UniFi Anda, di saku Anda.

Network Deck berkomunikasi langsung dengan API lokal kontroler UniFi Anda - baik UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) maupun kontroler UniFi Network mandiri. Klien, WiFi, firewall, port, VPN, dan wawasan, tanpa perlu membuka browser.

No. 01

◉ Dasbor Langsung

Kesehatan ISP, grafik bandwidth waktu nyata dengan jendela bergulir 60 sampel, dan kartu yang bisa disesuaikan - info sistem, lalu lintas DPI, alarm, peristiwa, klien teratas, riwayat uji kecepatan, dan pintasan cepat. Tata letak bertab yang urutannya bisa diatur.

Akun sub-admin mungkin menemukan beberapa endpoint mengembalikan 401 - itu batasan izin kontroler, bukan batasan aplikasi.

Cara kerjanya

Langsung ke kontroler Anda. Tanpa relai cloud.

Network Deck berkomunikasi langsung dengan kontroler UniFi Anda melalui jaringan lokal (atau VPN) Anda. Kredensial dan data jaringan Anda tidak pernah menyentuh server MiyaraHub.

1

Tambahkan Kontroler Anda

Masukkan hostname atau IP kontroler, port (default 443 untuk UniFi OS, 8443 untuk mandiri), dan kredensial admin lokal Anda. Network Deck mendeteksi otomatis apakah Anda memakai UniFi OS atau kontroler mandiri.

2

Autentikasi Secara Lokal

Masuk dengan nama pengguna dan kata sandi admin lokal Anda. Autentikasi dua faktor didukung sepenuhnya. Lebih suka kunci API? Pakai X-API-KEY untuk akses terprogram dan lewati alur cookie sepenuhnya.

3

Kelola dalam Sekali Lihat

Pantau grafik bandwidth langsung, keluarkan klien yang nakal, aktifkan aturan firewall, reset port PoE, undang tamu Teleport, atau pindah ke situs lain - setiap aksi diteruskan ke kontroler dan memperbarui aliran peristiwa langsung.

Keamanan & Privasi

Hanya lokal. Tanpa akun. Tanpa relay cloud.

Network Deck dirancang dengan arsitektur yang mengutamakan privasi dan hanya lokal. Tanpa akun MiyaraHub, tanpa relai cloud, tanpa pengumpulan data selain laporan crash.

◉

Tanpa Relay Cloud

Semua perintah dan aliran data langsung berlangsung langsung antara ponsel dan kontroler Anda melalui Wi-Fi lokal atau VPN. Tidak ada yang melewati server eksternal.

▣

Autentikasi UniFi Standar

Memakai kredensial admin lokal yang sama (atau kunci API) dengan UI web UniFi Network Anda. Kredensial disimpan di iOS Keychain / Android Keystore pada perangkat dan tidak pernah dikirim keluar perangkat kecuali ke kontroler Anda.

◎

Tanpa Akun MiyaraHub

Tanpa pendaftaran, tanpa email, tanpa akun MiyaraHub. Pasang, arahkan ke kontroler Anda, dan Anda langsung bisa memakainya.

◈

Analitik Minimal

Firebase Crashlytics hanya untuk laporan bug. Tanpa pelacakan penggunaan, tanpa iklan, tanpa penjualan data. Galat jaringan dicatat sebagai non-fatal untuk membantu kami meningkatkan kompatibilitas firmware tanpa mengumpulkan tata letak jaringan Anda.

◆

Menghormati Izin

Aplikasi bekerja sesuai izin yang dimiliki akun admin UniFi Anda. Sub-admin hanya melihat apa yang diizinkan kontroler. Tanpa eskalasi hak akses, tanpa pintu belakang.

◐

Hanya Izin Jaringan

Satu-satunya izin perangkat yang dibutuhkan Network Deck adalah akses jaringan, yang digunakan khusus untuk terhubung ke kontroler UniFi Anda di jaringan lokal (atau lewat VPN).

Kontroler UniFi apa saja yang didukung? +
Network Deck mendukung konsol UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) maupun kontroler UniFi Network mandiri v10.x yang berjalan di Linux, Docker, atau Windows. Aplikasi mendeteksi platform Anda secara otomatis saat terhubung dan menyesuaikan UI dengan endpoint yang benar-benar disediakan firmware Anda - fitur yang tidak Anda miliki tidak akan muncul. Sudah diuji langsung pada UDM Pro SE (UniFi OS 5.0.16) dan Network mandiri 10.2.105.
Bagaimana Network Deck berkomunikasi dengan kontroler saya? +
Network Deck memakai API lokal yang sama dengan UI web UniFi Network - kombinasi endpoint klasik /rest dan /cmd (dengan autentikasi sesi berbasis cookie) ditambah API integrasi v2 yang lebih baru. Aplikasi juga membuka WebSocket ke kontroler Anda untuk menerima peristiwa secara langsung. Seluruh komunikasi berlangsung langsung antara ponsel dan kontroler Anda melalui jaringan lokal atau VPN.
Apakah saya perlu akun cloud UniFi? +
Tidak. Network Deck hanya memakai autentikasi lokal. Masuk dengan nama pengguna dan kata sandi admin lokal UniFi Anda (atau kunci API). Jika kontroler Anda saat ini hanya bisa dijangkau lewat login cloud ui.com, aktifkan akun admin lokal di Settings → Admins untuk memakai Network Deck. Kontroler tidak pernah berkomunikasi dengan kami, dan kami tidak pernah berkomunikasi dengan cloud Ubiquiti atas nama Anda.
Bisakah saya mengelola aturan firewall dan port forward? +
Bisa. Network Deck punya perangkat firewall yang lengkap: kebijakan (izinkan / blokir / inspeksi), port forward dengan CRUD, aturan dan rute lalu lintas, grup firewall, zona firewall (matriks kebijakan v2), serta aplikasi / grup DPI. Semuanya bisa diaktifkan atau dimatikan langsung dari tampilan daftar - tanpa alur dialog demi dialog.
Apakah mendukung multi-situs? +
Ya. Jika kontroler Anda mengelola beberapa situs, Network Deck menampilkan pengalih situs di bagian atas. Setiap fitur - dasbor, klien, firewall, VPN - berlaku untuk situs yang sedang dipilih. Pindah situs cukup dengan satu ketukan.
Berapa harga Network Deck? +
Network Deck akan dijual dengan sekali beli seharga $4.99 di App Store, Google Play, dan Microsoft Store. Tanpa langganan, tanpa iklan, tanpa pembelian dalam aplikasi. Harga dapat berubah sebelum peluncuran publik.
Bisakah saya memakainya dari jauh (di luar rumah / kantor)? +
Network Deck terhubung ke hostname atau IP apa pun yang Anda atur. Jika kontroler Anda dapat dijangkau lewat VPN, Tailscale, WireGuard, atau port yang diteruskan, aplikasi akan berfungsi dari jarak jauh. Kami menyarankan memakai VPN atau Tailscale daripada membuka kontroler UniFi Anda langsung ke internet.
Platform apa saja yang didukung? +
Network Deck berjalan di iOS (13 ke atas) maupun Android (5.0 / API 21 ke atas). Tata letak ponsel dan tablet sama-sama didukung. Aplikasi ini akan diluncurkan serentak di App Store, Google Play, dan Microsoft Store.
