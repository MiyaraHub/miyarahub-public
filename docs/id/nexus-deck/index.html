MiyaraHub / NexusDeck

NexusDeck · untuk file kalibrasi AudysseySemua kalibrasi, dalam satu deck.✦

Pustaka file kalibrasi untuk receiver AV Denon dan Marantz dengan Audyssey MultEQ XT atau XT32.

Simpan file kalibrasi .ady dan .oca, proyek Dirac Live, dan file .mqx dari MultEQ-X dalam satu pustaka. Bandingkan kurva, beri pemotongan gain pada .ady dan .oca, kirim file .ady atau .oca ke Speaker Preset di receiver Denon atau Marantz Anda, dan kirim rekaman Dirac Live yang Anda buat sendiri ke slot Dirac. NexusDeck tidak mengukur ruangan Anda dan tidak membuat kurva.

Layar

Lihat dulu sebelum dirilis.

Tangkapan layar toko, diambil di dalam aplikasi dengan receiver demo bawaannya. Ketuk mana saja untuk memperbesar.

Fitur

Simpan, bandingkan, dan kirim.

NexusDeck menyimpan file yang dibuat oleh alat yang sudah Anda gunakan: Audyssey MultEQ Editor, A1 Evo, dan AcoustiX. Aplikasi ini tidak mengukur ruangan Anda dan tidak membuat kurva.

No. 01

◉ Semua file kurva dalam satu pustaka

Impor file .ady dari Audyssey MultEQ Editor dan file .oca dari A1 Evo dan AcoustiX. Tambahkan folder, tag, peringkat, dan catatan, lalu cari berdasarkan nama file, alat, model receiver, catatan, atau tag. Bagikan file kurva dari halamannya.

.ady.ocaFolderTag
No. 02

▣ Pengukuran

Buka .frd, teks REW, .liveproject dari Dirac Live dan .mqx dari MultEQ-X, lalu lihat dan bandingkan kurvanya. REW .mdat tidak dibaca.

.frdREW .txt.liveproject.mqx
No. 03

▢ Lihat dan bandingkan

Lihat semua kanal dalam satu grafik, dengan impulse response dan group delay. Ekspor gambar atau CSV. Dengan Pro, bandingkan kurva dengan tabel selisih.

Semua kanalCSVPerbandingan Pro
No. 04

▢ Pengeditan gain

Tempatkan pemotongan gain pada satu kanal, dari 0 hingga -12 dB, dan lihat hasilnya terlebih dahulu. File .ady atau .oca yang diedit hanya dapat dikirim ke Speaker Preset 1, sebagai filter hasil perhitungan, bukan hasil pengukuran. File tersimpan tidak pernah diubah.

0 hingga -12 dBPreset 1File tetap utuh
No. 05

◆ Kirim ke receiver Anda

NexusDeck menemukan receiver Anda di jaringan. Sebelum menulis apa pun, NexusDeck memeriksa file terhadap receiver: model, versi MultEQ, dan kanal. Ketidakcocokan diblokir beserta alasannya. NexusDeck bertanya sebelum mengganti preset, lalu mengirim ke Speaker Preset yang Anda pilih.

Speaker PresetDiperiksa duluBertanya dulu
No. 06

⚙ Slot Dirac Live

Baca slot Dirac Live dan beralih di antaranya. Putar ulang pengiriman Dirac Live yang Anda rekam sendiri ke sebuah slot, dan NexusDeck memilih slot itu dan membacanya kembali; hasilnya menyatakan: tersimpan, tidak tersimpan atau tidak diketahui. Speaker Preset itu lalu memakai Dirac Live, bukan Audyssey. NexusDeck tidak membuat, mengedit, atau mengonversi filter Dirac apa pun.

BacaPindahPutar ulang
No. 07

◈ Preset dan speaker

Lihat Speaker Preset mana yang aktif serta jarak dan trim tiap speaker. Beralih preset, bandingkan kurva yang terakhir dikirim ke dua preset, dan simpan cadangan: setiap pengiriman .ady atau .oca menyimpan preset terlebih dahulu. Level, jarak, dan crossover untuk sementara diatur di AVR Maestro (segera hadir).

Preset aktifJarakTrim
No. 08

▣ Cadangan preset

Sebelum setiap pengiriman .ady atau .oca, NexusDeck menyimpan pengaturan Speaker Preset tujuan di perangkat Anda, sehingga Anda bisa melihat apa yang digantikan oleh pengiriman. Back up now menyimpan pengaturan preset yang aktif tanpa mengirim apa pun. Keduanya gratis.

Sebelum setiap pengiriman .ady atau .ocaBack up nowGratis
No. 09

◆ Alat Pro

Cadangkan seluruh pustaka Anda, dengan folder, tag, catatan, hasil edit, dan pengukuran, ke file .ndbackup dan pulihkan di perangkat lain. Batch Map mengirim satu kurva ke setiap Speaker Preset sekaligus, dan Quick / Smart Select menyimpan sebanyak apa pun pengaturan receiver tersimpan yang Anda mau.

.ndbackupBatch MapQuick / Smart Select

Cara kerjanya

Dari file kurva ke receiver dalam tiga langkah.

Bawa file kurva, lihat, lalu kirim. Coba seluruh alur terlebih dahulu pada receiver demo di dalam aplikasi.

1

Impor file Anda

Impor file .ady dari Audyssey MultEQ Editor atau file .oca dari A1 Evo atau AcoustiX. File itu masuk ke pustaka Anda lengkap dengan kanal, kurva target, dan catatannya.

2

Lihat, bandingkan, edit

Buka kurva untuk melihat semua kanal dalam satu grafik. Bandingkan dengan kurva lain menggunakan Pro, atau tempatkan pemotongan gain. File tersimpan tidak pernah diubah.

3

Kirim ke preset speaker

Temukan receiver Anda, pilih Speaker Preset, lalu kirim. Tanpa Pro, pengiriman masuk ke Speaker Preset 1.

Keamanan & Privasi

Hanya lokal. Tanpa akun. Tanpa cloud.

File kalibrasi Anda tetap berada di perangkat Anda dan receiver Anda tetap berada di jaringan lokal Anda. Tidak ada data penyiapan Anda yang sampai ke MiyaraHub kecuali Anda sendiri mengirimkannya kepada kami.

◉

Tanpa akun

Tanpa pendaftaran dan tanpa login MiyaraHub. MiyaraHub tidak menjalankan server yang diajak bicara aplikasi.

▣

File tetap di perangkat Anda

Pustaka, hasil edit, dan pengaturan Anda disimpan di perangkat Anda. Tidak ada yang disinkronkan ke MiyaraHub.

◎

Hanya jaringan rumah Anda

NexusDeck berbicara langsung dengan receiver Anda di jaringan lokal. File kalibrasi tidak pernah melewati server MiyaraHub.

◆

Laporan error hanya jika Anda mengizinkannya

Di Android dan iOS, laporan error dikirim ke Firebase Crashlytics hanya setelah Anda mengizinkannya pada permintaan saat pertama dijalankan. Matikan di Pengaturan > Tentang. Aplikasi Mac dan Windows tidak mengirim apa pun.

●

Tanpa analitik, tanpa iklan

Tanpa pustaka analitik, tanpa iklan, dan tanpa ID iklan.

◈

Log hanya saat Anda mengirimnya

Pengaturan > Tentang membagikan log aplikasi sebagai satu file zip untuk dukungan, hanya saat Anda memilih untuk mengirimnya.

FAQ

Pertanyaan yang sering diajukan.

Semua yang perlu Anda ketahui tentang NexusDeck.

Apakah NexusDeck berafiliasi dengan Audyssey, Dirac, Denon, atau Marantz? +
Tidak. NexusDeck adalah aplikasi independen dari MiyaraHub Technologies LLC, tidak berafiliasi dengan atau didukung oleh Denon, Marantz, Audyssey, atau Dirac. Semua merek dagang adalah milik pemiliknya masing-masing.
Receiver mana yang didukung? +
Untuk file .ady dan .oca: model Denon dan Marantz berjaringan dengan Audyssey MultEQ XT atau XT32, dengan network standby aktif. Sebelum mengirim, NexusDeck memeriksa file terhadap receiver dan memblokir ketidakcocokan beserta alasannya.
File apa saja yang dibaca NexusDeck? +
Kurva yang dapat dikirim: .ady dari Audyssey MultEQ Editor dan .oca dari A1 Evo dan AcoustiX. Pengukuran untuk dilihat dan dibandingkan: .frd, teks REW, .liveproject dari Dirac Live dan .mqx dari MultEQ-X. Pengukuran dan file .mqx tidak berisi filter, jadi file untuk dikirim adalah .ady atau .oca. REW .mdat tidak dibaca.
Apakah NexusDeck menggantikan MultEQ Editor atau A1 Evo? +
Tidak. NexusDeck tidak mengukur ruangan Anda dan tidak membuat kurva. Aplikasi ini menyimpan, membandingkan, dan mengirim file yang dibuat oleh alat-alat tersebut. Pengeditan gain-nya hanya memotong filter yang sudah ada di file tersimpan, dan hasilnya disimpan di samping file itu.
Apakah berfungsi dengan Dirac Live? +
Ya, untuk membaca dan beralih antar slot Dirac Live dan memutar ulang pengiriman Dirac Live yang Anda rekam sendiri, bukan untuk membuat filter. NexusDeck memutar ulang pengiriman ke sebuah slot, memilih slot itu dan membacanya kembali; hasilnya menyatakan: tersimpan, tidak tersimpan atau tidak diketahui. Speaker Preset itu lalu memakai Dirac Live, bukan Audyssey.
Apakah NexusDeck memeriksa file sebelum mengirimnya? +
Ya. Sebelum menulis apa pun, NexusDeck memeriksa file terhadap receiver: model, versi MultEQ, dan kanal. Ketidakcocokan diblokir beserta alasannya, dan tidak ada yang ditulis.
Berapa harga NexusDeck? +
NexusDeck gratis diunduh. Tanpa Pro, aplikasi ini memasangkan satu receiver plus demo, menyimpan tiga file kurva hasil impor plus contoh, dan mengirim ke Speaker Preset 1, dengan total 15 pengiriman, termasuk pengiriman Dirac Live. Pro adalah satu pembelian dalam aplikasi, $19.99 di AS, dan menambahkan pengiriman tanpa batas ke preset mana pun, receiver dan file kurva tanpa batas, perbandingan banyak kurva, sakelar Speaker Preset di bilah atas, Quick / Smart Select, Batch Map, dan file cadangan pustaka. Cadangan preset, yang dibuat sebelum setiap pengiriman .ady atau .oca atau dengan Back up now, gratis.
Apakah ada panduan pengguna? +
Ya. Panduan pengguna NexusDeck ada di nexusdeck.app.
