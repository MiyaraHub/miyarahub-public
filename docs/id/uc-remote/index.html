Cara kerjanya

Langsung ke remote Anda. Tanpa cloud.

UC Remote dipasangkan dengan remote Unfolded Circle Anda di Wi-Fi Anda sendiri dan berkomunikasi langsung dengannya, memakai antarmuka integrasi milik remote itu sendiri. Pengaturan Anda tidak pernah menyentuh server eksternal.

1

Pasangkan Remote Anda

Masukkan alamat IP Unfolded Circle Remote Two atau Remote 3 Anda dan PIN yang ditampilkannya. UC Remote memasangkan dengan aman dan menarik profil, halaman, aktivitas, dan entitas Anda.

2

Tetap Sinkron

Koneksi dua arah langsung mengalirkan status dari remote - apa yang menyala, apa yang diputar - sementara ketukan Anda langsung kembali sebagai perintah. Tanpa jeda polling, tanpa perjalanan pulang-pergi ke cloud.

3

Kendalikan Semuanya

Jalankan aktivitas, gunakan halaman kustom, kendalikan setiap entitas dan pemutar media, berpindah antar beberapa remote, dan sematkan widget di layar utama - semuanya dari satu aplikasi.

Keamanan & Privasi

Hanya lokal. Tanpa akun. Tanpa cloud.

UC Remote dibangun dengan mengutamakan privasi dan hanya lokal: tanpa ketergantungan cloud, tanpa akun pengguna, dan tanpa pengumpulan data selain laporan crash.

◉

Tanpa Relay Cloud

Setiap perintah dan aliran status langsung berlangsung langsung antara ponsel dan remote Anda lewat Wi-Fi lokal. Tidak ada yang keluar dari jaringan Anda.

◎

Tanpa Akun

Tanpa pendaftaran, tanpa email, tanpa akun MiyaraHub. Pasangkan dengan PIN remote Anda dan Anda langsung memegang kendali.

▣

Akses Berpasangan PIN

Pemasangan menukar token akses aman yang disimpan secara lokal di perangkat Anda dan hanya dipakai untuk berkomunikasi dengan remote Anda.

◆

Hanya Penyimpanan Lokal

Alamat remote dan preferensi aplikasi disimpan di perangkat Anda. Tidak ada yang disinkronkan ke server.

▢

Hanya Tindakan Anda

Perintah hanya dikirim saat Anda bertindak. Tidak ada yang berjalan otomatis atau di latar belakang tanpa sepengetahuan Anda.

☰

Hanya Izin Jaringan

Satu-satunya izin yang dibutuhkan UC Remote adalah akses jaringan lokal, yang digunakan semata-mata untuk menjangkau remote Anda di Wi-Fi.

FAQ

Pertanyaan yang sering diajukan.

Semua yang perlu Anda ketahui tentang UC Remote.

Apakah UC Remote berafiliasi dengan Unfolded Circle? +
Tidak. UC Remote adalah aplikasi pendamping pihak ketiga yang independen, dikembangkan oleh MiyaraHub Technologies LLC. Aplikasi ini tidak dibuat, didukung, disponsori, atau berafiliasi dengan Unfolded Circle dengan cara apa pun. "Unfolded Circle," "Remote Two," dan "Remote 3" adalah merek dagang milik pemiliknya masing-masing; kami menggunakan nama-nama tersebut semata-mata untuk menjelaskan kompatibilitas.
Dengan perangkat apa saja aplikasi ini bekerja? +
UC Remote bekerja dengan Unfolded Circle Remote Two dan Remote 3 di jaringan lokal Anda. Jika remote Anda dapat dijangkau di Wi-Fi yang sama dengan ponsel, UC Remote dapat dipasangkan dengannya dan mencerminkan aktivitas, halaman, dan entitasnya.
Bagaimana aplikasi terhubung ke remote saya? +
Lewat Wi-Fi lokal Anda. Setelah pemasangan PIN sekali saja, UC Remote menjaga saluran peristiwa langsung tetap terbuka agar selalu sinkron dengan status remote Anda, dan mengirim perintah Anda secara langsung. Tidak ada relai cloud dan tidak ada akun - semuanya tetap di jaringan Anda.
Apakah saya perlu akun atau koneksi internet? +
Tidak perlu akun, selamanya. UC Remote hanya membutuhkan jaringan lokal Anda untuk menjangkau remote - tidak ada yang keluar dari Wi-Fi Anda, dan tidak ada layanan cloud untuk didaftarkan.
Bisakah saya mengontrol lebih dari satu remote? +
Bisa. Pasangkan remote Unfolded Circle sebanyak yang Anda mau dan berpindah antar remote dengan sekali ketuk. Setiap remote menyimpan profil, halaman, dan entitasnya sendiri.
Di platform apa UC Remote tersedia? +
UC Remote adalah aplikasi native untuk ponsel dan tablet Android, tersedia di Google Play.
