Compatibilità

Funziona con il tuo controller UniFi.

Network Deck supporta sia le console UniFi OS sia i controller UniFi Network standalone. Riconosce automaticamente quali endpoint espone il tuo firmware e adatta l'interfaccia di conseguenza: le funzioni che non hai semplicemente non compaiono.

◉ Console UniFi OS

  • UDM Pro SE (verificato)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Controller standalone

  • UniFi Network 10.x (verificato)
  • Self-hosted su Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Autenticazione

  • Nome utente + password dell'amministratore locale
  • Autenticazione a due fattori (TOTP)
  • X-API-KEY per l'accesso programmatico
  • Nessun account UniFi Cloud richiesto

◆ Piattaforme mobili

  • iOS 13 e successivi
  • Android 5.0 (API 21) e successivi
  • Layout per telefono e tablet
  • Temi chiaro e scuro

Tolleranza al firmware: Network Deck riconosce automaticamente gli endpoint esposti dal tuo controller e si adatta alle varianti JSON specifiche del firmware (nomi di campo diversi, conversioni di tipo, più formati per l'API di integrazione). Gli account sub-admin potrebbero ricevere un errore 401 su alcuni endpoint: è un limite di permessi del controller, non un limite dell'app.

Come funziona

Diretta al tuo controller. Nessun relay cloud.

Network Deck dialoga direttamente con il tuo controller UniFi sulla rete locale (o tramite VPN). Le tue credenziali e i dati della tua rete non passano mai da un server MiyaraHub.

1

Aggiungi il tuo controller

Inserisci il nome host o l'IP del controller, la porta (predefinita 443 per UniFi OS, 8443 per standalone) e le credenziali dell'amministratore locale. Network Deck riconosce automaticamente se usi UniFi OS o un controller standalone.

2

Autenticati in locale

Accedi con nome utente e password dell'amministratore locale. L'autenticazione a due fattori è supportata end-to-end. Preferisci le chiavi API? Usa X-API-KEY per l'accesso programmatico e salta del tutto il flusso con i cookie.

3

Gestisci tutto a colpo d'occhio

Guarda il grafico della banda in tempo reale, disconnetti un client indisciplinato, attiva una regola firewall, riavvia una porta PoE, invita un ospite Teleport o passa a un altro sito: ogni azione passa dal controller e aggiorna il flusso di eventi in tempo reale.

Sicurezza & privacy

Solo locale. Nessun account. Nessun relay cloud.

Network Deck è progettata con un'architettura solo locale che mette la privacy al primo posto. Nessun account MiyaraHub, nessun relay cloud, nessuna raccolta di dati oltre ai report di arresto anomalo.

◉

Nessun relay cloud

Tutti i comandi e i flussi in tempo reale passano direttamente tra il tuo telefono e il tuo controller, sul Wi-Fi locale o tramite VPN. Nulla passa da server esterni.

▣

Autenticazione UniFi standard

Usa le stesse credenziali dell'amministratore locale (o la chiave API) dell'interfaccia web di UniFi Network. Le credenziali sono salvate in iOS Keychain / Android Keystore sul dispositivo e non vengono mai trasmesse fuori dal dispositivo, se non al tuo controller.

◎

Nessun account MiyaraHub

Nessuna registrazione, nessuna email, nessun account MiyaraHub. Installa, punta l'app al tuo controller e sei dentro.

◈

Analisi minime

Firebase Crashlytics solo per le segnalazioni di errori. Nessun tracciamento dell'uso, nessuna pubblicità, nessuna vendita di dati. Gli errori di rete vengono registrati come non fatali per aiutarci a migliorare la compatibilità con i firmware, senza raccogliere la struttura della tua rete.

◆

Permessi rispettati

L'app opera entro i permessi del tuo account amministratore UniFi. I sub-admin vedono solo ciò che il controller consente loro di vedere. Nessuna escalation di privilegi, nessuna backdoor.

◐

Solo permesso di rete

L'unico permesso del dispositivo richiesto da Network Deck è l'accesso alla rete, usato esclusivamente per collegarsi al tuo controller UniFi sulla rete locale (o tramite VPN).

FAQ

Domande frequenti.

Tutto quello che c'è da sapere su Network Deck.

Network Deck è affiliata a Ubiquiti o UniFi? +

Non è creata, approvata, sponsorizzata né affiliata in alcun modo a Ubiquiti Inc. «Ubiquiti», «UniFi», «UniFi OS», «UniFi Network», «UDM», «UDR», «UCG», «Teleport» e tutti i nomi di prodotto correlati sono marchi di Ubiquiti Inc. Usiamo questi nomi esclusivamente per indicare la compatibilità (uso nominativo corretto).
Quali controller UniFi sono supportati? +
Network Deck supporta sia le console UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) sia i controller UniFi Network standalone con versione v10.x su Linux, Docker o Windows. All'accesso l'app riconosce automaticamente la piattaforma e adatta l'interfaccia agli endpoint che il tuo firmware espone davvero: le funzioni che non hai semplicemente non compaiono. Testata dal vivo su UDM Pro SE (UniFi OS 5.0.16) e su Network 10.2.105 standalone.
Come comunica Network Deck con il mio controller? +
Network Deck usa la stessa API locale dell'interfaccia web di UniFi Network: una combinazione dei classici endpoint /rest e /cmd (con autenticazione di sessione basata su cookie) e della più recente API di integrazione v2. Apre inoltre un WebSocket verso il controller per ricevere gli eventi in tempo reale. Tutta la comunicazione avviene direttamente tra il tuo telefono e il controller, sulla rete locale o tramite VPN.
Mi serve un account cloud UniFi? +
No. Network Deck usa solo l'autenticazione locale. Accedi con nome utente e password dell'amministratore locale UniFi (oppure con una chiave API). Se oggi il tuo controller è raggiungibile solo tramite il login cloud di ui.com, per usare Network Deck dovrai abilitare un account amministratore locale in Settings → Admins. Il controller non comunica mai con noi, e noi non comunichiamo mai con il cloud di Ubiquiti per tuo conto.
Posso gestire regole firewall e port forward? +
Sì. Network Deck offre uno stack firewall completo: policy (consenti / blocca / ispeziona), port forward con CRUD, regole e rotte di traffico, gruppi firewall, zone firewall (matrice di policy v2) e app / gruppi DPI. Tutto si attiva e disattiva direttamente dall'elenco, senza passare da una finestra all'altra.
Supporta il multi-sito? +
Sì. Se il tuo controller gestisce più siti, Network Deck mostra in alto un selettore di sito. Ogni funzione - dashboard, client, firewall, VPN - fa riferimento al sito selezionato. Si cambia con un tocco.
Quanto costerà Network Deck? +
Network Deck sarà un acquisto singolo da $4.99 su App Store, Google Play e Microsoft Store. Nessun abbonamento, nessuna pubblicità, nessun acquisto in-app. Il prezzo potrebbe cambiare prima del lancio pubblico.
Posso usarla da remoto (fuori casa / ufficio)? +
Network Deck si collega al nome host o all'IP che configuri. Se il tuo controller è raggiungibile tramite VPN, Tailscale, WireGuard o una porta inoltrata, l'app funziona anche da remoto. Ti consigliamo di usare una VPN o Tailscale invece di esporre direttamente il controller UniFi a internet.
Quali piattaforme sono supportate? +
Network Deck funziona sia su iOS (13 e successivi) sia su Android (5.0 / API 21 e successivi). Sono supportati sia i layout per telefono sia quelli per tablet. L'app sarà lanciata contemporaneamente su App Store, Google Play e Microsoft Store.
