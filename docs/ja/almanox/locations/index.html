保存した場所

Almanoxのすべての数値(太陽のイベント、判定、天の川の中心部、月の時刻)は、地球上の1点に対して計算されます。「場所」は、その1点を選ぶ画面です。GPS、都市名、正確な座標から選び、保存しておけば、実際に撮影する場所を切り替えられます。

たどり着く方法

空を計算する場所

「今日」または「今夜」の上部にある場所の名前をタップして、「場所」を開きます。

場所の名前は、「今日」と「今夜」の両方の画面の上部にあります。タップすると「場所」画面が開き、保存したすべての場所が一覧になり、現在使用中のものに印が付きます。切り替えはワンタップで、タイルを選ぶだけでアプリ全体がその地点に合わせて再計算され、次回のためにAlmanoxが選択を記憶します。

計画の対象となる場所を設定する方法は3つあります。

  • 現在地を使用 - GPS位置情報を再取得します。処理中は「現在地を取得しています」というダイアログが表示されます。位置を特定できない場合(権限の拒否、位置情報サービスのオフ、その他のエラー)は、Almanoxが位置情報を利用できないことをお知らせし、何も表示せずに終わらせるのではなく、内蔵のニューヨークの位置情報に切り替えます。
  • 都市を検索 - 場所の名前を入力して検索します。近くの候補が座標とともに一覧表示され、タップすると保存されます。入力した名前、または入力欄を空にした場合はその座標が使われます。
  • 座標 - 緯度と経度を直接入力します。実際の範囲(-90〜90、-180〜180)で検証され、任意でカスタム名を付けられます。名前を空にすると、Almanoxが座標を逆ジオコーディングして場所の名前を付けます。

整理整頓

切り替え、削除、デフォルト

リストは自由に整理できます。ただし、どこも選べなくなることがないように、1つだけ安全策があります。

  • 切り替え - 保存したタイルをタップすると、その場所が使用中になります。変更するまで、使用中の場所がすべての画面の基準になります。
  • 削除 - タイルを左にスワイプすると削除できます。最後に残った1つの場所は削除できません。アプリが計算の基準を失わないように、常に最低1つが必要です。
  • DEFAULTピル - 内蔵のニューヨークのフォールバックが保存済みの場所に含まれている場合、その場所に印が付きます。どれが安全網なのか、常にわかります。

無料版では3か所まで保存できるので、自宅、近くの暗い場所、旅行先をカバーできます。Proでは上限がなくなり、多くの場所で計画する方に最適です。

都市の検索と逆ジオコーディングには通信が必要です。いったん保存した場所は、太陽、月、星図の情報すべてが、電波がなくてもデバイス上で計算されます。
