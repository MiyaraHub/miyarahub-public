スタジオについて

小さなスタジオ。丁寧な仕事。

MiyaraHub Technologiesは、テキサス州Van Alstyneにある小さな独立系LLCで、Meir Miyaraが所有・運営しています。

私たちは工場ではありませんし、そのふりをするつもりもありません。細部を正しく仕上げることにこだわる小さなチームであり、自分の機器で、自分のギアを操作するために使いたいと思えるソフトウェアを作っています。

私たちはオープンに開発し、アプリを使ってくださる方々の声に耳を傾け、素早く修正します。リリースに含まれる多くの内容は、コミュニティの誰かからのメッセージから始まっており、これからもそうありたいと思っています。

誇張はしません。私たちのアプリには、すでに完成度が高く何千人もの方に届いているものもあれば、まだ開発中のものもあり、どちらなのかははっきりお伝えします。お約束するのは、誠実な努力と、ネイティブなソフトウェア、デフォルトでデバイス上で動作すること、そしてすでにお持ちのハードウェア上で動くものにサブスクリプションを求めないことです。
