MiyaraHub / Network Deck

Network Deck · UniFiネットワークコントローラー向けあなたのUniFiネットワークを、この手に。✦

UniFiネットワークを、スマートフォンから完全にコントロール。

Ubiquiti UniFiネットワークコントローラー向けのプレミアムモバイルアプリ。ライブダッシュボード、クライアントとデバイスの管理、WiFiとVLANの制御、ファイアウォールポリシー、ポート制御、VPN、スピードテスト、マルチサイト切り替えまで、すべてスマートフォンからコントローラーに直接アクセスできます。

機能

UniFiコントローラーを、ポケットに。

Network Deckは、UniFi OS（UDM Pro、Cloud Gateway、Dream Machine）でもスタンドアロンのUniFi Networkコントローラーでも、UniFiコントローラーのローカルAPIと直接やり取りします。ブラウザを開かずに、クライアント、WiFi、ファイアウォール、ポート、VPN、インサイトを操作できます。

対応状況

お使いのUniFiコントローラーに対応。

Network Deckは、UniFi OSコンソールとスタンドアロンのUniFi Networkコントローラーの両方に対応しています。お使いのファームウェアが公開しているエンドポイントを自動検出してUIを合わせるため、使えない機能は表示されません。

◉ UniFi OSコンソール

  • UDM Pro SE（動作確認済み）
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway（UCG）
  • UniFi Dream Machine

▣ スタンドアロンコントローラー

  • UniFi Network 10.x（動作確認済み）
  • Linux / Docker上のセルフホスト
  • Cloud Key Gen2 / Plus
  • UniFi Network Server（Windows）

◎ 認証

  • ローカル管理者のユーザー名 + パスワード
  • 二要素認証（TOTP）
  • プログラムからのアクセス用X-API-KEY
  • UniFiクラウドアカウントは不要

◆ 対応モバイルプラットフォーム

  • iOS 13以降
  • Android 5.0（API 21）以降
  • スマートフォンとタブレットのレイアウト
  • ライトテーマとダークテーマ

ファームウェアへの対応力：Network Deckは、コントローラーが公開しているエンドポイントを自動検出し、ファームウェア固有のJSONの違い（フィールド名の揺れ、型変換、インテグレーションAPIの複数の形式）にも対応します。サブ管理者アカウントでは一部のエンドポイントが401を返すことがありますが、これはアプリの制限ではなく、コントローラー側の権限の制限です。

使い方

コントローラーへ直接接続。クラウド中継なし。

Network Deckは、ローカルネットワーク（またはVPN）経由でUniFiコントローラーと直接通信します。認証情報やネットワークデータがMiyaraHubのサーバーを経由することはありません。

1

コントローラーを追加

コントローラーのホスト名またはIP、ポート（UniFi OSは既定で443、スタンドアロンは8443）、ローカル管理者の認証情報を入力します。Network Deckは、UniFi OSかスタンドアロンコントローラーかを自動的に検出します。

2

ローカルで認証

ローカル管理者のユーザー名とパスワードでサインインします。二要素認証にもエンドツーエンドで対応しています。APIキーをご希望ですか？プログラムからのアクセスにはX-API-KEYを使えば、Cookieのフローを完全に省略できます。

3

ひと目で管理

ライブ帯域グラフの確認、問題のあるクライアントのキック、ファイアウォールルールの切り替え、PoEポートの再起動、Teleportゲストの招待、別のサイトへの切り替えまで。すべての操作がコントローラーと往復し、ライブイベントストリームに反映されます。

セキュリティ & プライバシー

ローカルのみ。アカウント不要。クラウド中継なし。

Network Deckは、プライバシーを最優先にしたローカル専用のアーキテクチャで設計されています。MiyaraHubアカウントもクラウド中継も不要で、クラッシュレポート以外のデータ収集はありません。

◉

クラウド中継なし

すべてのコマンドとライブストリームは、ローカルWi-FiまたはVPN経由で、お使いのスマートフォンとコントローラーの間で直接行われます。外部サーバーを経由するものはありません。

▣

標準のUniFi認証

UniFi NetworkのWeb UIと同じローカル管理者の認証情報（またはAPIキー）を使用します。認証情報はデバイス上のiOS Keychain / Android Keystoreに保存され、コントローラー以外にデバイスの外へ送信されることはありません。

◎

MiyaraHubアカウント不要

サインアップもメールアドレスもMiyaraHubアカウントも不要です。インストールして、コントローラーを指定すれば、すぐに使えます。

◈

最小限の分析

Firebase Crashlyticsは不具合レポートのみに使用します。利用状況の追跡も、広告も、データ販売もありません。ネットワークエラーは非致命的なものとして記録され、お客様のネットワーク構成を収集することなく、ファームウェア互換性の改善に役立てられます。

◆

権限を尊重

アプリは、お使いのUniFi管理者アカウントが持つ権限の範囲内で動作します。サブ管理者には、コントローラーが許可した内容のみが表示されます。権限昇格もバックドアもありません。

◐

ネットワーク権限のみ

Network Deckが必要とするデバイス権限は、ネットワークアクセスのみです。ローカルネットワーク（またはVPN経由）でUniFiコントローラーに接続するためだけに使用されます。

よくある質問

Network Deckについて知っておきたいことのすべて。

Network DeckはUbiquitiやUniFiと提携していますか？ +
いいえ。Network Deckは、MiyaraHub Technologies LLCが開発した独立したサードパーティ製アプリケーションです。Ubiquiti Inc.によって作成、承認、後援されたものではなく、Ubiquiti Inc.といかなる形でも提携していません。「Ubiquiti」「UniFi」「UniFi OS」「UniFi Network」「UDM」「UDR」「UCG」「Teleport」および関連するすべての製品名は、Ubiquiti Inc.の商標です。これらの名称は、互換性を説明する目的のみで使用しています（指示的公正使用）。
対応しているUniFiコントローラーは？ +
Network Deckは、UniFi OSコンソール（UDM Pro / Pro SE、UCG、Dream Machine、UDR、Cloud Key Gen2 / Plus）と、Linux、Docker、Windows上で動作するv10.xのスタンドアロンUniFi Networkコントローラーの両方に対応しています。接続時にプラットフォームを自動検出し、お使いのファームウェアが実際に公開しているエンドポイントに合わせてUIを調整するため、使えない機能は表示されません。UDM Pro SE（UniFi OS 5.0.16）とスタンドアロンのNetwork 10.2.105で実機テスト済みです。
Network Deckはコントローラーとどのように通信しますか？ +
Network Deckは、UniFi NetworkのWeb UIと同じローカルAPIを使用します。具体的には、従来の/restと/cmdのエンドポイント（Cookieベースのセッション認証）と、新しいv2インテグレーションAPIの組み合わせです。また、ライブイベントをストリーミングするために、コントローラーへWebSocket接続も開きます。すべての通信は、ローカルネットワークまたはVPN経由で、お使いのスマートフォンとコントローラーの間で直接行われます。
UniFiのクラウドアカウントは必要ですか？ +
いいえ。Network Deckはローカル認証のみを使用します。UniFiのローカル管理者のユーザー名とパスワード（またはAPIキー）でサインインしてください。現在ui.comのクラウドログインでしかコントローラーにアクセスできない場合は、Network Deckを使うためにSettings → Adminsでローカル管理者アカウントを有効にしてください。コントローラーが当社と通信することはなく、当社がお客様に代わってUbiquitiのクラウドと通信することもありません。
ファイアウォールルールやポートフォワードを管理できますか？ +
はい。Network Deckにはファイアウォール機能一式があります。ポリシー（許可 / ブロック / 検査）、CRUD対応のポートフォワード、トラフィックルールとルート、ファイアウォールグループ、ファイアウォールゾーン（v2ポリシーマトリクス）、DPIアプリ / グループに対応しています。すべて一覧画面からそのまま切り替えられ、ダイアログを何度も開く必要はありません。
マルチサイトに対応していますか？ +
はい。コントローラーが複数のサイトを管理している場合、Network Deckの上部にサイトスイッチャーが表示されます。ダッシュボード、クライアント、ファイアウォール、VPNなど、すべての機能が現在選択中のサイトを対象に動作します。ワンタップで切り替えられます。
Network Deckの価格は？ +
Network Deckは、App Store、Google Play、Microsoft Storeで$4.99の買い切りになる予定です。サブスクリプションも広告もアプリ内課金もありません。価格は正式リリース前に変更される場合があります。
リモート（自宅 / オフィスの外）から使えますか？ +
Network Deckは、設定したホスト名またはIPアドレスに接続します。VPN、Tailscale、WireGuard、または転送ポート経由でコントローラーに到達できる場合、アプリはリモートでも動作します。UniFiコントローラーをインターネットに直接公開するのではなく、VPNまたはTailscaleのご利用をおすすめします。
対応プラットフォームは？ +
Network DeckはiOS（13以降）とAndroid（5.0 / API 21以降）の両方で動作します。スマートフォンとタブレットの両方のレイアウトに対応しています。アプリは、App Store、Google Play、Microsoft Storeで同時にリリースされる予定です。
