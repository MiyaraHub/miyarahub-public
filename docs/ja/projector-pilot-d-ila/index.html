MiyaraHub / Projector Pilot D-ILA

Projector Pilot D-ILA · JVC D-ILAプロジェクター向けD-ILAを、手のひらに。✦

スマートフォン、タブレット、パソコンから使える、JVC D-ILAプロジェクター向けのローカルネットワークリモコン。

Projector Pilot D-ILAは、プロジェクターに設定したネットワークパスワードを使い、ネットワーク制御ポート(TCP 20554)経由でプロジェクターと直接通信します。電源、入力、メニュー操作、ピクチャーモード、HDRレベル、カラー、モーション、レンズ、設置、アスペクトに加え、シーン、メンテナンス、ホームオートメーションにも対応。アカウントもクラウドサービスも介しません。

使い方

直接のネットワーク接続。クラウドは介しません。

Projector Pilot D-ILAは、ローカルネットワーク上のプロジェクターに直接接続します。MiyaraHubのサーバーもアカウントもありません。

1

プロジェクターを探す

ネットワークをスキャンすると、サブネットのすべてのアドレスでポート20554を試します。または、IPアドレスを指定してプロジェクターを追加します。

2

パスワードでサインイン

プロジェクターに設定したネットワークパスワードを入力します。アプリはTCP 20554でサインインしてモデルを読み取り、パスワードをデバイスの安全なストレージに保管します。

3

操作を始める

お使いのモデルが対応するリモコン、画質、レンズ、設定の各画面を使い、シーンを保存し、必要ならホームオートメーションを連携できます。

セキュリティ & プライバシー

ローカル優先。アカウント不要。広告なし。

アプリが通信するのは、ローカルネットワーク上のプロジェクターと、アプリ内購入のためのストアのみです。それ以外に何をいつ送信するかは、ここに記載しています。

◉

プロジェクターへ直接

コマンドとステータスの取得は、ローカルネットワーク上でお使いのデバイスとプロジェクターの間で直接行われ、クラウドサービスを介しません。

◎

アカウントは不要

サインアップもMiyaraHubアカウントも不要です。プロジェクターのアドレスをスキャンまたは入力して接続するだけです。

▣

クラッシュレポートと分析

不具合を修正できるよう、クラッシュレポートはAndroid、iPhone、iPadでは初期状態でオンになっており、設定でオフにできます。クラッシュレポートには、アプリを停止させたエラーのテキストが含まれることがあり、まれにネットワークアドレスが記載される場合があります。macOSとWindowsのアプリは送信しません。匿名の利用状況分析は、オプトインするまでオフで、送信するのは件数と結果のみです。プロジェクター名、アドレス、パスワード、ハブのアドレスが含まれることはありません。

◆

パスワードは安全なストレージに保管

各プロジェクターのネットワークパスワードは、デバイスの安全なストレージに保管されます。プロジェクターを追加したHome Assistant以外には送信されず、ログやバックアップにも含まれません。

▢

ホームオートメーションなしでは何も送信されません

ホームオートメーションを購入した場合、アプリは、トリガーを入力したウェブアドレスにのみ、電源と入力を連携したHubitatハブにのみ、プロジェクターのステータスをサインインしたHome Assistantにのみ送信します。購入していない場合、およびデモプロジェクターでは常に、何も送信されません。

☼

購入はストア経由

Pro、ホームオートメーション、バンドルは、ストアが処理する買い切りの購入です。MiyaraHubがお支払い情報を目にすることはありません。

どのJVCプロジェクターで使えますか? +
ネットワーク対応のJVC D-ILAプロジェクターに対応します。DLA-NZ900とNZ800、NZ700とNZ500の世代、NZ9、NZ8、NZ7、NP5の世代、NX9、NX7、NX5の世代、以前のX7、X9、X30、X70R、X90Rの各ファミリーで、地域ごとの名称のモデルも含まれます。旧型のHDおよびRS10からRS40のモデルとX3には、ネットワーク制御がありません。
プロジェクターにはどのように接続しますか? +
ローカルネットワーク上で、プロジェクターのネットワーク制御ポートであるTCP 20554に直接接続します。ネットワークをスキャンするかIPアドレスを入力し、プロジェクターに設定したネットワークパスワードでサインインします。クラウドサービスもアカウントもありません。
無料で使えるものと、購入が必要なものは何ですか? +
購入なしでも、電源オンとスタンバイ、HDMI 1、そしてメニュー操作20回分が使え、その後は1日3回です。ProではHDMI 2、無制限のメニュー操作、その他すべてのリモコンキー、シーン、メンテナンス、テストパターン、ウィジェットが利用できます。ホームオートメーションでは、ウェブリクエストのトリガー、Hubitat、Home Assistantが加わります。両方をまとめたバンドルもあり、いずれも買い切りで、サブスクリプションはありません。
アプリは何を、どこへ送信しますか? +
コマンドはプロジェクターに直接送信されます。クラッシュレポートはAndroid、iPhone、iPadでは初期状態でオンになっており、設定でオフにできます。macOSとWindowsのアプリは送信しません。匿名の利用状況分析は、オプトインするまでオフです。ホームオートメーションを使う場合、アプリは入力したウェブアドレス、連携したHubitatハブ、サインインしたHome Assistantにのみ送信します。
Epsonのプロジェクターを持っています。対応するバージョンはありますか? +
