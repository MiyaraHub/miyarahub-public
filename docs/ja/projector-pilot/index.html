機能

プロジェクターの完全なコントロールを、この手に。

Projector Pilot PJLink & VP21は、ローカルネットワーク経由でEpsonプロジェクターに接続し、電源や画質からレンズ、ジオメトリーまで、あらゆる設定を完全にコントロールできます。プロジェクター本体に触れたり、物理リモコンを探したりする必要はありません。

使い方

ネットワークに直接接続。クラウドは不要です。

Projector Pilot PJLink & VP21は、ローカルネットワーク上のプロジェクターと直接通信します。MiyaraHubのサーバーもアカウントもありません。

1

プロジェクターを探す

PJLink(4352)とESC/VP.net(3629)のポートで応答するプロジェクターをネットワーク上でスキャンするか、IPアドレスを入力します。アプリがモデルと対応機能を検出します。

2

ネットワークで接続

電源、入力、設定にはESC/VP21(ESC/VP.net経由、TCP 3629)とPJLink(TCP 4352)を使い、プロジェクターが対応している場合はEpson Web Control(HTTP 80、Digest認証でサインイン)も使います。すべてローカルネットワーク内で完結します。

3

すべてを操作

ピクチャー設定の調整、入力の切り替え、電動レンズの操作、キーストーン補正の管理、ランプ使用時間の確認、オンスクリーンディスプレイの操作まで、すべてをひとつのスマートなアプリで。

セキュリティ & プライバシー

ローカル優先。アカウント不要。広告なし。

アプリが通信するのは、ローカルネットワーク上のプロジェクターと、購入処理のためのストアのみです。それ以外に何をいつ送信するかは、ここに記載しています。

◉

クラウド中継なし

すべてのコマンドとステータスの取得は、ローカルネットワーク上でお使いのデバイスとプロジェクターの間で直接行われ、クラウドサービスを介しません。

◎

アカウントは不要

サインアップもメールアドレスもMiyaraHubアカウントも不要です。アプリを開いてプロジェクターのIPアドレスを入力すれば、すぐに操作できます。

▣

診断情報

Firebase Crashlyticsは、不具合を修正できるように、お客様の名前ではなくランダムIDに紐づけてクラッシュレポートを送信します。利用状況の分析は、オプトインするまでオフです。アカウントも広告もありません。

◆

パスワードは安全なストレージに保管

プロジェクターのパスワードはデバイスの安全なストレージに保管されます。アドレスとアプリの設定は、アプリのローカルストレージに保存されます。MiyaraHubのサーバーに同期されるものはありません。

▢

ホームオートメーションは、設定したときだけ

ホームオートメーションを購入した場合、アプリは、入力したウェブアドレス、連携したHubitatハブ、サインインしたHome Assistantに送信します。購入していなければ、スマートホームサービスへは何も送信されません。

☼

ネットワーク権限のみ

アプリは、ローカルネットワーク上のお客様のプロジェクターに接続するためにのみネットワークアクセスを使用し、お客様が設定したメンテナンスのリマインダーのためにのみ通知を使用します。

よくある質問

Projector Pilot PJLink & VP21について知っておきたいことをまとめました。

Projector Pilot PJLink & VP21はEpsonと提携していますか? +
いいえ。Projector Pilot PJLink & VP21は、MiyaraHub Technologies LLCが開発した独立したサードパーティ製アプリです。セイコーエプソン株式会社およびその子会社・関連会社が作成、承認、後援したものではなく、いかなる形でも提携していません。「Epson」はセイコーエプソン株式会社の登録商標です。この名称は互換性を説明する目的でのみ使用しています(指示的公正使用)。
iPhoneやAndroid向けのEpsonプロジェクターアプリはありますか? +
はい。Projector Pilot PJLink & VP21は、iPhoneとiPad(iOS 15以降)、Android、Mac(macOS 12以降)、Windowsで動作し、App Store、Google Play、Mac App Store、Microsoft Storeから入手できます。ローカルネットワーク上のEpsonプロジェクターを操作します。
Home Cinema 5050UB、LS12000、QB1000で使えますか? +
はい。EH-QB1000は実機で動作を確認済みで、EH-LS12000 / Pro Cinema LS12000とEH-TW8400 / Home Cinema 5050UBのプロファイルのほか、対応機種に掲載しているその他のモデルのプロファイルも搭載しています。アプリは接続時にモデルを読み取り、そのモデルが対応する操作だけを表示します。
Epson iProjectionの代わりになりますか? +
役割が異なります。Epson iProjectionは、画面や写真をプロジェクターに送るアプリです。Projector Pilot PJLink & VP21はコンテンツを投写するものではなく、電源、入力、画質、HDR、レンズ、キーストーン、メンテナンスを操作するリモコン兼設定コントローラーで、シーンとホームオートメーションにも対応します。
対応しているプロジェクターは？ +
ネットワーク対応のEpsonホームシネマプロジェクター。EH-QB1000、LS12000、LS11000、LS800、LS500のレーザーモデルから、6050UB、5050UB、4010、3800のランプモデル、さらに以前の6040UB、5040UB、5030UBの世代までに対応します。小型のHome Cinema、LS300、LS650、EFの各モデルでは電源と入力を操作できます。Home Cinema 3200にはネットワーク制御がありません。基本的なPJLink制御は、他メーカーのプロジェクターでも動作します。
プロジェクターとはどのように通信しますか? +
いずれもローカルネットワーク内で、3通りの方法を使います。TCPポート3629のESC/VP.net経由のESC/VP21(パスワードを設定している場合はプロジェクターのパスワードを使用)、電源、入力、ステータス用のTCPポート4352のPJLink、そして公開されている設定項目向けのHTTPポート80のEpson Web Controlインターフェース(Digest認証でサインイン)です。
電動レンズを操作できますか？ +
はい。電動レンズを搭載したプロジェクターで利用できます。レンズのシフト、フォーカス、ズームを操作でき、アスペクト比やスクリーン位置ごとにレンズメモリーのプリセットを保存して呼び出せます。電動レンズのないモデルでは、レンズ操作は表示されません。
HDRと広色域に対応していますか？ +
はい。対応しているモデルで利用できます。ダイナミックレンジ(オート、SDR、HDR PQ、HLG。モデルが対応するもの)と色空間を選択でき、キャリブレーション用にチャンネルごとのRGBゲインとオフセットも調整できます。
スタンバイから電源を入れられますか？ +
はい。スタンバイ中もプロジェクターがネットワークを有効に保つ場合に限ります。有線LANとプロジェクターのスタンバイ時ネットワーク設定を使うと、スタンバイからの起動が確実になります。
Projector Pilot PJLink & VP21の料金はいくらですか? +
ダウンロードは無料で、プロジェクター1台と基本操作が含まれます。Proは買い切りのアンロックで$9.99、ホームオートメーションは$2.99、両方をまとめたバンドルは$11.99です。サブスクリプションも広告もありません。一度購入すれば、ずっとご利用いただけます。
