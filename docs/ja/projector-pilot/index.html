機能

プロジェクターの完全なコントロールを、この手に。

Projector Pilotは、Wi-FiでEpsonプロジェクターに接続し、電源や画質からレンズ、ジオメトリーまで、あらゆる設定を完全にコントロールできます。プロジェクター本体に触れたり、物理リモコンを探したりする必要はありません。

使い方

ネットワークに直接接続。クラウドは不要です。

Projector Pilotは、標準的なネットワークプロトコルを使って、Wi-Fi経由でプロジェクターと直接通信します。お客様のデータが外部サーバーを経由することはありません。

1

プロジェクターを追加

EpsonプロジェクターのIPアドレスを入力します。Projector PilotがPJLinkとWeb Controlの接続をテストし、モデルを検出して、利用可能な機能をすべて自動で見つけます。

2

Wi-Fiで接続

Projector Pilotは、スタンバイの検出と電源制御にPJLinkを使い、電源オン時には、画質、レンズ、各種設定のフルコントロールにEpson Web Control APIを使います。すべてがローカルネットワーク内で完結します。

3

すべてを操作

ピクチャー設定の調整、入力の切り替え、電動レンズの操作、キーストーン補正の管理、ランプ使用時間の確認、オンスクリーンディスプレイの操作まで、すべてをひとつのスマートなアプリで。

セキュリティ & プライバシー

ローカルのみ。アカウント不要。クラウド不要。

Projector Pilotは、プライバシーを最優先にしたローカル専用のアーキテクチャで設計されています。クラウド依存もアカウントも不要で、クラッシュレポート以外のデータ収集はありません。

◉

クラウド中継なし

すべてのコマンドとステータスの取得は、ローカルWi-Fi経由で、お使いのスマートフォンとプロジェクターの間で直接行われます。ネットワークの外には何も出ません。

◎

アカウントは不要

サインアップもメールアドレスもMiyaraHubアカウントも不要です。アプリを開いてプロジェクターのIPアドレスを入力すれば、すぐに操作できます。

▣

最小限の分析

Firebase Crashlyticsは不具合レポートのみに使用します。個人データも、利用状況の追跡も、広告もありません。プロジェクターのデータがスマートフォンの外に出ることはありません。

◆

ローカル保存のみ

プロジェクターのIPアドレス、認証情報、アプリの設定は、SharedPreferencesを使ってお使いのデバイス上にローカル保存されます。サーバーに同期されるものはありません。

▢

ユーザーが指示した操作のみ

アプリがプロジェクターにコマンドを送るのは、お客様が明示的に操作したときだけです。お客様の知らないうちに、自動で、またはバックグラウンドで何かが実行されることはありません。

☼

ネットワーク権限のみ

Projector Pilotが必要とするデバイス権限は、インターネット / ネットワークアクセスのみです。ローカルWi-Fi上のプロジェクターに接続するためだけに使用されます。

よくある質問

Projector Pilotについて知っておきたいことのすべて。

Projector PilotはEpsonと提携していますか？ +
いいえ。Projector Pilotは、MiyaraHub Technologies LLCが開発した独立したサードパーティ製アプリケーションです。セイコーエプソン株式会社およびその子会社・関連会社によって作成、承認、後援されたものではなく、いかなる形でも提携していません。「Epson」はセイコーエプソン株式会社の登録商標です。この名称は、互換性を説明する目的のみで使用しています（指示的公正使用）。
対応しているプロジェクターは？ +
Projector Pilotは、PJLinkまたはWeb Controlに対応したネットワーク接続のEpsonプロジェクターすべてで動作します。フラッグシップのQB1000やLS12000から、ミッドレンジのホームシネマ、プロ向け設置モデルまで、過去10年以上のほとんどのモデルが対象です。接続時に利用可能な機能を自動検出するため、お使いのプロジェクターが実際に対応している機能だけが表示されます。基本的なPJLink制御は、NEC、Panasonic、Sonyなど、Epson以外のプロジェクターでも動作します。
Projector Pilotはどのようにプロジェクターと通信しますか？ +
Projector Pilotは2つのプロトコルを使用します。ひとつは、スタンバイからの電源オン、入力切り替え、ランプ状態など、プロジェクター全般の制御に使うPJLink（ポート4352）。もうひとつは、画質、レンズ、キーストーン、HDRなどの詳細な設定制御に使う、Digest認証付きのEpson Web Control API（ポート80）です。すべての通信は、お使いのローカルWi-Fiネットワーク内で直接行われます。
電動レンズを操作できますか？ +
はい。電動レンズ搭載のプロジェクターで可能です。Projector Pilotは、レンズシフト（水平と垂直）、フォーカス、ズームのフル操作を、リアルタイムの位置表示とともに提供します。アスペクト比、スクリーン位置、視聴環境ごとに、レンズメモリーのプリセットを保存して呼び出すこともできます。電動レンズのないモデルでは、レンズ操作は自動的に非表示になります。
HDRと広色域に対応していますか？ +
はい。Projector Pilotでは、ダイナミックレンジ（オート、HDR10、HLG、SDR）と色空間（オート、BT.709、BT.2020）を設定でき、精密なカラーキャリブレーションのためにチャンネルごとのRGBゲインとオフセットも調整できます。HDR関連の機能は、対応するモデルでのみ表示されます。
スタンバイから電源を入れられますか？ +
はい。Projector Pilotは、PJLinkを使って、スタンバイ状態のプロジェクターでも電源を入れられます。プロジェクターがネットワークに接続されていれば（スタンバイからの起動には有線LANをおすすめします）、スマートフォンから電源のオン / オフができます。
Projector Pilotの料金は？ +
Projector Pilotは無料でダウンロードでき、基本的な操作が含まれています。Pro版は$9.99の買い切りで解除、Home Automationは$2.99、両方をまとめたバンドルは$11.99です。サブスクリプションも広告もありません。一度購入すれば、ずっとお使いいただけます。価格はリリース前に変更される場合があります。
必要なAndroidのバージョンは？ +
Projector PilotにはAndroid 5.0（API 21）以降が必要です。現時点ではAndroid専用のアプリで、iOS対応は今後のリリースで追加される可能性があります。
