접근성 성명

시행일: 2026년 11월 15일.

1. 목표

miyarahub.com 사이트가 WCAG(Web Content Accessibility Guidelines) 2.2 AA 수준을 충족하는 것을 목표로 합니다. 당사는 사이트에 대해 완전한 적합성 감사를 받은 적이 없으므로 적합하다고 주장하지 않습니다.

2. 측정한 내용

2026년 11월 15일에 자동화 스크립트로 영어 페이지를 점검했습니다. 모든 페이지에는 페이지에 설정된 언어, 정확히 하나의 주 제목, 페이지 제목, 이미지의 대체 텍스트가 있습니다. 본문 텍스트의 페이지 배경 대비 명암비는 7.6 대 1이고, 제목은 17.8 대 1입니다.

3. 알려진 제한 사항

  • 대부분의 페이지에서 단락 안의 링크는 밑줄 없이 빨간색으로 표시됩니다. 주변 텍스트와의 명암비는 1.6 대 1로, 색상만으로 링크를 구분할 때 WCAG가 요구하는 3 대 1에 미치지 못합니다.
  • 더 어두운 카드 배경 위의 빨간색 텍스트는 명암비가 4.2 대 1로, 일반 크기 텍스트에 필요한 4.5 대 1에 미치지 못합니다.
  • 너비가 720 픽셀보다 좁은 화면에서는 상단 메뉴가 숨겨집니다. 같은 페이지가 바닥글에 링크되어 있습니다.
  • 페이지에 "본문 바로가기" 링크가 없으며, 브라우저의 기본 포커스 윤곽선에 의존합니다.
  • 번역된 페이지는 영어 페이지보다 갱신이 늦을 수 있습니다.

당사 앱은 표준 컨트롤을 사용하는 부분에서 iOS, Android, macOS, Windows 각 운영체제의 접근성 설정을 따릅니다. 앱을 WCAG 기준으로 감사한 적은 없습니다.

4. 의견 보내기

이 사이트나 당사 앱의 어떤 부분이 사용 중인 보조 기술로 이용하기 어렵다면, 제목에 "Accessibility"를 넣어 admin@miyarahub.com 주소로 이메일을 보내 주세요. 해당 페이지 또는 앱 화면과 무엇이 잘못되었는지 알려 주세요. 영업일 기준 10일 이내에 회신하는 것을 목표로 하며, 필요한 정보를 다른 형식으로 보내 드릴 수 있습니다.
