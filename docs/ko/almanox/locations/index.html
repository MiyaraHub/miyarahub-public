화면 소개

저장한 장소

Almanox의 모든 수치, 즉 해 이벤트, 평가, 은하수 중심부, 달 시각은 지구상의 한 지점을 기준으로 계산돼요. 장소 화면은 그 지점을 정하는 곳이에요. GPS, 도시 이름, 정확한 좌표로 지정하고 저장해 두면 실제로 촬영하는 곳들을 오가며 볼 수 있어요.

이동 방법

하늘을 계산하는 기준 위치

오늘 또는 오늘 밤 상단의 장소 이름을 탭하면 장소 화면이 열려요.

장소 이름은 오늘 화면과 오늘 밤 화면 상단에 있어요. 탭하면 장소 화면이 열리고, 저장한 모든 장소가 목록으로 나타나며 활성 장소에 표시가 붙어요. 전환은 탭 한 번이면 돼요. 타일을 고르면 앱 전체가 그 지점에 맞춰 다시 계산되고, Almanox가 다음번을 위해 선택을 기억해요.

계획할 위치를 정하는 방법은 세 가지예요.

  • 현재 위치 사용 - GPS 위치를 다시 요청해요. 작동하는 동안 "위치 찾는 중" 대화상자가 표시돼요. 권한 거부, 위치 서비스 꺼짐 등 어떤 이유로든 위치를 얻지 못하면 Almanox가 위치를 사용할 수 없다고 알려 주고, 아무것도 보여 주지 않는 대신 내장된 뉴욕 위치로 되돌아가요.
  • 도시 검색 - 장소 이름을 입력해 검색하면 근처 결과가 좌표와 함께 나열되고, 하나를 탭하면 저장돼요. 입력한 이름을 쓰거나, 입력란을 비워 두면 좌표를 써요.
  • 좌표 - 위도와 경도를 직접 입력해요. 실제 범위(-90에서 90, -180에서 180)로 검증하며 원하는 경우 이름도 지정할 수 있어요. 이름을 비워 두면 Almanox가 좌표를 역지오코딩해 장소 이름을 만들어 줘요.
장소 촬영하는 곳들
정리

전환, 삭제, 기본 장소

목록은 내 마음대로 관리할 수 있어요. 갈 곳이 없어지지 않도록 안전장치가 하나 있을 뿐이에요.

  • 전환 - 저장한 타일을 탭하면 활성 장소가 돼요. 바꾸기 전까지 활성 장소가 모든 화면의 기준이에요.
  • 삭제 - 타일을 왼쪽으로 밀면 삭제돼요. 마지막 하나 남은 장소는 삭제할 수 없어요. 앱이 계산할 곳이 없는 상태가 되지 않도록 항상 하나는 있어야 해요.
  • DEFAULT 표시 - 내장된 뉴욕 대체 위치가 저장 목록에 있을 때 표시되어, 어느 것이 안전망인지 항상 알 수 있어요.

무료에서는 집, 가까운 다크스카이 장소, 여행지를 담을 수 있는 세 곳을 저장할 수 있어요. Pro는 여러 곳을 계획하는 분들을 위해 한도를 무제한으로 풀어 줘요.

도시 검색과 역지오코딩에는 연결이 필요해요. 장소를 저장하고 나면 해, 달, 별자리 지도 수치는 모두 신호 없이 기기에서 계산돼요.

밤만이 아니라 장소까지 계획하세요

Almanox는 $12.99의 1회 결제예요. 구독도, 광고도, 계정도 없어요. 장소를 저장하면 천문력 전체가 각 장소로 따라가요.
