실제 작동 모습

모든 컨트롤이 탭 한 번 거리에 있어요.

AVR Maestro의 실제 스크린샷이에요. 대시보드, 장면, 사운드 모드, 입력, 가상 리모컨, 재생 중, 테마, 멀티 존을 보여 드려요. 탭하면 확대돼요.

기능

리시버 전체 제어를 손안에서.

박스에 들어 있는 리모컨보다 깊은 제어를 제공하며, 모든 것이 실물 리모컨 및 전면 패널과 동기화된 상태를 유지해요.

No. 01

✦ 탭 한 번으로 장면 실행

입력, 볼륨, 사운드 모드, Audyssey/Dirac, Speaker Preset, 채널 레벨, 존, 심지어 튜너까지 전체 설정을 저장하고 탭 한 번으로 모두 불러오세요. 영화의 밤, 게임, 늦은 밤 감상 모두 각자의 장면이 돼요.

No. 02

◉ 볼륨, 입력 & 서라운드

dB 표시가 있는 정밀한 볼륨 제어, 시각적 그리드로 탭 한 번에 입력 소스 전환, 리시버가 지원하는 모든 모드를 담은 전체 서라운드 모드 선택기를 제공해요.

No. 03

▣ 가상 리모컨

탐색 D-pad, 재생 컨트롤, 음소거, 빠른 볼륨 조절이 있는 프리미엄 가상 리모컨이에요. 실물 리모컨을 찾아 헤맬 필요 없이 필요한 모든 것을 쓸 수 있어요.

No. 04

▢ 멀티 존 제어

존 2와 존 3을 독립적으로 제어해요. 존마다 전용 전원, 볼륨, 입력 소스, 빠른 볼륨 프리셋을 하나의 화면에서 사용할 수 있어요.

No. 05

◎ Audyssey & 룸 보정

Audyssey MultEQ, Dynamic EQ, Dynamic Volume, LFC, Containment Amount를 완전히 제어해요. 리시버 메뉴를 헤매지 않고도 룸 보정을 세밀하게 조정할 수 있어요.

No. 06

◆ Dirac Live & IMAX Enhanced 고급

Dirac Live 필터 슬롯 전환, 크로스오버 설정이 있는 IMAX 모드 구성, Auro-3D 프리셋과 처리 강도 조절까지 모두 휴대전화에서 할 수 있어요.

No. 07

╿ 채널별 레벨

전면 좌/우부터 천장 높이 채널까지 시스템의 모든 스피커 볼륨을 독립적으로 조절해요. 룸 보정 후 미세 조정에 안성맞춤이에요.

No. 08

⚙ 시스템 구성

HDMI 출력 설정, 전면 패널 디머, 12V 트리거 출력, 에코 모드, 자동 대기 타이머, HDMI CEC, Bluetooth 송신기, 오디오 리스토러, 비디오 처리 모드를 제공해요.

No. 09

☼ Quick Select, 테마 & 맞춤 탐색

즐겨 쓰는 입력/볼륨/모드 조합을 탭 한 번으로 불러오세요. 라이트, 다크(AMOLED), 기기 설정 테마 중에서 선택하고, 사용자 지정 TJ Mode 강조 색상을 정하고, 탐색 탭을 끌어서 순서를 바꾸거나 표시하거나 숨겨 내 작업 방식에 맞출 수 있어요.

No. 10

♪ FM/AM 튜너 & 재생 중

앱에서 바로 주파수나 저장된 프리셋으로 FM/AM을 선택하고, HEOS 소스는 앨범 아트가 있는 실시간 재생 중 화면으로 확인하세요. 입력의 순서와 이름을 바꿔 그리드가 내 생각대로 읽히게 만드세요.

사용 방법

직접 네트워크 연결. 클라우드는 필요 없어요.

1

리시버 추가

리시버의 IP 주소를 입력하거나 앱이 네트워크에서 찾게 하세요. 계정도, 가입도 없어요.

2

Wi-Fi로 연결

AVR Maestro는 로컬 네트워크를 통해 리시버와 직접 통신해요. 명령은 HTTP, 실시간 이벤트는 Telnet, 재생 중 정보는 HEOS를 사용해요.

3

완전한 제어

볼륨, 입력, 서라운드, 존, 보정, 튜너, 장면을 모두 휴대전화, 태블릿, 데스크톱에서 제어하세요.

보안 & 개인정보

로컬 전용. 계정 없음. 클라우드 없음.

AVR Maestro는 개인정보 보호를 우선하는 로컬 전용 구조로 설계되었어요. 클라우드 의존성도, 사용자 계정도 없고, 충돌 보고 외에는 데이터를 수집하지 않아요.

◉

클라우드 중계 없음

모든 명령과 상태 조회는 로컬 Wi-Fi를 통해 휴대전화와 리시버 사이에서 직접 이루어져요. 네트워크 밖으로 나가는 것은 없어요.

▣

계정 필요 없음

가입도, 이메일도, MiyaraHub 계정도 필요 없어요. 앱을 열고 리시버의 IP를 입력하면 바로 제어할 수 있어요.

◎

최소한의 분석

Firebase Crashlytics는 버그 보고에만 사용해요. 개인 데이터도, 사용 추적도, 광고도 없어요. 리시버 데이터는 휴대전화 밖으로 나가지 않아요.

◆

로컬 저장만

기기 IP 주소와 앱 설정은 기기에만 저장돼요. 서버와 동기화되는 것은 없어요.

□

사용자가 시작한 동작만

앱은 내가 요청할 때만 리시버에 명령을 보내요. 백그라운드 변경도, 몰래 실행되는 자동화도 없어요.

FAQ

자주 묻는 질문.

AVR Maestro는 Denon이나 Marantz와 관련이 있나요? +
아니요. AVR Maestro는 MiyaraHub Technologies LLC가 개발한 독립적인 제3자 애플리케이션이에요. Denon, Marantz, 또는 그 모회사인 Sound United / Masimo가 제작, 보증, 후원하지 않았으며 어떤 식으로도 제휴 관계가 없어요. "Denon", "Marantz", "Audyssey", "Dirac Live", "IMAX Enhanced", "Auro-3D"는 각 소유자의 상표예요. 이 이름들은 호환성을 설명하기 위한 목적으로만 사용해요.
어떤 리시버를 지원하나요? +
AVR Maestro는 IP 제어(HTTP 및/또는 Telnet)를 지원하는 네트워크 연결형 Denon 및 Marantz AV 리시버와 함께 작동해요. 2014년 이후 대부분의 모델이 해당돼요. 앱은 연결할 때 사용 가능한 기능을 자동으로 감지해요. 연결 가능 여부는 모델만이 아니라 네트워크에 달려 있어요. 리시버의 자체 웹 포털, HEOS 앱, 공식 Denon 또는 Marantz 앱이 같은 네트워크에서 모두 접속할 수 있고 네트워크 포트가 차단되지 않았다면 AVR Maestro도 인식할 수 있어요.
AVR Maestro는 리시버와 어떻게 통신하나요? +
AVR Maestro는 세 가지 프로토콜을 사용해요. 안정적인 상태 조회와 명령에는 HTTP, 실시간 이벤트 스트리밍(볼륨 변경, 입력 전환)에는 Telnet, 앨범 아트가 있는 재생 중 정보에는 HEOS예요. 모든 통신은 로컬 Wi-Fi 네트워크에서 직접 이루어져요.
Audyssey, Dirac Live, IMAX Enhanced를 지원하나요? +
네. AVR Maestro는 Audyssey MultEQ, Dynamic EQ, Dynamic Volume, LFC, Containment를 완전히 제어할 수 있어요. 또한 Dirac Live 필터 슬롯 전환, 크로스오버 설정이 있는 IMAX Enhanced 모드, Auro-3D 구성도 지원해요. 사용 가능한 기능은 사용 중인 리시버 모델이 지원하는 범위에 따라 달라요.
여러 존을 제어할 수 있나요? +
네. AVR Maestro는 존 2와 존 3을 독립적인 전원, 볼륨, 입력 소스, 퀵 프리셋과 함께 지원해요. 각 존은 전용 섹션에서 제어할 수 있고, 존 상태는 메인 대시보드에서 한눈에 볼 수 있어요.
장면이란 무엇인가요? +
장면은 입력, 볼륨, 사운드 모드, Audyssey/Dirac 선택, Speaker Preset, 채널 레벨, 존, 심지어 튜너까지 전체 설정을 탭 한 번으로 저장한 스냅샷이에요. 영화의 밤, 게임, 늦은 밤 감상처럼 원하는 만큼 저장하고 즉시 불러올 수 있어요. 실제로 시스템을 쓰는 여러 방식 사이를 가장 빠르게 오가는 방법이에요.
AVR Maestro는 얼마인가요? +
AVR Maestro는 $9.99의 1회 결제예요. 구독도, 광고도, 앱 내 구매도 없어요. 한 번 구매하면 계속 쓸 수 있어요.
집 밖에서 리시버를 원격으로 제어할 수 있나요? +
AVR Maestro는 설정한 IP 주소에 연결해요. VPN이나 Tailscale로 리시버에 접근할 수 있다면 앱이 원격에서도 작동해요. 리시버를 인터넷에 직접 노출하기보다 VPN이나 Tailscale을 쓰시길 권해요.
어떤 플랫폼과 버전을 지원하나요? +
AVR Maestro는 iPhone(App Store), Android(Google Play), Windows(Microsoft Store), macOS(Mac App Store)에서 사용할 수 있어요. Android에서는 Android 5.0(API 21) 이상이 필요하고, iPhone에서는 최신 iOS를 쓰는 최근 기기가 필요해요. 전체 매뉴얼은 avrmaestro.com에 있어요.
