앱이 기기를 자동으로 감지하고 내 모델에 맞는 기능을 활성화해요.

No. 01

◉ 실시간 신호 정보

입력 신호, 비디오/오디오 출력, 싱크 EDID 상세, eARC 상태, 작동 모드를 한 번에 스크롤해서 볼 수 있는 실시간 개요예요.

No. 02

▣ EDID 관리

EDID 모드를 선택하고, Automix 설정을 구성하고, FRL 속도, VRR, ALLM, HDR 주입을 포함한 비디오 기능을 세밀하게 조정해요. 모든 EDID 파라미터를 깊이 있게 제어할 수 있어요.

No. 03

◎ HDR / Dolby Vision

형식별(HDR10, HLG, LLDV) 맞춤 HDR 메타데이터를 주입하거나 제거해요. DV 플래그 주입을 활성화하고, DV 모드 프로파일을 선택하고, 저지연 Dolby Vision 패스스루를 전환할 수 있어요.

No. 04

▢ CEC / eARC / 오디오

HDMI-CEC 통신을 구성하고, eARC/ARC 모드를 설정하고, RS232 보레이트를 조정하고, 개별 오디오 출력을 음소거해요. TrueHD, DTS-HDMA, DD+를 포함한 전체 오디오 코덱 패스스루 제어를 지원해요.

No. 05

◆ JVC 매크로 시스템 일부 모델

HDR 메타데이터 변경으로 트리거되는 JVC 프로젝터 자동 명령을 구성해요. 매크로 활성화, 이벤트 시 동기화, 조정 가능한 지연 시간을 설정할 수 있어요. VRRooM, VERTEX2, DIVA, Maestro에서 사용할 수 있어요.

No. 06

⚙ 전체 기기 구성

입력 자동 전환, HDCP 모드, 입력별 HTPC 저지연 모드, 아날로그 오디오 볼륨/저음/고음, IR 리모컨 설정, TX +5V 강제, 네트워크/TCP 구성을 설정해요.

No. 07

☼ OSD / OLED 디스플레이

기기에 내장된 OLED 디스플레이를 제어해요. 켜기/끄기, 정보 페이지 선택, 자동 페이드 시간 설정, 회전과 색상 반전 같은 고급 옵션을 조정할 수 있어요.

No. 08

No. 09

FAQ

자주 묻는 질문.

FuryPath는 HDFury 기기와 어떻게 통신하나요? +
FuryPath는 HDFury 기기에 내장된 웹 인터페이스와 같은 프로토콜을 사용해, 로컬 Wi-Fi 네트워크에서 기기로 HTTP GET 요청을 직접 보내요. 명령은 GET /cmd?key=value로 전송하고 상태 조회는 GET /ssi/*.ssi 엔드포인트에서 읽어요. 외부 서버는 관여하지 않아요. 기기는 휴대전화와 같은 Wi-Fi 네트워크에 있어야 해요.
어떤 운영 체제 버전을 지원하나요? +
FuryPath는 iPhone, iPad, Android, Mac, Windows에서 사용할 수 있어요. iOS는 iOS 16.0 이상, macOS는 macOS 11.0 이상, Android는 Android 7.0(API 24) 이상이 필요해요.
집 밖에서 HDFury 기기를 원격으로 제어할 수 있나요? +
FuryPath는 설정한 IP 주소에 연결해요. HDFury 기기에 VPN이나 Tailscale로 접근할 수 있다면 앱이 원격에서도 작동해요. 기기를 인터넷에 직접 노출하기보다 VPN이나 Tailscale을 쓰시길 권해요.
모든 HDFury 모델을 지원하나요? +
FuryPath는 VRRooM, VERTEX2, VERTEX, DIVA, Maestro, ARCANA2, Arcana, Dr.HDMI 8K를 지원해요. 앱이 연결할 때 기기를 자동으로 감지해서 내 모델에 맞는 기능을 활성화해요. 모든 모델이 모든 기능을 지원하는 것은 아니에요. 예를 들어 JVC 매크로는 VRRooM, VERTEX2, DIVA, Maestro에서만 사용할 수 있어요.
Bluetooth 동글이나 추가 하드웨어가 필요한가요? +
아니요. FuryPath는 기기에 내장된 웹 인터페이스를 이용해 집 네트워크로 HDFury 기기와 통신하기 때문에, Bluetooth 동글(GO2 등)이나 다른 하드웨어를 구매할 필요가 없어요. HDFury 기기가 휴대전화, 태블릿, 컴퓨터와 같은 네트워크에 연결되어 있기만 하면 돼요.
FuryPath는 HDFury 공식 앱인가요? +
아니요. FuryPath는 HDFury 기기를 제어하기 위해 MiyaraHub Technologies LLC가 만든 독립 앱이에요. HDFury가 만들거나 보증하거나 지원하지 않아요. HDFury 제품, 펌웨어, 공식 지원은 hdfury.com을 방문하세요.
FuryPath는 얼마인가요? +
FuryPath는 $9.99의 1회 결제예요. 구독도, 광고도, 앱 내 구매도 없어요. 한 번 구매하면 계속 쓸 수 있어요.
여러 HDFury 기기를 관리할 수 있나요? +
네. FuryPath는 여러 기기를 지원하며, 기기마다 자체 설정, 탐색 탭, 연결 상태를 유지해요. 메인 대시보드에서 탭 한 번으로 기기를 전환할 수 있어요.
탐색과 홈 화면을 사용자 지정할 수 있나요? +
기기마다 홈 화면과 모델에 따라 표시되는 기능 탭(INFO, EDID, HDR/AVI, DV, CEC/eARC, MACROS, OSD, OLED, CONFIG)이 있어요. 기기별로 하단 탐색 바에 표시할 탭을 고를 수 있고(홈과 최대 6개 추가, 최소 2개), 홈의 카드를 끌어서 순서를 바꾸거나 제거할 수 있어요. 기기마다 자기만의 레이아웃을 독립적으로 기억해요.
