휴대폰으로 UniFi 네트워크를 완벽하게 제어하세요.

기능

내 UniFi 컨트롤러를 주머니 속에.

Network Deck은 UniFi OS(UDM Pro, Cloud Gateway, Dream Machine)이든 독립형 UniFi Network 컨트롤러이든 컨트롤러의 로컬 API와 직접 통신합니다. 브라우저를 열지 않고도 클라이언트, WiFi, 방화벽, 포트, VPN, 인사이트를 확인하고 관리하세요.

호환성

내 UniFi 컨트롤러와 함께 작동합니다.

Network Deck은 UniFi OS 콘솔과 독립형 UniFi Network 컨트롤러를 모두 지원합니다. 펌웨어가 제공하는 엔드포인트를 자동으로 감지해 UI를 맞춰 주며, 지원되지 않는 기능은 아예 표시되지 않습니다.

◉ UniFi OS 콘솔

  • UDM Pro SE (검증됨)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ 독립형 컨트롤러

  • UniFi Network 10.x (검증됨)
  • Linux / Docker 자체 호스팅
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ 인증

  • 로컬 관리자 사용자 이름 + 비밀번호
  • 2단계 인증 (TOTP)
  • 프로그램 방식 접근을 위한 X-API-KEY
  • UniFi 클라우드 계정 불필요

◆ 모바일 플랫폼

  • iOS 13 이상
  • Android 5.0 (API 21) 이상
  • 휴대폰 및 태블릿 레이아웃
  • 라이트 및 다크 테마

펌웨어 호환성: Network Deck은 컨트롤러가 제공하는 엔드포인트를 자동으로 감지하고, 펌웨어마다 다른 JSON 형식(필드 이름 변경, 자료형 변환, 통합 API의 다양한 응답 형태)에도 맞춰 동작합니다. 하위 관리자 계정에서는 일부 엔드포인트가 401을 반환할 수 있는데, 이는 앱의 한계가 아니라 컨트롤러의 권한 제한입니다.

사용 방법

컨트롤러에 직접 연결합니다. 클라우드 중계는 없습니다.

Network Deck은 로컬 네트워크(또는 VPN)를 통해 UniFi 컨트롤러와 직접 통신합니다. 사용자의 인증 정보와 네트워크 데이터는 MiyaraHub 서버를 거치지 않습니다.

1

컨트롤러 추가

컨트롤러의 호스트 이름 또는 IP, 포트(UniFi OS는 기본 443, 독립형은 8443), 로컬 관리자 인증 정보를 입력하세요. Network Deck이 UniFi OS인지 독립형 컨트롤러인지 자동으로 감지합니다.

2

로컬 인증

로컬 관리자 사용자 이름과 비밀번호로 로그인하세요. 2단계 인증을 전 과정에서 지원합니다. API 키를 선호하시나요? 프로그램 방식 접근용 X-API-KEY를 사용하면 쿠키 방식 로그인을 완전히 건너뛸 수 있습니다.

3

한눈에 관리

실시간 대역폭 차트를 확인하고, 문제를 일으키는 클라이언트를 내보내고, 방화벽 규칙을 켜고 끄고, PoE 포트를 재시작하고, Teleport 게스트를 초대하고, 다른 사이트로 전환하세요. 모든 동작은 컨트롤러와 주고받으며 실시간 이벤트 스트림에 반영됩니다.

보안 & 개인정보

로컬 전용. 계정 없음. 클라우드 중계 없음.

Network Deck은 개인정보 보호를 최우선으로 하는 로컬 전용 구조로 설계되었습니다. MiyaraHub 계정도, 클라우드 중계도 없으며, 충돌 보고 외에는 어떤 데이터도 수집하지 않습니다.

◉

클라우드 중계 없음

모든 명령과 실시간 스트림은 로컬 Wi-Fi 또는 VPN을 통해 휴대폰과 컨트롤러 사이에서 직접 이루어집니다. 외부 서버를 거치는 것은 없습니다.

▣

표준 UniFi 인증

UniFi Network 웹 UI와 같은 로컬 관리자 인증 정보(또는 API 키)를 사용합니다. 인증 정보는 기기의 iOS Keychain / Android Keystore에 저장되며, 컨트롤러 외에는 기기 밖으로 전송되지 않습니다.

◎

MiyaraHub 계정 불필요

가입도, 이메일도, MiyaraHub 계정도 필요 없습니다. 설치하고 컨트롤러만 지정하면 바로 사용할 수 있습니다.

◈

최소한의 분석

버그 보고용 Firebase Crashlytics만 사용합니다. 사용 추적도, 광고도, 데이터 판매도 없습니다. 네트워크 오류는 치명적이지 않은 오류로 기록되어, 사용자의 네트워크 구성을 수집하지 않고도 펌웨어 호환성을 개선하는 데 도움이 됩니다.

◆

권한 준수

앱은 UniFi 관리자 계정이 가진 권한 범위 안에서만 동작합니다. 하위 관리자는 컨트롤러가 허용하는 항목만 볼 수 있습니다. 권한 상승도, 백도어도 없습니다.

◐

네트워크 권한만

Network Deck에 필요한 기기 권한은 네트워크 접근뿐이며, 로컬 네트워크(또는 VPN)에서 UniFi 컨트롤러에 연결하는 용도로만 사용됩니다.

Network Deck은 Ubiquiti 또는 UniFi와 제휴 관계인가요? +

UDM Pro SE(UniFi OS 5.0.16)와 독립형 Network 10.2.105에서 실제로 테스트했습니다.

UniFi 클라우드 계정이 필요한가요? +
아니요. Network Deck은 로컬 인증만 사용합니다. UniFi 로컬 관리자 사용자 이름과 비밀번호(또는 API 키)로 로그인하세요. 현재 컨트롤러에 ui.com 클라우드 로그인으로만 접속할 수 있다면, Network Deck을 사용하기 위해 Settings → Admins에서 로컬 관리자 계정을 활성화해야 합니다. 컨트롤러는 저희와 통신하지 않으며, 저희도 사용자를 대신해 Ubiquiti 클라우드와 통신하지 않습니다.
방화벽 규칙과 포트 포워딩을 관리할 수 있나요? +
네. Network Deck은 완전한 방화벽 기능을 갖추고 있습니다. 정책(허용 / 차단 / 검사), CRUD를 지원하는 포트 포워딩, 트래픽 규칙과 경로, 방화벽 그룹, 방화벽 영역(v2 정책 매트릭스), DPI 앱 / 그룹을 지원합니다. 모든 항목은 목록 화면에서 바로 켜고 끌 수 있어 대화 상자를 여러 번 누를 필요가 없습니다.
멀티 사이트를 지원하나요? +
네. 컨트롤러가 여러 사이트를 관리한다면 Network Deck 상단에 사이트 전환기가 표시됩니다. 대시보드, 클라이언트, 방화벽, VPN 등 모든 기능이 현재 선택한 사이트를 기준으로 동작하며, 한 번의 탭으로 전환할 수 있습니다.
Network Deck의 가격은 얼마인가요? +
Network Deck은 App Store, Google Play, Microsoft Store에서 $4.99에 한 번만 구매하는 방식입니다. 구독, 광고, 인앱 결제가 없습니다. 가격은 정식 출시 전에 변경될 수 있습니다.

Network Deck은 설정한 호스트 이름이나 IP로 연결합니다. VPN, Tailscale, WireGuard 또는 포트 포워딩으로 컨트롤러에 접속할 수 있다면 원격에서도 작동합니다. UniFi 컨트롤러를 인터넷에 직접 노출하기보다 VPN이나 Tailscale을 사용하시길 권장합니다.
