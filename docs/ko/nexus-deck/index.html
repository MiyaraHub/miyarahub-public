기능

모든 보정 파일 형식을 앱 하나로.

NexusDeck은 기존 도구가 만든 보정 파일을 그대로 읽어 휴대폰에서 라이브러리를 둘러보게 해 주고, 리시버에 바로 업로드합니다. 업로드 단계에는 노트북도, MultEQ Editor도 필요 없습니다.

◉ 주요 형식 모두 가져오기

사용 방법

측정 파일에서 리시버까지, 단 세 단계.

NexusDeck은 기존 도구들이 해결해 주지 못한 부분을 정확히 겨냥합니다. 노트북에 보정 파일은 있는데, 데스크톱 앱을 다시 실행하지 않고는 리시버에 넣을 방법이 마땅치 않다는 점입니다. NexusDeck이 그 틈을 메웁니다.

1

파일 가져오기

MultEQ Editor의 Audyssey .ady, A1 Evo Acoustix의 .oca, REW의 .mdat 또는 지원되는 다른 파일을 여세요. NexusDeck이 파일을 분석해 응답 커브를 추출하고 라이브러리에 추가합니다.

2

둘러보고 비교하기

라이브러리 항목을 열면 채널별 주파수 응답을 확인할 수 있습니다. 커브를 둘 이상 겹쳐 보면 룸 보정으로 무엇이 바뀌었는지 알 수 있습니다. 라이브러리가 커지면 항목의 이름을 바꾸고, 그룹으로 묶고, 삭제하세요.

3

Audyssey를 리시버에 업로드

Audyssey .ady 파일은 Speaker Preset 슬롯(1 또는 2)을 고르고 확인만 하면, NexusDeck이 Denon 또는 Marantz 리시버로 Wi-Fi를 통해 보정 데이터를 전송합니다. 리시버가 업로드를 검증하고, NexusDeck이 제대로 적용되었는지 알려 드립니다. .oca / .mdat / .frd / .txt로 가져온 파일은 라이브러리에 남아 둘러보기와 비교에 쓰이며, 이 형식들의 리시버 업로드는 이후 버전에서 제공될 예정입니다.

보안 & 개인정보

로컬 전용. 계정 없음. 클라우드 없음.

NexusDeck은 AVR Maestro와 같은 개인정보 보호 우선 구조로 만들어졌습니다. 보정 파일은 기기에 남고, 리시버는 로컬 네트워크에 머물며, 사용자의 설정에 관한 어떤 것도 MiyaraHub로 전송되지 않습니다.

◉

클라우드 중계 없음

보정 업로드는 로컬 Wi-Fi(TCP 포트 1256)를 통해 휴대폰과 리시버 사이에서 직접 이루어집니다. 파일이 MiyaraHub 서버를 거치지 않습니다.

▣

계정 필요 없음

가입도, 이메일도, MiyaraHub 로그인도 없습니다. 앱을 열고 첫 보정 파일을 넣으면 바로 라이브러리에서 사용할 수 있습니다.

◎

최소한의 진단

충돌 보고와 진단 데이터에만 Firebase Crashlytics를 사용하며, 사용자가 겪은 버그를 고치기 위한 목적입니다. 사용 추적도, 광고도, 개인화도 없습니다. 설정에서 해제할 수 있습니다.

◆

라이브러리는 로컬에 저장

보정 라이브러리는 로컬 SQLite 데이터베이스와 기기 내 파일 저장소로 구성됩니다. MiyaraHub 서버로 동기화하거나 업로드하는 것은 없습니다.

●

사용자가 직접 시작한 업로드만

커브는 사용자가 직접 업로드를 누르고 슬롯을 확인했을 때만 리시버로 전송됩니다. 자동으로 이루어지는 작업은 없으며, 실제로 기록된 내용을 확인하기 위해 리시버에서 다시 읽어 옵니다.

◈

네트워크 권한만 사용

NexusDeck에 필요한 시스템 권한은 네트워크 접근뿐이며, 로컬 Wi-Fi에서 리시버에 연결하는 용도로만 사용됩니다.

자주 묻는 질문.

NexusDeck에 대해 알아야 할 모든 것.

NexusDeck은 Audyssey, Denon 또는 Marantz와 제휴 관계인가요? +
아니요. NexusDeck은 MiyaraHub Technologies LLC가 개발한 독립적인 서드파티 애플리케이션입니다. Audyssey Laboratories, Denon, Marantz, Sound United, Masimo Corporation 및 그 자회사가 만들거나 보증, 후원하지 않으며 어떠한 제휴 관계도 없습니다. "Audyssey," "MultEQ," "Denon," "Marantz," "REW" / "Room EQ Wizard"는 각 소유자의 상표입니다. 이러한 이름은 호환성을 설명하기 위한 목적으로만 사용합니다.
NexusDeck으로 어떤 리시버에 업로드할 수 있나요? +
NexusDeck은 TCP 포트 1256의 바이너리 보정 업로드 프로토콜을 지원하는 네트워크 연결형 Denon 및 Marantz AV 리시버에 업로드합니다. 여기에는 Cinema 30 / 40 / 50, AV10, X3800H, X4800H, X6800H를 비롯해 최근 몇 년간 출시된 Audyssey MultEQ XT32 기반 모델이 포함됩니다. NexusDeck은 리시버와 업로드할 보정 파일에서 모델과 채널 구성을 자동으로 감지합니다.
NexusDeck은 어떤 파일 형식을 가져올 수 있나요? +
Audyssey .ady(MultEQ Editor 내보내기), A1 Evo Acoustix .oca, REW .mdat(Room EQ Wizard의 MEQX 측정 내보내기, 다중 위치 지원), .frd 응답 커브, REW PEQ .txt 내보내기 파일을 지원합니다. 현재는 .ady 파일만 리시버에 업로드할 수 있으며, .oca / .mdat / .frd / .txt는 라이브러리 보관과 비교 전용입니다. Dirac Live 필터 가져오기와 리시버 업로드는 v1에서 지원하지 않습니다.
NexusDeck이 보정 커브를 직접 생성하나요? +
아니요. 의도된 설계입니다. NexusDeck은 다른 도구(MultEQ Editor, A1 Evo Acoustix, REW, ratbuddyssey 등)에서 만든 보정 파일을 저장하고, 둘러보고, 비교하고, 업로드합니다. 실제 측정과 커브 생성은 해당 도구에서 이루어지며, NexusDeck은 관리자이자 기기 내 업로드 파이프라인 역할을 합니다.
기존 Speaker Preset은 안전한가요? +
네. 업로드하기 전에 NexusDeck이 대상 Speaker Preset 슬롯에 현재 들어 있는 내용을 읽어 와 라이브러리에 백업 항목으로 저장합니다. 한 번의 탭으로 어떤 슬롯이든 이전 보정 상태로 복원할 수 있습니다. 또한 전송이 끝나면 슬롯을 다시 읽어 업로드가 정상적으로 완료되었는지 확인합니다.
NexusDeck은 내 리시버와 어떻게 페어링하나요? +
AVR Maestro를 설치하고 리시버와 페어링해 두었다면, NexusDeck이 공유 앱 간 컨테이너를 통해 페어링된 기기 목록을 자동으로 읽어 옵니다. 다시 페어링하거나 IP를 중복 입력할 필요가 없습니다. AVR Maestro가 없다면 NexusDeck의 페어링 안내에 따라 리시버 IP를 직접 입력하시면 됩니다.
NexusDeck의 가격은 얼마인가요? +
NexusDeck은 무료로 다운로드할 수 있습니다. 무료 버전에서는 모든 라이브러리 가져오기, 둘러보기, 커브별 시각화를 사용할 수 있고, Speaker Preset 슬롯 1(SPP1)에 평생 최대 5회까지 업로드할 수 있어 구매 전에 내 리시버에서 업로드 과정을 처음부터 끝까지 직접 시험해 볼 수 있습니다. 무제한 업로드, SPP2 쓰기, 슬롯 백업 및 복원, 다중 커브 비교 화면, 가이드 워크스루, AVR Maestro 기기 연동 브리지는 $12.99의 일회성 인앱 구매로 잠금 해제됩니다. 구독도, 반복 결제도, 광고도 없습니다. 가격은 출시 전에 변경될 수 있습니다.
필요한 Android와 iOS 버전은 무엇인가요? +
NexusDeck은 Android 7.0(API 24) 이상, iOS 14 이상이 필요합니다. 두 플랫폼 모두 출시와 함께 제공됩니다.
