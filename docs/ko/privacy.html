개인정보 처리방침

최종 업데이트: 2026년 9월 23일

MiyaraHub Technologies LLC(이하 "당사")는 이용자의 개인정보를 보호하기 위해 최선을 다하고 있습니다. 이 개인정보 처리방침은 MiyaraHub Technologies LLC가 배포하는 모든 애플리케이션, 연동 기능 또는 서비스(이하 통칭하여 "서비스")를 이용하실 때 당사가 정보를 어떻게 수집, 이용, 공개, 보호하는지 설명합니다. 적용 대상 애플리케이션의 최신 목록은 아래 부록 A에서 확인하실 수 있습니다.

1. 데이터 최소화 원칙

MiyaraHub Technologies LLC는 데이터 최소화 원칙을 준수합니다. 당사는 애플리케이션과 서비스의 기능에 꼭 필요한 최소한의 개인정보만 수집합니다. 이용하시는 기능을 제공하는 데 필요한 범위를 넘어서는 데이터는 수집하지 않습니다.

당사의 애플리케이션 중 상당수는 전적으로 로컬 네트워크에서 작동하며, 기기 데이터, 인증 정보, 사용 정보를 당사 서버로 전송하지 않습니다. 데이터는 사용자의 기기에 남습니다. 각 애플리케이션의 데이터 처리 방식은 부록 A를 확인해 주세요.

2. 수집하는 정보

이용자가 제공하는 정보:

  • 연락처 정보: 지원팀에 문의하실 때 제공하시는 이름과 이메일 주소.
  • 거래 데이터: 서드파티 결제 서비스(Square, PayPal, Apple App Store, Google Play Store)를 통해 처리되는 결제 정보. 당사는 전체 신용카드 번호를 당사 서버에 저장하지 않습니다.
  • 문의 내용: 지원을 요청하실 때 제공하시는 정보.
  • 사용자 콘텐츠: 제품 리뷰, 견적, 설정 데이터 등 애플리케이션을 통해 제출하시는 모든 콘텐츠.

자동으로 수집되는 정보:

  • 충돌 보고서: 앱 안정성을 개선하기 위해 Firebase Crashlytics로 익명 충돌 보고서와 진단 데이터를 수집합니다. 이 보고서에는 개인정보, 인증 정보, 사용자 네트워크의 기기별 데이터가 포함되지 않습니다.
  • 사용 분석: 일부 애플리케이션(부록 A 참조)은 Firebase Analytics를 사용해 앱 실행, 화면 조회, 사용된 기능 등 익명의 통계성 사용 데이터를 수집하며, 이는 이용 패턴을 파악하고 앱을 개선하는 데 쓰입니다. 이 데이터는 이용자의 신원과 연결되지 않으며 광고나 앱 간 추적에 사용되지 않습니다.
  • 마이크 및 음성 입력: 음성 어시스턴트가 있는 애플리케이션(부록 A 참조)은 마이크 버튼을 누르고 있거나 누른 동안에만 오디오를 수집합니다. 이 오디오는 기기 자체의 음성 인식 서비스로 전달되고 애플리케이션은 텍스트만 돌려받습니다. 당사는 오디오를 수신, 저장, 전송하지 않으며, 요청이 끝난 뒤 기기에 녹음이 남지 않습니다. 기기와 설정에 따라 음성 인식은 완전히 오프라인으로 실행되거나 Google 또는 Apple의 서버에서 오디오를 처리할 수 있으며, 이는 당사가 아니라 운영 체제가 결정하고 해당 회사의 개인정보 처리방침을 따릅니다. 음성 입력은 언제나 선택 사항이며, 어시스턴트의 모든 기능은 직접 입력해서도 온전히 사용할 수 있습니다.
  • 기기 정보: 기본적인 기기 종류와 운영 체제 버전이며, 디버깅 목적으로 충돌 보고서를 통해서만 수집됩니다.
  • 로컬 네트워크 데이터: 로컬 네트워크 기기(예: 스마트 홈 컨트롤러, NAS, UPS)와 연동되는 애플리케이션의 경우, 기기 식별자, IP 주소, 설정 데이터는 사용자의 기기에만 수집되어 저장됩니다. 이 데이터는 당사 서버로 전송되지 않습니다.

수집하지 않는 정보:

  • 당사는 이용자의 인터넷 사용 기록을 수집하지 않으며, 어떤 애플리케이션도 기기 위치를 당사 서버로 전송하지 않습니다
  • 부록 A에 Firebase Analytics 사용으로 표시되지 않은 애플리케이션의 경우, 어떤 기능을 사용하는지 또는 앱을 얼마나 자주 사용하는지 추적하지 않습니다
  • 당사는 네트워크 기기의 인증 정보, 설정, 모니터링 데이터를 수집하지 않습니다
  • 당사는 광고 추적기를 사용하지 않으며, 이용자의 데이터를 판매하지 않고, 광고용 사용자 프로필을 만들지 않습니다

6. 데이터 저장 & 보안

당사는 전송 중(TLS/SSL) 및 저장 시 암호화를 포함한 업계 표준 보안 조치로 이용자의 정보를 보호합니다. 해당되는 경우 당사의 백엔드 서비스는 Supabase에서 호스팅되며, Row Level Security(RLS) 정책을 통해 엔터프라이즈급 보안을 제공합니다.

로컬 네트워크 기기에 연결하는 애플리케이션의 경우, 연결 인증 정보와 기기 데이터는 플랫폼 기본 보안 저장소(iOS는 Keychain, Android는 Keystore, Windows는 DPAPI로 보호되는 저장소)를 사용해 기기에 안전하게 저장되며 당사 서버로 전송되지 않습니다.

7. 아동의 개인정보

당사의 서비스는 아동을 대상으로 하지 않습니다. 당사는 만 13세 미만(유럽 경제 지역에서는 만 16세 미만, 또는 거주 지역의 해당 최소 연령 미만)의 개인정보를 고의로 수집하지 않습니다.

해당 최소 연령 미만 아동의 개인정보를 의도치 않게 수집했다는 사실을 알게 되면 즉시 삭제하겠습니다. 아동이 당사에 개인정보를 제공했다고 생각되시면 admin@miyarahub.com으로 연락해 주세요.
