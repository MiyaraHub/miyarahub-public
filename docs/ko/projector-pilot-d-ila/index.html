Projector Pilot D-ILA · JVC D-ILA 프로젝터용내 D-ILA를 손안에.✦

휴대폰, 태블릿, 컴퓨터에서 JVC D-ILA 프로젝터를 제어하는 로컬 네트워크 리모컨입니다.

Projector Pilot D-ILA 앱은 프로젝터에 설정한 네트워크 비밀번호로 프로젝터의 네트워크 제어 포트(TCP 20554)를 통해 직접 통신합니다. 전원, 입력, 메뉴 탐색, 화면 모드, HDR 레벨, 색상, 모션, 렌즈, 설치, 화면비에 더해 씬, 유지관리, 홈 오토메이션까지 지원합니다. 중간에 계정도 클라우드 서비스도 없습니다.

기능

문서화된 모든 명령을 모델별로.

키는 JVC가 공개한 네트워크 명령 레퍼런스를 따르며, 각 모델에는 해당 모델의 문서에 나열된 명령만 표시됩니다. 프로젝터가 어떤 명령을 받아들이는지는 여전히 모델과 펌웨어에 따라 다르며, 지원하지 않는 명령은 무시합니다.

◉ 전원, 입력 & 메뉴

전원 켜기와 대기 모드, HDMI 1과 HDMI 2, 위, 아래, 왼쪽, 오른쪽, OK, 뒤로, 메뉴 키로 메뉴를 탐색합니다. 화면을 숨기고 프로젝터의 메뉴와 정보 화면으로 바로 이동할 수도 있습니다.

광원 사용 시간알림테스트 패턴

사용 방법

직접 네트워크 연결. 중간에 클라우드 없음.

Projector Pilot D-ILA 앱은 로컬 네트워크에서 프로젝터에 직접 연결합니다. MiyaraHub 서버도, 계정도 없습니다.

1

프로젝터 찾기

서브넷의 모든 주소에서 포트 20554를 시도하는 네트워크 검색을 실행하거나, IP 주소로 프로젝터를 추가하세요.

2

프로젝터 비밀번호로 로그인

프로젝터에 설정한 네트워크 비밀번호를 입력하세요. 앱이 TCP 20554로 로그인해 모델을 읽고, 비밀번호는 기기의 보안 저장소에 보관합니다.

3

제어 시작

모델이 지원하는 리모컨, 화질, 렌즈, 설정 화면을 사용하고, 씬을 저장하고, 원한다면 홈 오토메이션을 연결하세요.

보안 & 개인정보

로컬 우선. 계정 없음. 광고 없음.

앱은 로컬 네트워크의 프로젝터와, 앱 내 구매를 위해 스토어와만 통신합니다. 그 밖에 무엇을 언제 전송하는지는 여기에 정리되어 있습니다.

◉

프로젝터로 직접 연결

명령과 상태 조회는 로컬 네트워크를 통해 기기와 프로젝터 사이에서 직접 이루어지며, 중간에 클라우드 서비스가 없습니다.

◎

계정 필요 없음

가입도, MiyaraHub 계정도 필요 없습니다. 프로젝터 주소를 검색하거나 입력해 연결하면 됩니다.

▣

충돌 보고서 및 분석

버그를 고칠 수 있도록 충돌 보고서는 Android, iPhone, iPad에서 기본으로 켜져 있으며 설정에서 끌 수 있습니다. 충돌 보고서에는 앱을 멈추게 한 오류 문구가 포함될 수 있고, 드물게 네트워크 주소가 들어갈 수 있습니다. macOS와 Windows 앱은 전송하지 않습니다. 익명 사용 분석은 사용자가 동의하기 전까지 꺼져 있으며, 횟수와 결과만 담고 프로젝터 이름, 주소, 비밀번호, 허브 주소는 절대 포함하지 않습니다.

◆

비밀번호는 보안 저장소에 보관

각 프로젝터의 네트워크 비밀번호는 기기의 보안 저장소에 보관됩니다. 프로젝터를 추가한 Home Assistant로 보내는 경우를 제외하면 로그나 백업을 포함해 다른 어디로도 전달되지 않습니다.

▢

Home Automation이 없으면 전송 없음

Home Automation을 구매하면 앱은 트리거를 사용자가 입력한 웹 주소로만, 전원과 입력은 연결한 Hubitat 허브로만, 프로젝터 상태는 로그인한 Home Assistant로만 보냅니다. 구매하지 않았거나 데모 프로젝터일 때는 항상 아무것도 전송하지 않습니다.

Pro, Home Automation, 번들은 스토어가 처리하는 일회성 구매입니다. MiyaraHub는 결제 정보를 볼 수 없습니다.
