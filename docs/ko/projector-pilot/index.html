기능

프로젝터 제어를 손안에서 완벽하게.

Projector Pilot은 Wi-Fi로 Epson 프로젝터에 연결해 전원과 화질부터 렌즈와 기하 보정까지 모든 설정을 완벽하게 제어하게 해 줍니다. 프로젝터를 직접 만지거나 리모컨을 찾아 헤맬 필요가 없습니다.

No. 01

◉ 전원 & 입력 제어

대기 상태에서 전원 켜기, HDMI 입력 즉시 전환, A/V 음소거, 그리고 천장 설치 프로젝터에서는 방향이 자동으로 뒤집히는 가상 D-pad로 OSD 탐색까지 지원합니다.

전원 켜기/끄기HDMI 전환A/V 음소거OSD D-Pad

HDR10HLGBT.2020RGB 게인/오프셋

사용 방법

직접 네트워크 연결. 클라우드는 필요 없어요.

Projector Pilot은 표준 네트워크 프로토콜을 사용해 Wi-Fi로 프로젝터와 직접 통신합니다. 사용자의 데이터는 외부 서버를 거치지 않습니다.

1

프로젝터 추가

Epson 프로젝터의 IP 주소를 입력하세요. Projector Pilot이 PJLink와 Web Control 연결을 테스트하고, 모델을 감지하며, 사용 가능한 모든 기능을 자동으로 찾아 줍니다.

2

Wi-Fi로 연결

Projector Pilot은 대기 상태 감지와 전원 제어에 PJLink를, 전원이 켜진 뒤의 전체 화질, 렌즈, 설정 제어에 Epson Web Control API를 사용합니다. 모든 것이 로컬 네트워크 안에서 이루어집니다.

3

완전한 제어

화질 설정 조정, 입력 전환, 전동 렌즈 제어, 키스톤 보정 관리, 램프 사용 시간 확인, OSD 탐색까지 하나의 세련된 앱에서 모두 해결하세요.

보안 & 개인정보

로컬 전용. 계정 없음. 클라우드 없음.

Projector Pilot은 개인정보 보호를 최우선으로 하는 로컬 전용 구조로 설계되었습니다. 클라우드 의존도 없고, 사용자 계정도 없으며, 충돌 보고 외에는 어떤 데이터도 수집하지 않습니다.

◉

클라우드 중계 없음

모든 명령과 상태 조회는 로컬 Wi-Fi를 통해 휴대폰과 프로젝터 사이에서 직접 이루어집니다. 네트워크 밖으로 나가는 것은 없습니다.

◎

계정 필요 없음

가입도, 이메일도, MiyaraHub 계정도 필요 없습니다. 앱을 열고 프로젝터의 IP 주소를 입력하면 바로 제어할 수 있습니다.

▣

최소한의 분석

버그 보고용 Firebase Crashlytics만 사용합니다. 개인 데이터도, 사용 추적도, 광고도 없습니다. 프로젝터 데이터는 휴대폰 밖으로 나가지 않습니다.

◆

로컬 저장만

프로젝터 IP 주소, 인증 정보, 앱 환경설정은 SharedPreferences를 사용해 기기에 로컬로 저장됩니다. 서버와 동기화되는 것은 없습니다.

▢

사용자가 시작한 동작만

앱은 사용자가 직접 동작을 실행할 때만 프로젝터로 명령을 보냅니다. 사용자가 모르는 사이에 자동으로 또는 백그라운드에서 일어나는 일은 없습니다.

☼

네트워크 권한만 사용

Projector Pilot에 필요한 기기 권한은 인터넷/네트워크 접근뿐이며, 로컬 Wi-Fi에서 프로젝터에 연결하는 용도로만 사용됩니다.

FAQ

자주 묻는 질문.

Projector Pilot에 대해 알아야 할 모든 것.

Projector Pilot은 Epson과 제휴 관계인가요? +
아니요. Projector Pilot은 MiyaraHub Technologies LLC가 개발한 독립적인 서드파티 애플리케이션입니다. Seiko Epson Corporation 및 그 자회사나 계열사가 만들거나 보증, 후원하지 않으며 어떠한 방식으로도 제휴하지 않습니다. "Epson"은 Seiko Epson Corporation의 등록 상표입니다. 이 이름은 호환성을 설명하기 위한 목적으로만 사용합니다(지정적 공정 사용).
어떤 프로젝터를 지원하나요? +
Projector Pilot은 PJLink 및/또는 Web Control을 지원하는 네트워크 연결형 Epson 프로젝터 모두와 호환됩니다. 플래그십 QB1000과 LS12000부터 중급 Home Cinema, 전문 설치용 모델까지 지난 10년 이상 출시된 대부분의 모델이 포함됩니다. 앱이 연결할 때 사용 가능한 기능을 자동으로 감지하므로, 각 사용자는 자신의 프로젝터가 지원하는 기능만 정확히 볼 수 있습니다. 기본 PJLink 제어는 NEC, Panasonic, Sony 등 Epson이 아닌 프로젝터에서도 작동합니다.
Projector Pilot은 내 프로젝터와 어떻게 통신하나요? +
Projector Pilot은 두 가지 프로토콜을 사용합니다. 대기 상태에서 전원 켜기, 입력 전환, 램프 상태 확인을 포함한 범용 프로젝터 제어에는 PJLink(포트 4352)를, 화질, 렌즈, 키스톤, HDR 등 풍부한 설정 제어에는 Digest 인증을 사용하는 Epson Web Control API(포트 80)를 사용합니다. 모든 통신은 로컬 Wi-Fi 네트워크에서 직접 이루어집니다.
전동 렌즈를 제어할 수 있나요? +
네, 전동 렌즈 시스템을 갖춘 프로젝터에서 가능합니다. Projector Pilot은 실시간 위치 피드백과 함께 렌즈 시프트(가로 및 세로), 포커스, 줌을 완벽하게 제어합니다. 화면비, 스크린 위치, 시청 환경별로 렌즈 메모리 프리셋을 저장하고 불러올 수도 있습니다. 전동 렌즈가 없는 모델에서는 렌즈 제어가 자동으로 숨겨집니다.
HDR과 광색역을 지원하나요? +
네. Projector Pilot에서 다이내믹 레인지 설정(Auto, HDR10, HLG, SDR)과 색 공간(Auto, BT.709, BT.2020)을 제어할 수 있고, 정밀한 색 보정을 위한 채널별 RGB 게인 및 오프셋 조정도 제공합니다. HDR 기능은 지원하는 모델에서만 표시됩니다.
대기 상태에서 프로젝터를 켤 수 있나요? +
네. Projector Pilot은 PJLink를 사용해 프로젝터가 대기 모드일 때도 전원을 켭니다. 프로젝터가 네트워크에 연결되어 있다면(대기 상태 웨이크업에는 유선 LAN을 권장합니다) 휴대폰으로 켜고 끌 수 있습니다.
Projector Pilot의 가격은 얼마인가요? +
Projector Pilot은 기본 제어 기능이 포함된 무료 다운로드 앱입니다. Pro는 $9.99의 일회성 잠금 해제, Home Automation은 $2.99이며, 둘을 묶은 번들은 $11.99입니다. 구독도, 광고도 없습니다. 한 번 구매하면 계속 사용할 수 있습니다. 가격은 출시 전에 변경될 수 있습니다.
필요한 Android 버전은 무엇인가요? +
Projector Pilot은 Android 5.0(API 21) 이상이 필요합니다. 현재는 Android 전용 앱이며, iOS 지원은 이후 버전에서 추가될 수 있습니다.
