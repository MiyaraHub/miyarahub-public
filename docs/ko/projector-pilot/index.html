사용 방법

직접 네트워크 연결. 클라우드는 필요 없어요.

Projector Pilot PJLink & VP21 앱은 로컬 네트워크에서 프로젝터와 직접 통신합니다. MiyaraHub 서버도, 계정도 없습니다.

1

프로젝터 찾기

PJLink(4352)와 ESC/VP.net(3629) 포트에 응답하는 프로젝터를 네트워크에서 검색하거나 IP 주소를 직접 입력하세요. 앱이 모델과 지원 기능을 자동으로 감지합니다.

2

네트워크로 연결

앱은 전원, 입력, 설정에 ESC/VP.net을 통한 ESC/VP21(TCP 3629)과 PJLink(TCP 4352)를 사용하고, 프로젝터가 제공하는 경우 Epson Web Control(HTTP 80, Digest 로그인)을 사용합니다. 모든 것이 로컬 네트워크 안에서 이루어집니다.

3

완전한 제어

화질 설정 조정, 입력 전환, 전동 렌즈 제어, 키스톤 보정 관리, 램프 사용 시간 확인, OSD 탐색까지 하나의 세련된 앱에서 모두 해결하세요.

보안 & 개인정보

로컬 우선. 계정 없음. 광고 없음.

앱은 로컬 네트워크의 프로젝터와, 구매를 위해 스토어와만 통신합니다. 그 밖에 무엇을 언제 전송하는지는 여기에 정리되어 있습니다.

◉

클라우드 중계 없음

모든 명령과 상태 조회는 로컬 네트워크를 통해 기기와 프로젝터 사이에서 직접 이루어지며, 중간에 클라우드 서비스가 없습니다.

◎

계정 필요 없음

가입도, 이메일도, MiyaraHub 계정도 필요 없습니다. 앱을 열고 프로젝터의 IP 주소를 입력하면 바로 제어할 수 있습니다.

▣

진단 정보

Firebase Crashlytics는 버그를 고칠 수 있도록 이름이 아닌 임의의 ID에 연결된 충돌 보고서를 보냅니다. 사용 분석은 이용자가 동의하기 전까지 꺼져 있습니다. 계정과 광고가 없습니다.

◆

비밀번호는 보안 저장소에 보관

프로젝터 비밀번호는 기기의 보안 저장소에 보관되고, 주소와 앱 환경설정은 로컬 앱 저장소에 남습니다. MiyaraHub 서버와 동기화되는 것은 없습니다.

▢

직접 설정할 때만 홈 오토메이션 사용

Home Automation을 구매하면 앱은 사용자가 입력한 웹 주소, 연결한 Hubitat 허브, 로그인한 Home Assistant로 데이터를 보냅니다. 구매하지 않으면 스마트홈 서비스로 나가는 것은 없습니다.

Projector Pilot PJLink & VP21 앱에 대해 알아야 할 모든 것.

Projector Pilot PJLink & VP21 앱은 Epson과 제휴 관계인가요? +
아니요. Projector Pilot PJLink & VP21 앱은 MiyaraHub Technologies LLC가 개발한 독립적인 서드파티 애플리케이션입니다. Seiko Epson Corporation 및 그 자회사나 계열사가 만들거나 보증, 후원하지 않으며 어떠한 방식으로도 제휴하지 않습니다. "Epson"은 Seiko Epson Corporation의 등록 상표입니다. 이 이름은 호환성을 설명하기 위한 목적으로만 사용합니다(지정적 공정 사용).
iPhone과 Android용 Epson 프로젝터 앱이 있나요? +
네. Projector Pilot PJLink & VP21 앱은 iPhone과 iPad(iOS 15 이상), Android, Mac(macOS 12 이상), Windows에서 실행되며 App Store, Google Play, Mac App Store, Microsoft Store에서 받을 수 있습니다. 로컬 네트워크의 Epson 프로젝터를 제어합니다.
Home Cinema 5050UB, LS12000, QB1000에서도 작동하나요? +
네. EH-QB1000은 실제 프로젝터로 검증했고, 앱에는 EH-LS12000 / Pro Cinema LS12000과 EH-TW8400 / Home Cinema 5050UB 프로필이 있으며 호환성 항목에 나열된 다른 모델도 지원합니다. 앱은 연결할 때 모델을 읽고 해당 모델이 지원하는 컨트롤만 표시합니다.
Epson iProjection의 대안인가요? +
역할이 다릅니다. Epson iProjection은 화면이나 사진을 프로젝터로 보냅니다. Projector Pilot PJLink & VP21 앱은 콘텐츠를 투사하지 않고, 전원, 입력, 화질, HDR, 렌즈, 키스톤, 유지관리를 위한 리모컨 및 설정 컨트롤러이며 씬과 홈 오토메이션도 지원합니다.
어떤 프로젝터를 지원하나요? +
네트워크에 연결된 Epson 홈 시네마 프로젝터를 지원합니다. EH-QB1000과 LS12000, LS11000, LS800, LS500 레이저 모델부터 6050UB, 5050UB, 4010, 3800 램프 모델, 이전 세대인 6040UB, 5040UB, 5030UB까지 포함합니다. 소형 Home Cinema, LS300, LS650, EF 모델은 전원과 입력만 지원합니다. Home Cinema 3200은 네트워크 제어를 지원하지 않습니다. 기본 PJLink 제어는 다른 제조사의 프로젝터에서도 작동합니다.
내 프로젝터와 어떻게 통신하나요? +
모두 로컬 네트워크에서 이루어지는 세 가지 방법을 사용합니다. TCP 포트 3629의 ESC/VP.net을 통한 ESC/VP21(프로젝터에 비밀번호를 설정했다면 그 비밀번호 사용), 전원, 입력, 상태를 위한 TCP 포트 4352의 PJLink, 그리고 프로젝터가 제공하는 설정을 위해 Digest 로그인을 쓰는 HTTP 포트 80의 Epson Web Control 인터페이스입니다.
전동 렌즈를 제어할 수 있나요? +
네, 전동 렌즈가 있는 프로젝터에서 가능합니다. 렌즈 시프트, 포커스, 줌을 제어할 수 있고, 화면비나 스크린 위치별로 렌즈 메모리 프리셋을 저장하고 불러올 수 있습니다. 전동 렌즈가 없는 모델에서는 렌즈 컨트롤이 숨겨집니다.
HDR과 광색역을 지원하나요? +
네, 지원하는 모델에서 가능합니다. 다이내믹 레인지(Auto, SDR, HDR PQ, HLG 중 모델이 지원하는 항목)와 색 공간을 선택할 수 있고, 보정을 위해 채널별 RGB 게인과 오프셋을 조정할 수 있습니다.
대기 상태에서 프로젝터를 켤 수 있나요? +
네, 프로젝터가 대기 모드에서도 네트워크를 활성 상태로 유지한다면 가능합니다. 유선 LAN과 프로젝터의 대기 모드 네트워크 설정을 사용하면 대기 모드에서 안정적으로 켤 수 있습니다.
Projector Pilot PJLink & VP21 앱의 가격은 얼마인가요? +
무료로 다운로드할 수 있으며 프로젝터 한 대와 기본 제어가 포함됩니다. Pro는 $9.99의 일회성 잠금 해제, Home Automation은 $2.99이며, 둘을 묶은 번들은 $11.99입니다. 구독도, 광고도 없습니다. 한 번 구매하면 계속 사용할 수 있습니다.
