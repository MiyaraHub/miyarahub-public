내 NAS 전체를 한눈에.

Syno Manager의 실제 스크린샷입니다. 대시보드, 시스템 모니터, 스토리지, 작업, 파일, 테마 등을 확인하세요. 이미지를 누르면 확대됩니다.

기능

NAS를 손안에서 완벽하게 제어하세요.

DSM이 보여주는 모든 것을 모바일로 담았고, 계정이 볼 수 없는 항목은 자연스럽게 숨겨집니다.

No. 01

◉ 실시간 대시보드

CPU, RAM, 온도, 가동 시간을 한눈에 실시간으로 확인하세요. 카드를 원하는 대로 구성해 시스템 상태, 스토리지 사용량, 네트워크 처리량 등 정말 중요한 정보만 볼 수 있습니다.

No. 02

▣ Docker 관리

실행 중인 모든 컨테이너를 실시간 CPU 및 메모리 사용량과 함께 확인하세요. 컨테이너를 시작, 중지, 재시작하고 로그를 열어 볼 수 있어 Docker를 휴대폰으로 완벽하게 제어합니다.

No. 03

◎ 감시 카메라

깔끔한 그리드 레이아웃으로 실시간 카메라 영상을 확인하세요. 탭하면 전체 화면으로 보고 녹화 상태도 확인할 수 있어, Surveillance Station의 모든 카메라를 한곳에서 모니터링합니다.

No. 04

▢ 스토리지 & 드라이브 상태

볼륨 사용량, RAID 상태, 개별 드라이브 온도, 모든 디스크의 SMART 상태 데이터를 확인하세요. 스토리지 상태를 언제든 파악할 수 있습니다.

No. 05

╿ 네트워크 모니터링

모든 네트워크 인터페이스의 실시간 대역폭 그래프를 제공합니다. 다운로드/업로드 속도, 활성 연결, 본딩 인터페이스, DNS 설정을 추적하세요.

No. 06

⚙ 패키지 관리

설치된 모든 DSM 패키지와 상태를 확인하세요. 실행 중인 서비스, 예약된 작업, UPS 배터리 상태, 로그 항목, 공유 폴더도 모니터링할 수 있습니다.

No. 07

☼ 자유로운 맞춤 설정

대시보드 카테고리를 구성하고, 탐색 바를 꾸미고, 테마를 고르고, 폴링 간격을 설정하세요. 앱을 원하는 방식으로 쓸 수 있습니다.

No. 08

✦ 홈 화면 위젯

빠른 실행, 스토리지 개요, 시스템 상태 위젯을 홈 화면에 추가하세요. 앱을 열지 않고도 NAS 상태를 확인할 수 있습니다.

사용 방법

DSM에 직접 연결합니다. 클라우드는 없습니다.

1

NAS 추가

NAS의 IP 또는 호스트 이름과 포트를 입력하세요. MiyaraHub 계정도, 가입도 필요 없습니다.

2

DSM으로 로그인

기존 DSM 계정으로 인증하세요. 인증 정보는 DSM 웹 포털과 같은 방식으로 NAS에만 전송됩니다.

3

모니터링 & 관리

대시보드, Docker, 카메라, 스토리지, 네트워크, 패키지, 작업을 휴대폰, 태블릿, 데스크톱에서 바로 관리하세요.

보안 & 개인정보

내 NAS, 내 데이터, 내 통제.

Syno Manager는 개인정보 보호를 최우선으로 하는 구조로 설계되었습니다. 최소한의 데이터 수집, 사용자 추적 없음, 클라우드 의존 없음.

◉

클라우드 중계 없음

모든 통신은 로컬 네트워크를 통해 기기와 NAS 사이에서 직접 이루어집니다. 외부 서버를 거치는 것은 없습니다.

▣

표준 DSM 인증

DSM 웹 인터페이스와 같은 인증 방식을 사용합니다. 인증 정보는 NAS에만 전송되며 저희에게는 전송되지 않습니다.

◎

최소한의 분석

버그를 잡고 안정성을 높이기 위해 Firebase Crashlytics를 사용합니다. 개인 데이터도, 사용 추적도, 광고도 없습니다. 앱은 기기 밖으로 NAS 데이터나 인증 정보를 수집하지 않습니다.

◆

안전한 로컬 저장

연결 정보는 플랫폼 보안 저장소인 iOS Keychain과 Android Keystore를 사용해 기기에 저장됩니다.

FAQ

자주 묻는 질문.

앱은 내 NAS에 어떻게 연결되나요? +
Syno Manager는 문서화된 Synology DSM API 엔드포인트를 사용해 로컬 네트워크에서 NAS와 통신합니다. 앱은 NAS로 요청을 직접 보내며, 중간 서버나 프록시, 클라우드 중계는 전혀 없습니다. NAS의 IP/호스트 이름과 포트를 입력하고 DSM 계정으로 인증하면 앱이 DSM과 직접 통신합니다.
앱에는 NAS에서 어떤 권한이 필요한가요? +
앱은 DSM 사용자 계정이 가진 권한 범위 안에서 동작합니다. 모든 대시보드 기능을 사용하려면 관리자 계정을 권장합니다. 다만 앱은 권한이 부족해도 자연스럽게 대응합니다. 계정에 Docker 권한이 없으면 Docker 섹션에 데이터가 표시되지 않을 뿐이며, Surveillance Station, 공유 폴더 등도 마찬가지입니다. 별도의 DSM 패키지를 설치할 필요는 없습니다.
앱이 내 NAS 인증 정보를 저장하나요? +
연결 정보는 플랫폼 보안 저장소(iOS Keychain / Android Keystore)를 사용해 기기에 로컬로 저장됩니다. 인증 정보는 MiyaraHub Technologies나 제3자에게 전송되지 않으며, NAS에 인증하는 용도로만 사용됩니다.
어떤 Synology 모델을 지원하나요? +
Syno Manager는 DSM 7.0 이상이 실행되는 모든 Synology NAS에서 작동합니다. 현재 판매 중인 모든 DiskStation(DS), RackStation(RS), FlashStation(FS) 모델이 포함됩니다. DSM 6.x가 실행되는 구형 모델은 API 차이로 인해 기능이 제한될 수 있습니다.
Docker 컨테이너를 원격으로 관리할 수 있나요? +
네. 앱에서 바로 컨테이너 상태와 CPU/메모리 사용량을 확인하고, 로그를 열어 보고, 중지/재시작할 수 있습니다. 컨테이너 생성과 설정 변경은 현재 지원하지 않으며, 모니터링과 빠른 관리 작업에 집중하고 있습니다.
Syno Manager의 가격은 얼마인가요? +
Syno Manager는 $9.99에 한 번만 구매하는 방식입니다. 구독도, 광고도, 인앱 결제도 없습니다. App Store 또는 Google Play에서 한 번 구매하면 계속 사용할 수 있습니다.
집 밖에서도 NAS에 원격으로 접속할 수 있나요? +
Syno Manager는 설정한 IP/호스트 이름으로 연결합니다. VPN, Tailscale 또는 포트 포워딩으로 NAS에 접속할 수 있다면 원격에서도 작동합니다. DSM을 인터넷에 직접 노출하기보다 VPN이나 Tailscale을 사용하시길 권장합니다.
