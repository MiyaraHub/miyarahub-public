기능

리모컨 전체를 손안에.

UC Remote는 Wi-Fi로 Unfolded Circle Remote Two 또는 Remote 3에 연결하여 액티비티, 페이지, 엔티티, 미디어 등 리모컨이 할 수 있는 모든 것을 휴대폰에 맞춘 빠른 네이티브 인터페이스로 그대로 보여 줍니다.

No. 01

◉ 한 번의 탭으로 액티비티 실행

Shield TV, Xbox, PS5 시청 같은 전체 액티비티를 깔끔한 목록에서 시작하고 중지하세요. 리모컨이 알맞은 장비의 전원을 켜고 입력을 전환하며, 앱은 해당 액티비티의 제어 화면으로 바로 이동합니다.

모든 액티비티에는 고유한 맞춤 페이지가 있습니다. 미디어 지금 재생 중 화면, 버튼 리모컨, 맞춤형 제어 타일 사이를 넘겨 보세요. 리모컨에서 설정한 그대로 배치됩니다.

사용 방법

리모컨에 직접 연결합니다. 클라우드는 필요 없습니다.

UC Remote는 내 Wi-Fi에서 Unfolded Circle 리모컨과 페어링하고, 리모컨 자체의 연동 인터페이스를 사용해 직접 통신합니다. 사용자의 설정은 외부 서버를 거치지 않습니다.

1

리모컨 페어링

Unfolded Circle Remote Two 또는 Remote 3의 IP 주소와 화면에 표시되는 PIN을 입력하세요. UC Remote가 안전하게 페어링하고 프로필, 페이지, 액티비티, 엔티티를 불러옵니다.

2

항상 동기화

실시간 양방향 연결로 리모컨의 상태(켜져 있는 것, 재생 중인 것)를 받아오고, 탭한 내용은 곧바로 명령으로 전달됩니다. 폴링 지연도, 클라우드 왕복도 없습니다.

3

모든 것을 제어

액티비티 실행, 맞춤 페이지 조작, 모든 엔티티와 미디어 플레이어 제어, 여러 리모컨 전환, 홈 화면 위젯 고정까지 앱 하나로 모두 할 수 있습니다.

보안 & 개인정보

로컬 전용. 계정 없음. 클라우드 없음.

UC Remote는 개인정보 보호를 최우선으로 하는 로컬 전용 구조로 만들어졌습니다. 클라우드 의존도 없고, 사용자 계정도 없으며, 충돌 보고 외에는 어떤 데이터도 수집하지 않습니다.

◉

클라우드 중계 없음

모든 명령과 실시간 상태 스트림은 로컬 Wi-Fi를 통해 휴대폰과 리모컨 사이에서 직접 이루어집니다. 네트워크 밖으로 나가는 것은 없습니다.

◎

계정 불필요

가입도, 이메일도, MiyaraHub 계정도 필요 없습니다. 리모컨의 PIN으로 페어링하면 바로 제어할 수 있습니다.

▣

PIN 페어링 접근

페어링 시 보안 액세스 토큰이 교환되며, 이 토큰은 기기에 로컬로 저장되어 리모컨과 통신하는 데에만 사용됩니다.

◆

로컬 저장만 사용

리모컨 주소와 앱 환경설정은 기기에 저장됩니다. 서버와 동기화되는 것은 없습니다.

▢

사용자의 동작만 반영

명령은 사용자가 직접 조작할 때만 전송됩니다. 사용자가 모르는 사이에 자동으로 또는 백그라운드에서 실행되는 일은 없습니다.

☰

네트워크 권한만

UC Remote에 필요한 권한은 로컬 네트워크 접근뿐이며, Wi-Fi에서 리모컨에 연결하는 용도로만 사용됩니다.

UC Remote에 대해 알아야 할 모든 것.

UC Remote는 Unfolded Circle과 제휴 관계인가요? +
아니요. UC Remote는 MiyaraHub Technologies LLC가 개발한 독립적인 서드파티 컴패니언 앱입니다. Unfolded Circle이 만들거나 보증, 후원하지 않으며 어떠한 방식으로도 제휴하지 않습니다. "Unfolded Circle," "Remote Two," "Remote 3"는 각 소유자의 상표이며, 이 이름들은 호환성을 설명하기 위한 목적으로만 사용합니다.
어떤 기기와 함께 작동하나요? +
UC Remote는 로컬 네트워크의 Unfolded Circle Remote Two 및 Remote 3와 함께 작동합니다. 리모컨이 휴대폰과 같은 Wi-Fi에서 접근 가능하다면 UC Remote가 페어링하여 리모컨의 액티비티, 페이지, 엔티티를 그대로 보여 줍니다.
내 리모컨에 어떻게 연결되나요? +
로컬 Wi-Fi를 통해 연결됩니다. 한 번 PIN으로 페어링하고 나면 UC Remote는 실시간 이벤트 채널을 열어 두어 리모컨의 상태와 동기화하고, 명령을 직접 전송합니다. 클라우드 중계도, 계정도 없으며 모든 것이 사용자의 네트워크 안에 머뭅니다.
계정이나 인터넷 연결이 필요한가요? +
계정은 절대 필요하지 않습니다. UC Remote는 리모컨에 연결하기 위한 로컬 네트워크만 있으면 됩니다. Wi-Fi 밖으로 나가는 것은 없으며, 가입해야 하는 클라우드 서비스도 없습니다.
리모컨을 두 대 이상 제어할 수 있나요? +
네. Unfolded Circle 리모컨을 원하는 만큼 페어링하고 한 번의 탭으로 전환할 수 있습니다. 각 리모컨은 자체 프로필, 페이지, 엔티티를 유지합니다.
UC Remote는 어떤 플랫폼에서 사용할 수 있나요? +
UC Remote는 Android 휴대폰과 태블릿용 네이티브 앱이며 Google Play에서 받으실 수 있습니다.

법적 고지 & 상표 안내

UC Remote는 MiyaraHub Technologies LLC가 개발하고 배포하는 독립적인 서드파티 애플리케이션입니다. Unfolded Circle ApS 및 그 자회사나 계열사가 만들거나 제휴, 보증, 후원하지 않으며 어떠한 방식으로도 공식적인 관계가 없습니다.

"Unfolded Circle," "Remote Two," "Remote 3" 및 관련 제품명과 로고는 각 소유자의 상표 또는 등록 상표입니다. 여기에 언급된 기타 모든 상표는 각 소유자의 자산입니다.

이 페이지와 앱에서 이러한 제품을 언급하는 것은 호환성을 식별하고 앱의 기능을 설명하기 위한 목적에 한정됩니다(지정적 공정 사용). 상표권자는 MiyaraHub Technologies LLC와 제휴 관계가 없으며 이 제품을 보증하지 않습니다.

UC Remote는 Unfolded Circle 리모컨의 로컬 네트워크 연동 인터페이스를 사용해 통신합니다. 이 앱의 사용에 따른 책임은 사용자에게 있습니다. MiyaraHub Technologies LLC는 설정 오류 또는 앱 사용 중 발생하는 기타 문제에 대해 책임지지 않습니다.
