기능

UPS가 알려 주는 모든 정보를 알기 쉽게.

홈 랩부터 랙 가득한 장비까지, 네트워크의 모든 UPS를 모니터링하고 관리하세요.

No. 01

◉ 실시간 대시보드

모든 UPS 기기의 상태를 한눈에 확인하세요. 배터리 잔량, 부하, 전압, 남은 가동 가능 시간을 보여 줍니다. 폴링 간격을 설정할 수 있어 항상 실시간으로 최신 상태를 유지합니다.

No. 02

▣ 전력 지표

입력 및 출력 전력 데이터를 자세히 보여 줍니다. 전압, 주파수, 전류, 와트, 피상 전력, 라인 품질을 모니터링하세요. 전원 환경을 이해하는 데 필요한 모든 것이 담겨 있습니다.

No. 03

◎ 배터리 상태

충전율, 전압, 온도, 예상 가동 가능 시간을 보여 주는 애니메이션 배터리 게이지를 제공합니다. 앱에서 바로 자가 테스트를 실행해 배터리 상태를 확인할 수 있습니다.

No. 04

▢ 콘센트 제어

UPS의 개별 콘센트를 확인하고 관리하세요. 어떤 콘센트가 활성 상태인지 보고, 쉽게 구분할 수 있도록 이름을 바꾸고, 제어 가능한 콘센트를 켜고 끌 수 있습니다.

No. 05

⚠ 스마트 알림

정전, 배터리 부족, 기기 오프라인, 전원 복구 이벤트에 대한 알림을 설정할 수 있습니다. 임계값을 직접 지정하고 소리와 진동 설정을 선택하세요.

No. 06

╿ 이벤트 기록

연결 변경, 상태 조회, 전원 이벤트, 알람 등 UPS 이벤트의 전체 로그를 제공합니다. 모든 기기의 타임스탬프가 찍힌 항목으로 언제 무슨 일이 있었는지 추적하세요.

No. 07

☼ 자유로운 맞춤 설정

다크, 라이트, 시스템 테마. 섭씨 또는 화씨. 조정 가능한 표시 크기, 사용자 지정 하단 탐색, 설정 가능한 폴링 간격. 나만의 스타일로 만드세요.

No. 08

✦ 내보내기 & 가져오기

백업이나 이전을 위해 기기 설정을 내보내세요. 새 기기에서 설정을 가져오면 연결 정보를 다시 입력하지 않고도 즉시 사용을 시작할 수 있습니다.

사용 방법

SNMP / NUT로 직접 연결합니다. 클라우드는 없습니다.

1

UPS 추가

IP 주소를 입력하고 SNMP(v1/v2c/v3) 또는 NUT를 선택하세요. 계정도, 가입도 필요 없습니다.

2

네트워크로 조회

UPSight는 로컬 네트워크에서 UPS와 직접 통신하며, 외부 서버를 거치는 것은 없습니다.

3

모니터링 & 알림 받기

배터리, 부하, 가동 가능 시간, 콘센트, 이벤트를 확인하고, 전원이 끊기거나 배터리가 부족해지면 스마트 알림을 받으세요.

준비물

네트워크에 연결된 UPS.

UPSight는 UPS의 네트워크 카드 또는 NUT 서버를 통해 네트워크로 UPS와 통신합니다.

◉

네트워크 카드가 있는 UPS

APC Network Management Card, CyberPower RMCARD, Eaton Network-M2 및 Network-M3, Tripp Lite WEBCARDLX, Vertiv Liebert IntelliSlot 및 SNMP를 지원하는 모든 UPS 네트워크 카드가 해당됩니다. 카드의 웹 페이지에서 SNMP를 켠 다음 UPSight에서 IP 주소를 추가하세요.

▣

또는 NUT로 공유한 UPS

UPS가 서버, NAS 또는 Raspberry Pi에 USB로 연결되어 있고 그 장비에서 Network UPS Tools(NUT) 서버가 실행 중이라면, UPSight에서 NUT 서버를 추가해 네트워크 어디에서나 UPS를 모니터링할 수 있습니다.

◎

USB 전용 구성은 안 됩니다

네트워크 카드도 NUT 서버도 없이 USB로 컴퓨터 한 대에만 연결된 UPS는 네트워크로 접근할 수 없어 UPSight에서 볼 수 없습니다.

개인정보 보호 우선 구조. 계정도, 클라우드도, 추적도 없습니다.

▣

한 번만 구매하면 됩니다. 구독도, 인앱 결제도 없으며 앞으로의 모든 업데이트가 포함됩니다.

FAQ

자주 묻는 질문.

UPS가 인터넷에 연결되어 있어야 하나요? +
아니요. UPSight는 로컬 네트워크에서만 통신합니다. UPS가 휴대폰과 같은 네트워크에 있거나 VPN/Tailscale로 접근 가능하기만 하면 됩니다. UPS 자체에는 인터넷 접속이 필요 없습니다.
UPS를 여러 대 모니터링할 수 있나요? +
네! UPSight는 UPS 기기를 개수 제한 없이 지원합니다. 대시보드에서 모든 장치를 한눈에 볼 수 있는 상태 카드로 확인할 수 있습니다. 기기를 누르면 개요, 전력, 배터리, 콘센트, 이벤트, 정보의 여섯 개 탭에서 자세한 내용을 볼 수 있습니다.
앱에서 UPS 콘센트를 제어할 수 있나요? +
네, SNMP로 콘센트 제어를 지원하는 UPS 모델(예: 제어 가능한 콘센트가 있는 CyberPower PR 시리즈)에서 가능합니다. 개별 콘센트를 켜고 끄고, 쉽게 구분할 수 있도록 이름을 바꿀 수 있습니다. 읽기 전용 콘센트는 상태만 표시되며 토글 제어는 제공되지 않습니다.
UPSight의 가격은 얼마인가요? +
UPSight는 $4.99에 한 번만 구매하는 방식입니다. 구독도, 인앱 결제도, 광고도 없습니다. 한 번 구매하면 계속 사용할 수 있으며 앞으로의 모든 업데이트가 포함됩니다.
어떤 SNMP 버전을 지원하나요? +
UPSight는 SNMP v1, v2c, v3를 지원합니다. 설정할 때 기기마다 버전을 선택할 수 있습니다. 대부분의 일반 소비자용 및 프로슈머용 UPS는 커뮤니티 문자열이 "public"인 v2c를 사용합니다. v3는 인증과 암호화가 필요한 기업 환경에서 사용할 수 있습니다.
집 밖에서도 UPSight를 원격으로 사용할 수 있나요? +
네, UPS가 VPN, Tailscale, WireGuard 등으로 접근 가능하다면 사용할 수 있습니다. UPSight는 설정한 IP 주소로 연결합니다. SNMP 포트를 인터넷에 직접 노출하기보다 VPN 접속을 권장합니다.
UPSight가 내 UPS 네트워크 카드와 호환되나요? +
네, 카드가 SNMP를 지원하면 됩니다. APC Network Management Card, CyberPower RMCARD, Eaton Network-M2 및 Network-M3, Tripp Lite WEBCARDLX, Vertiv Liebert IntelliSlot 카드가 해당됩니다. '카드'의 웹 인터페이스에서 SNMP를 켠 다음 UPSight에서 카드의 IP 주소를 추가하세요.
UPS에 USB 포트만 있어요. UPSight를 사용할 수 있나요? +
네, NUT를 통해 가능합니다. UPS를 Network UPS Tools(NUT) 서버가 실행되는 서버, NAS 또는 Raspberry Pi에 연결하고 UPSight에서 해당 서버를 추가하세요. NUT 없이 USB로 컴퓨터 한 대에만 연결된 UPS는 네트워크로 접근할 수 없습니다.
내 UPS 브랜드가 목록에 없어요. 작동하나요? +
아마도 작동할 거예요! UPS가 SNMP를 지원하고 표준 RFC 1628 UPS-MIB를 구현한다면 UPSight의 범용 드라이버가 작동합니다. 네트워크를 지원하는 대부분의 UPS가 이 표준을 따릅니다. 문제가 생기면 연락해 주세요. 해당 브랜드 전용 드라이버를 추가할 수 있는지 살펴보겠습니다.
