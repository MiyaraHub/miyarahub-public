Funksjoner

UniFi-kontrolleren din, i lommen.

Network Deck snakker direkte med det lokale API-et til UniFi-kontrolleren din - enten det er UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) eller en frittstående UniFi Network-kontroller. Klienter, WiFi, brannmur, porter, VPN og innsikt, uten å åpne en nettleser.

Nr. 01

◉ Live dashbord

ISP-helse, sanntidsgraf for båndbredde med et rullerende vindu på 60 målinger og tilpassbare kort - systeminfo, DPI-trafikk, alarmer, hendelser, toppklienter, historikk for hastighetstester og raske snarveier. Fanebasert layout som du kan omorganisere.

Nr. 02

▣ Klienter & enheter

Full klientliste med filtre for WiFi / kablet / alle og signalstyrke i dBm på et blikk. Blokker, opphev blokkering, kast ut eller glem i bulk. Detaljvisning per klient med historikk, DPI-fordeling, fast IP, brukergruppe og gjesteautentisering.

Blokker / kast utSignal dBmFast IPBulkhandlinger
Nr. 03

◎ WiFi, VLANs & portstyring

Opprett, rediger og slett WiFi-nettverk (SSIDs) med sikkerhet, bånd, gjest, VLAN, PMF og rask roaming. Administrer VLANs med DHCP, IPv6, mDNS, multicast og isolasjonsbrytere. PoE-styring per port og konfigurasjon av AP-radioer (kanal, TX-effekt, bredde, båndstyring, min. RSSI).

Policyer (tillat / blokker / inspiser), portvideresending, trafikkregler og ruter, brannmurgrupper, brannmursoner med v2-policymatrisen og kontroll over DPI-apper / -grupper - alt med innebygde brytere for å slå av og på. Ingen nettleser nødvendig.

Slå IPS / IDS av og på og velg modus, innholdsfilter per nettverk (jobb / familie / egendefinert), SSL-inspeksjon, geo-IP-blokkering med hvitliste / svarteliste for land, skanning etter useriøse AP-er og trusselhistorikk hentet fra alarmene i kontrolleren din.

Kompatibilitet

Fungerer med UniFi-kontrolleren din.

Network Deck støtter både UniFi OS-konsoller og frittstående UniFi Network-kontrollere. Appen oppdager automatisk hvilke endepunkter fastvaren din tilbyr og tilpasser grensesnittet - funksjoner du ikke har, vises rett og slett ikke.

◉ UniFi OS-konsoller

  • UDM Pro SE (verifisert)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Frittstående kontrollere

  • UniFi Network 10.x (verifisert)
  • Selvhostet på Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Autentisering

  • Brukernavn og passord for lokal administrator
  • Tofaktorautentisering (TOTP)
  • X-API-KEY for programmatisk tilgang
  • Ingen UniFi-skykonto nødvendig

◆ Mobilplattformer

  • iOS 13 og nyere
  • Android 5.0 (API 21) og nyere
  • Telefon- og nettbrettoppsett
  • Lyse og mørke temaer

Toleranse for fastvare: Network Deck oppdager automatisk hvilke endepunkter kontrolleren din tilbyr og tilpasser seg fastvarespesifikke JSON-varianter (endrede feltnavn, typekonvertering, flere former for integrasjons-API-et). Underadministratorkontoer kan oppleve at enkelte endepunkter svarer med 401 - det er en tillatelsesbegrensning i kontrolleren, ikke en begrensning i appen.

Slik fungerer det

Direkte til kontrolleren din. Ingen skyrelé.

Network Deck snakker direkte med UniFi-kontrolleren din over det lokale nettverket (eller VPN). Legitimasjonen din og nettverksdataene dine berører aldri en MiyaraHub-server.

1

Legg til kontrolleren din

Skriv inn kontrollerens vertsnavn eller IP, port (standard 443 for UniFi OS, 8443 for frittstående) og din lokale administratorlegitimasjon. Network Deck oppdager automatisk om du bruker UniFi OS eller en frittstående kontroller.

2

Logg inn lokalt

Logg inn med brukernavn og passord til din lokale administrator. Tofaktorautentisering støttes fullt ut. Foretrekker du API-nøkler? Bruk X-API-KEY for programmatisk tilgang og hopp helt over informasjonskapsel-flyten.

3

Styr alt på et blikk

Følg den levende båndbreddegrafen, kast ut en klient som oppfører seg dårlig, slå en brannmurregel av eller på, restart en PoE-port, inviter en Teleport-gjest eller bytt til en annen site - hver handling går til kontrolleren og oppdaterer live-hendelsesstrømmen.

Sikkerhet & personvern

Bare lokalt. Ingen konto. Ingen skyrelé.

Network Deck er utviklet med en personvern-først-arkitektur som kun er lokal. Ingen MiyaraHub-konto, ingen skyrelé, ingen datainnsamling utover krasjrapportering.

◉

Ingen skyrelé

Alle kommandoer og live-strømmer går direkte mellom telefonen og kontrolleren din over det lokale WiFi-nettverket eller VPN. Ingenting rutes via eksterne servere.

▣

Standard UniFi-autentisering

Bruker samme lokale administratorlegitimasjon (eller API-nøkkel) som webgrensesnittet i UniFi Network. Legitimasjonen lagres i iOS Keychain / Android Keystore på enheten og sendes aldri ut av enheten, bortsett fra til kontrolleren din.

◎

Ingen MiyaraHub-konto

Ingen registrering, ingen e-post, ingen MiyaraHub-konto nødvendig. Installer, pek appen mot kontrolleren din, så er du i gang.

◈

Minimal analyse

Firebase Crashlytics kun for feilrapporter. Ingen sporing av bruk, ingen reklame, ingen salg av data. Nettverksfeil logges som ikke-fatale for å hjelpe oss å forbedre fastvarekompatibiliteten uten at vi samler inn nettverksoppsettet ditt.

◆

Tillatelser respekteres

Appen opererer innenfor de tillatelsene UniFi-administratorkontoen din har. Underadministratorer ser bare det kontrolleren tillater. Ingen rettighetseskalering, ingen bakdør.

◐

Bare nettverkstilgang

Den eneste enhetstillatelsen Network Deck trenger er nettverkstilgang, som utelukkende brukes til å koble til UniFi-kontrolleren din på det lokale nettverket (eller via VPN).

Alt du trenger å vite om Network Deck.

Nei. Network Deck er en uavhengig tredjepartsapp utviklet av MiyaraHub Technologies LLC. Den er ikke laget av, godkjent av, sponset av eller tilknyttet Ubiquiti Inc. på noen måte. «Ubiquiti», «UniFi», «UniFi OS», «UniFi Network», «UDM», «UDR», «UCG», «Teleport» og alle tilhørende produktnavn er varemerker som tilhører Ubiquiti Inc. Vi bruker disse navnene utelukkende for å beskrive kompatibilitet (nominativ rimelig bruk).
Hvilke UniFi-kontrollere støttes? +
Network Deck støtter både UniFi OS-konsoller (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) og frittstående UniFi Network-kontrollere som kjører v10.x på Linux, Docker eller Windows. Appen oppdager plattformen din automatisk ved tilkobling og tilpasser grensesnittet til de endepunktene fastvaren din faktisk tilbyr - funksjoner du ikke har, vises rett og slett ikke. Testet live mot UDM Pro SE (UniFi OS 5.0.16) og frittstående Network 10.2.105.
Hvordan kommuniserer Network Deck med kontrolleren min? +
Network Deck bruker samme lokale API som webgrensesnittet i UniFi Network - en kombinasjon av de klassiske endepunktene /rest og /cmd (med øktautentisering via informasjonskapsler) og det nyere v2-integrasjons-API-et. Appen åpner også en WebSocket mot kontrolleren din for å strømme live-hendelser. All kommunikasjon skjer direkte mellom telefonen og kontrolleren din over det lokale nettverket eller VPN.
Trenger jeg en UniFi-skykonto? +
Nei. Network Deck bruker kun lokal autentisering. Logg inn med brukernavn og passord til din lokale UniFi-administrator (eller en API-nøkkel). Hvis kontrolleren din foreløpig bare er tilgjengelig via skyinnlogging på ui.com, må du aktivere en lokal administratorkonto under Settings → Admins for å bruke Network Deck. Kontrolleren snakker aldri med oss, og vi snakker aldri med Ubiquitis sky på dine vegne.
Kan jeg administrere brannmurregler og portvideresending? +
Ja. Network Deck har en komplett brannmurpakke: policyer (tillat / blokker / inspiser), portvideresending med full CRUD, trafikkregler og ruter, brannmurgrupper, brannmursoner (v2-policymatrise) og DPI-apper / -grupper. Alt kan slås av og på direkte fra listevisningen - ingen dialog-trykk-dialog-flyt.
Støtter den flere sites? +
Ja. Hvis kontrolleren din administrerer flere sites, viser Network Deck en site-velger øverst. Alle funksjoner - dashbord, klienter, brannmur, VPN - gjelder den valgte siten. Bytt med ett trykk.
Hva kommer Network Deck til å koste? +
Network Deck blir et engangskjøp til $4.99 i App Store, Google Play og Microsoft Store. Ingen abonnement, ingen reklame, ingen kjøp i appen. Prisen kan endres før den offentlige lanseringen.
Kan jeg bruke den eksternt (utenfor hjemmet / kontoret)? +
Network Deck kobler til det vertsnavnet eller den IP-adressen du konfigurerer. Hvis kontrolleren din er tilgjengelig via VPN, Tailscale, WireGuard eller en videresendt port, fungerer appen eksternt. Vi anbefaler å bruke VPN eller Tailscale i stedet for å eksponere UniFi-kontrolleren direkte mot internett.
Hvilke plattformer støttes? +
Network Deck kjører på både iOS (13 og nyere) og Android (5.0 / API 21 og nyere). Både telefon- og nettbrettoppsett støttes. Appen lanseres samtidig i App Store, Google Play og Microsoft Store.
