Hva du trenger

En UPS på nettverket ditt.

UPSight snakker med UPS-en din over nettverket, via nettverkskortet eller via en NUT-server.

◉

En UPS med nettverkskort

APC Network Management Card, CyberPower RMCARD, Eaton Network-M2 og Network-M3, Tripp Lite WEBCARDLX, Vertiv Liebert IntelliSlot og alle andre UPS-nettverkskort som snakker SNMP. Slå på SNMP på kortets nettside, og legg deretter til IP-adressen i UPSight.

▣

Eller en UPS delt med NUT

Hvis UPS-en er koblet til en server, NAS eller Raspberry Pi med USB og den maskinen kjører en Network UPS Tools (NUT)-server, kan du legge til NUT-serveren i UPSight for å overvåke UPS-en fra hvor som helst på nettverket ditt.

◎

Ikke et oppsett kun med USB

En UPS som bare er koblet til én datamaskin med USB, uten nettverkskort og uten NUT-server, kan ikke nås over nettverket, så UPSight kan ikke se den.

FAQ

Ofte stilte spørsmål.

Må UPS-en min være koblet til internett? +
Nei. UPSight kommuniserer kun over det lokale nettverket ditt. UPS-en må bare være på samme nettverk som telefonen din (eller nås via VPN/Tailscale). UPS-en trenger ikke internettilgang selv.
Kan jeg overvåke flere UPS-enheter? +
Ja! UPSight støtter ubegrenset antall UPS-enheter. Dashbordet viser alle enhetene dine med statuskort du kan lese på et blikk. Trykk på en enhet for full informasjon fordelt på seks faner: Oversikt, Strøm, Batteri, Uttak, Hendelser og Info.
Kan jeg styre UPS-ens uttak fra appen? +
Ja, for UPS-modeller som støtter styring av uttak via SNMP (f.eks. CyberPower PR-serien med styrbare uttak). Du kan slå enkeltuttak av og på og gi dem nytt navn så de er lette å kjenne igjen. Uttak som bare kan leses viser status, men har ingen brytere.
Hva koster UPSight? +
UPSight er et engangskjøp på $4.99. Ingen abonnement, ingen kjøp i appen, ingen reklame. Kjøp det én gang og bruk det for alltid. Alle fremtidige oppdateringer er inkludert.
Hvilke SNMP-versjoner støttes? +
UPSight støtter SNMP v1, v2c og v3. Du velger versjon per enhet under oppsettet. De fleste UPS-enheter for forbrukere og avanserte brukere bruker v2c med community-strengen «public». v3 er tilgjengelig for bedriftsmiljøer som krever autentisering og kryptering.
Kan jeg bruke UPSight eksternt (utenfor hjemmenettverket)? +
Ja, hvis UPS-en din er tilgjengelig via VPN, Tailscale, WireGuard eller lignende. UPSight kobler til den IP-adressen du konfigurerer. Vi anbefaler VPN-tilgang i stedet for å eksponere SNMP-porter direkte mot internett.
Fungerer UPSight med nettverkskortet i UPS-en min? +
Ja, hvis kortet snakker SNMP. Det omfatter APC Network Management Card, CyberPower RMCARD, Eaton Network-M2 og Network-M3, Tripp Lite WEBCARDLX og Vertiv Liebert IntelliSlot-kort. Slå på 'SNMP' i kortets nettgrensesnitt, og legg deretter til kortets IP-adresse i UPSight.
UPS-en min har bare en USB-port. Kan jeg bruke UPSight? +
Ja, via NUT. Koble UPS-en til en server, NAS eller Raspberry Pi som kjører en Network UPS Tools (NUT)-server, og legg til den serveren i UPSight. En UPS som bare er koblet til én datamaskin med USB, uten NUT, kan ikke nås over nettverket.
UPS-merket mitt er ikke oppført. Vil det fungere? +
Sannsynligvis! Hvis UPS-en din støtter SNMP og implementerer standarden RFC 1628 UPS-MIB, fungerer UPSights generiske driver. De fleste nettverkskompatible UPS-enheter følger denne standarden. Hvis du får problemer, kan du kontakte oss, så undersøker vi om vi kan legge til en egen driver for merket ditt.
