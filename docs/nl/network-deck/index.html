Functies

Je UniFi-controller, in je broekzak.

Network Deck praat rechtstreeks met de lokale API van je UniFi-controller - of dat nu UniFi OS is (UDM Pro, Cloud Gateway, Dream Machine) of een zelfstandige UniFi Network-controller. Clients, WiFi, firewall, poorten, VPN en inzichten, zonder een browser te openen.

Compatibiliteit

Werkt met jouw UniFi-controller.

Network Deck ondersteunt zowel UniFi OS-consoles als zelfstandige UniFi Network-controllers. De app herkent automatisch welke endpoints jouw firmware biedt en past de interface daarop aan - functies die je niet hebt, verschijnen gewoon niet.

◉ UniFi OS-consoles

  • UDM Pro SE (geverifieerd)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Zelfstandige controllers

  • UniFi Network 10.x (geverifieerd)
  • Zelf gehost op Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Authenticatie

  • Lokale beheerdersnaam + wachtwoord
  • Tweestapsverificatie (TOTP)
  • X-API-KEY voor programmatische toegang
  • Geen UniFi Cloud-account nodig

◆ Mobiele platforms

  • iOS 13 en hoger
  • Android 5.0 (API 21) en hoger
  • Telefoon- en tablet-indelingen
  • Lichte en donkere thema's

Firmwaretolerantie: Network Deck herkent automatisch de endpoints die je controller biedt en past zich aan firmwarespecifieke JSON-varianten aan (afwijkende veldnamen, typeconversie, meerdere vormen voor de integratie-API). Bij subbeheerdersaccounts kunnen sommige endpoints 401 teruggeven - dat is een rechtenbeperking van de controller, geen beperking van de app.

Hoe het werkt

Rechtstreeks naar je controller. Geen cloudrelay.

Network Deck praat rechtstreeks met je UniFi-controller via je lokale netwerk (of je VPN). Je inloggegevens en netwerkgegevens komen nooit op een MiyaraHub-server terecht.

1

Voeg je controller toe

Voer de hostnaam of het IP-adres van je controller in, de poort (standaard 443 voor UniFi OS, 8443 voor zelfstandig) en je lokale beheerdersgegevens. Network Deck herkent automatisch of je UniFi OS of een zelfstandige controller gebruikt.

2

Meld je lokaal aan

Meld je aan met je lokale beheerdersnaam en wachtwoord. Tweestapsverificatie wordt volledig ondersteund. Liever API-sleutels? Gebruik X-API-KEY voor programmatische toegang en sla de cookieprocedure helemaal over.

3

Beheer in één oogopslag

Volg de live bandbreedtegrafiek, werp een lastige client eruit, schakel een firewallregel om, herstart een PoE-poort, nodig een Teleport-gast uit of wissel naar een andere site - elke actie gaat heen en terug naar de controller en werkt de live gebeurtenisstroom bij.

Beveiliging & privacy

Alleen lokaal. Geen account. Geen cloudrelay.

Network Deck is ontworpen met een privacy-eerst, uitsluitend lokale architectuur. Geen MiyaraHub-account, geen cloudrelay, geen gegevensverzameling behalve crashrapportage.

◉

Geen cloudrelay

Alle opdrachten en livestreams lopen rechtstreeks tussen je telefoon en je controller, via je lokale Wi-Fi of VPN. Niets gaat via externe servers.

▣

Standaard UniFi-authenticatie

Gebruikt dezelfde lokale beheerdersgegevens (of API-sleutel) als de webinterface van UniFi Network. Inloggegevens worden op het apparaat bewaard in de iOS Keychain / Android Keystore en verlaten het apparaat nooit, behalve richting je controller.

◎

Geen MiyaraHub-account

Geen registratie, geen e-mailadres, geen MiyaraHub-account nodig. Installeer de app, wijs hem naar je controller en je bent binnen.

◈

Minimale analytics

Firebase Crashlytics alleen voor bugrapporten. Geen gebruikstracking, geen advertenties, geen verkoop van gegevens. Netwerkfouten worden als niet-fataal gelogd, zodat we de firmwarecompatibiliteit kunnen verbeteren zonder de indeling van je netwerk te verzamelen.

◆

Rechten worden gerespecteerd

De app werkt binnen de rechten die je UniFi-beheerdersaccount heeft. Subbeheerders zien alleen wat de controller hun toestaat te zien. Geen rechtenverhoging, geen achterdeur.

◐

Alleen netwerktoestemming

De enige apparaatmachtiging die Network Deck nodig heeft, is netwerktoegang, uitsluitend gebruikt om verbinding te maken met je UniFi-controller op je lokale netwerk (of via VPN).

Alles wat je over Network Deck wilt weten.

Is Network Deck gelieerd aan Ubiquiti of UniFi? +
Nee. Network Deck is een onafhankelijke app van derden, ontwikkeld door MiyaraHub Technologies LLC. De app is op geen enkele manier gemaakt door, goedgekeurd door, gesponsord door of gelieerd aan Ubiquiti Inc. “Ubiquiti”, “UniFi”, “UniFi OS”, “UniFi Network”, “UDM”, “UDR”, “UCG”, “Teleport” en alle verwante productnamen zijn handelsmerken van Ubiquiti Inc. Wij gebruiken deze namen uitsluitend om compatibiliteit te beschrijven (nominatief gebruik te goeder trouw).
Welke UniFi-controllers worden ondersteund? +
Network Deck ondersteunt zowel UniFi OS-consoles (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) als zelfstandige UniFi Network-controllers met v10.x op Linux, Docker of Windows. De app herkent je platform automatisch bij het verbinden en past de interface aan op de endpoints die jouw firmware daadwerkelijk biedt - functies die je niet hebt, verschijnen gewoon niet. Live getest met UDM Pro SE (UniFi OS 5.0.16) en een zelfstandige Network 10.2.105.
Hoe communiceert Network Deck met mijn controller? +
Network Deck gebruikt dezelfde lokale API als de webinterface van UniFi Network - een combinatie van de klassieke /rest- en /cmd-endpoints (met sessieauthenticatie via cookies) plus de nieuwere v2-integratie-API. Daarnaast opent de app een WebSocket naar je controller om live gebeurtenissen te streamen. Alle communicatie verloopt rechtstreeks tussen je telefoon en je controller, via je lokale netwerk of VPN.
Heb ik een UniFi-cloudaccount nodig? +
Nee. Network Deck gebruikt uitsluitend lokale authenticatie. Meld je aan met de lokale beheerdersnaam en het wachtwoord van je UniFi (of met een API-sleutel). Als je controller nu alleen bereikbaar is via de ui.com-cloudaanmelding, schakel dan een lokaal beheerdersaccount in via Settings → Admins om Network Deck te gebruiken. De controller communiceert nooit met ons en wij communiceren nooit namens jou met de cloud van Ubiquiti.
Kan ik firewallregels en port forwards beheren? +
Ja. Network Deck heeft een complete firewallset: beleidsregels (toestaan / blokkeren / inspecteren), port forwards met volledig CRUD, verkeersregels en routes, firewallgroepen, firewallzones (v2-beleidsmatrix) en DPI-apps / -groepen. Alles schakel je direct in de lijstweergave in of uit - geen eindeloos geklik door dialoogvensters.
Ondersteunt het multi-site? +
Ja. Als je controller meerdere sites beheert, toont Network Deck bovenaan een sitewisselaar. Elke functie - dashboard, clients, firewall, VPN - geldt voor de site die je op dat moment hebt gekozen. Wisselen doe je met één tik.
Wat gaat Network Deck kosten? +
Network Deck wordt een eenmalige aankoop van $4.99 in de App Store, Google Play en de Microsoft Store. Geen abonnement, geen advertenties, geen in-app-aankopen. De prijs kan nog wijzigen voor de officiële lancering.
Kan ik de app ook op afstand gebruiken (buiten mijn huis / kantoor)? +
Network Deck maakt verbinding met de hostnaam of het IP-adres dat je instelt. Is je controller bereikbaar via VPN, Tailscale, WireGuard of een doorgestuurde poort, dan werkt de app ook op afstand. Wij raden aan een VPN of Tailscale te gebruiken in plaats van je UniFi-controller rechtstreeks aan het internet bloot te stellen.
Welke platforms worden ondersteund? +
Network Deck draait op zowel iOS (13 en hoger) als Android (5.0 / API 21 en hoger). Zowel telefoon- als tablet-indelingen worden ondersteund. De app verschijnt tegelijkertijd in de App Store, Google Play en de Microsoft Store.
