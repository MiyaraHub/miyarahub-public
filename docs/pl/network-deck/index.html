Funkcje

Twój kontroler UniFi w kieszeni.

Network Deck komunikuje się bezpośrednio z lokalnym API Twojego kontrolera UniFi - czy to UniFi OS (UDM Pro, Cloud Gateway, Dream Machine), czy samodzielny kontroler UniFi Network. Klienci, WiFi, zapora, porty, VPN i statystyki, bez otwierania przeglądarki.

Zgodność

Działa z Twoim kontrolerem UniFi.

Network Deck obsługuje zarówno konsole UniFi OS, jak i samodzielne kontrolery UniFi Network. Automatycznie wykrywa, jakie punkty końcowe udostępnia Twoje oprogramowanie sprzętowe, i dopasowuje do nich interfejs - funkcje, których nie masz, po prostu się nie pojawiają.

◉ Konsole UniFi OS

  • UDM Pro SE (zweryfikowano)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Kontrolery samodzielne

  • UniFi Network 10.x (zweryfikowano)
  • Własny hosting na Linuksie / w Dockerze
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Uwierzytelnianie

  • Lokalna nazwa użytkownika i hasło administratora
  • Uwierzytelnianie dwuskładnikowe (TOTP)
  • X-API-KEY do dostępu programistycznego
  • Konto w chmurze UniFi nie jest wymagane

◆ Platformy mobilne

  • iOS 13 i nowszy
  • Android 5.0 (API 21) i nowszy
  • Układy na telefony i tablety
  • Motywy jasny i ciemny

Tolerancja na oprogramowanie sprzętowe: Network Deck automatycznie wykrywa punkty końcowe udostępniane przez Twój kontroler i dostosowuje się do wariantów JSON specyficznych dla danej wersji oprogramowania (zmiany nazw pól, konwersje typów, różne kształty API integracyjnego). Konta poddadministratorów mogą otrzymywać z niektórych punktów końcowych błąd 401 - to ograniczenie uprawnień kontrolera, a nie aplikacji.

Jak to działa

Bezpośrednio do Twojego kontrolera. Bez przekaźnika w chmurze.

Network Deck komunikuje się bezpośrednio z Twoim kontrolerem UniFi w sieci lokalnej (lub przez VPN). Twoje dane logowania i dane sieciowe nigdy nie trafiają na serwer MiyaraHub.

1

Dodaj swój kontroler

Wpisz nazwę hosta lub adres IP kontrolera, port (domyślnie 443 dla UniFi OS, 8443 dla kontrolera samodzielnego) oraz lokalne dane administratora. Network Deck automatycznie wykrywa, czy używasz UniFi OS, czy kontrolera samodzielnego.

2

Uwierzytelnij się lokalnie

Zaloguj się lokalną nazwą użytkownika i hasłem administratora. Uwierzytelnianie dwuskładnikowe jest obsługiwane od początku do końca. Wolisz klucze API? Użyj X-API-KEY do dostępu programistycznego i całkowicie pomiń przepływ z ciasteczkami.

3

Zarządzaj na pierwszy rzut oka

Obserwuj wykres przepustowości na żywo, rozłącz niesfornego klienta, przełącz regułę zapory, zrestartuj port PoE, zaproś gościa przez Teleport albo przełącz się na inną witrynę - każda akcja trafia do kontrolera i aktualizuje strumień zdarzeń na żywo.

Bezpieczeństwo & prywatność

Tylko lokalnie. Bez konta. Bez pośrednictwa chmury.

Network Deck został zaprojektowany z myślą o prywatności i działaniu wyłącznie lokalnym. Bez konta MiyaraHub, bez przekaźnika w chmurze, bez zbierania danych poza raportami o awariach.

◉

Bez pośrednictwa chmury

Wszystkie polecenia i strumienie na żywo płyną bezpośrednio między telefonem a kontrolerem przez Twoją lokalną sieć Wi-Fi lub VPN. Nic nie przechodzi przez zewnętrzne serwery.

▣

Standardowe uwierzytelnianie UniFi

Używa tych samych lokalnych danych administratora (lub klucza API) co interfejs webowy UniFi Network. Dane logowania są przechowywane w iOS Keychain / Android Keystore na urządzeniu i nigdy nie opuszczają go, poza wysyłką do Twojego kontrolera.

◎

Bez konta MiyaraHub

Bez rejestracji, bez e-maila, bez konta MiyaraHub. Zainstaluj, wskaż swój kontroler i gotowe.

◈

Minimalna analityka

Firebase Crashlytics wyłącznie do zgłaszania błędów. Bez śledzenia użycia, bez reklam, bez sprzedaży danych. Błędy sieciowe są zapisywane jako niekrytyczne, aby pomóc nam poprawiać zgodność z oprogramowaniem sprzętowym bez zbierania informacji o układzie Twojej sieci.

◆

Poszanowanie uprawnień

Aplikacja działa w granicach uprawnień Twojego konta administratora UniFi. Poddadministratorzy widzą tylko to, na co pozwala kontroler. Bez eskalacji uprawnień, bez tylnych drzwi.

◐

Tylko uprawnienie sieciowe

Jedyne uprawnienie urządzenia, którego wymaga Network Deck, to dostęp do sieci, używany wyłącznie do łączenia się z Twoim kontrolerem UniFi w sieci lokalnej (lub przez VPN).

Jakie kontrolery UniFi są obsługiwane? +
Network Deck obsługuje zarówno konsole UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus), jak i samodzielne kontrolery UniFi Network w wersji v10.x działające w systemie Linux, w Dockerze lub w Windows. Aplikacja automatycznie wykrywa Twoją platformę po połączeniu i dostosowuje interfejs do punktów końcowych, które faktycznie udostępnia Twoje oprogramowanie sprzętowe - funkcje, których nie masz, po prostu się nie pojawiają. Przetestowano na żywo z UDM Pro SE (UniFi OS 5.0.16) i samodzielnym Network 10.2.105.
Jak Network Deck komunikuje się z moim kontrolerem? +
Network Deck korzysta z tego samego lokalnego API, którego używa interfejs webowy UniFi Network - połączenia klasycznych punktów końcowych /rest i /cmd (z uwierzytelnianiem sesji opartym na ciasteczkach) oraz nowszego API integracyjnego v2. Otwiera też WebSocket do Twojego kontrolera, aby przesyłać zdarzenia na żywo. Cała komunikacja odbywa się bezpośrednio między telefonem a kontrolerem, w Twojej sieci lokalnej lub przez VPN.
Czy potrzebuję konta w chmurze UniFi? +
Nie. Network Deck korzysta wyłącznie z uwierzytelniania lokalnego. Zaloguj się lokalną nazwą użytkownika i hasłem administratora UniFi (albo kluczem API). Jeśli Twój kontroler jest obecnie dostępny tylko przez logowanie w chmurze ui.com, włącz lokalne konto administratora w Settings → Admins, aby korzystać z Network Deck. Kontroler nigdy nie łączy się z nami, a my nigdy nie łączymy się z chmurą Ubiquiti w Twoim imieniu.
Czy mogę zarządzać regułami zapory i przekierowaniami portów? +
Tak. Network Deck ma pełny zestaw funkcji zapory: polityki (zezwalaj / blokuj / inspekcja), przekierowania portów z pełną obsługą CRUD, reguły i trasy ruchu, grupy zapory, strefy zapory (macierz polityk v2) oraz aplikacje i grupy DPI. Wszystko włączysz i wyłączysz przełącznikiem prosto z listy - bez klikania od okna do okna.
Czy obsługuje wiele witryn? +
Tak. Jeśli Twój kontroler zarządza wieloma witrynami, Network Deck pokazuje u góry przełącznik witryn. Każda funkcja - pulpit, klienci, zapora, VPN - dotyczy aktualnie wybranej witryny. Przełączasz jednym dotknięciem.
Ile będzie kosztować Network Deck? +
Network Deck będzie jednorazowym zakupem za 4,99 USD w App Store, Google Play i Microsoft Store. Bez subskrypcji, bez reklam, bez zakupów w aplikacji. Cena może się zmienić przed publiczną premierą.
Czy mogę używać go zdalnie (poza domem / biurem)? +
Network Deck łączy się z dowolną nazwą hosta lub adresem IP, które skonfigurujesz. Jeśli Twój kontroler jest osiągalny przez VPN, Tailscale, WireGuard lub przekierowany port, aplikacja będzie działać zdalnie. Zalecamy korzystanie z VPN lub Tailscale zamiast wystawiania kontrolera UniFi bezpośrednio do internetu.
Jakie platformy są obsługiwane? +
Network Deck działa zarówno na iOS (13 i nowszy), jak i na Android (5.0 / API 21 i nowszy). Obsługiwane są układy zarówno na telefony, jak i na tablety. Aplikacja zadebiutuje jednocześnie w App Store, Google Play i Microsoft Store.
