Compatibilidade

Funciona com o seu controlador UniFi.

O Network Deck é compatível com consoles UniFi OS e com controladores UniFi Network independentes. Ele detecta automaticamente quais endpoints o seu firmware oferece e adapta a UI - recursos que você não tem simplesmente não aparecem.

◉ Consoles UniFi OS

  • UDM Pro SE (verificado)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Controladores independentes

  • UniFi Network 10.x (verificado)
  • Hospedagem própria em Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Autenticação

  • Usuário e senha de administrador local
  • Autenticação em dois fatores (TOTP)
  • X-API-KEY para acesso programático
  • Sem necessidade de conta na nuvem UniFi

◆ Plataformas móveis

  • iOS 13 ou superior
  • Android 5.0 (API 21) ou superior
  • Layouts para celular e tablet
  • Temas claro e escuro

Tolerância a firmware: o Network Deck detecta automaticamente os endpoints que o seu controlador expõe e se adapta às variações de JSON de cada firmware (mudança de nomes de campos, coerção de tipos, formatos diferentes na API de integração). Contas de subadministrador podem receber 401 em alguns endpoints - isso é um limite de permissões do controlador, não do app.

Como funciona

Direto no seu controlador. Sem retransmissão pela nuvem.

O Network Deck fala diretamente com o seu controlador UniFi pela rede local (ou pela sua VPN). Suas credenciais e os dados da sua rede nunca passam por um servidor da MiyaraHub.

1

Adicione o seu controlador

Informe o nome de host ou IP do controlador, a porta (padrão 443 para UniFi OS, 8443 para independente) e suas credenciais de administrador local. O Network Deck detecta sozinho se você usa UniFi OS ou um controlador independente.

2

Autentique-se localmente

Entre com seu usuário e senha de administrador local. A autenticação em dois fatores é compatível de ponta a ponta. Prefere chaves de API? Use X-API-KEY para acesso programático e dispense o fluxo de cookies.

3

Gerencie num relance

Acompanhe o gráfico de largura de banda ao vivo, desconecte um cliente problemático, ative uma regra de firewall, reinicie uma porta PoE, convide um visitante pelo Teleport ou troque de site - cada ação vai até o controlador e atualiza o fluxo de eventos ao vivo.

Segurança & Privacidade

Somente local. Sem conta. Sem relé na nuvem.

O Network Deck foi projetado com uma arquitetura focada em privacidade e totalmente local. Sem conta MiyaraHub, sem retransmissão pela nuvem, sem coleta de dados além de relatórios de falhas.

◉

Sem Relé na Nuvem

Todos os comandos e fluxos ao vivo acontecem diretamente entre o seu celular e o seu controlador, pelo seu Wi-Fi local ou VPN. Nada passa por servidores externos.

▣

Autenticação UniFi padrão

Usa as mesmas credenciais de administrador local (ou chave de API) da UI web do UniFi Network. As credenciais ficam guardadas no iOS Keychain / Android Keystore do aparelho e nunca saem dele, exceto para o seu controlador.

◎

Sem conta MiyaraHub

Sem cadastro, sem e-mail, sem precisar de conta MiyaraHub. Instale, aponte para o seu controlador e pronto.

◈

Análises Mínimas

Firebase Crashlytics somente para relatórios de bugs. Sem rastreamento de uso, sem anúncios, sem venda de dados. Os erros de rede são registrados como não fatais para nos ajudar a melhorar a compatibilidade com firmwares, sem coletar o desenho da sua rede.

◆

Permissões respeitadas

O app opera dentro das permissões que a sua conta de administrador UniFi tem. Subadministradores veem apenas o que o controlador permite. Sem escalonamento de privilégios, sem backdoor.

◐

Somente Permissão de Rede

A única permissão de dispositivo que o Network Deck exige é o acesso à rede, usado exclusivamente para conectar ao seu controlador UniFi na rede local (ou por VPN).

FAQ

Perguntas frequentes.

Tudo o que você precisa saber sobre o Network Deck.

O Network Deck é afiliado à Ubiquiti ou à UniFi? +
Não. O Network Deck é um aplicativo independente de terceiros, desenvolvido pela MiyaraHub Technologies LLC. Ele não é criado, endossado, patrocinado nem afiliado à Ubiquiti Inc. de nenhuma forma. “Ubiquiti”, “UniFi”, “UniFi OS”, “UniFi Network”, “UDM”, “UDR”, “UCG”, “Teleport” e todos os nomes de produtos relacionados são marcas comerciais da Ubiquiti Inc. Usamos esses nomes apenas para descrever a compatibilidade (uso nominativo legítimo).
Quais controladores UniFi são compatíveis? +
O Network Deck é compatível tanto com consoles UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) quanto com controladores UniFi Network independentes na versão v10.x, em Linux, Docker ou Windows. O app detecta sua plataforma automaticamente na conexão e adapta a UI aos endpoints que o seu firmware realmente oferece - recursos que você não tem simplesmente não aparecem. Testado ao vivo em um UDM Pro SE (UniFi OS 5.0.16) e no Network 10.2.105 independente.
Como o Network Deck se comunica com o meu controlador? +
O Network Deck usa a mesma API local que a UI web do UniFi Network - uma combinação dos endpoints clássicos /rest e /cmd (com autenticação de sessão por cookie) e da nova API de integração v2. Ele também abre um WebSocket com o seu controlador para receber eventos ao vivo. Toda a comunicação acontece diretamente entre o seu celular e o seu controlador, pela rede local ou por VPN.
Preciso de uma conta na nuvem UniFi? +
Não. O Network Deck usa apenas autenticação local. Entre com o usuário e a senha de administrador local do UniFi (ou uma chave de API). Se hoje o seu controlador só é acessível pelo login na nuvem do ui.com, será preciso habilitar uma conta de administrador local em Settings → Admins para usar o Network Deck. O controlador nunca fala com a gente, e nós nunca falamos com a nuvem da Ubiquiti em seu nome.
Consigo gerenciar regras de firewall e redirecionamentos de porta? +
Sim. O Network Deck tem uma pilha de firewall completa: políticas (permitir / bloquear / inspecionar), redirecionamentos de porta com CRUD, regras de tráfego e rotas, grupos de firewall, zonas de firewall (matriz de políticas v2) e apps / grupos DPI. Tudo pode ser ativado e desativado direto na lista - sem aquele vai e vem de diálogos.
Há suporte a vários sites? +
Sim. Se o seu controlador gerencia vários sites, o Network Deck mostra um seletor de site no topo. Todos os recursos - painel, clientes, firewall, VPN - se aplicam ao site selecionado no momento. Troque com um toque.
Quanto vai custar o Network Deck? +
O Network Deck será uma compra única de US$ 4.99 na App Store, no Google Play e na Microsoft Store. Sem assinatura, sem anúncios, sem compras dentro do app. O preço pode mudar antes do lançamento público.
Posso usar o app remotamente (fora de casa / do escritório)? +
O Network Deck se conecta ao nome de host ou IP que você configurar. Se o seu controlador estiver acessível por VPN, Tailscale, WireGuard ou uma porta redirecionada, o app funciona remotamente. Recomendamos usar uma VPN ou o Tailscale em vez de expor o controlador UniFi diretamente à internet.
Quais plataformas são compatíveis? +
O Network Deck roda tanto em iOS (13 ou superior) quanto em Android (5.0 / API 21 ou superior). Há layouts para celular e tablet. O app será lançado ao mesmo tempo na App Store, no Google Play e na Microsoft Store.
