O seu controlador UniFi, no bolso.

Compatibilidade

Funciona com o seu controlador UniFi.

O Network Deck suporta tanto consolas UniFi OS como controladores UniFi Network autónomos. Deteta automaticamente os endpoints que o seu firmware disponibiliza e adapta a interface em conformidade - as funcionalidades que não tem simplesmente não aparecem.

◉ Consolas UniFi OS

  • UDM Pro SE (verificado)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Controladores autónomos

  • UniFi Network 10.x (verificado)
  • Alojado por si em Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Autenticação

  • Nome de utilizador + palavra-passe de administrador local
  • Autenticação de dois fatores (TOTP)
  • X-API-KEY para acesso programático
  • Sem necessidade de conta UniFi Cloud

◆ Plataformas móveis

  • iOS 13 e superior
  • Android 5.0 (API 21) e superior
  • Layouts para telemóvel e tablet
  • Temas claro e escuro

Tolerância a firmware: o Network Deck deteta automaticamente os endpoints que o seu controlador disponibiliza e adapta-se às variantes de JSON específicas de cada firmware (nomes de campos que mudam, coerção de tipos, várias formas da API de integração). As contas de subadministrador podem ver alguns endpoints devolverem 401 - é um limite de permissões do controlador, não uma limitação da app.

Como funciona

Diretamente para o seu controlador. Sem relé na cloud.

O Network Deck comunica diretamente com o seu controlador UniFi através da rede local (ou da sua VPN). As suas credenciais e os dados da sua rede nunca passam por um servidor da MiyaraHub.

1

Adicione o seu controlador

Introduza o nome de anfitrião ou IP do seu controlador, a porta (por predefinição 443 para UniFi OS, 8443 para autónomo) e as credenciais de administrador local. O Network Deck deteta automaticamente se está num UniFi OS ou num controlador autónomo.

2

Autentique-se localmente

Inicie sessão com o nome de utilizador e a palavra-passe de administrador local. A autenticação de dois fatores é suportada de ponta a ponta. Prefere chaves de API? Use X-API-KEY para acesso programático e dispense por completo o fluxo de cookies.

3

Gira tudo num relance

Acompanhe o gráfico de largura de banda em direto, expulse um cliente problemático, ative uma regra de firewall, reinicie uma porta PoE, convide um convidado Teleport ou mude para outro site - cada ação vai ao controlador e atualiza o fluxo de eventos em direto.

Segurança & Privacidade

Só local. Sem conta. Sem retransmissão na nuvem.

O Network Deck foi concebido com uma arquitetura local, que dá prioridade à privacidade. Sem conta MiyaraHub, sem relé na cloud, sem recolha de dados além dos relatórios de falhas.

◉

Sem Retransmissão na Nuvem

Todos os comandos e fluxos em direto passam diretamente entre o seu telemóvel e o seu controlador, através da sua rede Wi-Fi local ou VPN. Nada é encaminhado por servidores externos.

▣

Autenticação UniFi padrão

Usa as mesmas credenciais de administrador local (ou chave de API) da interface web do UniFi Network. As credenciais ficam guardadas no iOS Keychain / Android Keystore do dispositivo e nunca são enviadas para fora dele, exceto para o seu controlador.

◎

Sem conta MiyaraHub

Sem registo, sem e-mail, sem conta MiyaraHub. Instale, aponte para o seu controlador e já está dentro.

◈

Análises Mínimas

Firebase Crashlytics apenas para relatórios de erros. Sem rastreio de utilização, sem anúncios, sem venda de dados. Os erros de rede são registados como não fatais para nos ajudar a melhorar a compatibilidade com firmware, sem recolher a estrutura da sua rede.

◆

Permissões respeitadas

A app funciona dentro das permissões que a sua conta de administrador UniFi tiver. Os subadministradores só veem o que o controlador lhes permite ver. Sem escalada de privilégios, sem backdoors.

◐

Apenas Permissão de Rede

A única permissão de dispositivo de que o Network Deck precisa é o acesso à rede, usado exclusivamente para ligar ao seu controlador UniFi na rede local (ou por VPN).

FAQ

Perguntas frequentes.

Tudo o que precisa de saber sobre o Network Deck.

O Network Deck está afiliado à Ubiquiti ou à UniFi? +
Não. O Network Deck é uma aplicação independente, de terceiros, desenvolvida pela MiyaraHub Technologies LLC. Não é criada, aprovada, patrocinada nem afiliada à Ubiquiti Inc. de forma alguma. “Ubiquiti”, “UniFi”, “UniFi OS”, “UniFi Network”, “UDM”, “UDR”, “UCG”, “Teleport” e todos os nomes de produtos relacionados são marcas comerciais da Ubiquiti Inc. Usamos estes nomes apenas para descrever a compatibilidade (uso nominativo legítimo).
Que controladores UniFi são suportados? +
O Network Deck suporta tanto as consolas UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) como os controladores UniFi Network autónomos com a v10.x em Linux, Docker ou Windows. A app deteta automaticamente a sua plataforma ao ligar e adapta a interface aos endpoints que o seu firmware realmente disponibiliza - as funcionalidades que não tem simplesmente não aparecem. Testado em direto com um UDM Pro SE (UniFi OS 5.0.16) e com o Network 10.2.105 autónomo.
Como comunica o Network Deck com o meu controlador? +
O Network Deck usa a mesma API local que a interface web do UniFi Network - uma combinação dos endpoints clássicos /rest e /cmd (com autenticação de sessão por cookie) e da nova API de integração v2. Abre também um WebSocket para o seu controlador para receber eventos em direto. Toda a comunicação acontece diretamente entre o seu telemóvel e o seu controlador, através da rede local ou de VPN.
Preciso de uma conta cloud UniFi? +
Não. O Network Deck usa apenas autenticação local. Inicie sessão com o nome de utilizador e a palavra-passe de administrador local do UniFi (ou uma chave de API). Se o seu controlador só estiver acessível através do início de sessão cloud do ui.com, terá de ativar uma conta de administrador local em Settings → Admins para usar o Network Deck. O controlador nunca comunica connosco, e nós nunca comunicamos com a cloud da Ubiquiti em seu nome.
Posso gerir regras de firewall e redirecionamento de portas? +
Sim. O Network Deck tem uma pilha de firewall completa: políticas (permitir / bloquear / inspecionar), redirecionamento de portas com CRUD, regras e rotas de tráfego, grupos de firewall, zonas de firewall (matriz de políticas v2) e apps / grupos DPI. Tudo se ativa e desativa diretamente na lista - sem ir e voltar entre caixas de diálogo.
Suporta vários sites? +
Sim. Se o seu controlador gere vários sites, o Network Deck mostra um seletor de sites no topo. Todas as funcionalidades - painel, clientes, firewall, VPN - aplicam-se ao site selecionado. Mude com um só toque.
Quanto vai custar o Network Deck? +
O Network Deck será uma compra única de $4.99 na App Store, no Google Play e na Microsoft Store. Sem subscrição, sem anúncios, sem compras na app. O preço pode mudar antes do lançamento público.
Posso usá-lo remotamente (fora de casa / do escritório)? +
O Network Deck liga-se ao nome de anfitrião ou IP que configurar. Se o seu controlador estiver acessível por VPN, Tailscale, WireGuard ou uma porta redirecionada, a app funciona remotamente. Recomendamos o uso de uma VPN ou do Tailscale em vez de expor o seu controlador UniFi diretamente à internet.
Que plataformas são suportadas? +
O Network Deck funciona em iOS (13 e superior) e em Android (5.0 / API 21 e superior). Há layouts para telemóvel e para tablet. A app será lançada em simultâneo na App Store, no Google Play e na Microsoft Store.
