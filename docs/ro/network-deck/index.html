Funcții

Controllerul tău UniFi, în buzunar.

Network Deck comunică direct cu API-ul local al controllerului tău UniFi - fie că este UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) sau un controller UniFi Network independent. Clienți, WiFi, firewall, porturi, VPN și statistici, fără să deschizi un browser.

Compatibilitate

Funcționează cu controllerul tău UniFi.

Network Deck acceptă atât consolele UniFi OS, cât și controllerele UniFi Network independente. Detectează automat ce endpoint-uri expune firmware-ul tău și adaptează interfața - funcțiile pe care nu le ai pur și simplu nu apar.

◉ Console UniFi OS

  • UDM Pro SE (verificat)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Controllere independente

  • UniFi Network 10.x (verificat)
  • Găzduit pe cont propriu pe Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Autentificare

  • Nume de utilizator + parolă de administrator local
  • Autentificare în doi pași (TOTP)
  • X-API-KEY pentru acces programatic
  • Nu este nevoie de cont UniFi Cloud

◆ Platforme mobile

  • iOS 13 și mai nou
  • Android 5.0 (API 21) și mai nou
  • Layout-uri pentru telefon și tabletă
  • Teme light și dark

Toleranță la firmware: Network Deck detectează automat endpoint-urile expuse de controllerul tău și se adaptează variantelor JSON specifice firmware-ului (nume de câmpuri diferite, conversii de tip, mai multe structuri pentru API-ul de integrare). Conturile de sub-administrator pot primi 401 de la unele endpoint-uri - aceasta este o limită de permisiuni a controllerului, nu o limitare a aplicației.

Cum funcționează

Direct la controllerul tău. Fără releu cloud.

Network Deck comunică direct cu controllerul tău UniFi prin rețeaua locală (sau prin VPN). Datele tale de autentificare și datele rețelei nu ajung niciodată pe un server MiyaraHub.

1

Adaugă controllerul

Introdu numele de gazdă sau IP-ul controllerului, portul (implicit 443 pentru UniFi OS, 8443 pentru cel independent) și datele de administrator local. Network Deck detectează automat dacă folosești UniFi OS sau un controller independent.

2

Autentifică-te local

Conectează-te cu numele de utilizator și parola de administrator local. Autentificarea în doi pași este acceptată complet. Preferi cheile API? Folosește X-API-KEY pentru acces programatic și sari complet peste fluxul cu cookie-uri.

3

Gestionează dintr-o privire

Urmărește graficul live de lățime de bandă, deconectează un client problematic, activează o regulă de firewall, repornește un port PoE, invită un oaspete Teleport sau comută pe alt site - fiecare acțiune ajunge la controller și actualizează fluxul de evenimente live.

Securitate & confidențialitate

Doar local. Fără cont. Fără releu cloud.

Network Deck este conceput cu o arhitectură exclusiv locală, care pune confidențialitatea pe primul loc. Fără cont MiyaraHub, fără releu cloud, fără colectare de date în afară de rapoartele de blocări.

◉

Fără releu cloud

Toate comenzile și fluxurile live circulă direct între telefonul tău și controller, prin rețeaua Wi-Fi locală sau VPN. Nimic nu trece prin servere externe.

▣

Autentificare UniFi standard

Folosește aceleași date de administrator local (sau cheie API) ca interfața web UniFi Network. Datele de autentificare sunt stocate în iOS Keychain / Android Keystore pe dispozitiv și nu sunt trimise nicăieri în afară de controllerul tău.

◎

Fără cont MiyaraHub

Fără înregistrare, fără e-mail, fără cont MiyaraHub. Instalezi, îl îndrepți spre controller și ești gata.

◈

Analize minime

Firebase Crashlytics doar pentru rapoarte de erori. Fără urmărirea utilizării, fără reclame, fără vânzare de date. Erorile de rețea sunt înregistrate ca nefatale, ca să ne ajute să îmbunătățim compatibilitatea cu firmware-ul, fără să colectăm structura rețelei tale.

◆

Permisiuni respectate

Aplicația funcționează în limitele permisiunilor contului tău de administrator UniFi. Sub-administratorii văd doar ce le permite controllerul. Fără escaladare de privilegii, fără portițe ascunse.

◐

Doar permisiunea de rețea

Singura permisiune de dispozitiv necesară pentru Network Deck este accesul la rețea, folosit exclusiv pentru conectarea la controllerul tău UniFi din rețeaua locală (sau prin VPN).

Tot ce trebuie să știi despre Network Deck.

Este Network Deck afiliat cu Ubiquiti sau UniFi? +
Nu. Network Deck este o aplicație independentă, a unui terț, dezvoltată de MiyaraHub Technologies LLC. Nu este creată, aprobată, sponsorizată sau afiliată cu Ubiquiti Inc. în niciun fel. „Ubiquiti”, „UniFi”, „UniFi OS”, „UniFi Network”, „UDM”, „UDR”, „UCG”, „Teleport” și toate numele de produse asociate sunt mărci comerciale ale Ubiquiti Inc. Folosim aceste nume strict pentru a descrie compatibilitatea (utilizare nominativă corectă).
Ce controllere UniFi sunt acceptate? +
Network Deck acceptă atât consolele UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus), cât și controllerele UniFi Network independente care rulează v10.x pe Linux, Docker sau Windows. Aplicația îți detectează automat platforma la conectare și adaptează interfața la endpoint-urile pe care firmware-ul tău le expune efectiv - funcțiile pe care nu le ai pur și simplu nu apar. Testat live pe UDM Pro SE (UniFi OS 5.0.16) și pe Network 10.2.105 independent.
Cum comunică Network Deck cu controllerul meu? +
Network Deck folosește același API local ca interfața web UniFi Network - o combinație între endpoint-urile clasice /rest și /cmd (cu autentificare de sesiune bazată pe cookie-uri) și noul API de integrare v2. Deschide, de asemenea, un WebSocket către controllerul tău pentru a transmite evenimente live. Toată comunicarea are loc direct între telefonul tău și controller, prin rețeaua locală sau VPN.
Am nevoie de un cont UniFi în cloud? +
Nu. Network Deck folosește doar autentificare locală. Conectează-te cu numele de utilizator și parola de administrator local UniFi (sau cu o cheie API). Dacă la ora actuală controllerul tău poate fi accesat doar prin autentificarea cloud ui.com, va trebui să activezi un cont de administrator local în Settings → Admins pentru a folosi Network Deck. Controllerul nu comunică niciodată cu noi, iar noi nu comunicăm niciodată cu cloudul Ubiquiti în numele tău.
Pot gestiona regulile de firewall și redirecționările de porturi? +
Da. Network Deck are un set complet de funcții de firewall: politici (permite / blochează / inspectează), redirecționări de porturi cu CRUD, reguli de trafic și rute, grupuri de firewall, zone de firewall (matricea de politici v2) și aplicații / grupuri DPI. Totul se activează direct din lista de elemente - fără lanțuri de dialoguri.
Acceptă multi-site? +
Da. Dacă controllerul tău gestionează mai multe site-uri, Network Deck afișează în partea de sus un selector de site. Fiecare funcție - tablou de bord, clienți, firewall, VPN - se aplică site-ului selectat în acel moment. Comuți dintr-o singură atingere.
Cât va costa Network Deck? +
Network Deck va fi o achiziție unică de $4.99 în App Store, Google Play și Microsoft Store. Fără abonament, fără reclame, fără achiziții în aplicație. Prețul se poate schimba înainte de lansarea publică.
Îl pot folosi de la distanță (în afara casei / biroului)? +
Network Deck se conectează la orice nume de gazdă sau IP configurezi. Dacă controllerul tău este accesibil prin VPN, Tailscale, WireGuard sau un port redirecționat, aplicația va funcționa și de la distanță. Îți recomandăm să folosești un VPN sau Tailscale în loc să expui controllerul UniFi direct la internet.
Ce platforme sunt acceptate? +
Network Deck rulează atât pe iOS (13 și mai nou), cât și pe Android (5.0 / API 21 și mai nou). Sunt acceptate atât layout-urile pentru telefon, cât și cele pentru tabletă. Aplicația se va lansa simultan în App Store, Google Play și Microsoft Store.
