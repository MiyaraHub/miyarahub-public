Funcții

Control complet al proiectorului, în palma ta.

Projector Pilot se conectează la proiectorul tău Epson prin Wi-Fi și îți oferă control complet asupra fiecărei setări - de la pornire și imagine până la obiectiv și geometrie - fără să atingi proiectorul sau să cauți telecomanda fizică.

Funcțiile disponibile diferă în funcție de model. Aplicația detectează automat funcțiile acceptate la conectare.

Cum funcționează

Conexiune directă în rețea. Fără cloud.

Projector Pilot comunică direct cu proiectorul tău prin Wi-Fi, folosind protocoale de rețea standard. Datele tale nu ating niciodată un server extern.

1

Adaugă-ți proiectorul

Introdu adresa IP a proiectorului tău Epson. Projector Pilot testează conectivitatea PJLink și Web Control, detectează modelul și descoperă automat toate funcțiile disponibile.

2

Conectează-te prin Wi-Fi

Projector Pilot folosește PJLink pentru detectarea standby-ului și controlul pornirii, plus Epson Web Control API pentru controlul complet al imaginii, obiectivului și setărilor când proiectorul este pornit. Totul rămâne în rețeaua ta locală.

3

Preia controlul complet

Ajustează setările de imagine, comută intrările, controlează obiectivul motorizat, gestionează corecția keystone, monitorizează orele lămpii și navighează în OSD - totul dintr-o singură aplicație elegantă.

Securitate & confidențialitate

Doar local. Fără cont. Fără cloud.

Projector Pilot este conceput cu o arhitectură exclusiv locală, care pune confidențialitatea pe primul loc. Fără dependență de cloud, fără cont de utilizator, fără colectare de date în afară de rapoartele de blocări.

◉

Fără releu cloud

Toate comenzile și interogările de stare au loc direct între telefonul tău și proiector, prin Wi-Fi local. Nimic nu părăsește rețeaua ta.

◎

Nu e nevoie de cont

Fără înregistrare, fără e-mail, fără cont MiyaraHub. Deschizi aplicația, introduci adresa IP a proiectorului și ai controlul.

▣

Analize minime

Firebase Crashlytics doar pentru rapoarte de erori. Fără date personale, fără urmărirea utilizării, fără reclame. Datele proiectorului tău nu părăsesc niciodată telefonul.

◆

Doar stocare locală

Adresele IP ale proiectoarelor, datele de autentificare și preferințele aplicației sunt stocate local pe dispozitivul tău, folosind SharedPreferences. Nimic nu este sincronizat cu un server.

▢

Doar acțiuni inițiate de utilizator

Aplicația trimite comenzi proiectorului tău doar la acțiunea ta explicită. Nimic nu se întâmplă automat sau în fundal fără știrea ta.

☼

Doar permisiunea de rețea

Singura permisiune de dispozitiv necesară pentru Projector Pilot este accesul la internet/rețea, folosit exclusiv pentru conectarea la proiectorul tău prin Wi-Fi local.

Este Projector Pilot afiliat cu Epson? +

Nu este creată, aprobată, sponsorizată sau afiliată cu Seiko Epson Corporation sau cu vreuna dintre filialele ori afiliații ei, în niciun fel. „Epson” este o marcă comercială înregistrată a Seiko Epson Corporation. Folosim acest nume strict pentru a descrie compatibilitatea (utilizare nominativă corectă).
Ce proiectoare sunt acceptate? +
Projector Pilot funcționează cu toate proiectoarele Epson conectate în rețea care acceptă PJLink și/sau Web Control. Aici intră majoritatea modelelor din ultimii 10+ ani - de la emblematicele QB1000 și LS12000 până la modelele Home Cinema de gamă medie și cele pentru instalări profesionale. Aplicația detectează automat funcțiile disponibile la conectare, astfel încât fiecare utilizator vede exact ce acceptă proiectorul său. Controlul de bază PJLink funcționează și cu proiectoare non-Epson de la NEC, Panasonic, Sony și altele.
Cum comunică Projector Pilot cu proiectorul meu? +
Projector Pilot folosește două protocoale: PJLink (port 4352) pentru controlul universal al proiectorului, inclusiv pornirea din standby, comutarea intrărilor și starea lămpii; și Epson Web Control API (port 80) cu autentificare Digest pentru controlul extins al setărilor, inclusiv imagine, obiectiv, keystone, HDR și altele. Toată comunicarea are loc direct în rețeaua ta Wi-Fi locală.
Pot controla obiectivul motorizat? +
Da, pe proiectoarele cu sisteme de obiectiv motorizate. Projector Pilot oferă control complet al deplasării obiectivului (orizontal și vertical), al focalizării și al zoomului, cu feedback de poziție în timp real. Poți salva și rechema presetări de memorie a obiectivului pentru diferite rapoarte de aspect, poziții ale ecranului sau configurații de vizionare. Controalele obiectivului sunt ascunse automat pentru modelele fără obiectiv motorizat.
Acceptă HDR și gamă largă de culori? +
Da. Projector Pilot îți permite să controlezi setările de gamă dinamică (Auto, HDR10, HLG, SDR), spațiul de culoare (Auto, BT.709, BT.2020) și oferă ajustări de câștig și decalaj RGB pe fiecare canal pentru o calibrare precisă a culorilor. Funcțiile HDR sunt afișate doar pe modelele care le acceptă.
Pot porni proiectorul din standby? +
Da. Projector Pilot folosește PJLink pentru a-ți porni proiectorul chiar și când este în modul standby. Atâta timp cât proiectorul este conectat la rețea (se recomandă LAN prin cablu pentru trezirea din standby), îl poți porni și opri de pe telefon.
Cât costă Projector Pilot? +
Projector Pilot se descarcă gratuit, cu controlul de bază inclus. Pro este o deblocare unică de $9.99, Automatizare Locuință costă $2.99, sau le iei pe amândouă într-un pachet cu $11.99. Fără abonament, fără reclame. Cumperi o dată și îl ai pentru totdeauna. Prețul se poate schimba înainte de lansare.
Ce versiune de Android este necesară? +
Projector Pilot necesită Android 5.0 (API 21) sau mai nou. Deocamdată este o aplicație doar pentru Android. Suportul pentru iOS ar putea fi adăugat într-o versiune viitoare.
