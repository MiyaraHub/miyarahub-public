Возможности

Ваш контроллер UniFi - всегда в кармане.

Совместимость

Работает с вашим контроллером UniFi.

Network Deck поддерживает как консоли UniFi OS, так и автономные контроллеры UniFi Network. Приложение само определяет, какие конечные точки отдаёт ваша прошивка, и подстраивает UI - недоступные функции просто не отображаются.

◉ Консоли UniFi OS

  • UDM Pro SE (проверено)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Автономные контроллеры

  • UniFi Network 10.x (проверено)
  • Самостоятельный хостинг на Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Аутентификация

  • Локальный логин и пароль администратора
  • Двухфакторная аутентификация (TOTP)
  • X-API-KEY для программного доступа
  • Учётная запись UniFi Cloud не нужна

◆ Мобильные платформы

  • iOS 13 и новее
  • Android 5.0 (API 21) и новее
  • Раскладки для телефонов и планшетов
  • Светлая и тёмная темы

Устойчивость к прошивкам: Network Deck сам определяет конечные точки вашего контроллера и подстраивается под особенности JSON в разных прошивках (изменившиеся имена полей, приведение типов, несколько форматов интеграционного API). У учётных записей субадминистраторов некоторые конечные точки могут отвечать 401 - это ограничение прав на стороне контроллера, а не приложения.

Как это работает

Напрямую к вашему контроллеру. Без облачного посредника.

Network Deck работает с вашим контроллером UniFi напрямую по локальной сети (или через VPN). Ваши учётные данные и данные сети никогда не попадают на серверы MiyaraHub.

1

Добавьте свой контроллер

Введите имя хоста или IP контроллера, порт (по умолчанию 443 для UniFi OS, 8443 для автономного) и локальные учётные данные администратора. Network Deck сам определит, UniFi OS у вас или автономный контроллер.

2

Войдите локально

Войдите с локальным логином и паролем администратора. Двухфакторная аутентификация поддерживается полностью. Предпочитаете ключи API? Используйте X-API-KEY для программного доступа и вовсе обойдитесь без cookie.

3

Всё под контролем с первого взгляда

Следите за графиком пропускной способности, отключайте шалящего клиента, переключайте правило межсетевого экрана, перезапускайте порт PoE, приглашайте гостя Teleport или переходите на другой сайт - каждое действие уходит на контроллер и отражается в потоке событий.

Network Deck построен на принципах конфиденциальности и работы только локально. Без учётной записи MiyaraHub, без облачного посредника, без сбора данных, кроме отчётов о сбоях.

◉

Без облачного ретранслятора

Все команды и потоки данных идут напрямую между вашим телефоном и контроллером по локальной сети Wi-Fi или VPN. Ничего не проходит через внешние серверы.

▣

Стандартная аутентификация UniFi

Используются те же локальные учётные данные администратора (или ключ API), что и в веб-интерфейсе UniFi Network. Учётные данные хранятся в iOS Keychain / Android Keystore на устройстве и никуда не передаются, кроме вашего контроллера.

◎

Без учётной записи MiyaraHub

Никакой регистрации, электронной почты и учётной записи MiyaraHub. Установите приложение, укажите контроллер - и вы внутри.

◈

Минимум аналитики

Firebase Crashlytics - только для отчётов об ошибках. Без отслеживания использования, без рекламы, без продажи данных. Сетевые ошибки записываются как некритичные, чтобы мы могли улучшать совместимость с прошивками, не собирая сведения о структуре вашей сети.

◆

Уважение к правам доступа

Приложение работает в пределах прав вашей учётной записи администратора UniFi. Субадминистраторы видят только то, что разрешает контроллер. Никакого повышения привилегий, никаких чёрных ходов.

◐

Только сетевое разрешение

Единственное разрешение, которое нужно Network Deck, - доступ к сети. Он используется исключительно для подключения к вашему контроллеру UniFi в локальной сети (или через VPN).

Всё, что нужно знать о Network Deck.

Связан ли Network Deck с Ubiquiti или UniFi? +
Нет. Network Deck - независимое стороннее приложение, разработанное MiyaraHub Technologies LLC. Оно не создано, не одобрено, не спонсируется и никак не связано с Ubiquiti Inc. "Ubiquiti", "UniFi", "UniFi OS", "UniFi Network", "UDM", "UDR", "UCG", "Teleport" и все связанные названия продуктов являются товарными знаками Ubiquiti Inc. Мы используем эти названия исключительно для описания совместимости (добросовестное номинативное использование).
Какие контроллеры UniFi поддерживаются? +
Network Deck поддерживает как консоли UniFi OS (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus), так и автономные контроллеры UniFi Network v10.x на Linux, Docker или Windows. При подключении приложение само определяет вашу платформу и подстраивает UI под те конечные точки, которые реально отдаёт ваша прошивка - недоступные функции просто не отображаются. Проверено вживую на UDM Pro SE (UniFi OS 5.0.16) и автономном Network 10.2.105.
Как Network Deck общается с моим контроллером? +
Network Deck использует тот же локальный API, что и веб-UI UniFi Network: классические конечные точки /rest и /cmd (с сеансовой аутентификацией на cookie) плюс новый интеграционный API v2. Кроме того, приложение открывает к контроллеру WebSocket для потока событий в реальном времени. Весь обмен идёт напрямую между вашим телефоном и контроллером по локальной сети или VPN.
Нужна ли учётная запись UniFi Cloud? +
Нет. Network Deck использует только локальную аутентификацию. Входите с локальным логином и паролем администратора UniFi (или с ключом API). Если сейчас ваш контроллер доступен только через облачный вход ui.com, включите локальную учётную запись администратора в Settings → Admins, чтобы работать с Network Deck. Контроллер никогда не обращается к нам, а мы никогда не обращаемся к облаку Ubiquiti от вашего имени.
Можно ли управлять правилами межсетевого экрана и пробросом портов? +
Да. В Network Deck есть полноценный набор средств межсетевого экрана: политики (разрешить / блокировать / проверять), проброс портов с полным набором операций CRUD, правила трафика и маршруты, группы межсетевого экрана, зоны межсетевого экрана (матрица политик v2) и приложения / группы DPI. Всё переключается прямо в списке - без цепочек из диалогов.
Поддерживается ли несколько сайтов? +
Да. Если ваш контроллер управляет несколькими сайтами, Network Deck показывает вверху переключатель сайтов. Все функции - дашборд, клиенты, межсетевой экран, VPN - работают в рамках выбранного сайта. Переключение одним касанием.
Сколько будет стоить Network Deck? +
Network Deck будет продаваться за единовременную плату $4.99 в App Store, Google Play и Microsoft Store. Без подписки, без рекламы, без встроенных покупок. Цена может измениться до публичного запуска.
Можно ли пользоваться им удалённо (вне дома / офиса)? +
Network Deck подключается к любому имени хоста или IP, который вы укажете. Если ваш контроллер доступен через VPN, Tailscale, WireGuard или проброшенный порт, приложение будет работать удалённо. Мы рекомендуем использовать VPN или Tailscale, а не выставлять контроллер UniFi напрямую в интернет.
Какие платформы поддерживаются? +
Network Deck работает как на iOS (13 и новее), так и на Android (5.0 / API 21 и новее). Поддерживаются раскладки для телефонов и планшетов. Приложение выйдет одновременно в App Store, Google Play и Microsoft Store.
