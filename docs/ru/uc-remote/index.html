Возможности

Весь ваш пульт - в вашей руке.

UC Remote подключается к вашему Unfolded Circle Remote Two или Remote 3 по Wi-Fi и отражает всё, что тот умеет, - активности, страницы, сущности и медиа - в быстром нативном интерфейсе, созданном для телефона.

№ 01

◉ Активности в одно касание

Запускайте и останавливайте целые активности - Watch Shield TV, Xbox, PS5 - из аккуратного списка. Пульт включает нужную технику и переключает входы, а приложение сразу открывает элементы управления этой активности.

Как это работает

Напрямую к вашему пульту. Облако не нужно.

UC Remote сопрягается с вашим пультом Unfolded Circle по вашей сети Wi-Fi и общается с ним напрямую через собственный интеграционный интерфейс пульта. Ваша система никогда не соприкасается с внешним сервером.

1

Подключите пульт

Введите IP-адрес вашего Unfolded Circle Remote Two или Remote 3 и PIN-код, который он показывает. UC Remote безопасно сопрягается и подтягивает ваши профили, страницы, активности и сущности.

2

Всегда синхронно

Постоянное двустороннее соединение передаёт состояние пульта - что включено, что играет, - а ваши касания тут же уходят обратно командами. Без задержек опроса, без обращения к облаку.

3

Управляйте всем

Запускайте активности, работайте с собственными страницами, управляйте каждой сущностью и медиаплеером, переключайтесь между несколькими пультами и закрепляйте виджеты на главном экране - всё в одном приложении.

Безопасность & конфиденциальность

Только локально. Без аккаунта. Без облака.

UC Remote построен на принципах конфиденциальности и работы только локально: без зависимости от облака, без учётной записи и без сбора данных, кроме отчётов о сбоях.

◉

Без облачного ретранслятора

Каждая команда и поток состояния в реальном времени идут напрямую между вашим телефоном и пультом по локальной сети Wi-Fi. Ничего не выходит за пределы вашей сети.

◎

Учётная запись не нужна

Без регистрации, без электронной почты, без учётной записи MiyaraHub. Сопрягитесь по PIN-коду пульта - и всё под вашим контролем.

▣

Доступ по PIN-коду

При сопряжении обменивается защищённый токен доступа, который хранится локально на вашем устройстве и используется только для связи с вашим пультом.

◆

Только локальное хранение

Адреса пультов и настройки приложения хранятся на вашем устройстве. Ничего не синхронизируется с сервером.

▢

Только ваши действия

Команды отправляются только по вашему действию. Ничего не срабатывает автоматически или в фоне без вашего ведома.

☰

Только сетевое разрешение

Единственное разрешение, которое нужно UC Remote, - доступ к локальной сети. Оно используется исключительно для связи с пультом по вашей сети Wi-Fi.

FAQ

Частые вопросы.

Всё, что нужно знать о UC Remote.

Связан ли UC Remote с Unfolded Circle? +
Нет. UC Remote - независимое стороннее приложение-компаньон, разработанное MiyaraHub Technologies LLC. Оно не создано, не одобрено, не спонсируется и никак не связано с Unfolded Circle. "Unfolded Circle", "Remote Two" и "Remote 3" являются товарными знаками их владельцев; мы используем эти названия исключительно для описания совместимости.
С какими устройствами оно работает? +
UC Remote работает с Unfolded Circle Remote Two и Remote 3 в вашей локальной сети. Если ваш пульт доступен в той же сети Wi-Fi, что и телефон, UC Remote может подключиться к нему и отразить его активности, страницы и сущности.
Как оно подключается к моему пульту? +
По вашей локальной сети Wi-Fi. После однократного сопряжения по PIN-коду UC Remote держит открытым канал событий в реальном времени, чтобы быть в курсе состояния пульта, и отправляет ваши команды напрямую. Никакого облачного посредника и никакой учётной записи - всё остаётся в вашей сети.
Нужна ли учётная запись или подключение к интернету? +
Учётная запись не нужна никогда. UC Remote нужна только ваша локальная сеть, чтобы связаться с пультом, - ничто не выходит за пределы вашей сети Wi-Fi, а регистрироваться в облачном сервисе не требуется.
Можно ли управлять несколькими пультами? +
Да. Подключайте сколько угодно пультов Unfolded Circle и переключайтесь между ними одним касанием. У каждого пульта свои профили, страницы и сущности.
На каких платформах доступен UC Remote? +
UC Remote - нативное приложение для телефонов и планшетов на Android, доступное в Google Play.
