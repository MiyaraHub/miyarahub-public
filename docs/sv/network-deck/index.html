Funktioner

Din UniFi-kontroller, i fickan.

Network Deck pratar direkt med din UniFi-kontrollers lokala API - oavsett om det är UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) eller en fristående UniFi Network-kontroller. Klienter, WiFi, brandvägg, portar, VPN och insikter, utan att öppna en webbläsare.

Kompatibilitet

Fungerar med din UniFi-kontroller.

Network Deck stöder både UniFi OS-konsoler och fristående UniFi Network-kontroller. Appen identifierar automatiskt vilka slutpunkter din firmware erbjuder och anpassar gränssnittet efter det - funktioner du inte har visas helt enkelt inte.

◉ UniFi OS-konsoler

  • UDM Pro SE (verifierad)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ Fristående kontroller

  • UniFi Network 10.x (verifierad)
  • Egen drift på Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ Autentisering

  • Lokalt administratörsanvändarnamn + lösenord
  • Tvåfaktorsautentisering (TOTP)
  • X-API-KEY för programmatisk åtkomst
  • Inget UniFi-molnkonto krävs

◆ Mobilplattformar

  • iOS 13 och senare
  • Android 5.0 (API 21) och senare
  • Telefon- och surfplattelayouter
  • Ljusa och mörka teman

Tolerans för firmware: Network Deck identifierar automatiskt vilka slutpunkter din kontroller erbjuder och anpassar sig till firmwarespecifika JSON-varianter (ändrade fältnamn, typkonvertering, flera format för integrations-API:et). Underadministratörskonton kan få 401 från vissa slutpunkter - det är en begränsning i kontrollerns behörigheter, inte i appen.

Så fungerar det

Direkt till din kontroller. Ingen molnrelä.

Network Deck pratar direkt med din UniFi-kontroller över ditt lokala nätverk (eller ditt VPN). Dina inloggningsuppgifter och nätverksdata passerar aldrig någon MiyaraHub-server.

1

Lägg till din kontroller

Ange din kontrollers värdnamn eller IP-adress, port (standard 443 för UniFi OS, 8443 för fristående) och dina lokala administratörsuppgifter. Network Deck identifierar automatiskt om du använder UniFi OS eller en fristående kontroller.

2

Autentisera lokalt

Logga in med ditt lokala administratörsanvändarnamn och lösenord. Tvåfaktorsautentisering stöds hela vägen. Föredrar du API-nycklar? Använd X-API-KEY för programmatisk åtkomst och hoppa över cookieflödet helt.

3

Hantera med en blick

Titta på det levande bandbreddsdiagrammet, koppla bort en besvärlig klient, slå på en brandväggsregel, starta om en PoE-port, bjud in en Teleport-gäst eller byt till en annan plats - varje åtgärd går fram och tillbaka till kontrollern och uppdaterar livehändelseströmmen.

Säkerhet & integritet

Bara lokalt. Inget konto. Ingen molnrelä.

Network Deck är utformat med en arkitektur som sätter integriteten främst och är helt lokal. Inget MiyaraHub-konto, ingen molnrelä, ingen datainsamling utöver kraschrapportering.

◉

Ingen molnrelä

Alla kommandon och liveströmmar går direkt mellan din telefon och din kontroller över ditt lokala Wi-Fi eller VPN. Ingenting dirigeras via externa servrar.

▣

Standardautentisering för UniFi

Använder samma lokala administratörsuppgifter (eller API-nyckel) som webbgränssnittet i UniFi Network. Uppgifterna lagras i iOS Keychain / Android Keystore på enheten och skickas aldrig från enheten annat än till din kontroller.

◎

Inget MiyaraHub-konto

Ingen registrering, ingen e-postadress, inget MiyaraHub-konto behövs. Installera, peka appen mot din kontroller så är du igång.

◈

Minimal analys

Firebase Crashlytics endast för felrapporter. Ingen spårning av användning, inga annonser, ingen försäljning av data. Nätverksfel loggas som icke-allvarliga för att hjälpa oss förbättra kompatibiliteten med firmware utan att vi samlar in hur ditt nätverk ser ut.

◆

Behörigheter respekteras

Appen arbetar inom de behörigheter som ditt UniFi-administratörskonto har. Underadministratörer ser bara det kontrollern tillåter dem att se. Ingen behörighetseskalering, ingen bakdörr.

◐

Bara nätverksbehörighet

Den enda enhetsbehörighet Network Deck kräver är nätverksåtkomst, som uteslutande används för att ansluta till din UniFi-kontroller på ditt lokala nätverk (eller via VPN).

Den är inte skapad av, godkänd av, sponsrad av eller knuten till Ubiquiti Inc. på något sätt. ”Ubiquiti”, ”UniFi”, ”UniFi OS”, ”UniFi Network”, ”UDM”, ”UDR”, ”UCG”, ”Teleport” och alla relaterade produktnamn är varumärken som tillhör Ubiquiti Inc. Vilka UniFi-kontroller stöds? +
Network Deck stöder både UniFi OS-konsoler (UDM Pro / Pro SE, UCG, Dream Machine, UDR, Cloud Key Gen2 / Plus) och fristående UniFi Network-kontroller som kör v10.x på Linux, Docker eller Windows. Appen identifierar din plattform automatiskt vid anslutningen och anpassar gränssnittet efter de slutpunkter som din firmware faktiskt erbjuder - funktioner du inte har visas helt enkelt inte. Testad live mot UDM Pro SE (UniFi OS 5.0.16) och fristående Network 10.2.105.
Hur kommunicerar Network Deck med min kontroller? +
Network Deck använder samma lokala API som webbgränssnittet i UniFi Network - en kombination av de klassiska slutpunkterna /rest och /cmd (med cookiebaserad sessionsautentisering) samt det nyare integrations-API:et v2. Appen öppnar också en WebSocket till din kontroller för att strömma händelser live. All kommunikation sker direkt mellan din telefon och din kontroller över ditt lokala nätverk eller VPN.
Behöver jag ett UniFi-molnkonto? +
Nej. Network Deck använder endast lokal autentisering. Logga in med ditt lokala UniFi-administratörsanvändarnamn och lösenord (eller en API-nyckel). Om din kontroller i dag bara kan nås via ui.com-molninloggning behöver du aktivera ett lokalt administratörskonto under Inställningar → Admins för att kunna använda Network Deck. Kontrollern pratar aldrig med oss, och vi pratar aldrig med Ubiquitis moln å dina vägnar.
Kan jag hantera brandväggsregler och portvidarebefordran? +
Ja. Network Deck har en komplett brandväggsfunktion: policyer (tillåt / blockera / inspektera), portvidarebefordran med fullständig CRUD, trafikregler och rutter, brandväggsgrupper, brandväggszoner (v2-policymatris) samt DPI-appar / -grupper. Allt växlas direkt från listvyn - inga dialogruta-tryck-dialogruta-flöden.
Stöds flera platser? +
Ja. Om din kontroller hanterar flera platser visar Network Deck en platsväljare högst upp. Varje funktion - instrumentpanel, klienter, brandvägg, VPN - gäller den för tillfället valda platsen. Byt med ett tryck.
Hur mycket kommer Network Deck att kosta? +
Network Deck blir ett engångsköp för $4.99 i App Store, Google Play och Microsoft Store. Ingen prenumeration, inga annonser, inga köp i appen. Priset kan ändras före den offentliga lanseringen.
Kan jag använda den på distans (utanför hemmet / kontoret)? +
Network Deck ansluter till det värdnamn eller den IP-adress du anger. Om din kontroller kan nås via VPN, Tailscale, WireGuard eller en vidarebefordrad port fungerar appen på distans. Vi rekommenderar att du använder VPN eller Tailscale i stället för att exponera din UniFi-kontroller direkt mot internet.
Vilka plattformar stöds? +
Network Deck körs på både iOS (13 och senare) och Android (5.0 / API 21 och senare). Både telefon- och surfplattelayouter stöds. Appen lanseras samtidigt i App Store, Google Play och Microsoft Store.
