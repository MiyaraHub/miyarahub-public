Funktioner

Komplett NAS-kontroll, i din hand.

Allt som DSM visar dig, anpassat för mobilen - och det döljer på ett smidigt sätt det ditt konto inte kan se.

Nr 01

◉ Instrumentpanel i realtid

CPU, RAM, temperatur och drifttid live med en blick. Anpassningsbara kort låter dig se exakt det som är viktigt - systemhälsa, lagringsanvändning, nätverksgenomströmning med mera.

Nr 02

▣ Docker-hantering

Se alla körande containrar med CPU- och minnesanvändning i realtid. Starta, stoppa och starta om containrar och öppna loggar - full Docker-kontroll från telefonen.

Nr 03

◎ Övervakningskameror

Livebilder från kamerorna i ett prydligt rutnät. Tryck för att visa i helskärm, se inspelningsstatus och övervaka alla dina Surveillance Station-kameror på ett ställe.

Nr 04

▢ Lagring & diskhälsa

Volymanvändning, RAID-status, temperaturer för enskilda diskar och SMART-hälsodata för varje disk. Ha koll på läget för din lagring hela tiden.

Nr 05

╿ Nätverksövervakning

Livediagram över bandbredd för varje nätverksgränssnitt. Följ nedladdnings-/uppladdningshastigheter, aktiva anslutningar, sammanslagna gränssnitt och DNS-konfiguration.

Nr 06

⚙ Pakethantering

Se alla installerade DSM-paket och deras status. Övervaka körande tjänster, schemalagda uppgifter, UPS-batteristatus, loggposter och delade mappar.

Nr 07

☼ Fullt anpassningsbar

Ställ in kategorierna på instrumentpanelen, anpassa navigeringsfältet, välj tema och sätt avsökningsintervall. Låt appen fungera som du vill ha den.

Nr 08

✦ Widgetar på hemskärmen

Widgetar för snabbåtgärder, lagringsöversikt och systemstatus på hemskärmen. Kolla hälsan på din NAS utan att ens öppna appen.

Så fungerar det

Direkt DSM-anslutning. Inget moln.

1

Lägg till din NAS

Ange din NAS IP-adress eller värdnamn och port. Inget MiyaraHub-konto, ingen registrering.

2

Logga in med DSM

Autentisera med dina befintliga DSM-uppgifter - de skickas bara till din NAS, med samma mekanism som DSM:s webbportal.

3

Övervaka & hantera

Instrumentpaneler, Docker, kameror, lagring, nätverk, paket och uppgifter - direkt från telefon, surfplatta eller dator.

Säkerhet & integritet

Din NAS, dina data, din kontroll.

Syno Manager är utformat med en arkitektur som sätter integriteten främst. Minimal datainsamling, ingen användarspårning, inget beroende av molnet.

◉

Ingen molnrelä

All kommunikation sker direkt mellan din enhet och din NAS över ditt lokala nätverk. Ingenting dirigeras via externa servrar.

▣

Standardautentisering för DSM

Använder samma autentiseringsmekanism som DSM:s webbgränssnitt. Dina uppgifter skickas bara till din NAS - aldrig till oss.

◎

Minimal analys

Firebase Crashlytics för att fånga fel och förbättra stabiliteten - inga personuppgifter, ingen spårning av användning, inga annonser. Appen samlar aldrig in NAS-data eller inloggningsuppgifter utanför din enhet.

◆

Säker lokal lagring

Anslutningsuppgifter lagras på enheten med plattformens säkra lagring - iOS Keychain och Android Keystore.

Vanliga frågor

Vanliga frågor.

Hur ansluter appen till min NAS? +
Syno Manager använder de dokumenterade Synology DSM API-slutpunkterna för att kommunicera med din NAS över ditt lokala nätverk. Appen skickar förfrågningar direkt till din NAS - det finns inga mellanliggande servrar, proxyservrar eller molnreläer inblandade. Du anger NAS:ens IP-adress/värdnamn och port, autentiserar med dina DSM-uppgifter, och appen kommunicerar direkt med DSM.
Vilka behörigheter behöver appen på min NAS? +
Appen arbetar inom de behörigheter som ditt DSM-användarkonto har. För full funktionalitet i instrumentpanelen rekommenderas ett administratörskonto. Appen degraderar dock på ett smidigt sätt - om ditt konto saknar Docker-behörighet visar Docker-avsnittet helt enkelt inga data. Detsamma gäller Surveillance Station, delade mappar med mera. Inga särskilda DSM-paket behöver installeras.
Lagrar appen mina NAS-uppgifter? +
Anslutningsuppgifter lagras lokalt på din enhet med plattformens säkra lagring (iOS Keychain / Android Keystore). Uppgifterna skickas aldrig till MiyaraHub Technologies eller någon tredje part. De används uteslutande för att autentisera mot din NAS.
Vilka Synology-modeller stöds? +
Syno Manager fungerar med alla Synology NAS som kör DSM 7.0 eller senare. Det omfattar alla aktuella modeller i DiskStation (DS), RackStation (RS) och FlashStation (FS). Äldre modeller med DSM 6.x kan ha begränsad funktionalitet på grund av skillnader i API:et.
Kan jag hantera Docker-containrar på distans? +
Ja. Du kan se containrars status, CPU-/minnesanvändning, öppna loggar och stoppa/starta om direkt i appen. Att skapa containrar och ändra konfiguration stöds inte just nu - fokus ligger på övervakning och snabba hanteringsåtgärder.
Vad kostar Syno Manager? +
Syno Manager är ett engångsköp för $9.99. Ingen prenumeration, inga annonser, inga köp i appen. Du köper den en gång i App Store eller Google Play och äger den.
Kan jag nå min NAS på distans (utanför mitt hemmanätverk)? +
Syno Manager ansluter till den IP-adress/det värdnamn du anger. Om din NAS kan nås via VPN, Tailscale eller en vidarebefordrad port fungerar appen på distans. Vi rekommenderar att du använder VPN eller Tailscale i stället för att exponera DSM direkt mot internet.
