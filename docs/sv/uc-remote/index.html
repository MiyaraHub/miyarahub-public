Funktioner

Hela din fjärrkontroll, i din hand.

UC Remote ansluter till din Unfolded Circle Remote Two eller Remote 3 över Wi-Fi och speglar allt den kan göra - aktiviteter, sidor, entiteter och media - i ett snabbt, inbyggt gränssnitt utformat för telefonen.

◉ Aktiviteter, ett tryck

Starta och stoppa hela aktiviteter - Titta på Shield TV, Xbox, PS5 - från en prydlig lista. Din fjärrkontroll slår på rätt utrustning och byter ingång; appen tar dig direkt till kontrollerna för den aktiviteten.

Så fungerar det

Direkt till din fjärrkontroll. Inget moln krävs.

UC Remote paras ihop med din Unfolded Circle-fjärrkontroll på ditt eget Wi-Fi och pratar direkt med den via fjärrkontrollens eget integrationsgränssnitt. Din konfiguration passerar aldrig någon extern server.

1

Para ihop din fjärrkontroll

Ange IP-adressen till din Unfolded Circle Remote Two eller Remote 3 och den PIN-kod som visas. UC Remote paras ihop på ett säkert sätt och hämtar in dina profiler, sidor, aktiviteter och entiteter.

2

Håll er synkroniserade

En levande tvåvägsanslutning strömmar status från fjärrkontrollen - vad som är på, vad som spelas - medan dina tryck går direkt tillbaka som kommandon. Ingen avsökningsfördröjning, ingen tur-och-retur via molnet.

3

Styr allt

Kör aktiviteter, använd de anpassade sidorna, styr varje entitet och mediaspelare, växla mellan flera fjärrkontroller och fäst widgetar på hemskärmen - allt från en enda app.

Säkerhet & integritet

Bara lokalt. Inget konto. Inget moln.

UC Remote är byggt med integriteten främst och helt lokalt: inget beroende av molnet, inget användarkonto och ingen datainsamling utöver kraschrapportering.

◉

Ingen molnrelä

Varje kommando och livestatusströmmen går direkt mellan din telefon och din fjärrkontroll över ditt lokala Wi-Fi. Ingenting lämnar ditt nätverk.

◎

Inget konto krävs

Ingen registrering, ingen e-postadress, inget MiyaraHub-konto. Para ihop med din fjärrkontrolls PIN-kod så har du kontrollen.

▣

Åtkomst via PIN-parning

Parningen utbyter en säker åtkomsttoken som lagras lokalt på din enhet och endast används för att prata med din fjärrkontroll.

◆

Endast lokal lagring

Fjärrkontrollernas adresser och apppreferenser lagras på din enhet. Ingenting synkroniseras till någon server.

▢

Bara dina åtgärder

Kommandon skickas bara när du gör något. Ingenting utlöses automatiskt eller i bakgrunden utan att du vet om det.

☰

Bara nätverksbehörighet

Den enda behörighet UC Remote behöver är åtkomst till lokalt nätverk, som enbart används för att nå din fjärrkontroll på ditt Wi-Fi.

Allt du behöver veta om UC Remote.

Är UC Remote knutet till Unfolded Circle? +
Nej. UC Remote är en oberoende följeslagarapp från tredje part, utvecklad av MiyaraHub Technologies LLC. Den är inte skapad av, godkänd av, sponsrad av eller knuten till Unfolded Circle på något sätt. ”Unfolded Circle”, ”Remote Two” och ”Remote 3” är varumärken som tillhör respektive ägare; vi använder dessa namn enbart för att beskriva kompatibilitet.
Vilka enheter fungerar den med? +
UC Remote fungerar med Unfolded Circle Remote Two och Remote 3 på ditt lokala nätverk. Om din fjärrkontroll kan nås på samma Wi-Fi som din telefon kan UC Remote paras ihop med den och spegla dess aktiviteter, sidor och entiteter.
Hur ansluter den till min fjärrkontroll? +
Över ditt lokala Wi-Fi. Efter en engångsparning med PIN-kod håller UC Remote en levande händelsekanal öppen för att hålla sig synkroniserad med fjärrkontrollens status och skickar dina kommandon direkt. Det finns inget molnrelä och inget konto - allt stannar på ditt nätverk.
Behöver jag ett konto eller en internetanslutning? +
Aldrig något konto. UC Remote behöver bara ditt lokala nätverk för att nå din fjärrkontroll - ingenting lämnar ditt Wi-Fi, och det finns ingen molntjänst att registrera sig för.
Kan jag styra mer än en fjärrkontroll? +
Ja. Para ihop så många Unfolded Circle-fjärrkontroller du vill och växla mellan dem med ett tryck. Varje fjärrkontroll behåller sina egna profiler, sidor och entiteter.
Vilka plattformar finns UC Remote på? +
UC Remote är en inbyggd app för Android-telefoner och surfplattor, tillgänglig på Google Play.
