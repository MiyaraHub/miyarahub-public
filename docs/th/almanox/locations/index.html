สถานที่ที่บันทึกไว้

ทุกตัวเลขใน Almanox ไม่ว่าจะเป็นเหตุการณ์ของดวงอาทิตย์ ผลประเมิน แกนกลางทางช้างเผือก หรือเวลาของดวงจันทร์ คำนวณสำหรับจุดเดียวบนโลก สถานที่คือที่ที่คุณเลือกจุดนั้น จะเป็น GPS ของคุณ เมืองตามชื่อ หรือพิกัดที่แน่นอน แล้วบันทึกไว้เพื่อสลับระหว่างจุดที่คุณไปถ่ายภาพจริงๆ

วิธีเข้าถึง

ท้องฟ้าถูกคำนวณสำหรับที่ไหน

เปิดสถานที่โดยแตะชื่อสถานที่ที่ด้านบนของ Today หรือ Tonight

ชื่อสถานที่อยู่ด้านบนของทั้งหน้าจอ Today และ Tonight แตะแล้วหน้าจอสถานที่จะเปิดขึ้น แสดงทุกแห่งที่คุณบันทึกไว้พร้อมทำเครื่องหมายแห่งที่ใช้งานอยู่ การสลับทำได้ด้วยการแตะครั้งเดียว เลือกไทล์แล้วทั้งแอปคำนวณใหม่สำหรับจุดนั้น และ Almanox จำตัวเลือกของคุณไว้ในครั้งหน้า

มีสามวิธีในการตั้งค่าว่าคุณกำลังวางแผนให้ที่ไหน

  • ใช้ตำแหน่งปัจจุบัน - ขอตำแหน่ง GPS ของคุณอีกครั้ง กล่องข้อความ “กำลังค้นหาตำแหน่งของคุณ” จะแสดงระหว่างทำงาน หากไม่สามารถระบุตำแหน่งได้ ไม่ว่าจะถูกปฏิเสธสิทธิ์ ปิดบริการตำแหน่ง หรือเกิดข้อผิดพลาดใดๆ Almanox จะแจ้งว่าไม่มีตำแหน่ง และใช้ตำแหน่ง New York ที่มีในตัวแทนการไม่แสดงอะไรเลย
  • ค้นหาเมือง - พิมพ์ชื่อสถานที่แล้วค้นหา รายการที่ตรงกันใกล้เคียงจะแสดงพร้อมพิกัด และแตะรายการเพื่อบันทึก ใช้ชื่อที่คุณพิมพ์ หรือพิกัดของรายการนั้นหากคุณเว้นช่องว่างไว้
  • พิกัด - พิมพ์ละติจูดและลองจิจูดโดยตรง ตรวจสอบกับช่วงจริง (-90 ถึง 90, -180 ถึง 180) พร้อมชื่อที่กำหนดเองได้ตามต้องการ หากเว้นชื่อว่างไว้ Almanox จะแปลงพิกัดย้อนกลับเป็นชื่อสถานที่ให้

การจัดการ

การสลับ การลบ และค่าเริ่มต้น

รายการเป็นของคุณที่จะจัดการ โดยมีราวกันตกหนึ่งอย่างเพื่อไม่ให้คุณไม่เหลือสถานที่เลย

  • การสลับ - แตะไทล์ที่บันทึกไว้ใดก็ได้เพื่อตั้งเป็นแห่งที่ใช้งาน สถานที่ที่ใช้งานอยู่จะกำหนดทุกหน้าจอจนกว่าคุณจะเปลี่ยน
  • การลบ - ปัดไทล์ไปทางซ้ายเพื่อลบ คุณไม่สามารถลบสถานที่สุดท้ายที่เหลืออยู่ได้ ต้องมีอย่างน้อยหนึ่งแห่งเสมอ แอปจึงไม่ตกอยู่ในสภาพที่ไม่มีที่ให้คำนวณ
  • ป้าย DEFAULT - ทำเครื่องหมายตำแหน่ง New York สำรองที่มีในตัว เมื่อเป็นหนึ่งในรายการที่บันทึกไว้ของคุณ คุณจึงรู้เสมอว่าแห่งไหนคือตาข่ายนิรภัย

ฟรีรวมสถานที่ที่บันทึกได้สามแห่ง ครอบคลุมบ้าน จุดมืดใกล้เคียง และจุดท่องเที่ยว Pro ปลดเพดานเป็นไม่จำกัด สำหรับคนที่วางแผนหลายสถานที่

การค้นหาเมืองและการแปลงพิกัดย้อนกลับต้องใช้การเชื่อมต่อ เมื่อบันทึกสถานที่แล้ว ค่าดวงอาทิตย์ ดวงจันทร์ และแผนที่ดาวทั้งหมดจะคำนวณบนอุปกรณ์โดยไม่ต้องมีสัญญาณ
