  • ซีรีส์ RX-A AVENTAGE
  • ไลน์ TSR / RX-A x80, x70, x60
  • รุ่นที่รองรับ MusicCast

เปิดปิด ระดับเสียง อินพุต โปรแกรมเสียง โซน และเพลง ทุกการกระทำไปกลับกับเครื่องรับและสะท้อนสถานะจริงของอุปกรณ์ เพิ่มวิดเจ็ต สลับโซน หรือเปลี่ยนโหมด DSP จากในกระเป๋าของคุณ
