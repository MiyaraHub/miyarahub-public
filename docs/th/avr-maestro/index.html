ทุกการควบคุม ห่างแค่แตะเดียว

ภาพหน้าจอจริงจาก AVR Maestro ทั้งแดชบอร์ด ฉาก โหมดเสียง อินพุต รีโมทเสมือน กำลังเล่น ธีม และหลายโซน แตะภาพใดก็ได้เพื่อขยาย

ฟีเจอร์

ควบคุมเครื่องรับได้ครบ อยู่ในมือคุณ

ควบคุมได้ลึกกว่ารีโมทในกล่อง และทุกอย่างซิงก์กับรีโมทจริงและแผงด้านหน้าเสมอ

ลำดับ 01

✦ ฉากแตะเดียว

บันทึกการตั้งค่าทั้งหมดของคุณ ทั้งอินพุต ระดับเสียง โหมดเสียง Audyssey/Dirac พรีเซ็ตลำโพง ระดับเสียงรายช่อง โซน และแม้แต่จูนเนอร์ แล้วเรียกคืนทั้งหมดด้วยการแตะเพียงครั้งเดียว คืนดูหนัง เล่นเกม ฟังดึกๆ แต่ละแบบเป็นฉากของตัวเอง

ลำดับ 02

◉ ระดับเสียง อินพุต & เซอร์ราวด์

ควบคุมระดับเสียงอย่างแม่นยำพร้อมค่า dB สลับแหล่งอินพุตในแตะเดียวด้วยตารางภาพ และตัวเลือกโหมดเซอร์ราวด์ครบทุกโหมดที่เครื่องรับของคุณรองรับ

ลำดับ 03

▣ รีโมทเสมือน

รีโมทเสมือนระดับพรีเมียม พร้อมปุ่มนำทาง D-pad ปุ่มควบคุมการเล่น ปิดเสียง และปรับระดับเสียงด่วน ทุกอย่างที่คุณต้องการ โดยไม่ต้องหารีโมทจริง

ลำดับ 04

▢ ควบคุมหลายโซน

ควบคุม Zone 2 และ Zone 3 แยกอิสระ มีปุ่มเปิดปิด ระดับเสียง แหล่งอินพุต และพรีเซ็ตระดับเสียงด่วนเฉพาะของแต่ละโซน ทั้งหมดจากหน้าจอเดียว

ลำดับ 05

◎ Audyssey & การปรับแก้ห้อง

ควบคุม Audyssey MultEQ, Dynamic EQ, Dynamic Volume, LFC และ Containment Amount ได้เต็มที่ ปรับแต่งการแก้ห้องของคุณโดยไม่ต้องเดินเมนูของเครื่องรับ

ลำดับ 06

◆ Dirac Live & IMAX Enhanced ขั้นสูง

สลับระหว่างสล็อตตัวกรอง Dirac Live ตั้งค่าโหมด IMAX พร้อมการตั้งค่าครอสโอเวอร์ และปรับพรีเซ็ตและความแรงของการประมวลผล Auro-3D ทั้งหมดจากโทรศัพท์ของคุณ

ลำดับ 07

╿ ระดับเสียงรายช่อง

ปรับระดับเสียงของลำโพงทุกตัวในระบบแยกอิสระ ตั้งแต่ซ้าย/ขวาด้านหน้าไปจนถึงช่องความสูงเหนือศีรษะ เหมาะสำหรับการปรับแต่งละเอียดหลังการแก้ห้อง

ลำดับ 08

⚙ การกำหนดค่าระบบ

การตั้งค่าเอาต์พุต HDMI ไฟหรี่แผงด้านหน้า เอาต์พุตทริกเกอร์ 12V โหมด eco ตัวตั้งเวลาสแตนด์บายอัตโนมัติ HDMI CEC ตัวส่งสัญญาณ Bluetooth audio restorer และโหมดประมวลผลวิดีโอ

ลำดับ 09

☼ Quick select ธีม & แท็บนำทางที่กำหนดเอง

เรียกคืนชุดอินพุต/ระดับเสียง/โหมดที่ชอบด้วยการแตะครั้งเดียว เลือกธีม Light, Dark (AMOLED) หรือตามอุปกรณ์ ตั้งสีเน้น TJ Mode ที่กำหนดเอง และลากเพื่อจัดเรียง แสดง หรือซ่อนแท็บนำทางให้เข้ากับวิธีที่คุณใช้งาน

ลำดับ 10

♪ จูนเนอร์ FM/AM & กำลังเล่น

จูน FM/AM ตามความถี่หรือพรีเซ็ตที่เก็บไว้จากในแอปได้เลย และดูหน้าจอกำลังเล่นแบบสดพร้อมปกอัลบั้มสำหรับแหล่ง HEOS จัดเรียงและเปลี่ยนชื่ออินพุตของคุณใหม่ เพื่อให้ตารางอ่านได้อย่างที่คุณคิด

วิธีการทำงาน

เชื่อมต่อเครือข่ายโดยตรง ไม่ต้องพึ่งคลาวด์

1

เพิ่มเครื่องรับของคุณ

ป้อนที่อยู่ IP ของเครื่องรับ หรือให้แอปค้นหาในเครือข่ายของคุณ ไม่ต้องมีบัญชี ไม่ต้องลงทะเบียน

2

เชื่อมต่อผ่าน Wi-Fi

AVR Maestro คุยกับเครื่องรับของคุณโดยตรงผ่านเครือข่ายภายใน HTTP สำหรับคำสั่ง Telnet สำหรับเหตุการณ์สด HEOS สำหรับกำลังเล่น

3

ควบคุมได้เต็มที่

ระดับเสียง อินพุต เซอร์ราวด์ โซน การปรับเทียบ จูนเนอร์ และฉาก ทั้งหมดจากโทรศัพท์ แท็บเล็ต หรือเดสก์ท็อปของคุณ

ความปลอดภัย & ความเป็นส่วนตัว

ทำงานในเครื่องเท่านั้น ไม่ต้องมีบัญชี ไม่มีคลาวด์

AVR Maestro ออกแบบด้วยสถาปัตยกรรมที่ให้ความสำคัญกับความเป็นส่วนตัวและทำงานเฉพาะภายใน ไม่พึ่งคลาวด์ ไม่มีบัญชีผู้ใช้ ไม่เก็บข้อมูลนอกจากรายงานการแครช

◉

ไม่มีรีเลย์คลาวด์

ทุกคำสั่งและการโพลสถานะเกิดขึ้นโดยตรงระหว่างโทรศัพท์ของคุณกับเครื่องรับผ่าน Wi-Fi ภายในบ้านของคุณ ไม่มีอะไรออกจากเครือข่ายของคุณ

▣

ไม่ต้องมีบัญชี

ไม่ต้องลงทะเบียน ไม่ต้องใช้อีเมล ไม่ต้องมีบัญชี MiyaraHub เปิดแอป ป้อน IP ของเครื่องรับ แล้วคุณก็ควบคุมได้เลย

◎

การวิเคราะห์ขั้นต่ำ

ใช้ Firebase Crashlytics เฉพาะรายงานบั๊ก ไม่มีข้อมูลส่วนบุคคล ไม่ติดตามการใช้งาน ไม่มีโฆษณา ข้อมูลเครื่องรับของคุณไม่เคยออกจากโทรศัพท์

◆

จัดเก็บในเครื่องเท่านั้น

ที่อยู่ IP ของอุปกรณ์และการตั้งค่าแอปถูกเก็บไว้ในอุปกรณ์ของคุณ ไม่มีอะไรซิงก์ไปยังเซิร์ฟเวอร์

□

ทำงานเมื่อคุณสั่งเท่านั้น

แอปส่งคำสั่งไปยังเครื่องรับเฉพาะเมื่อคุณสั่งให้ทำ ไม่มีการเปลี่ยนแปลงเบื้องหลัง ไม่มีอะไรอัตโนมัติลับหลังคุณ

คำถามที่พบบ่อย

AVR Maestro เกี่ยวข้องกับ Denon หรือ Marantz ไหม? +
ไม่เกี่ยวข้อง AVR Maestro เป็นแอปพลิเคชันอิสระของบุคคลที่สาม พัฒนาโดย MiyaraHub Technologies LLC ไม่ได้สร้าง รับรอง สนับสนุน หรือเกี่ยวข้องกับ Denon, Marantz หรือบริษัทแม่ Sound United / Masimo ไม่ว่าในทางใด “Denon” “Marantz” “Audyssey” “Dirac Live” “IMAX Enhanced” และ “Auro-3D” เป็นเครื่องหมายการค้าของเจ้าของที่เกี่ยวข้อง เราใช้ชื่อเหล่านี้เพื่ออธิบายความเข้ากันได้เท่านั้น
รองรับเครื่องรับรุ่นใดบ้าง? +
AVR Maestro ใช้งานได้กับเครื่องรับ AV ของ Denon และ Marantz ที่เชื่อมต่อเครือข่ายและรองรับการควบคุมผ่าน IP (HTTP และ/หรือ Telnet) ซึ่งเกือบทุกรุ่นตั้งแต่ปี 2014 เป็นต้นมา แอปตรวจหาฟีเจอร์ที่ใช้ได้โดยอัตโนมัติเมื่อเชื่อมต่อ การเข้าถึงขึ้นอยู่กับเครือข่ายของคุณ ไม่ใช่แค่รุ่น หากเว็บพอร์ทัลของเครื่องรับเอง แอป HEOS และแอปทางการของ Denon หรือ Marantz เข้าถึงมันได้บนเครือข่ายเดียวกัน และพอร์ตเครือข่ายของมันไม่ถูกบล็อก AVR Maestro ก็ควรเห็นมันเช่นกัน
AVR Maestro สื่อสารกับเครื่องรับของฉันอย่างไร? +
AVR Maestro ใช้สามโปรโตคอล คือ HTTP สำหรับการโพลสถานะและคำสั่งที่เชื่อถือได้ Telnet สำหรับสตรีมเหตุการณ์แบบเรียลไทม์ (การเปลี่ยนระดับเสียง การสลับอินพุต) และ HEOS สำหรับข้อมูลที่กำลังเล่นพร้อมปกอัลบั้ม การสื่อสารทั้งหมดเกิดขึ้นโดยตรงบนเครือข่าย Wi-Fi ภายในบ้านของคุณ
รองรับ Audyssey, Dirac Live และ IMAX Enhanced ไหม? +
รองรับ AVR Maestro ควบคุม Audyssey MultEQ, Dynamic EQ, Dynamic Volume, LFC และ Containment ได้ครบ และรองรับการสลับสล็อตตัวกรอง Dirac Live โหมด IMAX Enhanced พร้อมการตั้งค่าครอสโอเวอร์ และการกำหนดค่า Auro-3D ฟีเจอร์ที่ใช้ได้ขึ้นอยู่กับสิ่งที่เครื่องรับรุ่นของคุณรองรับ
ควบคุมหลายโซนได้ไหม? +
ได้ AVR Maestro รองรับ Zone 2 และ Zone 3 พร้อมการเปิดปิด ระดับเสียง แหล่งอินพุต และพรีเซ็ตด่วนที่เป็นอิสระต่อกัน แต่ละโซนควบคุมได้จากส่วนเฉพาะของตัวเอง และเห็นสถานะของโซนได้ในพริบตาจากแดชบอร์ดหลัก
ฉากคืออะไร? +
ฉากคือสแนปช็อตการตั้งค่าทั้งหมดของคุณในแตะเดียว ทั้งอินพุต ระดับเสียง โหมดเสียง การเลือก Audyssey/Dirac พรีเซ็ตลำโพง ระดับเสียงรายช่อง โซน และแม้แต่จูนเนอร์ บันทึกได้มากเท่าที่ต้องการ (คืนดูหนัง เล่นเกม ฟังดึกๆ) แล้วเรียกคืนได้ทันที เป็นวิธีที่เร็วที่สุดในการสลับระหว่างแบบที่คุณใช้ระบบจริงๆ
AVR Maestro ราคาเท่าไร? +
AVR Maestro เป็นการซื้อครั้งเดียวราคา $9.99 ไม่มีค่าสมัครสมาชิก ไม่มีโฆษณา ไม่มีการซื้อในแอป ซื้อครั้งเดียวแล้วเป็นเจ้าของ
ควบคุมเครื่องรับจากนอกบ้านได้ไหม? +
AVR Maestro เชื่อมต่อกับที่อยู่ IP ใดก็ได้ที่คุณกำหนด หากเข้าถึงเครื่องรับได้ผ่าน VPN หรือ Tailscale แอปก็ใช้งานจากระยะไกลได้ เราแนะนำให้ใช้ VPN หรือ Tailscale แทนการเปิดเครื่องรับของคุณสู่อินเทอร์เน็ตโดยตรง
รองรับแพลตฟอร์มและเวอร์ชันใดบ้าง? +
AVR Maestro มีให้ใช้บน iPhone (App Store), Android (Google Play), Windows (Microsoft Store) และ macOS (Mac App Store) บน Android ต้องใช้ Android 5.0 (API 21) ขึ้นไป บน iPhone ต้องเป็นอุปกรณ์รุ่นใหม่ที่ใช้ iOS รุ่นปัจจุบัน คู่มือฉบับเต็มอยู่ที่ avrmaestro.com
