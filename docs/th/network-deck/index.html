Network Deck · สำหรับตัวควบคุมเครือข่าย UniFiเครือข่าย UniFi ของคุณ อยู่ในมือคุณ✦

ควบคุมเครือข่าย UniFi ของคุณได้เต็มที่จากโทรศัพท์

แอปมือถือระดับพรีเมียมสำหรับตัวควบคุมเครือข่าย Ubiquiti UniFi แดชบอร์ดสด การจัดการไคลเอนต์และอุปกรณ์ การควบคุม WiFi และ VLAN นโยบายไฟร์วอลล์ การควบคุมพอร์ต VPN การทดสอบความเร็ว และการสลับหลายไซต์ ทั้งหมดจากโทรศัพท์ของคุณ เชื่อมต่อตรงถึงตัวควบคุม

ฟีเจอร์

ตัวควบคุม UniFi ของคุณ อยู่ในกระเป๋า

Network Deck สื่อสารโดยตรงกับ API ภายในเครือข่ายของตัวควบคุม UniFi ไม่ว่าจะเป็น UniFi OS (UDM Pro, Cloud Gateway, Dream Machine) หรือตัวควบคุม UniFi Network แบบสแตนด์อโลน ดูไคลเอนต์ WiFi ไฟร์วอลล์ พอร์ต VPN และข้อมูลเชิงลึกได้ โดยไม่ต้องเปิดเบราว์เซอร์

ลำดับ 01

◉ แดชบอร์ดสด

สุขภาพของ ISP กราฟแบนด์วิดท์แบบเรียลไทม์ที่ใช้หน้าต่างเลื่อน 60 ตัวอย่าง และการ์ดที่ปรับแต่งได้ ทั้งข้อมูลระบบ ทราฟฟิก DPI การแจ้งเตือน เหตุการณ์ ไคลเอนต์ยอดนิยม ประวัติการทดสอบความเร็ว และทางลัดด่วน เลย์เอาต์แบบแท็บที่จัดเรียงใหม่ได้

แบนด์วิดท์สุขภาพ ISPทราฟฟิก DPIไคลเอนต์ยอดนิยม
ลำดับ 02

▣ ไคลเอนต์ & อุปกรณ์

รายชื่อไคลเอนต์ครบถ้วน พร้อมตัวกรอง WiFi / แบบสาย / ทั้งหมด และสัญญาณ dBm ให้เห็นในพริบตา บล็อก เลิกบล็อก เตะออก หรือลืมอุปกรณ์เป็นกลุ่มได้ หน้ารายละเอียดของแต่ละไคลเอนต์มีประวัติ รายละเอียด DPI IP คงที่ กลุ่มผู้ใช้ และการยืนยันตัวตนแขก

บล็อก / เตะออกสัญญาณ dBmIP คงที่การดำเนินการเป็นกลุ่ม
ลำดับ 03

◎ WiFi, VLAN & การควบคุมพอร์ต

สร้าง แก้ไข และลบ SSID (ความปลอดภัย ย่านความถี่ แขก VLAN PMF การโรมมิ่งเร็ว) จัดการ VLAN พร้อมตัวเลือก DHCP, IPv6, mDNS, มัลติคาสต์ และการแยกเครือข่าย ควบคุม PoE รายพอร์ต และตั้งค่าคลื่นวิทยุของ AP (ช่องสัญญาณ กำลังส่ง TX ความกว้าง band steering และ min RSSI)

SSID CRUDVLANควบคุม PoEคลื่นวิทยุ AP
ลำดับ 04

◈ ไฟร์วอลล์ & กฎการรับส่งข้อมูล

นโยบาย (อนุญาต / บล็อก / ตรวจสอบ) การส่งต่อพอร์ต กฎและเส้นทางการรับส่งข้อมูล กลุ่มไฟร์วอลล์ โซนไฟร์วอลล์พร้อมเมทริกซ์นโยบาย v2 และการควบคุมแอป / กลุ่ม DPI ทั้งหมดมีสวิตช์เปิดปิดในหน้ารายการ ไม่ต้องใช้เบราว์เซอร์

นโยบายการส่งต่อพอร์ตโซน v2DPI
ลำดับ 05

◆ ความปลอดภัย & ข้อมูลเชิงลึก

เปิดปิด IPS / IDS และเลือกโหมด ตัวกรองเนื้อหาแยกตามเครือข่าย (งาน / ครอบครัว / กำหนดเอง) การตรวจสอบ SSL การบล็อก geo-IP พร้อมรายการอนุญาต / ปฏิเสธรายประเทศ การสแกน AP ปลอม และประวัติภัยคุกคามที่ดึงจากการแจ้งเตือนของตัวควบคุม

IPS / IDSGeo-IPตัวกรองเนื้อหาการตรวจสอบ SSL
ลำดับ 06

◐ VPN & Teleport

สร้างคำเชิญแขกของ Teleport ที่หมดอายุใน 24 ชั่วโมง สร้างอุโมงค์ไซต์ต่อไซต์ด้วย IPsec, OpenVPN หรือ WireGuard โดยใช้ pre-shared key เปิดปิดการเชื่อมต่อแบบ peer-to-peer และการค้นหาอุปกรณ์ได้ในแตะเดียว

ความเข้ากันได้

ใช้งานได้กับตัวควบคุม UniFi ของคุณ

Network Deck รองรับทั้งคอนโซล UniFi OS และตัวควบคุม UniFi Network แบบสแตนด์อโลน แอปตรวจจับโดยอัตโนมัติว่าเฟิร์มแวร์ของคุณเปิด endpoint ใดบ้าง แล้วปรับหน้าจอให้ตรงกัน ฟีเจอร์ที่คุณไม่มีจะไม่แสดงขึ้นมา

◉ คอนโซล UniFi OS

  • UDM Pro SE (ยืนยันแล้ว)
  • UDM Pro
  • UDM / UDR
  • UniFi Cloud Gateway (UCG)
  • UniFi Dream Machine

▣ ตัวควบคุมแบบสแตนด์อโลน

  • UniFi Network 10.x (ยืนยันแล้ว)
  • โฮสต์เองบน Linux / Docker
  • Cloud Key Gen2 / Plus
  • UniFi Network Server (Windows)

◎ การยืนยันตัวตน

  • ชื่อผู้ใช้ + รหัสผ่านผู้ดูแลระบบภายใน
  • การยืนยันตัวตนสองขั้นตอน (TOTP)
  • X-API-KEY สำหรับการเข้าถึงด้วยโปรแกรม
  • ไม่ต้องมีบัญชีคลาวด์ UniFi

◆ แพลตฟอร์มมือถือ

  • iOS 13 ขึ้นไป
  • Android 5.0 (API 21) ขึ้นไป
  • เลย์เอาต์สำหรับโทรศัพท์และแท็บเล็ต
  • ธีมสว่างและมืด

ความยืดหยุ่นต่อเฟิร์มแวร์: Network Deck ตรวจจับ endpoint ที่ตัวควบคุมของคุณเปิดให้ใช้โดยอัตโนมัติ และปรับตัวเข้ากับ JSON ที่ต่างกันตามเฟิร์มแวร์ (ชื่อฟิลด์ที่เปลี่ยนไป การแปลงชนิดข้อมูล รูปแบบที่หลากหลายของ integration API) บัญชีผู้ดูแลระดับรองอาจพบว่าบาง endpoint ตอบกลับ 401 ซึ่งเป็นข้อจำกัดด้านสิทธิ์ของตัวควบคุม ไม่ใช่ข้อจำกัดของแอป

วิธีการทำงาน

เชื่อมต่อตรงถึงตัวควบคุมของคุณ ไม่ผ่านคลาวด์รีเลย์

Network Deck สื่อสารโดยตรงกับตัวควบคุม UniFi ของคุณผ่านเครือข่ายภายใน (หรือ VPN ของคุณ) ข้อมูลรับรองและข้อมูลเครือข่ายของคุณไม่เคยผ่านเซิร์ฟเวอร์ของ MiyaraHub

1

เพิ่มตัวควบคุมของคุณ

ป้อนโฮสต์เนมหรือ IP ของตัวควบคุม พอร์ต (ค่าเริ่มต้น 443 สำหรับ UniFi OS และ 8443 สำหรับแบบสแตนด์อโลน) และข้อมูลรับรองผู้ดูแลระบบภายในของคุณ Network Deck จะตรวจจับเองว่าคุณใช้ UniFi OS หรือตัวควบคุมแบบสแตนด์อโลน

2

ยืนยันตัวตนภายในเครือข่าย

เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านผู้ดูแลระบบภายใน รองรับการยืนยันตัวตนสองขั้นตอนตลอดทาง ถ้าชอบใช้ API key ก็ใช้ X-API-KEY สำหรับการเข้าถึงด้วยโปรแกรม และข้ามขั้นตอนคุกกี้ไปได้เลย

3

จัดการได้ในพริบตา

ดูกราฟแบนด์วิดท์สด เตะไคลเอนต์ที่ทำตัวมีปัญหา สลับกฎไฟร์วอลล์ รีสตาร์ตพอร์ต PoE เชิญแขกผ่าน Teleport หรือสลับไปอีกไซต์หนึ่ง ทุกการดำเนินการส่งไปถึงตัวควบคุมและอัปเดตสตรีมเหตุการณ์สดทันที

ความปลอดภัย & ความเป็นส่วนตัว

ทำงานในเครื่องเท่านั้น ไม่ต้องมีบัญชี ไม่มีรีเลย์คลาวด์

Network Deck ออกแบบด้วยสถาปัตยกรรมที่ให้ความสำคัญกับความเป็นส่วนตัวและทำงานภายในเครือข่ายเท่านั้น ไม่มีบัญชี MiyaraHub ไม่มีคลาวด์รีเลย์ ไม่เก็บข้อมูลใด ๆ นอกจากรายงานการแครช

◉

ไม่มีรีเลย์คลาวด์

คำสั่งและสตรีมสดทั้งหมดเกิดขึ้นโดยตรงระหว่างโทรศัพท์ของคุณกับตัวควบคุมผ่าน Wi-Fi ภายในหรือ VPN ไม่มีสิ่งใดผ่านเซิร์ฟเวอร์ภายนอก

▣

การยืนยันตัวตนมาตรฐานของ UniFi

ใช้ข้อมูลรับรองผู้ดูแลระบบภายใน (หรือ API key) ชุดเดียวกับเว็บ UI ของ UniFi Network ข้อมูลรับรองเก็บไว้ใน iOS Keychain / Android Keystore บนอุปกรณ์ และไม่ถูกส่งออกจากอุปกรณ์ ยกเว้นไปยังตัวควบคุมของคุณ

◎

ไม่ต้องมีบัญชี MiyaraHub

ไม่ต้องสมัคร ไม่ต้องใช้อีเมล ไม่ต้องมีบัญชี MiyaraHub ติดตั้ง ชี้ไปที่ตัวควบคุมของคุณ แล้วใช้งานได้เลย

◈

การวิเคราะห์ขั้นต่ำ

ใช้ Firebase Crashlytics เพื่อรายงานข้อบกพร่องเท่านั้น ไม่ติดตามการใช้งาน ไม่มีโฆษณา ไม่ขายข้อมูล ข้อผิดพลาดของเครือข่ายจะถูกบันทึกเป็นแบบไม่ร้ายแรงเพื่อช่วยให้เราปรับปรุงความเข้ากันได้กับเฟิร์มแวร์ โดยไม่ต้องเก็บผังเครือข่ายของคุณ

◆

เคารพสิทธิ์การเข้าถึง

แอปทำงานภายในสิทธิ์ที่บัญชีผู้ดูแล UniFi ของคุณมี ผู้ดูแลระดับรองจะเห็นเฉพาะสิ่งที่ตัวควบคุมอนุญาตให้เห็น ไม่มีการยกระดับสิทธิ์ ไม่มีช่องทางลับ

◐

ขอสิทธิ์เครือข่ายเท่านั้น

สิทธิ์เดียวของอุปกรณ์ที่ Network Deck ต้องใช้คือการเข้าถึงเครือข่าย ซึ่งใช้เพื่อเชื่อมต่อกับตัวควบคุม UniFi ของคุณในเครือข่ายภายใน (หรือผ่าน VPN) เท่านั้น

ต้องมีบัญชีคลาวด์ UniFi ไหม +
ไม่ต้อง Network Deck ใช้การยืนยันตัวตนภายในเครือข่ายเท่านั้น เข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านผู้ดูแลระบบภายในของ UniFi (หรือ API key) หากตอนนี้ตัวควบคุมของคุณเข้าถึงได้ผ่านการล็อกอินคลาวด์ ui.com เท่านั้น คุณจะต้องเปิดใช้บัญชีผู้ดูแลระบบภายในที่ Settings → Admins เพื่อใช้ Network Deck ตัวควบคุมไม่เคยสื่อสารกับเรา และเราไม่เคยสื่อสารกับคลาวด์ของ Ubiquiti แทนคุณ
จัดการกฎไฟร์วอลล์และการส่งต่อพอร์ตได้ไหม +
ได้ Network Deck มีชุดเครื่องมือไฟร์วอลล์ครบถ้วน ทั้งนโยบาย (อนุญาต / บล็อก / ตรวจสอบ) การส่งต่อพอร์ตแบบ CRUD เต็มรูปแบบ กฎและเส้นทางการรับส่งข้อมูล กลุ่มไฟร์วอลล์ โซนไฟร์วอลล์ (เมทริกซ์นโยบาย v2) และแอป / กลุ่ม DPI ทุกอย่างสลับเปิดปิดได้จากหน้ารายการโดยตรง ไม่ต้องกดวนผ่านหลายกล่องโต้ตอบ
รองรับหลายไซต์ไหม +
รองรับ หากตัวควบคุมของคุณดูแลหลายไซต์ Network Deck จะแสดงตัวสลับไซต์ไว้ด้านบน ทุกฟีเจอร์ ไม่ว่าจะเป็นแดชบอร์ด ไคลเอนต์ ไฟร์วอลล์ หรือ VPN จะทำงานตามไซต์ที่เลือกอยู่ สลับได้ในแตะเดียว
Network Deck ราคาเท่าไร +
Network Deck จะเป็นการซื้อครั้งเดียวในราคา $4.99 บน App Store, Google Play และ Microsoft Store ไม่มีค่าสมาชิก ไม่มีโฆษณา ไม่มีการซื้อในแอป ราคาอาจเปลี่ยนแปลงก่อนเปิดตัวสู่สาธารณะ
ใช้งานจากระยะไกล (นอกบ้าน / นอกออฟฟิศ) ได้ไหม +
Network Deck เชื่อมต่อกับโฮสต์เนมหรือ IP ใดก็ตามที่คุณตั้งค่าไว้ หากตัวควบคุมของคุณเข้าถึงได้ผ่าน VPN, Tailscale, WireGuard หรือพอร์ตที่ฟอร์เวิร์ดไว้ แอปก็ใช้งานจากระยะไกลได้ เราแนะนำให้ใช้ VPN หรือ Tailscale แทนการเปิดตัวควบคุม UniFi สู่อินเทอร์เน็ตโดยตรง
