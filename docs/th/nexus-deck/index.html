NexusDeck เป็นแอปพลิเคชันอิสระของบุคคลที่สามที่พัฒนาและเผยแพร่โดย MiyaraHub Technologies LLC และไม่ได้สร้างโดย ไม่มีส่วนเกี่ยวข้องกับ ไม่ได้รับการรับรองจาก ไม่ได้รับการสนับสนุนจาก หรือเชื่อมโยงอย่างเป็นทางการกับผู้ผลิตเครื่องรับ ซอฟต์แวร์สอบเทียบ หรือรูปแบบไฟล์ที่แอปทำงานด้วยแต่อย่างใด

"Audyssey", "MultEQ", "Dirac", "Dirac Live", "Denon", "Marantz", "HEOS", "Room EQ Wizard", "REW", "MEQX" และชื่อผลิตภัณฑ์และโลโก้ที่เกี่ยวข้องทั้งหมดเป็นเครื่องหมายการค้าหรือเครื่องหมายการค้าจดทะเบียนของเจ้าของแต่ละราย เครื่องหมายการค้าอื่นทั้งหมดที่อ้างถึงในที่นี้เป็นทรัพย์สินของเจ้าของแต่ละราย

การอ้างถึงผลิตภัณฑ์เหล่านี้ในหน้านี้และในแอปทำขึ้นเพื่อระบุความเข้ากันได้ของรูปแบบไฟล์และอธิบายการทำงานของแอปเท่านั้น (nominative fair use) เจ้าของเครื่องหมายการค้าไม่มีส่วนเกี่ยวข้องกับ MiyaraHub Technologies LLC และไม่ได้รับรองผลิตภัณฑ์นี้

NexusDeck สื่อสารกับเครื่องรับ Denon/Marantz โดยใช้อินเทอร์เฟซควบคุมผ่านเครือข่ายของเครื่อง (HTTP, Telnet, โปรโตคอลอัปโหลดการสอบเทียบแบบไบนารีบนพอร์ต TCP 1256 และสำหรับ Dirac Live คือพอร์ตที่เครื่องรับประกาศ) การใช้แอปนี้เป็นความเสี่ยงของคุณเอง MiyaraHub Technologies LLC ไม่รับผิดชอบต่อการตั้งค่าผิดพลาด ปัญหาด้านเสียง การสอบเทียบที่สูญหาย หรือปัญหาอื่นใดที่เกิดจากการใช้แอปพลิเคชันนี้ โปรดยืนยันการสำรองข้อมูลชุดตั้งค่าลำโพงเดิมของคุณทุกครั้งก่อนใช้การสอบเทียบใหม่
