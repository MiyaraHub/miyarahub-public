MiyaraHub / Projector Pilot D-ILA

Projector Pilot D-ILA · สำหรับโปรเจกเตอร์ JVC D-ILAD-ILA ของคุณ อยู่ในมือคุณ✦

รีโมทเครือข่ายภายในสำหรับโปรเจกเตอร์ JVC D-ILA จากโทรศัพท์ แท็บเล็ต หรือคอมพิวเตอร์ของคุณ

Projector Pilot D-ILA สื่อสารกับโปรเจกเตอร์ของคุณโดยตรงผ่านพอร์ตควบคุมเครือข่าย (TCP 20554) ด้วยรหัสผ่านเครือข่ายที่คุณตั้งไว้บนโปรเจกเตอร์ ควบคุมการเปิดปิด อินพุต การนำทางเมนู โหมดภาพ ระดับ HDR สี การเคลื่อนไหว เลนส์ การติดตั้ง และอัตราส่วนภาพ พร้อมฉาก การบำรุงรักษา และระบบบ้านอัตโนมัติเพิ่มเติม ไม่มีบัญชีและบริการคลาวด์คั่นกลาง

✦ วิดเจ็ตและโปรเจกเตอร์สาธิต

วิธีการทำงาน

เชื่อมต่อเครือข่ายโดยตรง ไม่มีคลาวด์คั่นกลาง

Projector Pilot D-ILA เชื่อมต่อกับโปรเจกเตอร์ของคุณโดยตรงบนเครือข่ายภายใน ไม่มีเซิร์ฟเวอร์ของ MiyaraHub และไม่ต้องมีบัญชี

1

ค้นหาโปรเจกเตอร์ของคุณ

สแกนเครือข่ายของคุณ ซึ่งจะลองพอร์ต 20554 บนทุกที่อยู่ในซับเน็ต หรือเพิ่มโปรเจกเตอร์ด้วยที่อยู่ IP

2

ลงชื่อเข้าใช้ด้วยรหัสผ่าน

ป้อนรหัสผ่านเครือข่ายที่คุณตั้งไว้บนโปรเจกเตอร์ แอปจะลงชื่อเข้าใช้บน TCP 20554 อ่านรุ่น และเก็บรหัสผ่านไว้ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์คุณ

3

เริ่มควบคุม

ใช้หน้าจอรีโมท ภาพ เลนส์ และการตั้งค่าที่รุ่นของคุณรองรับ บันทึกฉาก และเชื่อมต่อระบบบ้านอัตโนมัติหากต้องการ

ความปลอดภัย & ความเป็นส่วนตัว

ทำงานในเครือข่ายภายใน ไม่ต้องมีบัญชี ไม่มีโฆษณา

แอปสื่อสารกับโปรเจกเตอร์ของคุณบนเครือข่ายภายใน และสื่อสารกับสโตร์เพื่อการซื้อในแอป สิ่งอื่นที่แอปส่งและส่งเมื่อใด ระบุไว้ที่นี่

◉

ตรงไปยังโปรเจกเตอร์

คำสั่งและการอ่านสถานะเกิดขึ้นโดยตรงระหว่างอุปกรณ์ของคุณกับโปรเจกเตอร์บนเครือข่ายภายใน โดยไม่มีบริการคลาวด์คั่นกลาง

◎

ไม่ต้องมีบัญชี

ไม่ต้องสมัครและไม่ต้องมีบัญชี MiyaraHub สแกนหรือป้อนที่อยู่ของโปรเจกเตอร์ แล้วเชื่อมต่อ

▣

รายงานข้อผิดพลาดและการวิเคราะห์การใช้งาน

รายงานข้อผิดพลาดเปิดไว้ตามค่าเริ่มต้นบน Android, iPhone และ iPad เพื่อให้แก้ไขบั๊กได้ และปิดได้ในการตั้งค่า รายงานข้อผิดพลาดอาจมีข้อความของข้อผิดพลาดที่ทำให้แอปหยุดทำงาน ซึ่งในบางกรณีอาจมีที่อยู่เครือข่าย แอป macOS และ Windows ไม่ส่งเลย การวิเคราะห์การใช้งานแบบไม่ระบุตัวตนปิดอยู่จนกว่าคุณจะเลือกเข้าร่วม และมีเฉพาะจำนวนและผลลัพธ์ ไม่เคยมีชื่อโปรเจกเตอร์ ที่อยู่ รหัสผ่าน หรือที่อยู่ฮับ

◆

รหัสผ่านในที่เก็บข้อมูลที่ปลอดภัย

รหัสผ่านเครือข่ายของโปรเจกเตอร์แต่ละเครื่องถูกเก็บไว้ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์คุณ ไม่ไปที่อื่น ทั้งในบันทึกและข้อมูลสำรอง ยกเว้น Home Assistant ที่คุณเพิ่มโปรเจกเตอร์เข้าไป

▢

ไม่ส่งสิ่งใดหากไม่มี Home Automation

เมื่อซื้อ Home Automation แอปจะส่งทริกเกอร์ของคุณไปยังที่อยู่เว็บที่คุณป้อนเท่านั้น ส่งเฉพาะการเปิดปิดและอินพุตไปยังฮับ Hubitat ที่คุณเชื่อมต่อ และส่งสถานะโปรเจกเตอร์ไปยัง Home Assistant ที่คุณลงชื่อเข้าใช้ หากไม่ได้ซื้อ และกับโปรเจกเตอร์สาธิตเสมอ จะไม่มีสิ่งใดถูกส่ง
