เชื่อมต่อเครือข่ายโดยตรง ไม่ต้องพึ่งคลาวด์

Projector Pilot PJLink & VP21 สื่อสารกับโปรเจกเตอร์ของคุณโดยตรงบนเครือข่ายภายใน ไม่มีเซิร์ฟเวอร์ของ MiyaraHub และไม่ต้องมีบัญชี

1

ค้นหาโปรเจกเตอร์ของคุณ

สแกนเครือข่ายเพื่อหาโปรเจกเตอร์ที่ตอบสนองบนพอร์ต PJLink (4352) และ ESC/VP.net (3629) หรือป้อนที่อยู่ IP แอปจะตรวจจับรุ่นและฟีเจอร์ที่รองรับ

2

เชื่อมต่อบนเครือข่ายของคุณ

แอปใช้ ESC/VP21 ผ่าน ESC/VP.net (TCP 3629) และ PJLink (TCP 4352) สำหรับการเปิดปิด อินพุต และการตั้งค่า และใช้ Epson Web Control (HTTP 80 เข้าสู่ระบบแบบ Digest) หากโปรเจกเตอร์มีให้ ทุกอย่างอยู่บนเครือข่ายภายในของคุณ

3

ควบคุมได้เต็มที่

ปรับการตั้งค่าภาพ สลับอินพุต ควบคุมเลนส์มอเตอร์ จัดการการแก้ไขคีย์สโตน ติดตามชั่วโมงหลอดภาพ และนำทาง OSD ได้ทั้งหมดในแอปเดียวที่สวยงาม

ความปลอดภัย & ความเป็นส่วนตัว

ทำงานในเครือข่ายภายใน ไม่ต้องมีบัญชี ไม่มีโฆษณา

แอปสื่อสารกับโปรเจกเตอร์ของคุณบนเครือข่ายภายใน และสื่อสารกับสโตร์เพื่อการซื้อ สิ่งอื่นที่แอปส่งและส่งเมื่อใด ระบุไว้ที่นี่

◉

ไม่มีรีเลย์คลาวด์

คำสั่งและการอัปเดตสถานะเป็นระยะทั้งหมดเกิดขึ้นโดยตรงระหว่างอุปกรณ์ของคุณกับโปรเจกเตอร์บนเครือข่ายภายใน โดยไม่มีบริการคลาวด์คั่นกลาง

◎

ไม่ต้องมีบัญชี

ไม่ต้องสมัคร ไม่ต้องใช้อีเมล ไม่ต้องมีบัญชี MiyaraHub เปิดแอป ป้อนที่อยู่ IP ของโปรเจกเตอร์ แล้วคุณก็ควบคุมได้เลย

▣

การวินิจฉัย

Firebase Crashlytics ส่งรายงานการแครช โดยเชื่อมโยงกับรหัสสุ่ม ไม่ใช่ชื่อของคุณ เพื่อให้เราแก้ไขข้อบกพร่องได้ การวิเคราะห์การใช้งานปิดอยู่จนกว่าคุณจะเลือกเปิดใช้ ไม่มีบัญชีและไม่มีโฆษณา

◆

รหัสผ่านในที่เก็บข้อมูลที่ปลอดภัย

รหัสผ่านของโปรเจกเตอร์ถูกเก็บไว้ในที่เก็บข้อมูลที่ปลอดภัยของอุปกรณ์คุณ ส่วนที่อยู่และการตั้งค่าแอปอยู่ในที่เก็บข้อมูลของแอปบนเครื่อง ไม่มีสิ่งใดถูกซิงค์ไปยังเซิร์ฟเวอร์ของ MiyaraHub

▢

ระบบบ้านอัตโนมัติเมื่อคุณตั้งค่าเท่านั้น

เมื่อซื้อ Home Automation แอปจะส่งข้อมูลไปยังที่อยู่เว็บที่คุณป้อน ฮับ Hubitat ที่คุณเชื่อมต่อ และ Home Assistant ที่คุณลงชื่อเข้าใช้ หากไม่ได้ซื้อ จะไม่มีสิ่งใดถูกส่งไปยังบริการสมาร์ทโฮม

☼

ใช้สิทธิ์เครือข่ายเท่านั้น

แอปใช้การเข้าถึงเครือข่ายเพื่อเชื่อมต่อกับโปรเจกเตอร์ของคุณบนเครือข่ายภายในของคุณเท่านั้น และใช้การแจ้งเตือนสำหรับการแจ้งเตือนบำรุงรักษาที่คุณตั้งไว้เท่านั้น
