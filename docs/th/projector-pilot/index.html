มาตรฐาน PJLink: Projector Pilot ยังให้การควบคุมพื้นฐาน (เปิดปิด อินพุต ปิดเสียง ชั่วโมงหลอดภาพ) สำหรับโปรเจกเตอร์ที่เข้ากันได้กับ PJLink จากผู้ผลิตรายอื่น รวมถึง NEC, Panasonic, Sony, BenQ, Christie และ Barco ฟีเจอร์ที่ใช้ได้แตกต่างกันไปตามรุ่น แอปตรวจจับฟีเจอร์ที่รองรับโดยอัตโนมัติเมื่อเชื่อมต่อ

วิธีการทำงาน

เชื่อมต่อเครือข่ายโดยตรง ไม่ต้องพึ่งคลาวด์

Projector Pilot สื่อสารกับโปรเจกเตอร์ของคุณโดยตรงผ่าน Wi-Fi โดยใช้โปรโตคอลเครือข่ายมาตรฐาน ข้อมูลของคุณไม่เคยผ่านเซิร์ฟเวอร์ภายนอก

1

เพิ่มโปรเจกเตอร์ของคุณ

ป้อนที่อยู่ IP ของโปรเจกเตอร์ Epson ของคุณ Projector Pilot จะทดสอบการเชื่อมต่อ PJLink และ Web Control ตรวจจับรุ่น และค้นหาฟีเจอร์ที่ใช้ได้ทั้งหมดโดยอัตโนมัติ

2

เชื่อมต่อผ่าน Wi-Fi

Projector Pilot ใช้ PJLink สำหรับตรวจจับสแตนด์บายและควบคุมการเปิดปิด รวมถึง Epson Web Control API สำหรับควบคุมภาพ เลนส์ และการตั้งค่าอย่างเต็มรูปแบบเมื่อเปิดเครื่องแล้ว ทุกอย่างอยู่ในเครือข่ายภายในของคุณ

3

ควบคุมได้เต็มที่

ปรับการตั้งค่าภาพ สลับอินพุต ควบคุมเลนส์มอเตอร์ จัดการการแก้ไขคีย์สโตน ติดตามชั่วโมงหลอดภาพ และนำทาง OSD ได้ทั้งหมดในแอปเดียวที่สวยงาม

ความปลอดภัย & ความเป็นส่วนตัว

ทำงานในเครื่องเท่านั้น ไม่ต้องมีบัญชี ไม่มีคลาวด์

Projector Pilot ออกแบบด้วยสถาปัตยกรรมที่ให้ความสำคัญกับความเป็นส่วนตัวและทำงานภายในเครือข่ายเท่านั้น ไม่พึ่งพาคลาวด์ ไม่ต้องมีบัญชีผู้ใช้ ไม่เก็บข้อมูลใด ๆ นอกจากรายงานการแครช

◉

ไม่มีรีเลย์คลาวด์

คำสั่งและการอัปเดตสถานะทั้งหมดเกิดขึ้นโดยตรงระหว่างโทรศัพท์ของคุณกับโปรเจกเตอร์ผ่าน Wi-Fi ภายใน ไม่มีสิ่งใดออกจากเครือข่ายของคุณ

◎

ไม่ต้องมีบัญชี

ไม่ต้องสมัคร ไม่ต้องใช้อีเมล ไม่ต้องมีบัญชี MiyaraHub เปิดแอป ป้อนที่อยู่ IP ของโปรเจกเตอร์ แล้วคุณก็ควบคุมได้เลย

▣

การวิเคราะห์ขั้นต่ำ

ใช้ Firebase Crashlytics เพื่อรายงานข้อบกพร่องเท่านั้น ไม่มีข้อมูลส่วนบุคคล ไม่ติดตามการใช้งาน ไม่มีโฆษณา ข้อมูลโปรเจกเตอร์ของคุณไม่เคยออกจากโทรศัพท์

◆

จัดเก็บในเครื่องเท่านั้น

ที่อยู่ IP ของโปรเจกเตอร์ ข้อมูลรับรอง และค่ากำหนดของแอปจะเก็บไว้ในเครื่องโดยใช้ SharedPreferences ไม่มีสิ่งใดถูกซิงค์ไปยังเซิร์ฟเวอร์

▢

ทำงานเมื่อคุณสั่งเท่านั้น

แอปส่งคำสั่งไปยังโปรเจกเตอร์ของคุณเมื่อคุณสั่งเองเท่านั้น ไม่มีอะไรเกิดขึ้นเองอัตโนมัติหรือทำงานเบื้องหลังโดยที่คุณไม่รู้

☼

ใช้สิทธิ์เครือข่ายเท่านั้น

สิทธิ์เดียวของอุปกรณ์ที่ Projector Pilot ต้องใช้คือการเข้าถึงอินเทอร์เน็ต/เครือข่าย ซึ่งใช้เพื่อเชื่อมต่อกับโปรเจกเตอร์ของคุณบน Wi-Fi ภายในเท่านั้น
