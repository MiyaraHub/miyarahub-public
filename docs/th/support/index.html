ฝ่ายสนับสนุน

ต้องการความช่วยเหลือเกี่ยวกับแอปของเราใช่ไหม มาถูกที่แล้ว เราอ่านทุกข้อความและตอบกลับให้เร็วที่สุด

ติดต่อเรา

ติดต่อเราได้สองช่องทาง อีเมลจะได้รับคำตอบเป็นลายลักษณ์อักษรภายในไม่กี่วันทำการ ส่วน Discord เป็นที่ที่เราอยู่กัน และคำถามสั้น ๆ มักได้คำตอบเร็วกว่าจากเราหรือชุมชน

admin@miyarahub.com เข้าร่วม Discord ของเรา

โดยปกติเราตอบอีเมลภายใน 1-2 วันทำการ ปัญหาเร่งด่วนที่กระทบการใช้งานจริงจะได้รับความสำคัญก่อน

สิ่งที่ควรระบุในข้อความของคุณ

การให้รายละเอียดเหล่านี้ตั้งแต่แรกช่วยลดการสอบถามกลับไปมา และทำให้คุณได้รับการแก้ไขเร็วขึ้น:

  • ชื่อแอปและเวอร์ชัน - ดูได้ในหน้าการตั้งค่าหรือหน้าเกี่ยวกับของแอป (เช่น "AVR Maestro v2.9.6+131")
  • อุปกรณ์และระบบปฏิบัติการ - รุ่นโทรศัพท์/แท็บเล็ตและเวอร์ชันระบบปฏิบัติการ (เช่น "iPhone 15 Pro, iOS 18.2" หรือ "Samsung Galaxy S24, Android 15")
  • สิ่งที่คุณคาดว่าจะเกิดขึ้น เทียบกับสิ่งที่เกิดขึ้นจริง
  • ขั้นตอนการทำซ้ำปัญหา - เพื่อให้เราเห็นปัญหาเดียวกันได้ฝั่งเรา
  • ภาพหน้าจอหรือคลิปบันทึกหน้าจอสั้น ๆ หากปัญหาเกี่ยวกับการแสดงผล
  • ข้อมูลฮาร์ดแวร์ สำหรับแอปควบคุมอุปกรณ์ - รุ่นเครื่องรับ/NAS/UPS/โปรเจกเตอร์ และเวอร์ชันเฟิร์มแวร์หากทราบ

แอปของเราส่วนใหญ่มีตัวเลือก "ส่งความคิดเห็น" ในตัวที่เติมข้อมูลเหล่านี้ให้คุณล่วงหน้า ลองมองหาในหน้าเกี่ยวกับหรือหน้าการตั้งค่า

แอปที่เราสนับสนุน

ช่องทางนี้ดูแลการสนับสนุนสำหรับแอปพลิเคชันทั้งหมดของ MiyaraHub Technologies บน iOS, Android และเดสก์ท็อป ไม่ว่าคุณจะใช้แอปควบคุมอุปกรณ์ เครื่องมือตรวจสอบ หรือยูทิลิตี้เสียง/วิดีโอของเรา ดูรายชื่อแอปล่าสุดได้ที่หน้าแรก

คำถามที่พบบ่อย

แอปเชื่อมต่อกับอุปกรณ์ของฉันในเครือข่ายภายในไม่ได้

แอปควบคุมอุปกรณ์ของเรา (AVR Maestro, UPSight, Syno Manager, FuryPath, Projector Pilot) ต้องเข้าถึงฮาร์ดแวร์ของคุณผ่าน Wi-Fi หรืออีเทอร์เน็ต หากไม่พบอุปกรณ์:

  • ตรวจสอบว่าโทรศัพท์และอุปกรณ์เป้าหมายอยู่ในเครือข่ายเดียวกัน (SSID และ VLAN เดียวกัน)
  • ตรวจสอบว่าเปิดใช้ฟีเจอร์ควบคุมผ่านเครือข่ายหรือ API ในเมนูการตั้งค่าของอุปกรณ์เองแล้ว
  • บน iOS ให้ยอมรับข้อความขอสิทธิ์ "ค้นหาและเชื่อมต่อกับอุปกรณ์บนเครือข่ายภายใน" เมื่อเปิดแอปครั้งแรก หากคุณปฏิเสธไป ให้เปิดใหม่ที่ Settings → [App Name] → Local Network
  • บน Android แอปต้องมีสิทธิ์ Wi-Fi + อินเทอร์เน็ต (ให้อัตโนมัติเมื่อติดตั้ง)
  • เราเตอร์บางรุ่นแยกอุปกรณ์ออกจากกัน ("AP isolation" หรือ "เครือข่ายแขก") ให้ปิดการแยกสำหรับซับเน็ตที่อุปกรณ์ของคุณอยู่

ข้อความขอให้ให้คะแนนในแอปปรากฏขึ้น - จำเป็นต้องทำไหม

ไม่จำเป็น คุณปิดข้อความได้ เลือก "ภายหลัง" เพื่อเลื่อนไป หรือแตะ "ไม่ต้องถามอีก" เพื่อปิดถาวร การให้คะแนนหรือส่งความคิดเห็นเป็นทางเลือกทั้งหมด และไม่กระทบการทำงานของแอป

ฉันซื้อแอปแล้ว ขอคืนเงินได้อย่างไร

แอปแบบชำระเงินทั้งหมดซื้อผ่าน Apple App Store หรือ Google Play Store คำขอคืนเงินจัดการโดยแพลตฟอร์มเหล่านั้นโดยตรง:

  • Apple: reportaproblem.apple.com
  • Google: ประวัติการสั่งซื้อใน Google Play

หากคุณติดขัดกับแพลตฟอร์มใดแพลตฟอร์มหนึ่ง ส่งอีเมลมาหาเรา แล้วเราจะช่วยผลักดันเรื่องการคืนเงินให้

ฮาร์ดแวร์ของฉันทำงานต่างไปหลังอัปเดตเฟิร์มแวร์

บางครั้งผู้ผลิตบุคคลที่สามเปลี่ยน API เครือข่ายระหว่างเฟิร์มแวร์แต่ละเวอร์ชัน หากแอปทำงานต่างไปทันทีหลังคุณอัปเดตอุปกรณ์ ส่งอีเมลบอกรุ่นอุปกรณ์ เฟิร์มแวร์เดิม เฟิร์มแวร์ปัจจุบัน และสิ่งที่เปลี่ยนไป เราจะตรวจสอบและออกการแก้ไขหากเป็นสิ่งที่เราปรับตามได้

ดูได้ที่ไหนว่าเวอร์ชันล่าสุดมีอะไรเปลี่ยนแปลง

เปิดหน้าเกี่ยวกับหรือหน้าการตั้งค่าของแอป แอปของเราส่วนใหญ่มีบันทึกการเปลี่ยนแปลงในตัว บันทึกประจำรุ่นยังปรากฏในหน้ารายการของสโตร์ด้วย

มีโรดแมปสาธารณะไหม

เราไม่เผยแพร่โรดแมปตายตัว เพราะเราปล่อยเมื่อโค้ดพร้อม ไม่ใช่ตามปฏิทิน อย่างไรก็ตาม หากมีฟีเจอร์ที่คุณอยากเห็น ส่งอีเมลมาได้เลย ความคิดเห็นของผู้ใช้มีผลโดยตรงต่อสิ่งที่เราจะสร้างต่อไป

ความเป็นส่วนตัว ข้อกำหนด และกฎหมาย
