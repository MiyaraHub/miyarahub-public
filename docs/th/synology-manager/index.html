ดูการใช้งานจริง

NAS ทั้งเครื่องของคุณ ในพริบตา

ภาพหน้าจอจริงจาก Syno Manager ได้แก่ แดชบอร์ด ตัวตรวจสอบระบบ พื้นที่จัดเก็บ งาน ไฟล์ ธีม และอื่น ๆ แตะภาพใดก็ได้เพื่อขยาย

ฟีเจอร์

ควบคุม NAS ได้ครบ ในมือคุณ

ทุกอย่างที่ DSM แสดงให้คุณเห็น ย้ายมาอยู่บนมือถือ และซ่อนสิ่งที่บัญชีของคุณมองไม่เห็นอย่างนุ่มนวล

ลำดับ 01

◉ แดชบอร์ดเรียลไทม์

ดู CPU, RAM, อุณหภูมิ และเวลาทำงานแบบสดได้ในพริบตา การ์ดที่ปรับแต่งได้ช่วยให้คุณเห็นสิ่งที่สำคัญจริง ๆ ทั้งสุขภาพระบบ การใช้พื้นที่จัดเก็บ ปริมาณข้อมูลเครือข่าย และอื่น ๆ

ลำดับ 02

▣ การจัดการ Docker

ดูคอนเทนเนอร์ที่กำลังทำงานทั้งหมดพร้อมการใช้ CPU และหน่วยความจำแบบเรียลไทม์ เริ่ม หยุด รีสตาร์ตคอนเทนเนอร์ และเข้าถึงบันทึก ควบคุม Docker ได้เต็มรูปแบบจากโทรศัพท์ของคุณ

ลำดับ 03

◎ กล้องวงจรปิด

ดูภาพสดจากกล้องในตารางที่เป็นระเบียบ แตะเพื่อดูเต็มจอ ดูสถานะการบันทึก และตรวจสอบกล้อง Surveillance Station ทั้งหมดในที่เดียว

ลำดับ 04

▢ พื้นที่จัดเก็บ & สุขภาพไดรฟ์

การใช้ volume สถานะ RAID อุณหภูมิของแต่ละไดรฟ์ และข้อมูลสุขภาพ SMART ของทุกดิสก์ รู้สถานะพื้นที่จัดเก็บของคุณได้ตลอดเวลา

ลำดับ 05

╿ การตรวจสอบเครือข่าย

กราฟแบนด์วิดท์สดของทุกอินเทอร์เฟซเครือข่าย ติดตามความเร็วดาวน์โหลด/อัปโหลด การเชื่อมต่อที่ใช้งานอยู่ อินเทอร์เฟซที่รวมกัน และการตั้งค่า DNS

ลำดับ 06

⚙ การจัดการแพ็กเกจ

ดูแพ็กเกจ DSM ที่ติดตั้งทั้งหมดและสถานะของแพ็กเกจ ตรวจสอบบริการที่กำลังทำงาน งานตามกำหนดเวลา สถานะแบตเตอรี่ UPS รายการบันทึก และโฟลเดอร์แชร์

ลำดับ 07

☼ ปรับแต่งได้เต็มที่

กำหนดหมวดหมู่แดชบอร์ด ปรับแต่งแถบนำทาง เลือกธีม และตั้งช่วงเวลาอัปเดตข้อมูล ทำให้แอปทำงานในแบบที่คุณต้องการ

ลำดับ 08

✦ วิดเจ็ตหน้าจอหลัก

วิดเจ็ต Quick Actions, Storage Overview และ System Status สำหรับหน้าจอหลักของคุณ ดูสุขภาพ NAS ได้ในพริบตาโดยไม่ต้องเปิดแอป

วิธีการทำงาน

เชื่อมต่อ DSM โดยตรง ไม่ผ่านคลาวด์

1

เพิ่ม NAS ของคุณ

ป้อน IP หรือโฮสต์เนมและพอร์ตของ NAS ไม่ต้องมีบัญชี MiyaraHub ไม่ต้องสมัคร

2

ลงชื่อเข้าใช้ด้วย DSM

ยืนยันตัวตนด้วยข้อมูลรับรอง DSM ที่คุณมีอยู่ ส่งไปยัง NAS ของคุณเท่านั้น โดยใช้กลไกเดียวกับพอร์ทัลเว็บของ DSM

3

ตรวจสอบ & จัดการ

แดชบอร์ด Docker กล้อง พื้นที่จัดเก็บ เครือข่าย แพ็กเกจ และงาน ตรงจากโทรศัพท์ แท็บเล็ต หรือเดสก์ท็อปของคุณ

ความปลอดภัย & ความเป็นส่วนตัว

NAS ของคุณ ข้อมูลของคุณ การควบคุมของคุณ

Syno Manager ออกแบบด้วยสถาปัตยกรรมที่ให้ความสำคัญกับความเป็นส่วนตัว เก็บข้อมูลน้อยที่สุด ไม่ติดตามผู้ใช้ ไม่พึ่งพาคลาวด์

◉

ไม่มีรีเลย์คลาวด์

การสื่อสารทั้งหมดเกิดขึ้นโดยตรงระหว่างอุปกรณ์ของคุณกับ NAS ผ่านเครือข่ายภายใน ไม่มีสิ่งใดผ่านเซิร์ฟเวอร์ภายนอก

▣

การยืนยันตัวตน DSM มาตรฐาน

ใช้กลไกการยืนยันตัวตนเดียวกับเว็บอินเทอร์เฟซของ DSM ข้อมูลรับรองของคุณถูกส่งไปยัง NAS ของคุณเท่านั้น ไม่เคยส่งถึงเรา

◎

การวิเคราะห์ขั้นต่ำ

ใช้ Firebase Crashlytics เพื่อจับข้อบกพร่องและปรับปรุงเสถียรภาพ ไม่มีข้อมูลส่วนบุคคล ไม่ติดตามการใช้งาน ไม่มีโฆษณา แอปไม่เคยเก็บข้อมูล NAS หรือข้อมูลรับรองนอกอุปกรณ์ของคุณ

◆

ที่เก็บข้อมูลในเครื่องที่ปลอดภัย

รายละเอียดการเชื่อมต่อถูกเก็บบนอุปกรณ์โดยใช้ที่เก็บข้อมูลปลอดภัยของแพลตฟอร์ม ได้แก่ iOS Keychain และ Android Keystore

คำถามที่พบบ่อย

คำถามที่พบบ่อย

แอปเชื่อมต่อกับ NAS ของฉันอย่างไร +
Syno Manager ใช้ endpoint ของ Synology DSM API ที่มีเอกสารกำกับเพื่อสื่อสารกับ NAS ของคุณผ่านเครือข่ายภายใน แอปส่งคำขอตรงไปยัง NAS ของคุณ ไม่มีเซิร์ฟเวอร์กลาง พร็อกซี หรือคลาวด์รีเลย์เข้ามาเกี่ยวข้อง คุณระบุ IP/โฮสต์เนมและพอร์ตของ NAS ยืนยันตัวตนด้วยข้อมูลรับรอง DSM ของคุณ และแอปสื่อสารกับ DSM โดยตรง
แอปต้องใช้สิทธิ์อะไรบน NAS ของฉัน +
แอปทำงานภายในสิทธิ์ที่บัญชีผู้ใช้ DSM ของคุณมี เพื่อให้แดชบอร์ดใช้งานได้ครบ แนะนำให้ใช้บัญชีผู้ดูแลระบบ อย่างไรก็ตาม แอปจะปรับตัวได้อย่างนุ่มนวล หากบัญชีของคุณไม่มีสิทธิ์ Docker ส่วน Docker ก็จะไม่แสดงข้อมูล เช่นเดียวกับ Surveillance Station โฟลเดอร์แชร์ ฯลฯ ไม่ต้องติดตั้งแพ็กเกจ DSM พิเศษใด ๆ
แอปเก็บข้อมูลรับรอง NAS ของฉันไหม +
รายละเอียดการเชื่อมต่อถูกเก็บไว้ในเครื่องบนอุปกรณ์ของคุณโดยใช้ที่เก็บข้อมูลปลอดภัยของแพลตฟอร์ม (iOS Keychain / Android Keystore) ข้อมูลรับรองไม่เคยถูกส่งไปยัง MiyaraHub Technologies หรือบุคคลที่สามใด ๆ และใช้เพื่อยืนยันตัวตนกับ NAS ของคุณเท่านั้น
รองรับ Synology รุ่นใดบ้าง +
Syno Manager ใช้ได้กับ Synology NAS ทุกเครื่องที่รัน DSM 7.0 ขึ้นไป รวมถึงรุ่น DiskStation (DS), RackStation (RS) และ FlashStation (FS) ปัจจุบันทั้งหมด รุ่นเก่าที่รัน DSM 6.x อาจใช้งานได้จำกัดเนื่องจากความแตกต่างของ API
จัดการคอนเทนเนอร์ Docker จากระยะไกลได้ไหม +
ได้ คุณดูสถานะคอนเทนเนอร์ การใช้ CPU/หน่วยความจำ เข้าถึงบันทึก และสั่งหยุด/รีสตาร์ตได้โดยตรงจากแอป ยังไม่รองรับการสร้างคอนเทนเนอร์และการเปลี่ยนการตั้งค่า เพราะเน้นการตรวจสอบและการจัดการแบบรวดเร็ว
Syno Manager ราคาเท่าไร +
Syno Manager เป็นการซื้อครั้งเดียวในราคา $9.99 ไม่มีค่าสมาชิก ไม่มีโฆษณา ไม่มีการซื้อในแอป ซื้อครั้งเดียวบน App Store หรือ Google Play แล้วเป็นเจ้าของตลอดไป
เข้าถึง NAS จากระยะไกล (นอกเครือข่ายที่บ้าน) ได้ไหม +
Syno Manager เชื่อมต่อกับ IP/โฮสต์เนมใดก็ตามที่คุณตั้งค่าไว้ หาก NAS ของคุณเข้าถึงได้ผ่าน VPN, Tailscale หรือพอร์ตที่ฟอร์เวิร์ดไว้ แอปก็ใช้งานจากระยะไกลได้ เราแนะนำให้ใช้ VPN หรือ Tailscale แทนการเปิด DSM สู่อินเทอร์เน็ตโดยตรง
