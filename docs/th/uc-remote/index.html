รีโมตทั้งตัว อยู่ในมือคุณ

UC Remote เชื่อมต่อกับ Unfolded Circle Remote Two หรือ Remote 3 ของคุณผ่าน Wi-Fi และสะท้อนทุกอย่างที่รีโมตทำได้ ทั้งกิจกรรม หน้า เอนทิตี และสื่อ ในอินเทอร์เฟซเนทีฟที่รวดเร็วซึ่งออกแบบมาสำหรับโทรศัพท์

ลำดับ 01

◉ กิจกรรมในแตะเดียว

เริ่มและหยุดกิจกรรมเต็มรูปแบบ เช่น ดู Shield TV, Xbox, PS5 จากรายการที่สะอาดตา รีโมตของคุณเปิดอุปกรณ์ที่ถูกต้องและสลับอินพุต ส่วนแอปพาคุณไปยังตัวควบคุมของกิจกรรมนั้นทันที

เริ่ม / หยุดกลุ่มกิจกรรมแตะเดียว
ลำดับ 02

▣ หน้ากิจกรรมที่สวยงาม

ทุกกิจกรรมมีหน้าแบบกำหนดเองของตัวเอง ปัดสลับระหว่างมุมมองสถานะกำลังเล่นของสื่อ รีโมตแบบปุ่ม และไทล์ควบคุมที่ปรับแต่งเฉพาะ จัดวางตรงตามที่ตั้งค่าไว้บนรีโมตของคุณ

หน้าที่ปัดได้เลย์เอาต์กำหนดเองไทล์ปุ่ม
ลำดับ 03

♫ สถานะกำลังเล่นแบบสด

ภาพปกอัลบั้ม ชื่อเพลงและศิลปิน ปุ่มควบคุมการเล่น (ก่อนหน้า เล่น / หยุดชั่วคราว ถัดไป) พร้อมตัวเลือกแหล่งสัญญาณและโหมดเสียงสำหรับเครื่องเล่นสื่อของคุณ อัปเดตแบบสดทุกครั้งที่มีการเปลี่ยนแปลง

ภาพปกอัลบั้มปุ่มควบคุมการเล่นสถานะสด
ลำดับ 04

◎ ทุกเอนทิตี ออกแบบเฉพาะตัว

ไฟพร้อมความสว่างและสี เครื่องปรับอากาศพร้อมค่าที่ตั้ง ม่าน สวิตช์ เซ็นเซอร์ และเครื่องเล่นสื่อ แต่ละอย่างมีหน้าจอควบคุมที่ออกแบบมาเฉพาะ พร้อมไอคอนและการทำงานที่เหมาะสม ไม่ใช่แค่ปุ่มเปิดปิดทั่วไป

ไฟเครื่องปรับอากาศม่านเซ็นเซอร์
ลำดับ 05

☰ ตัวเรียกดูเอนทิตีเต็มรูปแบบ

ค้นหาและกรองการตั้งค่าทั้งหมดของคุณ หลายร้อยเอนทิตี ตามประเภท ไม่ว่าจะเป็นไฟ เครื่องเล่นสื่อ สวิตช์ หรือเครื่องปรับอากาศ แล้วกระโดดเข้าไปยังรายการใดก็ได้ทันที

ค้นหากรองตามประเภทเปิดด่วน
ลำดับ 06

▤ รีโมตหลายตัว

จับคู่รีโมต Unfolded Circle มากกว่าหนึ่งตัวและสลับระหว่างกันได้ทันที แต่ละตัวจดจำโปรไฟล์ หน้า และเอนทิตีของตัวเอง รีโมตห้องโฮมเธียเตอร์กับรีโมตห้องทำงานจึงแยกจากกันโดยสิ้นเชิง

หลายรีโมตสลับด่วนโปรไฟล์ต่อรีโมต
ลำดับ 07

▦ วิดเจ็ตหน้าจอหลัก

วางวิดเจ็ตกิจกรรม เครื่องเล่นสื่อ หรืออุปกรณ์บนหน้าจอหลักได้เลย โดยแต่ละอันชี้ไปยังรีโมตที่คุณเลือก เพื่อควบคุมในแตะเดียวและดูสถานะกำลังเล่นแบบสดโดยไม่ต้องเปิดแอป

กิจกรรมสื่ออุปกรณ์

UC Remote คุยกับรีโมตของคุณโดยตรงผ่าน Wi-Fi ของคุณเอง สตรีมเหตุการณ์สดช่วยให้สถานะซิงค์กันและคำสั่งของคุณส่งตรงถึงรีโมต จับคู่ด้วย PIN ไม่มีคลาวด์รีเลย์และไม่มีบัญชี

ตรงถึงรีโมตของคุณ ไม่ต้องใช้คลาวด์

UC Remote จับคู่กับรีโมต Unfolded Circle ของคุณบน Wi-Fi ของคุณเองและคุยกับรีโมตโดยตรง โดยใช้อินเทอร์เฟซการเชื่อมต่อของตัวรีโมตเอง การตั้งค่าของคุณไม่เคยแตะเซิร์ฟเวอร์ภายนอก

1

จับคู่รีโมตของคุณ

ป้อนที่อยู่ IP ของ Unfolded Circle Remote Two หรือ Remote 3 และ PIN ที่แสดงบนรีโมต UC Remote จะจับคู่อย่างปลอดภัยและดึงโปรไฟล์ หน้า กิจกรรม และเอนทิตีของคุณเข้ามา

2

ซิงค์กันตลอดเวลา

การเชื่อมต่อสองทางแบบสดสตรีมสถานะจากรีโมต ทั้งสิ่งที่เปิดอยู่และสิ่งที่กำลังเล่น ขณะที่การแตะของคุณถูกส่งกลับเป็นคำสั่งทันที ไม่มีความหน่วงจากการโพลล์ ไม่ต้องวนผ่านคลาวด์

3

ควบคุมได้ทุกอย่าง

เริ่มกิจกรรม ใช้หน้าที่กำหนดเอง ควบคุมทุกเอนทิตีและเครื่องเล่นสื่อ สลับระหว่างรีโมตหลายตัว และปักวิดเจ็ตบนหน้าจอหลัก ทั้งหมดจากแอปเดียว

ความปลอดภัย & ความเป็นส่วนตัว

ทำงานในเครื่องเท่านั้น ไม่ต้องมีบัญชี ไม่มีคลาวด์

UC Remote สร้างขึ้นโดยให้ความสำคัญกับความเป็นส่วนตัวและทำงานภายในเครือข่ายเท่านั้น ไม่พึ่งพาคลาวด์ ไม่ต้องมีบัญชีผู้ใช้ และไม่เก็บข้อมูลใด ๆ นอกจากรายงานการแครช

◉

ไม่มีรีเลย์คลาวด์

ทุกคำสั่งและสตรีมสถานะสดเกิดขึ้นโดยตรงระหว่างโทรศัพท์ของคุณกับรีโมตผ่าน Wi-Fi ภายใน ไม่มีสิ่งใดออกจากเครือข่ายของคุณ

◎

ไม่ต้องมีบัญชี

ไม่ต้องสมัคร ไม่ต้องใช้อีเมล ไม่ต้องมีบัญชี MiyaraHub จับคู่ด้วย PIN ของรีโมต แล้วคุณก็ควบคุมได้เลย

▣

เข้าถึงด้วยการจับคู่ PIN

การจับคู่จะแลกเปลี่ยนโทเค็นการเข้าถึงที่ปลอดภัย ซึ่งเก็บไว้ในเครื่องบนอุปกรณ์ของคุณและใช้เพื่อคุยกับรีโมตของคุณเท่านั้น

◆

จัดเก็บในเครื่องเท่านั้น

ที่อยู่รีโมตและค่ากำหนดของแอปจะเก็บไว้บนอุปกรณ์ของคุณ ไม่มีสิ่งใดถูกซิงค์ไปยังเซิร์ฟเวอร์

▢

ทำงานเมื่อคุณสั่งเท่านั้น

คำสั่งจะถูกส่งเมื่อคุณสั่งเองเท่านั้น ไม่มีอะไรเกิดขึ้นเองอัตโนมัติหรือทำงานเบื้องหลังโดยที่คุณไม่รู้

☰

ขอสิทธิ์เครือข่ายเท่านั้น

สิทธิ์เดียวที่ UC Remote ต้องใช้คือการเข้าถึงเครือข่ายภายใน ซึ่งใช้เพื่อเข้าถึงรีโมตของคุณบน Wi-Fi เท่านั้น

การอ้างถึงผลิตภัณฑ์เหล่านี้ในหน้านี้และภายในแอปมีไว้เพื่อระบุความเข้ากันได้และอธิบายการทำงานของแอปเท่านั้น (nominative fair use) เจ้าของเครื่องหมายการค้าไม่ได้เกี่ยวข้องกับ MiyaraHub Technologies LLC และไม่ได้รับรองผลิตภัณฑ์นี้

UC Remote สื่อสารกับรีโมต Unfolded Circle โดยใช้อินเทอร์เฟซการเชื่อมต่อผ่านเครือข่ายภายใน การใช้งานแอปนี้เป็นความเสี่ยงของคุณเอง MiyaraHub Technologies LLC ไม่รับผิดชอบต่อการตั้งค่าที่ผิดพลาดหรือปัญหาอื่นใดที่เกิดจากการใช้งาน
