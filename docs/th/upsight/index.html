ฟีเจอร์

ทุกอย่างที่ UPS รายงาน ชัดเจนในที่เดียว

ตรวจสอบและจัดการ UPS ทุกเครื่องในเครือข่ายของคุณ ตั้งแต่โฮมแล็บไปจนถึงตู้แร็ก

ลำดับ 01

◉ แดชบอร์ดเรียลไทม์

สถานะของ UPS ทุกเครื่องในพริบตา เปอร์เซ็นต์แบตเตอรี่ โหลด แรงดันไฟ และเวลาสำรองไฟที่เหลือ สดและเป็นปัจจุบันเสมอ พร้อมช่วงเวลาโพลล์ที่ปรับได้

ลำดับ 02

▣ ค่าพลังงาน

ข้อมูลพลังงานขาเข้าและขาออกโดยละเอียด ตรวจสอบแรงดันไฟ ความถี่ กระแส วัตต์ กำลังปรากฏ และคุณภาพสายไฟ ทุกอย่างที่ต้องใช้เพื่อเข้าใจสภาพแวดล้อมด้านพลังงานของคุณ

ลำดับ 03

◎ สุขภาพแบตเตอรี่

มาตรวัดแบตเตอรี่แบบเคลื่อนไหวพร้อมเปอร์เซ็นต์การชาร์จ แรงดันไฟ อุณหภูมิ และเวลาสำรองไฟโดยประมาณ รันการทดสอบตัวเองได้โดยตรงจากแอปเพื่อยืนยันความพร้อมของแบตเตอรี่

ลำดับ 04

▢ การควบคุมเต้ารับ

ดูและจัดการเต้ารับของ UPS ทีละจุด ดูว่าเต้ารับใดทำงานอยู่ ตั้งชื่อใหม่เพื่อให้จำง่าย และเปิดหรือปิดเต้ารับที่ควบคุมได้

ลำดับ 05

⚠ การแจ้งเตือนอัจฉริยะ

การแจ้งเตือนที่ปรับแต่งได้สำหรับไฟดับ แบตเตอรี่ต่ำ อุปกรณ์ออฟไลน์ และเหตุการณ์ไฟกลับมา ตั้งค่าเกณฑ์เองและเลือกเสียงและการสั่นได้ตามต้องการ

ลำดับ 06

╿ ประวัติเหตุการณ์

บันทึกเหตุการณ์ของ UPS ครบถ้วน ทั้งการเปลี่ยนแปลงการเชื่อมต่อ การโพลล์สถานะ เหตุการณ์ด้านพลังงาน และสัญญาณเตือน ติดตามว่าเกิดอะไรขึ้นเมื่อใด พร้อมรายการที่มีเวลากำกับของทุกอุปกรณ์

ลำดับ 07

☼ ปรับแต่งได้เต็มที่

ธีมมืด สว่าง และตามระบบ เซลเซียสหรือฟาเรนไฮต์ ขนาดการแสดงผลที่ปรับได้ แถบนำทางด้านล่างที่ปรับแต่งได้ และช่วงเวลาโพลล์ที่ตั้งค่าได้ ทำให้เป็นสไตล์คุณ

ลำดับ 08

✦ ส่งออก & นำเข้า

ส่งออกการตั้งค่าอุปกรณ์เพื่อสำรองข้อมูลหรือย้ายเครื่อง นำเข้าการตั้งค่าบนอุปกรณ์เครื่องใหม่เพื่อเริ่มใช้งานได้ทันที โดยไม่ต้องป้อนรายละเอียดการเชื่อมต่อซ้ำ

วิธีการทำงาน

SNMP / NUT โดยตรง ไม่ใช้คลาวด์

1

เพิ่ม UPS ของคุณ

ป้อนที่อยู่ IP แล้วเลือก SNMP (v1/v2c/v3) หรือ NUT ไม่ต้องมีบัญชี ไม่ต้องสมัคร

2

โพลล์ผ่านเครือข่ายของคุณ

UPSight คุยกับ UPS ของคุณโดยตรงในเครือข่ายภายใน ไม่มีสิ่งใดผ่านเซิร์ฟเวอร์ภายนอก

3

ตรวจสอบ & รับการแจ้งเตือน

แบตเตอรี่ โหลด เวลาสำรองไฟ เต้ารับ และเหตุการณ์ พร้อมการแจ้งเตือนอัจฉริยะเมื่อไฟตกหรือแบตเตอรี่ใกล้หมด

สิ่งที่คุณต้องมี

UPS ในเครือข่ายของคุณ

UPSight คุยกับ UPS ของคุณผ่านเครือข่าย ทางการ์ดเครือข่ายหรือผ่านเซิร์ฟเวอร์ NUT

◉

UPS ที่มีการ์ดเครือข่าย

APC Network Management Card, CyberPower RMCARD, Eaton Network-M2 และ Network-M3, Tripp Lite WEBCARDLX, Vertiv Liebert IntelliSlot และการ์ดเครือข่าย UPS อื่นใดที่รองรับ SNMP เปิด SNMP ในหน้าเว็บของการ์ด แล้วเพิ่มที่อยู่ IP ของการ์ดใน UPSight

▣

หรือ UPS ที่แชร์ผ่าน NUT

หาก UPS ของคุณเสียบอยู่กับเซิร์ฟเวอร์ NAS หรือ Raspberry Pi ผ่าน USB และเครื่องนั้นรันเซิร์ฟเวอร์ Network UPS Tools (NUT) ให้เพิ่มเซิร์ฟเวอร์ NUT ใน UPSight เพื่อตรวจสอบ UPS จากที่ใดก็ได้ในเครือข่ายของคุณ

◎

ไม่ใช่การตั้งค่าแบบ USB อย่างเดียว

UPS ที่เสียบกับคอมพิวเตอร์เครื่องเดียวด้วย USB โดยไม่มีการ์ดเครือข่ายและไม่มีเซิร์ฟเวอร์ NUT จะเข้าถึงผ่านเครือข่ายไม่ได้ UPSight จึงมองไม่เห็น

ความปลอดภัย & ความเป็นส่วนตัว

ข้อมูลพลังงานของคุณ การควบคุมของคุณ

สถาปัตยกรรมที่ให้ความสำคัญกับความเป็นส่วนตัว ไม่มีบัญชี ไม่ใช้คลาวด์ ไม่ติดตาม

◉

ไม่มีรีเลย์คลาวด์

การสื่อสารทั้งหมดเกิดขึ้นโดยตรงระหว่างอุปกรณ์ของคุณกับ UPS ผ่านเครือข่ายภายใน ไม่มีสิ่งใดผ่านเซิร์ฟเวอร์ภายนอก

▣

ข้อมูลรับรองในเครื่องเท่านั้น

SNMP community string ถูกเก็บอย่างปลอดภัยบนอุปกรณ์ของคุณ ไม่เคยถูกส่งไปยัง MiyaraHub Technologies หรือบุคคลที่สามใด

◎

การวิเคราะห์ขั้นต่ำ

ใช้ Firebase Crashlytics เฉพาะรายงานบั๊ก ไม่มีข้อมูลส่วนบุคคล ไม่ติดตามการใช้งาน ไม่มีโฆษณา

◆

ซื้อครั้งเดียว เป็นเจ้าของ

ซื้อครั้งเดียว ไม่มีค่าสมาชิก ไม่มีการซื้อในแอป รวมการอัปเดตในอนาคตทั้งหมด

คำถามที่พบบ่อย

UPS ของฉันต้องเชื่อมต่ออินเทอร์เน็ตไหม +
ไม่ต้อง UPSight สื่อสารผ่านเครือข่ายภายในของคุณเท่านั้น UPS ของคุณเพียงแค่อยู่ในเครือข่ายเดียวกับโทรศัพท์ (หรือเข้าถึงได้ผ่าน VPN/Tailscale) ไม่ต้องใช้อินเทอร์เน็ตสำหรับตัว UPS เอง
ตรวจสอบ UPS หลายเครื่องได้ไหม +
ได้ UPSight รองรับ UPS ได้ไม่จำกัดจำนวน แดชบอร์ดแสดงทุกเครื่องของคุณด้วยการ์ดสถานะที่ดูได้ในพริบตา แตะอุปกรณ์ใดก็ได้เพื่อดูรายละเอียดเต็มใน 6 แท็บ ได้แก่ ภาพรวม พลังงาน แบตเตอรี่ เต้ารับ เหตุการณ์ และข้อมูล
ควบคุมเต้ารับของ UPS จากแอปได้ไหม +
ได้ สำหรับ UPS รุ่นที่รองรับการควบคุมเต้ารับผ่าน SNMP (เช่น CyberPower ซีรีส์ PR ที่มีเต้ารับควบคุมได้) คุณเปิด/ปิดแต่ละเต้ารับและตั้งชื่อใหม่เพื่อให้จำง่ายได้ เต้ารับแบบอ่านอย่างเดียวจะแสดงสถานะแต่ไม่มีปุ่มเปิดปิด
UPSight ราคาเท่าไร +
UPSight เป็นการซื้อครั้งเดียวในราคา $4.99 ไม่มีค่าสมาชิก ไม่มีการซื้อในแอป ไม่มีโฆษณา ซื้อครั้งเดียวใช้ได้ตลอดไป รวมการอัปเดตในอนาคตทั้งหมด
รองรับ SNMP เวอร์ชันใดบ้าง +
UPSight รองรับ SNMP v1, v2c และ v3 เลือกเวอร์ชันของแต่ละอุปกรณ์ได้ระหว่างการตั้งค่า UPS สำหรับผู้บริโภคและมือโปรส่วนใหญ่ใช้ v2c กับ community string "public" ส่วน v3 ใช้ได้สำหรับสภาพแวดล้อมองค์กรที่ต้องการการยืนยันตัวตนและการเข้ารหัส
ใช้ UPSight จากระยะไกล (นอกเครือข่ายที่บ้าน) ได้ไหม +
ได้ หาก UPS ของคุณเข้าถึงได้ผ่าน VPN, Tailscale, WireGuard หรือสิ่งที่คล้ายกัน UPSight เชื่อมต่อกับที่อยู่ IP ใดก็ตามที่คุณตั้งค่าไว้ เราแนะนำให้ใช้ VPN แทนการเปิดพอร์ต SNMP สู่อินเทอร์เน็ตโดยตรง
UPSight ใช้กับการ์ดเครือข่าย UPS ของฉันได้ไหม +
ได้ หากการ์ดรองรับ SNMP ซึ่งครอบคลุม APC Network Management Card, CyberPower RMCARD, Eaton Network-M2 และ Network-M3, Tripp Lite WEBCARDLX และการ์ด Vertiv Liebert IntelliSlot เปิด SNMP ใน 'เว็บอินเทอร์เฟซ' ของการ์ด แล้วเพิ่มที่อยู่ IP ของการ์ดใน UPSight
UPS ของฉันมีแค่พอร์ต USB ใช้ UPSight ได้ไหม +
ได้ ผ่าน NUT เสียบ UPS เข้ากับเซิร์ฟเวอร์ NAS หรือ Raspberry Pi ที่รันเซิร์ฟเวอร์ Network UPS Tools (NUT) แล้วเพิ่มเซิร์ฟเวอร์นั้นใน UPSight UPS ที่เชื่อมต่อด้วย USB กับคอมพิวเตอร์เครื่องเดียวโดยไม่มี NUT จะเข้าถึงผ่านเครือข่ายไม่ได้
ยี่ห้อ UPS ของฉันไม่อยู่ในรายการ จะใช้ได้ไหม +
น่าจะได้ หาก UPS ของคุณรองรับ SNMP และใช้มาตรฐาน RFC 1628 UPS-MIB ไดรเวอร์ทั่วไปของ UPSight จะทำงานได้ UPS ที่เชื่อมต่อเครือข่ายได้ส่วนใหญ่เป็นไปตามมาตรฐานนี้ หากพบปัญหา ติดต่อเรามา แล้วเราจะพิจารณาเพิ่มไดรเวอร์เฉพาะสำหรับยี่ห้อของคุณ
