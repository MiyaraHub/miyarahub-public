В облікових записах субадміністраторів деякі кінцеві точки можуть повертати 401 - це обмеження прав доступу на контролері, а не обмеження застосунку.

Як це працює

Напряму до вашого контролера. Без хмарного посередника.

Network Deck спілкується з вашим контролером UniFi безпосередньо через локальну мережу (або VPN). Ваші облікові дані та мережеві дані ніколи не потрапляють на сервер MiyaraHub.

1

Додайте свій контролер

Введіть ім'я хоста або IP контролера, порт (за замовчуванням 443 для UniFi OS, 8443 для окремого контролера) і локальні облікові дані адміністратора. Network Deck сам визначить, чи це UniFi OS, чи окремий контролер.

2

Увійдіть локально

Увійдіть за допомогою локального імені користувача й пароля адміністратора. Двофакторна автентифікація підтримується повністю. Віддаєте перевагу ключам API? Використовуйте X-API-KEY для програмного доступу й повністю оминіть потік із cookie.

3

Керуйте одним поглядом

Стежте за живим графіком пропускної здатності, відключіть проблемного клієнта, перемкніть правило брандмауера, перезавантажте порт PoE, запросіть гостя через Teleport чи перейдіть на інший сайт - кожна дія надсилається на контролер і оновлює потік подій наживо.

Увесь обмін відбувається безпосередньо між вашим телефоном і контролером через локальну мережу або VPN.

Якщо ваш контролер наразі доступний лише через хмарний вхід ui.com, для роботи з Network Deck увімкніть локальний обліковий запис адміністратора в Settings → Admins. Контролер ніколи не звертається до нас, а ми ніколи не звертаємося до хмари Ubiquiti від вашого імені.

Так. Якщо ваш контролер керує кількома сайтами, угорі Network Deck показує перемикач сайтів. Кожна функція - дашборд, клієнти, брандмауер, VPN - працює в межах поточного вибраного сайту. Перемикання одним дотиком.
