FAQ

Поширені запитання.

Чи має мій UPS бути підключений до інтернету? +
Ні. UPSight працює лише через вашу локальну мережу. Вашому UPS достатньо бути в тій самій мережі (або доступним через VPN/Tailscale), що й телефон. Самому UPS доступ до інтернету не потрібен.
Чи можу я стежити за кількома пристроями UPS? +
Так! UPSight підтримує необмежену кількість пристроїв UPS. Дашборд показує всі ваші пристрої на картках стану, які видно одним поглядом. Торкніться будь-якого пристрою, щоб побачити всі подробиці на шести вкладках: Overview, Power, Battery, Outlets, Events та Info.
Чи можу я керувати розетками UPS із застосунку? +
Так, для моделей UPS, що підтримують керування розетками через SNMP (наприклад, серія CyberPower PR з керованими розетками). Ви можете вмикати й вимикати окремі розетки та перейменовувати їх для зручного розпізнавання. Розетки лише для читання показуватимуть стан, але не матимуть перемикачів.
Скільки коштує UPSight? +
UPSight - це одноразова покупка за $4.99. Без підписок, без внутрішніх покупок, без реклами. Купіть раз - користуйтеся завжди. Усі майбутні оновлення включено.
Які версії SNMP підтримуються? +
UPSight підтримує SNMP v1, v2c і v3. Версію можна вибрати для кожного пристрою під час налаштування. Більшість побутових і напівпрофесійних пристроїв UPS використовують v2c з рядком спільноти «public». v3 доступна для корпоративних середовищ, що вимагають автентифікації та шифрування.
Чи можу я користуватися UPSight віддалено (поза домашньою мережею)? +
Так, якщо ваш UPS доступний через VPN, Tailscale, WireGuard чи подібне. UPSight підключається до будь-якої IP-адреси, яку ви вкажете. Ми радимо доступ через VPN, а не відкривати порти SNMP напряму в інтернет.
Чи працює UPSight з мережевою картою мого UPS? +
Так, якщо карта працює з SNMP. Це APC Network Management Card, CyberPower RMCARD, Eaton Network-M2 і Network-M3, Tripp Lite WEBCARDLX та карти Vertiv Liebert IntelliSlot. Щоб під'єднати карту, увімкніть SNMP в її вебінтерфейсі, а потім додайте її IP-адресу в UPSight, і пристрій з'явиться в списку.
Мій UPS має лише порт USB. Чи можу я використовувати UPSight? +
Так, через NUT. Підключіть UPS до сервера, NAS або Raspberry Pi, на якому працює сервер Network UPS Tools (NUT), і додайте цей сервер в UPSight. UPS, підключений лише через USB до одного комп'ютера, без NUT, недоступний через мережу.
Марки мого UPS немає в списку. Чи працюватиме він? +
Скоріш за все! Якщо ваш UPS підтримує SNMP і реалізує стандартну UPS-MIB RFC 1628, загальний драйвер UPSight працюватиме. Більшість мережевих пристроїв UPS відповідають цьому стандарту. Якщо виникнуть проблеми, напишіть нам, і ми розглянемо можливість додати окремий драйвер для вашої марки.
