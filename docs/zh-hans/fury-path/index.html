功能

整个 HDFury 网页界面，握在你手中。

应用会自动检测你的设备，并启用适合你型号的功能集。

No. 01

◉ 实时信号信息

输入信号、视频/音频输出、接收端 EDID 详情、eARC 状态和工作模式的实时概览，集中在一个可滚动视图中，实时更新。

No. 02

▣ EDID 管理

选择 EDID 模式，配置 Automix 设置，并微调视频能力，包括 FRL 速率、VRR、ALLM 和 HDR 注入。对每个 EDID 参数进行深度控制。

No. 03

◎ HDR / Dolby Vision

按格式（HDR10、HLG、LLDV）注入或剥离自定义 HDR 元数据。启用 DV 标志注入，选择 DV 模式配置文件，并开关低延迟 Dolby Vision 直通。

No. 04

▢ CEC / eARC / 音频

配置 HDMI-CEC 通信，设置 eARC/ARC 模式，调整 RS232 波特率，并单独静音各个音频输出。完整的音频编码直通控制，包括 TrueHD、DTS-HDMA、DD+。

No. 05

◆ JVC 宏系统 部分型号

配置由 HDR 元数据变化触发的 JVC 投影机自动命令。设置宏启用、事件同步和可调延迟时间。适用于 VRRooM、VERTEX2、DIVA 和 Maestro。

No. 06

⚙ 完整的设备配置

设置输入自动切换、HDCP 模式、按输入设置的 HTPC 低延迟模式、模拟音频音量/低音/高音、红外遥控设置、TX +5V 强制，以及网络/TCP 配置。

No. 07

☼ OSD / OLED 显示屏

控制设备内置的 OLED 显示屏：启用/停用、选择信息页面、设置自动淡出超时，并调整旋转和颜色反转等高级选项。

No. 08

✦ 自定义导航 & 多设备

为每台设备选择底部栏中放置哪些标签页：首页加最多 6 个其他标签页，至少 2 个。在一款应用中管理多台 HDFury 设备，每台都有各自的设置、导航和连接状态。

No. 09

常见问题

常见问题。

FuryPath 如何与我的 HDFury 设备通信？+
FuryPath 通过你的本地 Wi-Fi 网络，直接向 HDFury 设备发送 HTTP GET 请求，使用的协议与 HDFury 内置网页界面相同。命令发送到 GET /cmd?key=value，状态轮询则读取 GET /ssi/*.ssi 端点。不涉及任何外部服务器。你的设备必须与手机处于同一 Wi-Fi 网络。
支持哪些操作系统版本？+
FuryPath 支持 iPhone、iPad、Android、Mac 和 Windows。iOS 需要 iOS 16.0 或更高版本。macOS 需要 macOS 11.0 或更高版本。Android 需要 Android 7.0（API 24）或更高版本。
可以在家以外远程控制 HDFury 设备吗？+
FuryPath 会连接到你配置的任何 IP 地址。如果你的 HDFury 设备可以通过 VPN 或 Tailscale 访问，应用就能远程使用。我们建议使用 VPN 或 Tailscale，而不是将设备直接暴露在互联网上。
支持所有 HDFury 型号吗？+
FuryPath 支持 VRRooM、VERTEX2、VERTEX、DIVA、Maestro、ARCANA2、Arcana 和 Dr.HDMI 8K。应用会在连接时自动检测你的设备，并启用与你的型号相关的功能集。并非所有型号都支持所有功能。例如，JVC 宏仅适用于 VRRooM、VERTEX2、DIVA 和 Maestro。
需要蓝牙加密狗或额外硬件吗？+
不需要。FuryPath 通过家庭网络，使用设备内置的网页界面与 HDFury 设备通信，因此无需购买蓝牙加密狗（例如 GO2）或其他硬件。你的 HDFury 设备只需与手机、平板或电脑连接到同一网络即可。
FuryPath 是 HDFury 的官方应用吗？+
不是。FuryPath 是 MiyaraHub Technologies LLC 开发的独立应用，用于控制 HDFury 设备，并非由 HDFury 制作、认可或提供支持。如需了解 HDFury 的产品、固件和官方支持，请访问 hdfury.com。
FuryPath 多少钱？+
FuryPath 是一次性购买，价格 $9.99。无订阅，无广告，无应用内购买。买一次，永久拥有。
可以管理多台 HDFury 设备吗？+
可以。FuryPath 支持多台设备，每台都有各自的设置、导航标签页和连接状态。在主面板上点按一下，即可在设备之间切换。
可以自定义导航和首页吗？+
每台设备都有一个首页，外加按型号显示的功能标签页（INFO、EDID、HDR/AVI、DV、CEC/eARC、MACROS、OSD、OLED、CONFIG）。你可以为每台设备选择哪些标签页显示在底部导航栏中（首页加最多 6 个其他标签页，至少 2 个），也可以拖动来重新排序和移除首页上的卡片。每台设备都独立记住自己的布局。
