工作室

小工作室，用心做事。

MiyaraHub Technologies 是位于德克萨斯州 Van Alstyne 的一家小型独立 LLC，由 Meir Miyara 拥有并经营。

我们不是工厂，也不假装是。我们是一个在意细节的小团队，做的是你自己也想装在设备上、用来控制自己器材的那种软件。

我们公开地构建，倾听使用者的声音，并快速修复问题。每个版本里的很多内容，都始于社区里某个人发来的一条消息，我们也希望一直如此。

我们不会夸大其词。我们的一些应用已经打磨完善，正交付给成千上万的人；还有几款仍在酝酿中，哪些是哪些，我们会如实告诉你。我们承诺的是诚实的努力、原生软件、默认在设备上运行，以及对运行在你已拥有的硬件上的东西不收订阅费。
