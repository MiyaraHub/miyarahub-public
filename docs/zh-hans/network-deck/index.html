工作方式

直连你的控制器，不经过云端中转。

Network Deck 通过本地网络（或你的 VPN）直接与 UniFi 控制器通信。你的凭据和网络数据绝不会经过 MiyaraHub 的服务器。

1

添加你的控制器

输入控制器的主机名或 IP、端口（UniFi OS 默认 443，独立版默认 8443）以及本地管理员凭据。Network Deck 会自动判断你使用的是 UniFi OS 还是独立控制器。

2

本地认证

使用本地管理员用户名和密码登录，全程支持双重身份验证。更喜欢 API 密钥？使用 X-API-KEY 进行程序化访问，完全跳过 Cookie 流程。

3

一览全局，轻松管理

查看实时带宽图表，踢出捣乱的客户端，切换防火墙规则，重启 PoE 端口，邀请 Teleport 访客，或切换到另一个站点。每个操作都会与控制器往返同步，并更新实时事件流。

安全 & 隐私

仅限本地。无需账号。没有云端中转。

Network Deck 采用隐私优先、纯本地的架构设计。无需 MiyaraHub 账号，无云端中转，除崩溃报告外不收集任何数据。

◉

没有云端中转

所有指令和实时数据流都在你的手机与控制器之间通过本地 Wi-Fi 或 VPN 直接传输，不经过任何外部服务器。

▣

标准 UniFi 认证

使用与 UniFi Network 网页界面相同的本地管理员凭据（或 API 密钥）。凭据存储在设备上的 iOS 钥匙串 / Android Keystore 中，除发送给你的控制器外，绝不会传出设备。

◎

无需 MiyaraHub 账号

无需注册，无需邮箱，也不需要 MiyaraHub 账号。安装后指向你的控制器，即可开始使用。

◈

极简统计

仅使用 Firebase Crashlytics 收集错误报告。不追踪使用情况，没有广告，也不出售数据。网络错误会以非致命错误记录，帮助我们改进固件兼容性，而不会收集你的网络布局。

◆

尊重权限

应用只在你的 UniFi 管理员账号权限范围内运行。子管理员只能看到控制器允许其查看的内容。无权限提升，无后门。

◐

仅需网络权限

Network Deck 唯一需要的设备权限是网络访问，仅用于连接你本地网络（或通过 VPN）中的 UniFi 控制器。

关于 Network Deck，你需要知道的一切。

Network Deck 与 Ubiquiti 或 UniFi 有关联吗？+
没有。Network Deck 是由 MiyaraHub Technologies LLC 开发的独立第三方应用，并非由 Ubiquiti Inc. 创建，也未获其认可或赞助，与其没有任何关联。“Ubiquiti”“UniFi”“UniFi OS”“UniFi Network”“UDM”“UDR”“UCG”“Teleport”以及所有相关产品名称均为 Ubiquiti Inc. 的商标。我们使用这些名称纯粹是为了说明兼容性（指示性合理使用）。
支持哪些 UniFi 控制器？+
Network Deck 既支持 UniFi OS 主机（UDM Pro / Pro SE、UCG、Dream Machine、UDR、Cloud Key Gen2 / Plus），也支持运行在 Linux、Docker 或 Windows 上的 v10.x 独立 UniFi Network 控制器。连接时应用会自动识别你的平台，并根据固件实际开放的接口调整界面，没有的功能就不会显示。已在 UDM Pro SE（UniFi OS 5.0.16）和独立版 Network 10.2.105 上完成实机测试。
Network Deck 如何与我的控制器通信？+
Network Deck 使用与 UniFi Network 网页界面相同的本地 API，包括经典的 /rest 和 /cmd 接口（基于 Cookie 的会话认证），以及较新的 v2 集成 API。它还会与你的控制器建立 WebSocket 连接，以接收实时事件流。所有通信都在你的手机与控制器之间通过本地网络或 VPN 直接完成。
我需要 UniFi 云账号吗？+
不需要。Network Deck 只使用本地认证。使用你的 UniFi 本地管理员用户名和密码（或 API 密钥）登录即可。如果你的控制器目前只能通过 ui.com 云登录访问，则需要在“设置 → 管理员”中启用一个本地管理员账号才能使用 Network Deck。控制器不会与我们通信，我们也不会代你访问 Ubiquiti 的云服务。
我可以管理防火墙规则和端口转发吗？+
可以。Network Deck 提供完整的防火墙功能：策略（允许 / 阻止 / 检测）、可增删改查的端口转发、流量规则与路由、防火墙分组、防火墙区域（v2 策略矩阵），以及 DPI 应用 / 分组。所有操作都可直接在列表中切换，无需反复弹窗点击。
支持多站点吗？+
支持。如果你的控制器管理多个站点，Network Deck 会在顶部显示站点切换器。仪表盘、客户端、防火墙、VPN 等所有功能都作用于当前选中的站点，轻点一下即可切换。
Network Deck 的售价是多少？+
Network Deck 将在 App Store、Google Play 和 Microsoft Store 以 $4.99 的价格一次性买断。无订阅、无广告、无内购。价格可能在正式发布前调整。
可以远程使用吗（在家或办公室之外）？+
Network Deck 会连接你配置的任意主机名或 IP。只要你的控制器能通过 VPN、Tailscale、WireGuard 或端口转发访问，应用就能远程使用。我们建议使用 VPN 或 Tailscale，而不是把 UniFi 控制器直接暴露在互联网上。
支持哪些平台？+
Network Deck 可运行于 iOS（13 及以上）和 Android（5.0 / API 21 及以上），手机和平板布局均支持。应用将在 App Store、Google Play 和 Microsoft Store 同步上线。
