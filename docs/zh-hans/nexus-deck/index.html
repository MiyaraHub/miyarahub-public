MiyaraHub / NexusDeck

NexusDeck · 专为 Audyssey 校准文件打造每一份校准，一个应用搞定。✦

适用于配备 Audyssey MultEQ XT 或 XT32 的 Denon 和 Marantz AV 接收机的校准文件库。

在一个文件库中保存 .ady 与 .oca 校准文件、Dirac Live 项目以及 MultEQ-X 的 .mqx 文件。比较曲线，在 .ady 与 .oca 上设置增益削减，将一个 .ady 或 .oca 文件发送到 Denon 或 Marantz 接收机的扬声器预设，并将您自己录制的 Dirac Live 捕获发送到 Dirac 插槽。NexusDeck 不测量您的房间，也不创建曲线。

功能

保存、比较、发送。

NexusDeck 保存您已在使用的工具生成的文件：Audyssey MultEQ Editor、A1 Evo 和 AcoustiX。它不测量您的房间，也不创建曲线。

No. 01

◉ 所有曲线文件集中在一个资料库

导入来自 Audyssey MultEQ Editor 的 .ady 文件，以及来自 A1 Evo 和 AcoustiX 的 .oca 文件。添加文件夹、标签、评级和备注，并按文件名、工具、接收机型号、备注或标签搜索。可从曲线文件页面分享该文件。

.ady.oca文件夹标签
No. 02

▣ 测量

打开 .frd、REW 文本、Dirac Live 的 .liveproject 和 MultEQ-X 的 .mqx 文件，查看并比较它们的曲线。REW .mdat 不会被读取。

.frdREW .txt.liveproject.mqx
No. 03

◎ 查看与比较

在同一图表上查看每个声道，并附脉冲响应和群延迟。可导出图像或 CSV。使用 Pro，可通过差值表比较曲线。

所有声道CSVPro 比较
No. 04

▢ 增益编辑

在声道上设置 0 至 -12 dB 的增益削减，并可先查看结果。编辑后的 .ady 或 .oca 只能发送到扬声器预设 1，作为计算得出而非测量得到的滤波器。已存储的文件绝不会被更改。

0 至 -12 dB预设 1保留原文件
No. 05

◆ 发送到您的接收机

NexusDeck 会在网络中找到您的接收机。在写入任何内容之前，它会将文件与接收机核对：型号、MultEQ 版本和声道。发现不匹配时会阻止并说明原因。替换预设之前 NexusDeck 会先询问，然后发送到您选择的扬声器预设。

扬声器预设先检查先询问
No. 06

⚙ Dirac Live 槽位

读取 Dirac Live 插槽并在它们之间切换。将您自己录制的 Dirac Live 发送重放到一个插槽，NexusDeck 会选中该插槽并读回；结果会显示：已保留、未保留或未知。该扬声器预设随后使用 Dirac Live 而不是 Audyssey。NexusDeck 不构建、编辑或转换任何 Dirac 滤波器。

读取切换重放
No. 07

◈ 预设和扬声器

查看哪个扬声器预设处于启用状态，以及每只扬声器的距离和微调。切换预设，比较最近发送到两个预设的曲线，并保留备份：每次发送 .ady 或 .oca 都会先保存预设。电平、距离和分频目前在 AVR Maestro 中设置（即将推出）。

当前预设距离微调
No. 08

▣ 预设备份

每次发送 .ady 或 .oca 之前，NexusDeck 都会在您的设备上保留目标扬声器预设的设置，让您看到发送替换了什么。Back up now 会在不发送任何内容的情况下保留当前预设的设置。两者都免费。

每次发送 .ady 或 .oca 之前Back up now免费
No. 09

◆ Pro 工具

将整个资料库（含文件夹、标签、备注、编辑和测量）备份到 .ndbackup 文件，并在另一台设备上恢复。Batch Map 一次将一条曲线发送到每个扬声器预设，Quick / Smart Select 则可保存任意数量的接收机设置。

.ndbackupBatch MapQuick / Smart Select

工作方式

从曲线文件到接收机，只需三步。

带入曲线文件，查看它，发送它。可先在应用内的演示接收机上试用整个流程。

1

导入文件

导入来自 Audyssey MultEQ Editor 的 .ady，或来自 A1 Evo 或 AcoustiX 的 .oca。它连同声道、目标曲线和备注一起加入您的资料库。

2

查看、比较、编辑

打开曲线，在同一图表上查看每个声道。使用 Pro 可将其与另一条曲线比较，或设置增益削减。已存储的文件绝不会被更改。

3

发送到扬声器预设

找到您的接收机，选择扬声器预设并发送。没有 Pro 时，发送会进入扬声器预设 1。

安全 & 隐私

仅限本地。无需账号。没有云端。

您的校准文件保留在您的设备上，您的接收机保留在本地网络中。除非您发送给我们，否则关于您设置的任何信息都不会到达 MiyaraHub。

◉

没有账号

无需注册，也没有 MiyaraHub 登录。MiyaraHub 不运行应用所连接的任何服务器。

▣

文件保留在您的设备上

您的资料库、编辑和设置保存在您的设备上。不会同步到 MiyaraHub。

◎

仅限您的家庭网络

NexusDeck 在本地网络中直接与您的接收机通信。校准文件绝不会经过 MiyaraHub 服务器。

◆

仅在您允许时才发送崩溃报告

在 Android 和 iOS 上，只有在您于首次运行提示中允许后，崩溃报告才会发送到 Firebase Crashlytics。可在设置 > 关于中关闭。Mac 和 Windows 应用不发送任何报告。

●

无分析，无广告

没有分析库，没有广告，也没有广告标识符。

◈

仅在您发送时才提供日志

设置 > 关于 会将应用日志打包为一个 zip 文件供支持使用，仅在您选择发送时才会分享。

常见问题

常见问题。

关于 NexusDeck，你需要知道的一切。

NexusDeck 与 Audyssey、Dirac、Denon 或 Marantz 有关联吗？ +
没有。NexusDeck 是 MiyaraHub Technologies LLC 开发的独立应用，与 Denon、Marantz、Audyssey 或 Dirac 无关联，也未获得它们的认可。所有商标均归其各自所有者所有。
哪些接收机可用？ +
适用于 .ady 和 .oca 文件：支持联网的 Denon 和 Marantz 型号，配备 Audyssey MultEQ XT 或 XT32，并开启网络待机。发送之前，NexusDeck 会将文件与接收机核对，发现不匹配时会阻止并说明原因。
NexusDeck 能读取哪些文件？ +
可发送的曲线：来自 Audyssey MultEQ Editor 的 .ady，以及来自 A1 Evo 和 AcoustiX 的 .oca。可查看与比较的测量：.frd、REW 文本、Dirac Live 的 .liveproject 和 MultEQ-X 的 .mqx。测量和 .mqx 文件不含滤波器，因此要发送的文件是 .ady 或 .oca。REW .mdat 不会被读取。
NexusDeck 会取代 MultEQ Editor 或 A1 Evo 吗？ +
不会。NexusDeck 不测量您的房间，也不创建曲线。它保存、比较并发送这些工具生成的文件。其增益编辑只会削减已存储文件中原有的滤波器，结果保存在该文件旁边。
它支持 Dirac Live 吗？ +
是的，用于读取并切换 Dirac Live 插槽，以及重放您自己录制的 Dirac Live 发送，而不是制作滤波器。NexusDeck 将发送重放到一个插槽，选中该插槽并读回；结果会显示：已保留、未保留或未知。该扬声器预设随后使用 Dirac Live 而不是 Audyssey。
NexusDeck 会在发送前检查文件吗？+
会。在写入任何内容之前，它会将文件与接收机核对：型号、MultEQ 版本和声道。发现不匹配时会阻止并说明原因，不会写入任何内容。
NexusDeck 的价格是多少？+
NexusDeck 可免费下载。没有 Pro 时，可配对一台接收机加演示，保留三个导入的曲线文件加示例，并发送到扬声器预设 1，共 15 次发送，包括 Dirac Live 发送。Pro 是一次应用内购买，美国售价 $19.99，可无限发送到任何预设，无限接收机和曲线文件，多曲线比较，顶部栏的扬声器预设切换，Quick / Smart Select，Batch Map 和资料库备份文件。预设备份在每次发送 .ady 或 .oca 之前或通过 Back up now 创建，免费。
有用户指南吗？ +
有。NexusDeck 用户指南位于 nexusdeck.app。
