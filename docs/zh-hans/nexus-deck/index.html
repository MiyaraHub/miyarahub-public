功能

所有校准文件格式，一个应用搞定。

NexusDeck 能读取你现有工具生成的校准文件，让你在手机上浏览曲线库，并直接上传到接收机。上传这一步不再需要笔记本电脑，也不需要 MultEQ Editor。

No. 01

◉ 导入所有常见格式

原生解析 Audyssey .ady、A1 Evo Acoustix .oca、REW .mdat（MEQX 导出）、.frd 响应曲线和 REW PEQ .txt 导出文件。导入过一次的文件会永久缓存在你的本地曲线库中。

.ady.oca.mdat.frdPEQ .txt
No. 02

▣ 本地曲线库

你导入过的所有内容都保存在设备上。可重命名测量、将多位置 .mdat 同组文件归为一组，并对共享文件数据进行引用计数，只有在没有条目引用时才会在删除后释放磁盘空间。本地 SQLite 存储，应用重启和更新后依然保留。

SQLite引用计数重命名
No. 03

◎ 并排对比曲线

可叠加显示 Audyssey、A1 Evo Acoustix 和 REW 导入文件中任意组合的频率响应曲线。X 轴为对数频率，Y 轴为 dB 幅度，支持多位置平均和平滑控制。清楚看到每次校准之间究竟改变了什么。

叠加对数频率平滑
No. 04

▢ 将 Audyssey 直接上传到接收机

通过 Wi-Fi 将 Audyssey .ady 文件直接发送到 Denon / Marantz 接收机的扬声器预设槽位 1 或槽位 2。机身会校验上传内容，NexusDeck 会反馈是否写入成功。无需数据线，无需笔记本电脑，上传这一步也不需要 MultEQ Editor。

Audyssey端口 1256SPP1 / SPP2字节校验
No. 05

◆ 槽位备份&恢复

每次上传前，NexusDeck 都会读回机身中的当前内容，并作为备份条目保存到你的曲线库。一键恢复即可让任意槽位回到之前的校准。再也不用担心上传出错而丢失可用的配置。

上传前备份一键恢复
No. 06

⚙ 引导式演示

逐个声道查看已导入测量的内容：单声道响应、目标曲线、已应用的滤波器组，以及最终的校正后响应。专为想要弄懂这些数字含义的校准发烧友打造。

单声道目标曲线滤波器组
No. 07

◈ 与 AVR Maestro 配合使用

如果你已安装 AVR Maestro，NexusDeck 会通过平台的共享容器自动读取它的已配对接收机列表，无需重新配对，无需再次输入 IP，也不用重复设置设备。两款应用合为一体，组成完整的生态。

工作方式

从测量文件到接收机，只需三步。

NexusDeck 正好解决现有工具留下的难题：校准文件在你的笔记本电脑上，却没有简单的办法把它送到接收机，除非重新运行桌面应用。NexusDeck 填补了这一空白。

1

导入文件

打开 MultEQ Editor 的 Audyssey .ady、A1 Evo Acoustix 的 .oca、REW 的 .mdat 或任何其他受支持的文件。NexusDeck 会解析文件、提取响应曲线，并添加到你的曲线库。

2

浏览与对比

打开任意曲线库条目，查看逐声道的频率响应。叠加两条或更多曲线，看看房间校正改变了什么。随着曲线库不断壮大，你可以重命名、分组或删除条目。

3

将 Audyssey 上传到接收机

对于 Audyssey .ady 文件：选择扬声器预设槽位（1 或 2），确认后，NexusDeck 会通过 Wi-Fi 将校准数据传输到你的 Denon 或 Marantz 接收机。机身会校验上传内容，NexusDeck 会反馈是否写入成功。导入的 .oca / .mdat / .frd / .txt 文件会保留在曲线库中用于浏览和对比；这些格式的机身上传将在日后版本中提供。

安全 & 隐私

仅限本地。无需账号。没有云端。

NexusDeck 与 AVR Maestro 采用同样的隐私优先架构。你的校准文件留在设备上，接收机留在本地网络中，关于你的设置，没有任何内容会发送给 MiyaraHub。

◉

没有云端中转

校准上传通过本地 Wi-Fi（TCP 端口 1256）在你的手机与接收机之间直接完成，文件绝不会经过 MiyaraHub 的服务器。

▣

无需账号

无需注册，无需邮箱，无需 MiyaraHub 登录。打开应用，放入你的第一份校准文件，就能进入曲线库。

◎

最少的诊断数据

仅使用 Firebase Crashlytics 收集崩溃报告和诊断数据，以便我们修复你遇到的错误。不追踪使用情况，没有广告，没有个性化推荐。可在设置中关闭。

◆

曲线库保存在本地

你的校准曲线库是一个本地 SQLite 数据库，加上设备上的文件存储。不会向 MiyaraHub 服务器同步或上传任何内容。

●

仅限用户主动上传

只有当你明确点按“上传”并确认槽位后，曲线才会发送到接收机。不会自动执行任何操作，并且会读回机身内容，核实实际写入的数据。

◈

仅需网络权限

NexusDeck 唯一需要的系统权限是网络访问，仅用于通过本地 Wi-Fi 连接你的接收机。

常见问题。

关于 NexusDeck，你需要知道的一切。

NexusDeck 与 Audyssey、Denon 或 Marantz 有关联吗？+
没有。NexusDeck 是由 MiyaraHub Technologies LLC 开发的独立第三方应用，并非由 Audyssey Laboratories、Denon、Marantz、Sound United、Masimo Corporation 或其任何子公司创建，也未获其认可或赞助，与其没有任何关联。“Audyssey”“MultEQ”“Denon”“Marantz”以及“REW”/“Room EQ Wizard”均为其各自所有者的商标。我们使用这些名称纯粹是为了说明兼容性。
NexusDeck 可以上传到哪些接收机？+
NexusDeck 可上传到支持 TCP 端口 1256 二进制校准上传协议的联网 Denon 和 Marantz AV 接收机，涵盖 Cinema 30 / 40 / 50、AV10、X3800H、X4800H、X6800H，以及近几年其他采用 Audyssey MultEQ XT32 的机型。NexusDeck 会根据接收机以及你要上传的校准文件，自动识别机型和声道布局。
NexusDeck 可以导入哪些文件格式？+
Audyssey .ady（MultEQ Editor 导出）、A1 Evo Acoustix .oca、REW .mdat（Room EQ Wizard 的 MEQX 测量导出，支持多位置）、.frd 响应曲线，以及 REW PEQ .txt 导出文件。目前只有 .ady 文件可以上传到接收机；.oca / .mdat / .frd / .txt 仅用于曲线库管理和对比。v1 暂不支持 Dirac Live 滤波器导入和机身上传。
NexusDeck 能自己生成校准曲线吗？+
不能，这是有意为之。NexusDeck 负责存储、浏览、对比和上传由其他工具（MultEQ Editor、A1 Evo Acoustix、REW、ratbuddyssey 等）生成的校准文件。实际的测量和曲线生成都在那些工具中完成；NexusDeck 是管理器，也是设备端的上传通道。
我现有的扬声器预设会安全吗？+
会。每次上传前，NexusDeck 都会读回目标扬声器预设槽位中的当前内容，并作为备份条目保存到你的曲线库中。轻点一下即可将任意槽位恢复到之前的校准。传输完成后，NexusDeck 还会重新读取该槽位，确认上传无误。
NexusDeck 如何与我的接收机配对？+
如果你已安装 AVR Maestro 并与接收机配对，NexusDeck 会通过跨应用共享容器自动读取已配对设备列表，无需二次配对，也不用重复输入 IP。如果你没有 AVR Maestro，NexusDeck 的配对流程会引导你直接输入接收机的 IP。
NexusDeck 的价格是多少？+
NexusDeck 可免费下载。免费版涵盖所有曲线库导入、浏览和单条曲线可视化，另外可向扬声器预设槽位 1 (SPP1) 终身上传最多 5 次，让你在决定购买前，先在自己的接收机上完整体验上传流程。解锁无限次上传、SPP2 写入、槽位备份与恢复、多曲线对比视图、引导式演示，以及 AVR Maestro 设备交接桥接，只需一次性内购 $12.99。无订阅，无定期扣费，无广告。价格可能在发布前调整。
需要哪些版本的 Android 和 iOS？+
NexusDeck 需要 Android 7.0 (API 24) 或更高版本，以及 iOS 14 或更高版本。两个平台同步上线。
