隐私政策

最后更新：2026年9月23日

MiyaraHub Technologies LLC（以下简称“我们”）致力于保护你的隐私。本隐私政策说明了当你使用 MiyaraHub Technologies LLC 发布的任何应用、集成或服务（统称“服务”）时，我们如何收集、使用、披露和保护你的信息。当前涵盖的应用列表见下方附录 A。

1. 数据最小化原则

MiyaraHub Technologies LLC 恪守数据最小化原则。我们只收集应用和服务功能所必需的最少量个人数据，不会收集超出你所使用功能所需的数据。

我们的许多应用完全在你的本地网络中运行，不会向我们的服务器传输任何设备数据、凭据或使用信息。数据留在你的设备上。各应用的数据处理方式详见附录 A。

2. 我们收集的信息

你提供的信息：

  • 联系信息：你联系我们的支持团队时提供的姓名和电子邮件地址。
  • 交易数据：通过第三方支付服务商（Square、PayPal、Apple App Store、Google Play Store）处理的付款信息。我们不会在服务器上存储完整的信用卡号。
  • 沟通内容：你联系我们寻求支持时提供的信息。
  • 用户内容：你通过我们的应用提交的任何内容，例如产品评价、报价或配置数据。

自动收集的信息：

  • 崩溃报告：我们使用 Firebase Crashlytics 收集匿名崩溃报告和诊断数据，以提高应用稳定性。这些报告不包含个人信息、凭据或来自你网络的特定设备数据。
  • 使用情况分析：部分应用（见附录 A）使用 Firebase Analytics 收集匿名的汇总使用数据，例如应用打开次数、屏幕浏览情况和使用了哪些功能，帮助我们了解使用模式并改进应用。这些数据不会与你的身份关联，也绝不会用于广告或跨应用追踪。
  • 麦克风与语音输入：带有语音助手的应用（见附录 A）仅在你主动按住或点按麦克风控件时才会采集音频。该音频会交给你设备自带的语音识别服务，应用只会收到返回的文字。我们绝不会接收、存储或传输音频，请求完成后设备上也不会保留任何录音。根据你的设备及其设置，该语音服务可能完全离线运行，也可能在 Google 或 Apple 的服务器上处理音频。这一选择取决于你的操作系统而非我们，并受其隐私政策约束。语音输入始终是可选的，所有助手功能都可以通过打字完整使用。
  • 设备信息：基本的设备类型和操作系统版本，仅通过崩溃报告收集，用于调试。
  • 本地网络数据：对于与本地网络设备交互的应用（例如智能家居控制器、NAS 系统、UPS 设备），设备标识符、IP 地址和配置数据仅收集并存储在你的设备上，绝不会传输到我们的服务器。

我们不收集的信息：

  • 我们不收集你的浏览记录，也没有任何应用会把你的设备位置传输到我们的服务器
  • 对于附录 A 中未列明使用 Firebase Analytics 的应用，我们不会追踪你使用了哪些功能或使用应用的频率
  • 我们不收集网络设备的凭据、配置或监控数据
  • 我们不使用广告追踪器，不出售你的数据，也不为广告目的建立用户画像

3. 我们如何使用你的信息

  • 提供、维护和改进我们的服务
  • 处理交易并发送相关信息
  • 回复你的支持请求和沟通
  • 通过崩溃报告诊断并修复软件错误
  • 遵守法律义务

4. 信息共享

我们不会出售、出租或交易你的个人信息。仅在以下有限情形下，我们才可能共享信息：

  • 支付处理方：Square、PayPal、Apple 和 Google 依据各自的隐私政策处理付款。
  • 崩溃报告&分析：Firebase (Google) 会接收匿名崩溃数据，并在部分应用中接收匿名使用情况分析数据，帮助我们修复错误、改进应用。
  • 法律要求：在法律、传票或其他法律程序要求时。
  • 业务转让：与合并、收购或资产出售相关时。

5. 第三方服务&硬件

我们的应用会与第三方硬件和服务交互。对于第三方制造商或服务提供商的数据处理行为，我们概不负责。你对第三方产品的使用受其各自隐私政策约束：

  • Supabase：supabase.com/privacy（Elan Audio Lab 的后端）
  • Square：squareup.com/legal/privacy（支付处理）
  • PayPal：paypal.com/privacy（支付处理）
  • Firebase (Google)：firebase.google.com/support/privacy（崩溃报告，以及部分应用的匿名使用情况分析）
  • Apple App Store： apple.com/legal/privacy
  • Google Play: policies.google.com/privacy

我们的应用可能会与你本地网络中的第三方硬件设备通信。这些制造商有各自的数据处理规范。我们不控制、不访问，也不代表任何第三方硬件或服务提供商传输数据。

6. 数据存储&安全

我们采用行业标准的安全措施保护你的信息，包括传输加密 (TLS/SSL) 和静态加密。我们的后端服务（如适用）托管在 Supabase 上，其提供企业级安全保障，并采用行级安全 (RLS) 策略。

对于连接本地网络设备的应用，连接凭据和设备数据会使用平台原生的安全存储（iOS 上的 Keychain、Android 上的 Keystore，以及 Windows 上受 DPAPI 保护的存储）安全地保存在你的设备上，并且绝不会传输到我们的服务器。

7. 儿童隐私

我们的服务不面向儿童。我们不会有意收集 13 岁以下任何人的个人信息（在欧洲经济区为 16 岁以下，或低于你所在司法管辖区适用的最低年龄）。

如果我们发现无意中收集了低于适用最低年龄的儿童的个人信息，会立即将其删除。如果你认为有儿童向我们提供了个人信息，请通过 admin@miyarahub.com 联系我们。

8. 你的权利&选择

根据你所在的地区，你可能对自己的个人信息享有以下权利：

  • 访问权：请求获取我们持有的关于你的个人信息副本。
  • 更正权：请求更正不准确的个人信息。
  • 删除权：请求删除你的个人信息。
  • 可携带权：请求获取你的数据的可携带副本。
  • 退出权：退出某些数据收集（例如，在提供该选项的应用中，可在应用设置里关闭崩溃报告）。
  • 不得出售：我们不出售个人信息。无需退出，但你可以联系我们进行确认。

如需行使上述任何权利，请通过 admin@miyarahub.com 联系我们。

9. 数据保留

我们仅在实现本政策所述目的所需的期限内保留你的信息。具体如下：

  • 支持沟通记录：自你最后一次互动起最长保留 2 年。
  • 交易数据：按适用的税务和财务法规要求保留。
  • 崩溃报告：由 Firebase Crashlytics 最长保留 90 天。
  • 本地设备数据：仅存储在你的设备上；卸载应用或清除应用数据时即被删除。

10. 国际用户

如果你在美国境外访问我们的服务，你的信息可能会被传输到美国并在美国存储和处理。使用我们的服务即表示你同意此类传输。我们依照适用的数据保护法律处理数据。

11. 德克萨斯州数据隐私与安全法案

对于德克萨斯州居民：MiyaraHub Technologies LLC 遵守《德克萨斯州数据隐私与安全法案》(TDPSA)。你有权访问、更正、删除并获取你的个人数据的可携带副本。如需行使这些权利，或就你的请求所作的决定提出申诉，请通过 admin@miyarahub.com 联系我们。

12. 本政策的变更

我们可能会不时更新本隐私政策。如有重大变更，我们会在本页面发布新政策并更新“最后更新”日期以通知你。建议你定期查看本页面。

本地网络应用通用规则：标注为“仅限本地网络”的应用，会将所有设备凭据、配置和监控数据仅存储在你的设备上。没有任何设备数据、网络凭据或使用遥测数据会传输到 MiyaraHub 的服务器。云端通信仅限于通过 Firebase Crashlytics 发送的匿名崩溃报告，以及（上表中注明的情况下）通过 Firebase Analytics 发送的匿名使用情况分析，二者均不包含个人信息或特定于网络的数据。

AVR Maestro 具体披露：助手的语言模型运行在你的设备上。你的接收机配置、你提出的问题和得到的回答绝不会传输给 MiyaraHub。语音输入是唯一值得明确说明的例外：当你点按麦克风时，音频会交给你设备的语音识别服务，在某些设备和设置下，该服务是由 Google 或 Apple 运营的云服务。应用不指定特定的识别器，只接收返回的文字结果。如果你希望完全没有任何内容离开你的设备，请改用打字提问，助手的表现完全相同。

Elan Audio Lab 具体披露：作为电子商务平台，Elan Audio Lab 会收集完成购买所必需的交易数据（姓名、电子邮件、收货地址）。支付卡数据完全由 Square 和 PayPal 处理，我们不会看到或存储完整的卡号。商品目录、博客内容和艺术家数据由 Supabase 云后端提供。

Almanox 具体披露：Almanox 是一款独立的日月与天文规划应用。如果你授予位置权限，设备位置仅在你的设备上用于计算你所在位置的日月和天空数据；它绝不会传输到 MiyaraHub 服务器，也不会存储在设备以外的任何地方。你也可以拒绝该权限，改为手动输入坐标。已保存的位置和设置都留在你的设备上。云端通信仅限于通过 Firebase Crashlytics 发送的匿名崩溃报告，以及通过 Firebase Analytics 发送的匿名汇总使用情况分析，二者均不包含个人身份信息或你保存的位置。Almanox Pro 的一次性升级由 Apple 或 Google 处理，我们不会看到或存储你的付款信息。

Projector Pilot 具体披露：Projector Pilot 控制你本地网络中的 Epson 投影机；设备凭据、投影机设置和任何 Home Assistant 配置都只存储在你的设备上，绝不会传输到 MiyaraHub 服务器。通过 Firebase Analytics 进行的使用情况分析需主动开启，默认关闭：除非你接受首次启动时显示的提示，否则不会收集任何内容，并且你可以随时在“设置”中再次关闭。开启后，它只会报告匿名的汇总事件，例如应用打开次数和使用了哪些界面；绝不会包含你的投影机地址、序列号、凭据或 Home Assistant 信息。Pro 和家庭自动化购买由 Apple 或 Google 处理，我们不会看到或存储你的付款信息。
