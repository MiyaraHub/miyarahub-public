4. 我们按来源处理的数据

4.1 您发送给我们的电子邮件

当您给我们写信时，我们会收到您的电子邮件地址、您提供的姓名、您的邮件内容以及任何附件。我们使用这些信息来回复您。

4.2 您选择发送的诊断报告

许多应用有一个按钮，可准备诊断电子邮件或文件。它会打开您自己的电子邮件应用或分享面板，在您按下发送之前不会发送任何内容。根据应用不同，报告可能包含您的设备型号和系统版本、应用设置、日志，以及您所控制设备的网络地址、硬件 (MAC) 地址、主机名、型号名称和序列号。有些应用会先移除其中的部分信息；许多应用不会。附录 A 列出了每款应用包含的内容。请在发送前阅读报告，并移除您不想分享的任何内容。

4.3 崩溃报告 (Firebase Crashlytics)

当应用崩溃或遇到严重错误时，Crashlytics 会向 Google 发送一份报告，其中包含错误和代码位置、应用版本、设备型号、系统版本、可用内存和存储空间、一个随机的 Crashlytics 安装标识符和一个 Firebase 安装标识符。报告上传时，Google 会收到您的 IP 地址。在许多应用中，错误文本可能包含您所控制设备的网络地址或名称。附录 A 针对每款应用说明了崩溃报告是否默认开启、开关在哪里，以及发送前移除了哪些内容。

4.4 使用分析 (Firebase Analytics)

在启用该功能的应用中，Firebase Analytics 会向 Google 发送事件，例如首次打开、会话开始、屏幕浏览、应用内购买，以及附录 A 列出的应用事件。每个事件都带有一个随机的应用实例标识符、一个 Firebase 安装标识符、设备型号、系统版本、语言、应用版本，以及 Google 根据您的 IP 地址推断的大致位置（国家或地区）。在 iOS 上，它还可能使用供应商标识符。在附录 A 有所说明的应用中，它还会收集 Android 广告 ID。我们使用分析数据来了解哪些功能被使用以及应用在哪些地方出现故障。我们不将其用于展示广告。

4.5 购买和商店报告

当您购买应用或应用内升级时，由 Apple、Google 或 Microsoft 处理付款。它们会向我们发送销售报告，其中包含日期、国家、产品、价格和订单号。我们不会收到您的银行卡详细信息。应用会在您的设备上保存您的购买记录，以便解锁功能；附录 A 说明了保存位置。

4.6 Elan Audio Lab 商店

商店处理账户、订单、付款、送货地址、评论、新闻通讯订阅、联系表单、报价请求、保修登记、赠品活动和艺术家申请。请参阅第 14 节以及附录 A 中的 Elan Audio Lab 部分。

4.7 本网站

miyarahub.com 由 GitHub Pages 托管。您加载页面时，GitHub 会收到您的 IP 地址和浏览器详细信息，并为安全目的保留日志。我们的字体由 miyarahub.com 自身提供，因此不会向第三方发送任何字体请求。我们的页面不设置 Cookie，也不运行分析。如果您选择语言，您的选择会以键名“lang”保存在浏览器的本地存储中，绝不会发送给我们。

您输入的设备地址、设置、密码和令牌存储在您的设备上。除非您在诊断报告中发送给我们，否则我们不会收到它们。您设备自带的备份（iCloud、Google 或其他备份工具）可能会复制这些数据；附录 A 说明了各应用将哪些内容排除在备份之外。
