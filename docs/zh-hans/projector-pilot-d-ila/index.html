MiyaraHub / Projector Pilot D-ILA

Projector Pilot D-ILA · 适用于 JVC D-ILA 投影机你的 D-ILA，尽在掌握。✦

适用于 JVC D-ILA 投影机的本地网络遥控器，可在手机、平板或电脑上使用。

Projector Pilot D-ILA 通过投影机的网络控制端口（TCP 20554），使用你在投影机上设置的网络密码，直接与投影机通信。涵盖电源、输入源、菜单导航、画面模式、HDR 级别、色彩、动态、镜头、安装和画面比例，并提供场景、维护和 Home Automation。中间没有账户，也没有云服务。

工作方式

直接的网络连接。中间没有云服务。

Projector Pilot D-ILA 在你的本地网络中直接连接投影机。没有 MiyaraHub 服务器，也无需账户。

1

查找你的投影机

扫描你的网络（会尝试子网内每个地址的 20554 端口），或通过 IP 地址添加投影机。

2

使用密码登录

输入你在投影机上设置的网络密码。应用会通过 TCP 20554 登录、读取机型，并将密码保存在你设备的安全存储中。

3

掌控一切

使用你的机型支持的遥控、画面、镜头和设置界面，保存场景，并在需要时关联 Home Automation。

安全 & 隐私

本地优先。无需账户。没有广告。

应用只与你本地网络中的投影机以及商店（用于应用内购买）通信。它还会发送什么、何时发送，都列在这里。

◉

直达投影机

命令和状态读取都直接在你的设备与投影机之间通过本地网络进行，中间没有任何云服务。

◎

无需账号

无需注册，也没有 MiyaraHub 账户。扫描或输入投影机的地址即可连接。

▣

崩溃报告和使用情况分析

崩溃报告在 Android、iPhone 和 iPad 上默认开启，以便修复问题，你可以在设置中将其关闭。崩溃报告可能包含导致应用停止运行的错误文本，在少数情况下其中会出现网络地址。macOS 和 Windows 应用不发送任何崩溃报告。匿名使用情况分析在你主动选择开启之前保持关闭，并且只包含次数和结果，绝不包含投影机名称、地址、密码或中枢地址。

◆

密码保存在安全存储中

每台投影机的网络密码都保存在你设备的安全存储中。除了发送到你添加该投影机的 Home Assistant 之外，它不会去往任何其他地方，不会进入日志或备份。

▢

没有 Home Automation 就不会发送任何内容

购买 Home Automation 后，应用只会把你的触发发送到你输入的网址，只把电源和输入源发送到你关联的 Hubitat 中枢，并把投影机状态发送到你登录的 Home Assistant。未购买时，以及对于演示投影机始终如此，都不会发送任何内容。

☼

通过商店购买

Pro、Home Automation 和组合包都是由商店处理的一次性购买。MiyaraHub 绝不会看到你的付款信息。

没有。Projector Pilot D-ILA 是由 MiyaraHub Technologies LLC 开发的独立应用。与 JVCKENWOOD Corporation 没有关联，也未获其认可。JVC 和 D-ILA 是其各自所有者的商标，在此提及仅为说明兼容性。
什么时候可以使用？ +

它支持哪些 JVC 投影机？ +
联网的 JVC D-ILA 投影机：DLA-NZ900 和 NZ800，NZ700 和 NZ500 世代，NZ9、NZ8、NZ7 和 NP5 世代，NX9、NX7 和 NX5 世代，以及更早的 X7、X9、X30、X70R 和 X90R 系列，也包括它们的各地区名称。较早的 HD 和 RS10 至 RS40 机型以及 X3 没有网络控制。
它如何连接我的投影机？ +
直接在你的本地网络中，通过投影机的网络控制端口 TCP 20554 连接。你可以扫描网络或输入 IP 地址，然后使用你在投影机上设置的网络密码登录。没有云服务，也无需账户。
哪些功能免费，哪些需要购买？ +
不购买也可以使用开机和待机、HDMI 1，以及 20 次菜单导航按键，之后每天 3 次。Pro 可解锁 HDMI 2、不限次数的导航、所有其他遥控按键、场景、维护、测试图案和小组件。Home Automation 增加网络请求触发器、Hubitat 和 Home Assistant。组合包同时包含两者，每项都是一次性购买，没有订阅。
应用会发送什么，发送到哪里？ +
命令直接发送到你的投影机。崩溃报告在 Android、iPhone 和 iPad 上默认开启，可在设置中关闭；macOS 和 Windows 应用不发送任何崩溃报告。匿名使用情况分析在你主动选择开启之前保持关闭。使用 Home Automation 时，应用只会向你输入的网址、你关联的 Hubitat 中枢以及你登录的 Home Assistant 发送数据。
我有 Epson 投影机，有适用的版本吗？ +
有。Projector Pilot PJLink & VP21 控制 Epson 投影机，现已在 App Store、Google Play、Mac App Store 和 Microsoft Store 上架。
