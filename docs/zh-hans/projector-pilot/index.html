功能

投影机的完整控制，尽在手中。

Projector Pilot 通过 Wi-Fi 连接你的 Epson 投影机，让你全面掌控每一项设置，从电源、画面到镜头和几何校正，无需触碰投影机，也不用到处找实体遥控器。

No. 01

◉ 电源&输入控制

从待机状态开机，即时切换 HDMI 输入，开关 A/V 静音，并通过虚拟方向键导航 OSD，吊装投影机时方向键会自动反转。

电源开 / 关HDMI 切换A/V 静音OSD 方向键
No. 02

▣ 画面设置

全面控制色彩模式、亮度、对比度、饱和度、色调、锐度、伽马、色温、降噪、超分辨率和图像处理模式。

色彩模式亮度伽马锐度
No. 03

◆ HDR &色彩空间

动态范围选择（Auto、HDR10、HLG、SDR）、色彩空间控制（Auto、BT.709、BT.2020），以及逐通道的 RGB 增益和偏移调节，实现精准校准。

HDR10HLGBT.2020RGB 增益/偏移
No. 04

◎ 镜头控制&记忆

电动镜头位移、对焦和变焦调节，并实时显示位置。针对不同画面比例或银幕位置，保存并调用镜头记忆预设。

镜头位移对焦变焦记忆预设
No. 05

▢ 几何校正&梯形校正

水平和垂直梯形校正，并支持 QuickCorner、Point Correction、Curved Surface、Corner Wall 和 FreeForm 等校正方式。

H/V 梯形校正QuickCornerCurved Surface
No. 06

⚙ 状态&监控

实时追踪灯泡和激光使用时长，并提供更换提醒。监控错误和警告状态，查看设备信息、序列号、固件版本和连接诊断。

灯泡时长错误监控设备信息
No. 07

☼ 动态&画面处理

帧插值控制（Off、Low、Normal、High）、降噪、超分辨率增强，以及 Fine/Fast 图像处理模式选择。

帧插值降噪超分辨率
No. 08

✦ 主题&个性化

AMOLED 深色主题呈现纯黑，另有浅色主题，并支持 Material You（设备主题）。可调节的显示比例适配任何屏幕尺寸，包括 Samsung Galaxy S25+ 的紧凑布局。

工作方式

直连网络，无需云端。

Projector Pilot 使用标准网络协议，通过 Wi-Fi 直接与你的投影机通信。你的数据绝不会经过外部服务器。

1

添加您的投影机

输入 Epson 投影机的 IP 地址。Projector Pilot 会测试 PJLink 和 Web Control 的连通性，识别型号，并自动发现所有可用功能。

2

通过 Wi-Fi 连接

Projector Pilot 使用 PJLink 检测待机状态并控制电源，开机后再通过 Epson Web Control API 全面控制画面、镜头和各项设置。一切都留在你的本地网络中。

3

全面掌控

调节画面设置、切换输入、控制电动镜头、管理梯形校正、监控灯泡时长、导航 OSD，全部集中在一款优雅的应用里。

安全 & 隐私

仅限本地。无需账号。没有云端。

Projector Pilot 采用隐私优先、纯本地的架构设计。不依赖云端，无需用户账号，除崩溃报告外不收集任何数据。

◉

没有云端中转

所有指令和状态轮询都在你的手机与投影机之间通过本地 Wi-Fi 直接完成，没有任何内容离开你的网络。

◎

无需账号

无需注册，无需邮箱，也不需要 MiyaraHub 账号。打开应用，输入投影机的 IP 地址，即可开始控制。

▣

极简统计

仅使用 Firebase Crashlytics 收集错误报告。不收集个人数据，不追踪使用情况，没有广告。你的投影机数据绝不会离开手机。

◆

仅本地存储

投影机 IP 地址、凭据和应用偏好使用 SharedPreferences 存储在你的设备本地，不会同步到任何服务器。

▢

仅执行用户主动发起的操作

应用只会在你明确操作时才向投影机发送指令。不会在你不知情的情况下自动或在后台执行任何操作。

☼

仅需网络权限

Projector Pilot 唯一需要的设备权限是互联网/网络访问，仅用于通过本地 Wi-Fi 连接你的投影机。

常见问题。

关于 Projector Pilot，你需要知道的一切。

Projector Pilot 与 Epson 有关联吗？+
没有。Projector Pilot 是由 MiyaraHub Technologies LLC 开发的独立第三方应用，并非由 Seiko Epson Corporation 或其任何子公司、关联公司创建，也未获其认可或赞助，与其没有任何关联。“Epson”是 Seiko Epson Corporation 的注册商标。我们使用该名称纯粹是为了说明兼容性（指示性合理使用）。
支持哪些投影机？+
Projector Pilot 支持所有联网且支持 PJLink 和/或 Web Control 的 Epson 投影机，包括过去 10 多年的大多数型号，从旗舰 QB1000 和 LS12000，到中端家庭影院和专业工程安装机型。应用在连接时会自动检测可用功能，因此每位用户看到的都是自己的投影机所支持的内容。基础的 PJLink 控制也适用于 NEC、Panasonic、Sony 等品牌的非 Epson 投影机。
Projector Pilot 如何与我的投影机通信？+
Projector Pilot 使用两种协议：PJLink（端口 4352）用于通用投影机控制，包括待机开机、输入切换和灯泡状态；以及采用 Digest 认证的 Epson Web Control API（端口 80），用于丰富的设置控制，包括画面、镜头、梯形校正、HDR 等。所有通信都直接在你的本地 Wi-Fi 网络中完成。
我可以控制电动镜头吗？+
可以，适用于配备电动镜头系统的投影机。Projector Pilot 提供完整的镜头位移（水平和垂直）、对焦和变焦控制，并实时反馈位置。你还可以针对不同的画面比例、银幕位置或观影场景，保存并调用镜头记忆预设。没有电动镜头的机型会自动隐藏镜头控制。
支持 HDR 和广色域吗？+
支持。Projector Pilot 可让你控制动态范围设置（Auto、HDR10、HLG、SDR）、色彩空间（Auto、BT.709、BT.2020），并提供逐通道的 RGB 增益和偏移调节，实现精准的色彩校准。HDR 功能仅在支持的机型上显示。
可以从待机状态开机吗？+
可以。即使投影机处于待机模式，Projector Pilot 也能通过 PJLink 将其开机。只要投影机已接入你的网络（待机唤醒建议使用有线网络），你就可以用手机开关机。

需要哪个版本的 Android？+
Projector Pilot 需要 Android 5.0 (API 21) 或更高版本。目前仅支持 Android。日后版本可能会加入 iOS 支持。
