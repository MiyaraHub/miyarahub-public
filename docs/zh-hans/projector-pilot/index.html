工作方式

直连网络，无需云端。

Projector Pilot PJLink & VP21 在你的本地网络中直接与投影机通信。没有 MiyaraHub 服务器，也无需账户。

1

查找你的投影机

扫描你的网络，查找在 PJLink (4352) 和 ESC/VP.net (3629) 端口上应答的投影机，或直接输入 IP 地址。应用会检测机型及其支持的功能。

2

在你的网络中连接

应用使用 ESC/VP21 over ESC/VP.net（TCP 3629）和 PJLink（TCP 4352）来控制电源、输入源和设置；在投影机提供时，还使用 Epson Web Control（HTTP 80，Digest 登录）。所有数据都保留在你的本地网络中。

3

全面掌控

调节画面设置、切换输入、控制电动镜头、管理梯形校正、监控灯泡时长、导航 OSD，全部集中在一款优雅的应用里。

关于 Projector Pilot PJLink & VP21 你需要了解的一切。

Projector Pilot PJLink & VP21 与 Epson 有关联吗？ +
没有。Projector Pilot PJLink & VP21 是由 MiyaraHub Technologies LLC 开发的独立第三方应用。它并非由 Seiko Epson Corporation 或其任何子公司、关联公司创建、认可或赞助，也与它们没有任何关联。“Epson”是 Seiko Epson Corporation 的注册商标。我们使用该名称纯粹是为了说明兼容性（指示性合理使用）。
有适用于 iPhone 和 Android 的 Epson 投影机应用吗？ +
有。Projector Pilot PJLink & VP21 可在 iPhone 和 iPad（iOS 15 或更高版本）、Android、Mac（macOS 12 或更高版本）和 Windows 上运行，可从 App Store、Google Play、Mac App Store 和 Microsoft Store 获取。它控制你本地网络中的 Epson 投影机。
它支持 Home Cinema 5050UB、LS12000 或 QB1000 吗？ +
支持。EH-QB1000 已在真实投影机上确认，应用还内置了 EH-LS12000 / Pro Cinema LS12000 和 EH-TW8400 / Home Cinema 5050UB 的配置文件，以及“兼容性”下列出的其他机型。应用会在连接时读取机型，并且只显示该机型支持的控制项。
它能替代 Epson iProjection 吗？ +
它们的用途不同。Epson iProjection 把你的屏幕或照片发送到投影机。Projector Pilot PJLink & VP21 不投射内容；它是一款遥控与设置控制器，可控制电源、输入源、画面、HDR、镜头、梯形校正和维护，并提供场景和 Home Automation。
支持哪些投影机？+
联网的 Epson 家庭影院投影机，从 EH-QB1000 以及 LS12000、LS11000、LS800 和 LS500 激光机型，到 6050UB、5050UB、4010 和 3800 灯泡机型，以及更早的 6040UB、5040UB 和 5030UB 世代。较小的 Home Cinema、LS300、LS650 和 EF 机型支持电源和输入源控制。Home Cinema 3200 没有网络控制。基础的 PJLink 控制也适用于其他厂商的投影机。
它如何与我的投影机通信？ +
三种方式，全部在你的本地网络中进行：通过 ESC/VP.net 使用 TCP 端口 3629 的 ESC/VP21（如果你设置了投影机密码，则需使用该密码）；使用 TCP 端口 4352 的 PJLink，用于电源、输入源和状态；以及使用 HTTP 端口 80 并以 Digest 方式登录的 Epson Web Control 界面，用于它开放的设置。
我可以控制电动镜头吗？+
支持，适用于配备电动镜头的投影机。你可以进行镜头位移、对焦和变焦，还可以为不同的画面比例或屏幕位置保存和调用镜头记忆预设。在没有电动镜头的机型上，镜头控制项会被隐藏。
支持 HDR 和广色域吗？+
支持，适用于提供这些功能的机型。你可以选择动态范围（Auto、SDR、HDR PQ 和 HLG，以机型列出的为准）和色彩空间，并调整各通道的 RGB 增益和偏移以进行校准。
可以从待机状态开机吗？+
可以，前提是投影机在待机时保持网络处于活动状态。使用有线局域网并开启投影机的待机网络设置，可让待机唤醒更可靠。
