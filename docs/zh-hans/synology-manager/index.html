功能

全面掌控 NAS，尽在手中。

DSM 显示的一切，都能在手机上查看；而你的账号无权查看的内容，应用会自然隐藏。

No. 01

◉ 实时仪表盘

CPU、内存、温度和运行时间实时呈现，一目了然。可自定义的卡片让你准确看到最重要的内容：系统健康、存储用量、网络吞吐量等。

No. 02

▣ Docker 管理

查看所有运行中的容器及其实时 CPU 和内存使用情况。启动、停止、重启容器并访问日志，用手机即可完整控制 Docker。

No. 03

◎ 监控摄像头

以清爽的网格布局显示实时摄像头画面。点按即可全屏查看，了解录像状态，并在一处监控你所有的 Surveillance Station 摄像头。

No. 04

▢ 存储&硬盘健康

存储卷用量、RAID 状态、每块硬盘的温度，以及每个磁盘的 SMART 健康数据。随时掌握存储的状态。

No. 05

╿ 网络监控

每个网络接口的实时带宽图表。追踪下载/上传速度、活动连接、绑定接口和 DNS 配置。

No. 06

⚙ 套件管理

查看所有已安装的 DSM 套件及其状态。监控运行中的服务、计划任务、UPS 电池状态、日志条目和共享文件夹。

No. 07

☼ 高度可自定义

配置仪表盘类别，自定义导航栏，选择主题，并设置轮询间隔。让应用按你的方式工作。

No. 08

✦ 主屏幕小组件

为主屏幕提供快捷操作、存储概览和系统状态小组件。无需打开应用，就能瞥见 NAS 的健康状况。

直连 DSM，不经过云端。

3

监控&管理

仪表盘、Docker、摄像头、存储、网络、套件和任务，都可以直接在手机、平板或桌面端上完成。

安全的本地存储

连接信息使用平台安全存储保存在设备上：iOS 钥匙串和 Android Keystore。

常见问题

常见问题。

应用如何连接到我的 NAS？+
Syno Manager 使用 Synology DSM 公开的 API 接口，通过你的本地网络与 NAS 通信。应用直接向你的 NAS 发送请求，不涉及任何中间服务器、代理或云端中转。你只需提供 NAS 的 IP/主机名和端口，使用 DSM 凭据登录，应用便会直接与 DSM 通信。
应用在我的 NAS 上需要哪些权限？+
应用只在你的 DSM 用户账号权限范围内运行。要使用完整的仪表盘功能，建议使用管理员账号。不过应用会平稳降级：如果你的账号没有 Docker 权限，Docker 部分就只是不显示数据；Surveillance Station、共享文件夹等也是如此。无需在 DSM 上安装任何特殊套件。
应用会保存我的 NAS 凭据吗？+
连接信息使用平台安全存储（iOS 钥匙串 / Android Keystore）保存在你的设备本地。凭据绝不会传输给 MiyaraHub Technologies 或任何第三方，仅用于向你的 NAS 进行认证。
支持哪些 Synology 型号？+
Syno Manager 适用于运行 DSM 7.0 或更高版本的任何 Synology NAS，包括当前所有的 DiskStation (DS)、RackStation (RS) 和 FlashStation (FS) 型号。运行 DSM 6.x 的旧型号可能因 API 差异而功能受限。
我可以远程管理 Docker 容器吗？+
可以。你可以直接在应用中查看容器状态、CPU/内存使用情况、访问日志，并执行停止/重启操作。目前不支持创建容器和更改配置，重点是监控和快捷管理操作。
Syno Manager 的售价是多少？+
Syno Manager 一次性买断，售价 $9.99。无订阅，无广告，无内购。你只需在 App Store 或 Google Play 购买一次，即可永久拥有。
可以远程访问我的 NAS 吗（在家庭网络之外）？+
Syno Manager 会连接你配置的任意 IP/主机名。只要你的 NAS 能通过 VPN、Tailscale 或端口转发访问，应用就能远程使用。我们建议使用 VPN 或 Tailscale，而不是把 DSM 直接暴露在互联网上。
