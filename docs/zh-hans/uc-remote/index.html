功能

你的整个遥控器，尽在你手中。

UC Remote 通过 Wi-Fi 连接你的 Unfolded Circle Remote Two 或 Remote 3，并在专为手机设计的快速原生界面中，呈现它能做的一切：活动、页面、实体和媒体。

No. 01

◉ 活动，一键搞定

从清爽的列表中启动和停止完整活动，比如观看 Shield TV、Xbox、PS5。你的遥控器会打开相应的设备并切换输入，应用则直接带你进入该活动的控制界面。

启动 / 停止活动分组一键操作
No. 02

▣ 精美的活动页面

每个活动都有自己的自定义页面。在媒体正在播放视图、按键遥控器和量身定制的控制磁贴之间滑动切换，布局与你在遥控器上的配置完全一致。

可滑动页面自定义布局按键磁贴
No. 03

♫ 实时正在播放

专辑封面、标题和艺术家、播放控制（上一首、播放 / 暂停、下一首），以及媒体播放器的信号源和音效模式选择器，所有内容都会随变化实时更新。

专辑封面播放控制实时状态
No. 04

◎ 每种实体，专属设计

支持亮度和颜色的灯光、支持设定温度的空调、窗帘、开关、传感器和媒体播放器，每一种都有专为它设计的控制界面，配有合适的图标和操作，而不是千篇一律的开关。

灯光空调窗帘传感器
No. 05

☰ 完整的实体浏览器

搜索并筛选你的整套设置，数百个实体也不在话下，可按类型筛选，无论是灯光、媒体播放器、开关还是空调，并直接跳转到其中任何一个。

搜索按类型筛选快速打开
No. 06

▤ 多个遥控器

配对多个 Unfolded Circle 遥控器并即时切换。每个遥控器都记住自己的配置、页面和实体，因此影音室遥控器和办公室遥控器完全互不干扰。

多遥控器快速切换各遥控器独立配置
No. 07

▦ 主屏幕小组件

直接在主屏幕上放置活动、媒体播放器或设备小组件，每个都可指向所选遥控器，无需打开应用，即可一键控制并查看实时正在播放。

活动媒体设备

工作方式

直连你的遥控器，无需云端。

UC Remote 在你自己的 Wi-Fi 上与 Unfolded Circle 遥控器配对，并利用遥控器自身的集成接口直接与其通信。你的设置绝不会经过外部服务器。

1

配对你的遥控器

输入 Unfolded Circle Remote Two 或 Remote 3 的 IP 地址以及它显示的 PIN 码。UC Remote 会安全配对，并导入你的配置、页面、活动和实体。

2

保持同步

实时双向连接会从遥控器传来状态，例如什么设备开着、正在播放什么，而你的点按则作为指令直接发回。没有轮询延迟，也无需经过云端往返。

3

掌控一切

运行活动，操作自定义页面，驱动每个实体和媒体播放器，在多个遥控器之间切换，并把小组件固定到主屏幕，一切都在一款应用中完成。

安全 & 隐私

仅限本地。无需账号。没有云端。

UC Remote 采用隐私优先、纯本地的设计：不依赖云端，无需用户账号，除崩溃报告外不收集任何数据。

◉

没有云端中转

每条指令和实时状态流都在你的手机与遥控器之间通过本地 Wi-Fi 直接传输，没有任何内容离开你的网络。

◎

无需账号

无需注册，无需邮箱，也不需要 MiyaraHub 账号。使用遥控器的 PIN 码配对，即可开始控制。

▣

PIN 码配对访问

配对时会交换一个安全的访问令牌，它存储在你的设备本地，仅用于与你的遥控器通信。

◆

仅本地存储

遥控器地址和应用偏好存储在你的设备上，不会同步到任何服务器。

▢

仅在你操作时执行

只有在你操作时才会发送指令。不会在你不知情的情况下自动或在后台触发任何操作。

☰

仅需网络权限

UC Remote 唯一需要的权限是本地网络访问，仅用于通过 Wi-Fi 连接你的遥控器。

常见问题。

关于 UC Remote，你需要知道的一切。

UC Remote 与 Unfolded Circle 有关联吗？+
没有。UC Remote 是由 MiyaraHub Technologies LLC 开发的独立第三方配套应用，并非由 Unfolded Circle 创建，也未获其认可或赞助，与其没有任何关联。“Unfolded Circle”“Remote Two”和“Remote 3”均为其各自所有者的商标；我们使用这些名称仅仅是为了说明兼容性。
它支持哪些设备？+
UC Remote 适用于你本地网络中的 Unfolded Circle Remote Two 和 Remote 3。只要你的遥控器与手机处于同一 Wi-Fi 下，UC Remote 就能与其配对，并同步显示其活动、页面和实体。
它如何连接到我的遥控器？+
通过你的本地 Wi-Fi。完成一次性 PIN 码配对后，UC Remote 会保持一条实时事件通道，与遥控器的状态同步，并直接发送你的指令。没有云端中转，也无需账号，一切都留在你的网络中。
我需要账号或互联网连接吗？+
永远不需要账号。UC Remote 只需要你的本地网络来连接遥控器，没有任何内容离开你的 Wi-Fi，也没有需要注册的云服务。
我可以控制多个遥控器吗？+
可以。你可以配对任意数量的 Unfolded Circle 遥控器，并一键切换。每个遥控器都保留自己的配置、页面和实体。
UC Remote 支持哪些平台？+
UC Remote 是适用于 Android 手机和平板的原生应用，已在 Google Play 上架。
