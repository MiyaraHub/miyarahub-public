功能

UPS 报告的一切，清晰呈现。

监控并管理你网络上的每一台 UPS，无论是家庭实验室还是整机架的 UPS。

No. 01

◉ 实时仪表盘

一目了然地查看所有 UPS 设备的状态：电池百分比、负载、电压和剩余续航时间。实时更新，轮询间隔可配置。

▣ 电力指标

详细的输入和输出电力数据。监控电压、频率、电流、瓦数、视在功率和线路质量。了解你的用电环境所需的一切。

带动画的电池仪表，显示电量百分比、电压、温度和预估续航时间。可直接在应用中运行自检，验证电池是否就绪。

▢ 插座控制

可配置的通知，涵盖断电、电池电量低、设备离线和供电恢复事件。可设置自定义阈值，并选择声音和振动偏好。

常见问题

常见问题。

我的 UPS 需要连接互联网吗？+
不需要。UPSight 仅通过你的本地网络通信。你的 UPS 只需与手机处于同一网络（或可通过 VPN/Tailscale 访问）。UPS 本身无需访问互联网。
我可以监控多台 UPS 设备吗？+
可以！UPSight 支持无限数量的 UPS 设备。仪表盘会以一目了然的状态卡片显示你的所有设备。点按任意设备，即可在六个标签页中查看完整详情：概览、电力、电池、插座、事件和信息。
我可以在应用中控制 UPS 插座吗？+
可以，适用于支持通过 SNMP 进行插座控制的 UPS 型号（例如带可控插座的 CyberPower PR 系列）。你可以单独开关各个插座，并重命名以便识别。只读插座只显示状态，没有开关控件。
UPSight 的售价是多少？+
UPSight 一次性买断，售价 $4.99。无订阅，无内购，无广告。买一次，永久使用，并包含所有后续更新。
支持哪些 SNMP 版本？+
UPSight 支持 SNMP v1、v2c 和 v3。你可以在设置时为每台设备选择版本。大多数消费级和准专业级 UPS 设备使用 v2c，团体字符串为“public”。v3 适用于需要认证和加密的企业环境。
我可以远程使用 UPSight 吗（在家庭网络之外）？+
可以，只要你的 UPS 能通过 VPN、Tailscale、WireGuard 或类似方式访问。UPSight 会连接你配置的任意 IP 地址。我们建议通过 VPN 访问，而不是把 SNMP 端口直接暴露在互联网上。
UPSight 能用于我的 UPS 网络卡吗？+
可以，只要网络卡支持 SNMP。这包括 APC Network Management Card、CyberPower RMCARD、Eaton Network-M2 和 Network-M3、Tripp Lite WEBCARDLX，以及 Vertiv Liebert IntelliSlot 网络卡。在网络卡的'网页界面'中启用 SNMP，然后在 UPSight 中添加该网络卡的 IP 地址即可。
我的 UPS 只有 USB 接口，能用 UPSight 吗？+
可以，通过 NUT。将 UPS 接到运行 Network UPS Tools (NUT) 服务器的服务器、NAS 或 Raspberry Pi 上，然后在 UPSight 中添加该服务器即可。如果 UPS 仅通过 USB 连接到一台电脑，又没有 NUT，则无法通过网络访问。
我的 UPS 品牌不在列表中，能用吗？+
很可能可以！如果你的 UPS 支持 SNMP 并实现了标准的 RFC 1628 UPS-MIB，UPSight 的通用驱动就能工作。大多数支持联网的 UPS 设备都符合该标准。如果遇到问题，请联系我们，我们可以研究为你的品牌添加专用驱动。
