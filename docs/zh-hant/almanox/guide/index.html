如何使用 Almanox

Almanox 只回答一個問題：今晚值不值得出門？如果值得，要去哪裡、什麼時候、怎麼拍。本指南會逐一帶您了解每個部分：讀懂評比、規劃銀河、對齊太陽或月亮的拍攝、攝影計算，以及尋找真正黑暗的夜空。

初啟

三步驟輕鬆上手

1

選擇您的地點

Almanox 會使用您的位置，您也可以用名稱新增任何地點。所有讀數，包括時間、評比與銀河，都會依您所站的確切位置計算。

2

看懂評比

開啟「今晚」，就能看到一個 0-100 的分數，將黑暗程度、月亮、銀河高度與雲量整合成一個誠實的答案。

3

規劃拍攝

在「今天」拖曳時間軸，在「規劃」對齊拍攝方位，再把拍到的內容記在日誌裡，它會依地點、依夜晚替您記住。
