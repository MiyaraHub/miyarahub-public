已儲存的地點

Almanox 中的每個數字，包括太陽事件、評比、銀河核心與月亮時間，都是針對地球上的某一點計算。「地點」就是讓您選擇那一點的地方：您的 GPS、以名稱搜尋的城市，或精確座標，並加以儲存，讓您能在實際拍攝的幾個據點之間輕鬆切換。

前往方式

天空是依哪裡計算的

點選「今天」或「今晚」頂端的地點名稱，即可開啟「地點」。

地點名稱位於「今天」與「今晚」兩個畫面的頂端。點一下就會開啟「地點」畫面，列出您已儲存的所有地點，並標示目前使用中的那個。切換只要一下：選一個圖塊，整個應用程式就會依該地點重新計算，而且 Almanox 會記住您的選擇供下次使用。

設定您要為哪裡規劃，共有三種方式：

  • 使用目前位置 - 重新要求您的 GPS 位置。處理期間會顯示「正在尋找您的位置」對話框。如果無法定位，不論是權限被拒、定位服務關閉或任何錯誤，Almanox 都會告訴您位置無法使用，並退回內建的紐約位置，而不是什麼都不顯示。
  • 搜尋城市 - 輸入地名並搜尋；附近的相符結果會連同座標一起列出，點選其中一個即可儲存。它會採用您輸入的名稱；若您將欄位留白，則採用座標。
  • 座標 - 直接輸入緯度與經度，並依實際範圍驗證 (-90 至 90, -180 至 180)，還可以選填自訂名稱。若名稱留白，Almanox 會將座標反向地理編碼，為您換成地名。
地點您拍攝的據點
管理整理

切換、刪除與預設值

清單由您自己整理，只有一道防護欄，確保您不會落得無處可去。

  • 切換 - 點選任何已儲存的圖塊，即可設為使用中。使用中的地點會驅動每個畫面，直到您更換為止。
  • 刪除 - 將圖塊向左滑動即可移除。您無法刪除唯一剩下的地點；至少要保留一個，這樣應用程式才不會沒有可供計算的地點。
  • DEFAULT 標籤 - 當內建的紐約備用位置是您已儲存的項目之一時，會以此標示，讓您隨時知道哪一個是安全網。

免費版包含三個已儲存地點，足以涵蓋住家、附近的暗空地點與一個旅行據點。Pro 則取消上限、無限數量，適合橫跨多個地方規劃的人。

城市搜尋與反向地理編碼需要網路連線；地點一旦儲存，其所有太陽、月亮與星圖讀數都在裝置上計算，不需訊號。
