畫面

設定、主題與提醒

Almanox 依您的使用習慣調整：三種介面與一組強調色、可重新排序或隱藏的分頁與卡片、將您所有儲存內容打包成單一檔案的備份，以及在光線出現之前而非之後提醒您的通知。

外觀

介面與強調色

選擇適合您眼睛的黑暗程度，以及貫穿整個應用程式的顏色。

介面決定基底：淺色適合白天規劃、深色適合夜晚、AMOLED（純黑）則能省電，並在拍攝現場保持低調，因為明亮的螢幕既會毀掉您的夜視能力，也會毀掉那張照片。

強調色會替一切重新上色，包括圓環、重點標示與使用中的分頁，共有七種預設：金色、月光、紫羅蘭、極光、翠綠與玫瑰，另有自訂滴管，讓您調出任何喜歡的顏色。所有主題與強調色都免費，沒有任何一項放在付費牆後。

AMOLED 加上深色強調色是野外的最愛：介面幾乎隱沒在黑暗中，只有您需要的數字向您發出微光。

設定外觀與版面配置
打造專屬於您

依您的習慣重新安排應用程式

底部分頁，以及「今天」與「今晚」上的卡片，都由您自行安排。

  • 自訂分頁 - 重新排序或隱藏底部分頁，讓您最常開啟的畫面剛好落在拇指所在的位置。
  • 自訂「今天」卡片 - 重新排序或隱藏「今天」畫面上的卡片。如果您從不看即時位置，就把它拿掉；如果月亮是您的拍攝主題，就把它移到最上面。
  • 自訂「今晚」卡片 - 「今晚」畫面也有同樣的控制，讓評比、銀河與時段依您閱讀的順序排列。

這裡沒有任何破壞性的操作，隱藏卡片或分頁只是整理您的檢視畫面，您隨時都能從同一個畫面把它找回來。

永不遺失

備份與還原

您的地點、筆記與設定，匯出成單一檔案。

備份與還原會把您建立的一切，包括已儲存的地點、日誌筆記與設定，匯出成一個由您掌控的檔案。換新手機後還原，您的設定就會一起帶過去。由於 Almanox 把一切都留在裝置上，這個檔案就是您的副本，沒有任何東西存放在伺服器上讓您弄丟。

提醒

在光線出現之前收到通知，而不是之後

黃金時刻、暗空時段與極光，提前多久由您設定。

在提醒中，Almanox 可以在值得停下腳步的時刻之前通知您：黃金時刻開始、暗空時段開啟，以及極光活動。每一項都有可調整的提前時間，讓通知在您來得及趕到腳架前時送達，而不是時段結束之際。

通知屬於 Pro 的一部分，因此免費使用者點選提醒開關時會開啟升級頁面。這個畫面上的其他一切，包括每種介面、每種強調色、分頁與卡片配置，以及備份，都是免費的。

黃金時刻與自訂提醒屬於一次性 $12.99 的 Pro，與銀河核心預報、詳細的逐時預報、拍攝規劃器、主畫面小工具和無限數量的地點並列，而好夜晚暗空提醒則是免費的。沒有訂閱，一次付清。

Almanox 為一次性購買，價格 $12.99，沒有訂閱、沒有廣告、不需帳號。您的主題、您的版面配置、您的地點，全都在您的裝置上。
