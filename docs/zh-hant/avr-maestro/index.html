功能

完整的接收器控制，就在您手中。

比隨附遙控器更深入的控制，而且一切都與實體遙控器和前面板保持同步。

No. 01

✦ 一鍵場景

擷取您的整套設定，包括輸入、音量、音效模式、Audyssey/Dirac、喇叭預設、聲道電平、分區，甚至調諧器，只要點一下就能全部叫用。電影之夜、遊戲、深夜聆聽，各有各的場景。

No. 02

◉ 音量、輸入與環繞

精準的音量控制並顯示 dB 讀數、以視覺化網格一鍵切換輸入訊源，以及完整的環繞模式選擇器，涵蓋您的接收器支援的每種模式。

No. 03

▣ 虛擬遙控器

頂級的虛擬遙控器，備有導覽方向鍵、播放傳輸控制、靜音與快速音量調整。需要的一切都在手邊，不必再翻找實體遙控器。

No. 04

▢ 多分區控制

獨立控制分區 2 與分區 3。每個分區都有專屬的電源、音量、輸入訊源與快速音量預設，全都在同一個畫面上。

No. 05

◎ Audyssey 與房間校正

完整控制 Audyssey MultEQ、Dynamic EQ、Dynamic Volume、LFC 與抑制量。不必翻遍接收器選單，就能微調您的房間校正。

No. 06

◆ Dirac Live 與 IMAX Enhanced 進階

在 Dirac Live 濾波器插槽之間切換、設定含分頻的 IMAX 模式，並調整 Auro-3D 預設與處理強度，全都能在手機上完成。

No. 07

╿ 各聲道電平

獨立調整系統中每顆喇叭的音量，從前置左/右到頭頂增高聲道。非常適合在房間校正之後微調。

No. 08

⚙ 系統設定

HDMI 輸出設定、前面板亮度、12V 觸發輸出、ECO 模式、自動待機計時器、HDMI CEC、藍牙發射器、音訊修復器與視訊處理模式。

No. 09

☼ Quick Select、主題與自訂導覽

一鍵叫用您最愛的輸入/音量/模式組合。可選擇淺色、深色（AMOLED）或跟隨裝置的主題，設定自訂的 TJ Mode 強調色，並可拖曳來重新排序、顯示或隱藏導覽分頁，配合您的使用習慣。

No. 10

♪ FM/AM 調諧器與正在播放

直接在應用程式中依頻率或已儲存的預設來調 FM/AM，並為 HEOS 訊源觀看含專輯封面的即時正在播放畫面。重新排序並重新命名您的輸入，讓網格依您的思考方式排列。

運作方式

直接網路連線，不需要雲端。

1

新增您的接收器

輸入接收器的 IP 位址，或讓應用程式在您的網路中自行尋找。不需帳號、不用註冊。

2

透過 Wi-Fi 連線

AVR Maestro 透過區域網路直接與接收器溝通：用 HTTP 傳送指令、用 Telnet 接收即時事件、用 HEOS 顯示正在播放內容。

3

完全掌控

音量、輸入、環繞、分區、校正、調諧器與場景，全都能從手機、平板或桌面電腦操作。

安全與隱私

僅限本機。沒有帳號。沒有雲端。

AVR Maestro 以隱私優先、僅限本機的架構設計。不依賴雲端、沒有使用者帳號，除了當機回報之外不蒐集任何資料。

◉

沒有雲端中繼

所有指令與狀態輪詢，都透過您的本地 Wi-Fi 直接在手機與接收器之間進行。沒有任何資料離開您的網路。

▣

不需要帳號

不用註冊、不用電子郵件、不需要 MiyaraHub 帳號。開啟應用程式、輸入接收器的 IP，就能掌控一切。

◎

最低限度的分析

Firebase Crashlytics 僅用於問題回報。沒有個人資料、沒有使用追蹤、沒有廣告。您的接收器資料絕不會離開手機。

◆

僅限本機儲存

裝置 IP 位址與應用程式偏好設定都儲存在您的裝置本機。沒有任何內容會同步到伺服器。

□

僅限使用者主動操作

應用程式只會在您要求時才向接收器傳送指令，沒有背景變更，也沒有任何在您背後自動執行的動作。

FAQ

常見問題。

AVR Maestro 與 Denon 或 Marantz 有關係嗎？ +
沒有。AVR Maestro 是由 MiyaraHub Technologies LLC 開發的獨立第三方應用程式，並非由 Denon、Marantz 或其母公司 Sound United / Masimo 所建立、背書、贊助，也與他們沒有任何關聯。「Denon」、「Marantz」、「Audyssey」、「Dirac Live」、「IMAX Enhanced」與「Auro-3D」均為其各自擁有者的商標。我們使用這些名稱，純粹是為了說明相容性。
支援哪些接收器？ +
AVR Maestro 適用於支援 IP 控制（HTTP 和/或 Telnet）的連網 Denon 與 Marantz AV 接收器，大多數 2014 年以後的機型都可使用。應用程式會在連線時自動偵測可用功能。能否連上取決於您的網路，而不只是機型：如果接收器自己的網頁入口、HEOS 應用程式，以及官方的 Denon 或 Marantz 應用程式，都能在同一個網路中連上它，而且它的網路連接埠沒有被封鎖，AVR Maestro 應該也能看到它。
AVR Maestro 如何與我的接收器溝通？ +
AVR Maestro 使用三種通訊協定：HTTP 用於可靠的狀態輪詢與指令，Telnet 用於即時事件串流（音量變更、輸入切換），HEOS 則用於顯示含專輯封面的正在播放資訊。所有通訊都直接在您的本地 Wi-Fi 網路中進行。
支援 Audyssey、Dirac Live 與 IMAX Enhanced 嗎？ +
支援。AVR Maestro 可完整控制 Audyssey MultEQ、Dynamic EQ、Dynamic Volume、LFC 與抑制量，也支援 Dirac Live 濾波器插槽切換、含分頻設定的 IMAX Enhanced 模式，以及 Auro-3D 設定。可用功能取決於您的接收器機型所支援的內容。
可以控制多個分區嗎？ +
可以。AVR Maestro 支援分區 2 與分區 3，各自擁有獨立的電源、音量、輸入訊源與快速預設。每個分區都可從專屬區塊控制，並可從主儀表板一眼看到各分區的狀態。
什麼是場景？ +
場景是整套設定的一鍵快照，包含輸入、音量、音效模式、Audyssey/Dirac 選擇、喇叭預設、聲道電平、分區，甚至是調諧器。想存多少都可以（電影之夜、遊戲、深夜聆聽），並隨時立即叫用。這是在您實際使用系統的各種方式之間跳轉的最快辦法。
AVR Maestro 要多少錢？ +
AVR Maestro 為一次性購買，價格 $9.99。沒有訂閱、沒有廣告、沒有應用程式內購買。買一次，永久擁有。
我可以在家以外的地方遠端控制接收器嗎？ +
AVR Maestro 會連線到您設定的任何 IP 位址。如果您的接收器可透過 VPN 或 Tailscale 存取，應用程式就能遠端運作。我們建議使用 VPN 或 Tailscale，而不要把接收器直接暴露在網際網路上。
支援哪些平台與版本？ +
AVR Maestro 提供於 iPhone（App Store）、Android（Google Play）、Windows（Microsoft Store）與 macOS（Mac App Store）。在 Android 上需要 Android 5.0（API 21）或更高版本；在 iPhone 上，則需要搭載目前 iOS 版本的較新裝置。完整手冊請見 avrmaestro.com。
