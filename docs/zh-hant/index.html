工作室

小工作室，細心的作品。

MiyaraHub Technologies 是位於德州 Van Alstyne 的小型獨立 LLC，由 Meir Miyara 擁有並經營。

我們不是工廠，也不假裝是。我們是一個在意細節的小團隊，做的是您會想放在自己裝置上、用來控制自己設備的那種軟體。

我們公開地打造，傾聽使用者的聲音，並快速修正問題。每次發行的許多內容，都始於社群中某個人的一則訊息，而我們也希望一直如此。

我們不會誇大其辭。有些應用程式已經精緻成熟，正服務成千上萬的使用者；有幾款還在工作台上，我們會誠實告訴您是哪一款。我們承諾的是誠懇的努力、原生軟體、預設在裝置端運作，以及不對運行於您已擁有硬體上的東西收取訂閱費。
