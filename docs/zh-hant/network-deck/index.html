功能

您的 UniFi 控制器，隨身帶著走。

Network Deck 直接與您的 UniFi 控制器的本機 API 通訊，無論是 UniFi OS（UDM Pro、Cloud Gateway、Dream Machine）或獨立版 UniFi Network 控制器皆可。用戶端、WiFi、防火牆、連接埠、VPN 與各項分析洞察，不必開啟瀏覽器就能掌握。

運作方式

直接連線到您的控制器，沒有雲端中繼。

Network Deck 透過您的區域網路（或 VPN）直接與 UniFi 控制器通訊。您的憑證與網路資料絕不會經過 MiyaraHub 的伺服器。

1

新增您的控制器

輸入控制器的主機名稱或 IP、連接埠（UniFi OS 預設為 443，獨立版為 8443），以及您的本機管理員憑證。Network Deck 會自動偵測您使用的是 UniFi OS 還是獨立版控制器。

2

在本機驗證

使用本機管理員帳號與密碼登入，全程支援雙重驗證。偏好 API 金鑰嗎？使用 X-API-KEY 進行程式化存取，即可完全略過 Cookie 流程。

3

一眼掌握全局

查看即時頻寬圖表、踢除搗亂的用戶端、切換防火牆規則、重啟 PoE 連接埠、邀請 Teleport 訪客，或切換到另一個站點。每個動作都會與控制器往返確認，並更新即時事件串流。

安全與隱私

僅限本機。沒有帳號。沒有雲端中繼。

Network Deck 採用隱私優先的純本機架構設計。不需要 MiyaraHub 帳號、沒有雲端中繼，除了當機報告外不收集任何資料。

◉

沒有雲端中繼

所有指令與即時串流都只在您的手機與控制器之間，透過本機 Wi-Fi 或 VPN 直接進行，不會經過任何外部伺服器。

▣

標準 UniFi 驗證

使用與 UniFi Network 網頁介面相同的本機管理員憑證（或 API 金鑰）。憑證儲存於裝置上的 iOS Keychain / Android Keystore，除了傳送給您的控制器之外，絕不會傳出裝置。

◎

不需要 MiyaraHub 帳號

不需註冊、不需電子郵件、不需 MiyaraHub 帳號。安裝後指向您的控制器，就能開始使用。

◈

最低限度的分析

僅使用 Firebase Crashlytics 回報錯誤。沒有使用追蹤、沒有廣告、不販售資料。網路錯誤會以非致命事件記錄，協助我們改善韌體相容性，而不會收集您的網路架構。

◆

尊重權限

應用程式只會在您的 UniFi 管理員帳號所擁有的權限範圍內運作。子管理員只能看到控制器允許他們看到的內容。沒有提權、沒有後門。

◐

僅需網路權限

Network Deck 唯一需要的裝置權限是網路存取，僅用於連線到您區域網路（或透過 VPN）上的 UniFi 控制器。

關於 Network Deck，您需要知道的一切。

Network Deck 與 Ubiquiti 或 UniFi 有關係嗎？ +
沒有。Network Deck 是由 MiyaraHub Technologies LLC 開發的獨立第三方應用程式，與 Ubiquiti Inc. 沒有任何開發、背書、贊助或隸屬關係。「Ubiquiti」、「UniFi」、「UniFi OS」、「UniFi Network」、「UDM」、「UDR」、「UCG」、「Teleport」及所有相關產品名稱均為 Ubiquiti Inc. 的商標。我們使用這些名稱純粹是為了說明相容性（指示性合理使用）。
支援哪些 UniFi 控制器？ +
Network Deck 同時支援 UniFi OS 主機（UDM Pro / Pro SE、UCG、Dream Machine、UDR、Cloud Key Gen2 / Plus），以及執行於 Linux、Docker 或 Windows 上的 v10.x 獨立版 UniFi Network 控制器。連線時，應用程式會自動偵測您的平台，並依據您的韌體實際提供的端點調整介面，沒有的功能就不會顯示。已實機測試 UDM Pro SE（UniFi OS 5.0.16）與獨立版 Network 10.2.105。
Network Deck 如何與我的控制器通訊？ +
Network Deck 使用與 UniFi Network 網頁介面相同的本機 API，結合傳統的 /rest 與 /cmd 端點（以 Cookie 工作階段驗證），以及較新的 v2 整合 API。它也會與您的控制器建立 WebSocket 連線，以串流即時事件。所有通訊都只在您的手機與控制器之間，透過區域網路或 VPN 直接進行。
我需要 UniFi 雲端帳號嗎？ +
不需要。Network Deck 僅使用本機驗證。請以您的 UniFi 本機管理員帳號與密碼（或 API 金鑰）登入。如果您的控制器目前只能透過 ui.com 雲端登入，請先在 Settings → Admins 中啟用本機管理員帳號，才能使用 Network Deck。控制器不會與我們通訊，我們也不會代您與 Ubiquiti 的雲端通訊。
我可以管理防火牆規則與連接埠轉發嗎？ +
可以。Network Deck 提供完整的防火牆功能：原則（允許 / 封鎖 / 檢查）、可完整增刪修查的連接埠轉發、流量規則與路由、防火牆群組、防火牆區域（v2 原則矩陣），以及 DPI 應用程式 / 群組。所有項目都能在清單檢視中直接切換，不必在一個又一個對話框之間來回點選。
支援多站點嗎？ +
支援。如果您的控制器管理多個站點，Network Deck 會在頂端顯示站點切換器。儀表板、用戶端、防火牆、VPN 等所有功能，都會依目前選取的站點為範圍。只需輕點一下即可切換。
Network Deck 的價格是多少？ +
Network Deck 將在 App Store、Google Play 與 Microsoft Store 以 $4.99 一次買斷。沒有訂閱、沒有廣告、沒有應用程式內購買。正式推出前價格可能會調整。
我可以遠端使用嗎（不在家裡 / 辦公室時）？ +
Network Deck 會連線到您設定的任何主機名稱或 IP。只要您的控制器能透過 VPN、Tailscale、WireGuard 或轉發的連接埠連上，應用程式就能遠端使用。我們建議使用 VPN 或 Tailscale，而不要將 UniFi 控制器直接暴露在網際網路上。
支援哪些平台？ +
Network Deck 可在 iOS（13 以上）與 Android（5.0 / API 21 以上）上執行，同時支援手機與平板版面。應用程式將同步在 App Store、Google Play 與 Microsoft Store 推出。
