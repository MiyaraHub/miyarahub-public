MiyaraHub / NexusDeck

NexusDeck · 專為 Audyssey 校正檔案打造所有校正，一個應用程式搞定。✦

適用於配備 Audyssey MultEQ XT 或 XT32 的 Denon 和 Marantz AV 接收器的校準檔案庫。

將您的 .ady 和 .oca 曲線檔案保存在同一個資料庫中，進行比較，並透過家用網路將您選擇的檔案傳送到喇叭預設。在 Dirac Live 接收器上，它還能重播您錄製的 Dirac Live 傳送。NexusDeck 不量測您的房間，也不建立曲線。

功能

保存、比較、傳送。

NexusDeck 保存您已在使用的工具產生的檔案：Audyssey MultEQ Editor、A1 Evo 和 AcoustiX。它不量測您的房間，也不建立曲線。

No. 01

◉ 所有曲線檔案集中在一個資料庫

匯入來自 Audyssey MultEQ Editor 的 .ady 檔案，以及來自 A1 Evo 和 AcoustiX 的 .oca 檔案。新增資料夾、標籤、評分和備註，並依檔案名稱、工具、接收器型號、備註或標籤搜尋。可從曲線檔案頁面分享該檔案。

.ady.oca資料夾標籤
No. 02

▣ 量測，僅供檢視

開啟 .frd、REW 文字、Dirac Live .liveproject 和 MultEQ-X .mqx 檔案進行檢視。量測絕不會傳送到接收器。不讀取 REW .mdat。

.frdREW .txt.liveproject.mqx
No. 03

◎ 檢視與比較

在同一張圖表上檢視每個聲道，並附脈衝響應和群延遲。可匯出影像或 CSV。使用 Pro，可透過差值表比較曲線。

所有聲道CSVPro 比較
No. 04

▢ 增益編輯

在聲道上設定 0 至 -12 dB 的增益削減，並可先檢視結果。編輯後的 .ady 或 .oca 只能傳送到喇叭預設 1，作為計算得出而非量測得到的濾波器。已儲存的檔案絕不會被變更。

0 至 -12 dB預設 1保留原檔案
No. 05

◆ 傳送到您的接收器

在網路中找到您的接收器，選擇喇叭預設並傳送。NexusDeck 會先檢查接收器和檔案，並在兩者不相符時提示。傳送後它不會回讀濾波器。.ady 傳送已在 Marantz Cinema 30 上測試；.oca 傳送及其他型號依檔案格式支援，不作保證。

喇叭預設先檢查Cinema 30
No. 06

⚙ Dirac Live 插槽

讀取 Dirac Live 插槽並在其間切換。將您自己錄製的 Dirac Live 傳送重播到某個插槽。該傳送只是暫存在接收器上，並未儲存，當喇叭預設切換時，接收器會將其捨棄。NexusDeck 不建構、編輯或轉換任何 Dirac 濾波器。

讀取切換重播
No. 07

◈ 預設與喇叭，唯讀

檢視目前啟用的喇叭預設，以及每個喇叭的距離和微調。NexusDeck 只讀取它們，絕不變更位準、距離或分頻點。

目前預設距離微調
No. 08

▣ 預設備份

每次傳送前，NexusDeck 會在您的裝置上保存目標喇叭預設的設定，讓您看到傳送取代了什麼。Back up now 會在不傳送任何內容的情況下保存目前預設的設定。兩者均免費。

每次傳送前Back up now免費
No. 09

◆ Pro 工具

將整個資料庫（含資料夾、標籤、備註、編輯和量測）備份到 .ndbackup 檔案，並在另一台裝置上還原。Batch Map 一次將一條曲線傳送到每個喇叭預設，Quick / Smart Select 則可保存任意數量的接收器設定。

.ndbackupBatch MapQuick / Smart Select
No. 10

✦ 先試用

示範接收器是應用程式內建的 Marantz Cinema 30，無需硬體即可展示完整流程，且從不消耗傳送次數。

示範接收器無需硬體
運作方式

從曲線檔案到接收器，只需三步。

帶入曲線檔案，檢視它，傳送它。可先在應用程式內的示範接收器上試用整個流程。

1

匯入您的檔案

匯入來自 Audyssey MultEQ Editor 的 .ady，或來自 A1 Evo 或 AcoustiX 的 .oca。它連同聲道、目標曲線和備註一起加入您的資料庫。

2

檢視、比較、編輯

開啟曲線，在同一張圖表上檢視每個聲道。使用 Pro 可將其與另一條曲線比較，或設定增益削減。已儲存的檔案絕不會被變更。

3

傳送到揚聲器預設組

找到您的接收器，選擇喇叭預設並傳送。沒有 Pro 時，傳送到喇叭預設 1。應用程式在傳送後不會回讀濾波器。

安全與隱私

僅限本機。沒有帳號。沒有雲端。

您的校準檔案保留在您的裝置上，您的接收器保留在本地網路中。除非您傳送給我們，否則關於您設定的任何資訊都不會到達 MiyaraHub。

◉

沒有帳號

無需註冊，也沒有 MiyaraHub 登入。MiyaraHub 不運行應用程式所連接的任何伺服器。

▣

檔案保留在您的裝置上

您的資料庫、編輯和設定保存在您的裝置上。不會同步到 MiyaraHub。

◎

僅限您的家用網路

NexusDeck 在本地網路中直接與您的接收器通訊。校準檔案絕不會經過 MiyaraHub 伺服器。

◆

僅在您允許時才傳送當機報告

在 Android 和 iOS 上，只有在您於首次執行提示中允許後，當機報告才會傳送到 Firebase Crashlytics。可在設定 > 關於中關閉。Mac 和 Windows 應用程式不傳送任何報告。

●

無分析，無廣告

沒有分析函式庫，沒有廣告，也沒有廣告識別碼。

◈

僅在您傳送時才提供記錄檔

設定 > 關於 會將應用程式記錄檔打包為一個 zip 檔案供支援使用，僅在您選擇傳送時才會分享。

FAQ

常見問題。

關於 NexusDeck，您需要知道的一切。

NexusDeck 與 Audyssey、Dirac、Denon 或 Marantz 有關聯嗎？ +
沒有。NexusDeck 是 MiyaraHub Technologies LLC 開發的獨立應用程式，與 Denon、Marantz、Audyssey 或 Dirac 無關聯，也未獲得它們的認可。所有商標均歸其各自擁有者所有。
哪些接收器可用？ +
對於 .ady 和 .oca：支援連網、配備 Audyssey MultEQ XT 或 XT32 且已開啟網路待機的 Denon 和 Marantz 型號。.ady 傳送已在 Marantz Cinema 30 上測試；.oca 傳送及其他型號依檔案格式支援，不作保證。
NexusDeck 能讀取哪些檔案？ +
曲線（可傳送）：來自 Audyssey MultEQ Editor 的 .ady，以及來自 A1 Evo 和 AcoustiX 的 .oca。量測（僅供檢視，絕不傳送）：.frd、REW 文字、Dirac Live .liveproject 和 MultEQ-X .mqx。不讀取 REW .mdat。
NexusDeck 會取代 MultEQ Editor 或 A1 Evo 嗎？ +
不會。NexusDeck 不量測您的房間，也不建立曲線。它保存、比較並傳送這些工具產生的檔案。其增益編輯只會削減已儲存檔案中原有的濾波器，結果保存在該檔案旁邊。
它支援 Dirac Live 嗎？ +
會，用於讀取和切換 Dirac Live 插槽，以及重播您自己錄製的 Dirac Live 傳送，而不是產生濾波器。重播的傳送只是暫存在接收器上，並未儲存，當喇叭預設切換時，接收器會將其捨棄。Dirac Live 傳送已在 Marantz Cinema 30 上測試；其他型號受支援，不作保證。
NexusDeck 會檢查它傳送的內容嗎？ +
傳送前，它會檢查接收器和檔案，並在兩者不相符時提示。傳送後它不會回讀濾波器，因此從不把一次傳送稱為已驗證。
NexusDeck 的價格是多少？ +
NexusDeck 可免費下載。沒有 Pro 時，它可配對一台接收器加示範接收器，保存三個匯入的曲線檔案加範例檔案，並傳送到喇叭預設 1，總共 15 次傳送，包括 Dirac Live 傳送。Pro 是一次應用程式內購買，在美國為 $19.99，可增加：傳送到任何預設不限次數、接收器和曲線檔案不限數量、多曲線比較、頂端列中的喇叭預設切換、Quick / Smart Select、Batch Map 以及資料庫備份檔案。每次傳送前或透過 Back up now 建立的預設備份是免費的。
有使用指南嗎？ +
有。NexusDeck 使用指南位於 nexusdeck.app。
