MiyaraHub / NexusDeck

NexusDeck · 專為 Audyssey 校正檔案打造所有校正，一個應用程式搞定。✦

透過 Wi-Fi 將 Audyssey .ady 校正直接上傳到喇叭預設欄位。將 A1 Evo Acoustix .oca、REW .mdat、.frd 與 PEQ 匯出檔匯入本機資料庫，以便瀏覽與比較。是 AVR Maestro 的最佳搭檔。

功能

所有校正檔案格式，一個應用程式搞定。

NexusDeck 能讀取您現有工具已產生的校正檔案，讓您在手機上瀏覽資料庫，並直接上傳到接收器。上傳這一步不需要筆電，也不需要 MultEQ Editor。

No. 01

◉ 匯入所有常見格式

原生支援解析 Audyssey .ady、A1 Evo Acoustix .oca、REW .mdat（MEQX 匯出）、.frd 響應曲線，以及 REW PEQ .txt 匯出檔。匯入過一次的檔案會永久快取在您的本機資料庫中。

No. 02

▣ 本機曲線資料庫

您匯入過的所有內容都存放在裝置上。可重新命名量測、將多位置 .mdat 同組檔案歸為一組，並以參照計數管理共用的檔案位元組，只有在沒有任何項目參照時，刪除才會釋放磁碟空間。採用本機 SQLite 儲存，重新啟動與更新應用程式後依然保留。

◎ 並排比較曲線

可疊加 Audyssey、A1 Evo Acoustix 與 REW 匯入的任意組合的頻率響應曲線。X 軸為對數頻率，Y 軸為 dB 量值，並提供多位置平均與平滑化控制。清楚看見每次校正之間究竟改變了什麼。

疊加對數頻率平滑化

Audyssey連接埠 1256SPP1 / SPP2位元組驗證

上傳前備份一鍵還原

運作方式

從量測檔案到接收器，只要三個步驟。

NexusDeck 瞄準的正是現有工具讓您卡關的地方：校正檔案在筆電裡，卻沒有簡單的方法把它送到接收器，除非重新開啟桌面應用程式。NexusDeck 補上了這個缺口。

1

匯入您的檔案

開啟 MultEQ Editor 的 Audyssey .ady、A1 Evo Acoustix 的 .oca、REW 的 .mdat，或任何其他支援的檔案。NexusDeck 會解析檔案、擷取響應曲線，並加入您的資料庫。

2

瀏覽與比較

開啟任一資料庫項目，即可查看逐聲道的頻率響應。疊加兩條或更多曲線，看看房間校正改變了什麼。隨著資料庫成長，可重新命名、分組或刪除項目。

3

將 Audyssey 上傳到接收器

對於 Audyssey .ady 檔案：選擇喇叭預設欄位（1 或 2）、確認後，看著 NexusDeck 透過 Wi-Fi 將校正串流到您的 Denon 或 Marantz 接收器。機身會驗證上傳內容，NexusDeck 也會回報是否成功寫入。匯入的 .oca / .mdat / .frd / .txt 會留在資料庫中供瀏覽與比較；這些格式的機身上傳將在未來版本推出。

安全與隱私

僅限本機。沒有帳號。沒有雲端。

NexusDeck 採用與 AVR Maestro 相同的隱私優先架構。您的校正檔案留在您的裝置上，接收器留在您的區域網路中，您的設定資訊不會有任何內容傳送給 MiyaraHub。

◉

沒有雲端中繼

校正上傳是透過本機 Wi-Fi（TCP 連接埠 1256），直接在您的手機與接收器之間進行。檔案絕不會經過 MiyaraHub 伺服器。

▣

不需要帳號

不需註冊、不需電子郵件、不需 MiyaraHub 登入。開啟應用程式、放入第一個校正檔案，就能進入資料庫。

◎

最少的診斷資料

僅使用 Firebase Crashlytics 收集當機報告與診斷資料，讓我們能修正您遇到的錯誤。沒有使用追蹤、沒有廣告、沒有個人化。可在設定中關閉。

◆

資料庫存放於本機

您的校正資料庫是本機 SQLite 資料庫，加上裝置上的檔案儲存。沒有任何內容會同步或上傳到 MiyaraHub 伺服器。

●

僅限使用者主動上傳

只有當您明確輕點「上傳」並確認欄位後，曲線才會傳送到接收器。不會有任何自動動作，並且會讀回機身內容，確認實際寫入了什麼。

◈

僅需網路權限

NexusDeck 唯一需要的系統權限是網路存取，僅用於連線到您本機 Wi-Fi 上的接收器。

關於 NexusDeck，您需要知道的一切。

NexusDeck 與 Audyssey、Denon 或 Marantz 有關係嗎？ +
沒有。NexusDeck 是由 MiyaraHub Technologies LLC 開發的獨立第三方應用程式，與 Audyssey Laboratories、Denon、Marantz、Sound United、Masimo Corporation 或其任何子公司都沒有開發、背書、贊助或隸屬關係。「Audyssey」、「MultEQ」、「Denon」、「Marantz」以及「REW」/「Room EQ Wizard」均為其各自所有者的商標。我們使用這些名稱純粹是為了說明相容性。
NexusDeck 可以上傳到哪些接收器？ +
NexusDeck 可上傳到支援 TCP 連接埠 1256 二進位校正上傳協定的連網 Denon 與 Marantz AV 接收器，涵蓋近幾年的 Cinema 30 / 40 / 50、AV10、X3800H、X4800H、X6800H 以及其他 Audyssey MultEQ XT32 機種。NexusDeck 會從接收器與您要上傳的校正檔案中，自動偵測機種型號與聲道配置。
NexusDeck 可以匯入哪些檔案格式？ +
Audyssey .ady（MultEQ Editor 匯出檔）、A1 Evo Acoustix .oca、REW .mdat（Room EQ Wizard 的 MEQX 量測匯出檔，支援多位置）、.frd 響應曲線，以及 REW PEQ .txt 匯出檔。目前只有 .ady 檔案可以上傳到接收器；.oca / .mdat / .frd / .txt 僅供資料庫收藏與比較。v1 不支援 Dirac Live 濾波器匯入與機身上傳。
NexusDeck 會自己產生校正曲線嗎？ +
不會，而且這是刻意的設計。NexusDeck 負責儲存、瀏覽、比較並上傳由其他工具（MultEQ Editor、A1 Evo Acoustix、REW、ratbuddyssey 等）產生的校正檔案。實際的量測與曲線產生是在那些工具中完成；NexusDeck 是管理工具，也是裝置端的上傳管道。
我現有的喇叭預設會安全嗎？ +
會。每次上傳前，NexusDeck 都會讀回目標喇叭預設欄位目前的內容，並在您的資料庫中儲存為備份項目。只要輕點一下，就能將任何欄位還原成先前的校正。傳輸完成後，NexusDeck 也會重新讀取該欄位，確認上傳確實無誤。
NexusDeck 如何與我的接收器配對？ +
如果您已安裝 AVR Maestro 並與接收器配對，NexusDeck 會透過共用的跨應用程式容器自動讀取已配對的裝置清單，不必再次配對，也不必重複輸入 IP。如果您沒有 AVR Maestro，NexusDeck 的配對流程會引導您直接輸入接收器的 IP。
NexusDeck 的價格是多少？ +
NexusDeck 可免費下載。免費版涵蓋所有資料庫匯入、瀏覽與單一曲線視覺化，並提供最多 5 次終身上傳到喇叭預設欄位 1（SPP1），讓您在決定購買前，先在自己的接收器上完整體驗上傳流程。解鎖無限次上傳、SPP2 寫入、欄位備份與還原、多曲線比較檢視、引導式導覽，以及 AVR Maestro 裝置交接橋接功能，只需一次性的 $12.99 應用程式內購買。沒有訂閱、沒有定期扣款、沒有廣告。正式推出前價格可能會調整。
需要哪些 Android 與 iOS 版本？ +
NexusDeck 需要 Android 7.0（API 24）或更高版本，以及 iOS 14 或更高版本。兩個平台將於上市時同步推出。
