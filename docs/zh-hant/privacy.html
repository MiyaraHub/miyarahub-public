4.4 使用分析（Firebase Analytics）

在啟用此功能的應用程式中，Firebase Analytics 會向 Google 傳送事件，例如首次開啟、工作階段開始、畫面檢視、應用程式內購買，以及附錄 A 所列的應用程式事件。每個事件都帶有隨機的應用程式執行個體識別碼、Firebase 安裝識別碼、裝置型號、系統版本、語言、應用程式版本，以及 Google 根據您的 IP 位址推得的大致位置（國家或地區）。在 iOS 上，它還可能使用供應商識別碼。在附錄 A 有所說明的應用程式中，它也會蒐集 Android 廣告 ID。我們使用分析資料來了解哪些功能被使用以及應用程式在哪些地方出錯。我們不將其用於顯示廣告。

Projector Pilot PJLink & VP21，一款適用於 Android、iOS、macOS 與 Windows 的投影機控制應用程式。已在 App Store 發行，並已在 Google Play 與 Microsoft Store 上線。
資料模型
應用程式在您的區域網路上與您的投影機通訊。沒有帳號，也沒有 MiyaraHub 伺服器。當機報告，以及在您選擇加入後的分析資料，會傳送至 Google Firebase。
網路目的地
您的投影機，透過 ESC/VP21、PJLink 與 Epson Web Control。為了尋找投影機，應用程式會連線至您 Wi-Fi 子網路中每個位址的投影機連接埠。此外還有 Google Firebase、商店計費與評論，以及您點選的連結；沒有更新檢查。
當機報告
預設值：自首次啟動起開啟。開關：無；分析開關不影響當機報告。傳送的內容：錯誤訊息與堆疊、Firebase 安裝 ID、裝置型號、作業系統版本、記憶體與磁碟狀態，且 Google 會看到您的 IP 位址。資料遮蔽：當機路徑上沒有；網路錯誤文字可能包含投影機或 Home Assistant 的 IP 位址。
分析
在您選擇加入之前保持關閉。提示會在首次設定期間出現，開關位於 Settings > About。識別碼：應用程式執行個體 ID 與 Firebase 安裝 ID；廣告 ID 在 Android 上已移除，在 iOS 上因從不要求追蹤權限而讀取為零。事件：app_open、scan_started、scan_finished、connection_tested、device_added、projector_connected、command_sent、paywall_view、paywall_unlock_tap、purchase_result 與 restore_tap，以及 Firebase 自動事件；關閉分析不會重設應用程式執行個體 ID。
權限
Android：網際網路、網路與 Wi-Fi 狀態（用於尋找子網路）與通知（維護提醒）。iOS：區域網路；相片、相機與位置的字串僅因外掛程式引用而存在，且它們已如此說明。
購買項目
三項選用的一次性購買項目：Pro、Home Automation，以及兩者合一的組合包，透過 App Store、Google Play 或 Microsoft Store 提供。解鎖狀態會快取在您裝置上的安全儲存空間中。
本機儲存與解除安裝
已儲存的投影機（名稱、IP 位址、連接埠、序號、型號、MAC 位址）位於應用程式儲存空間中，且對於 Epson Web Control，密碼也未加密地位於應用程式儲存空間中。其他投影機密碼以及 Home Assistant 與 Hubitat 權杖位於安全儲存空間中。Android 自動備份與 iCloud 備份包含應用程式儲存空間，Epson Web Control 密碼也在內。在 iOS 上，Keychain 項目（包括密碼與免費使用計數器）在解除安裝後仍然存在，且沒有面向使用者的全部刪除動作。
傳送至您所選服務的資料
您輸入的位址上的 Home Assistant 會收到投影機名稱、型號、序號、燈泡與濾網使用時數、輸入與錯誤。您輸入的位址上的 Hubitat 與 webhook 會收到投影機名稱、輸入與事件。備份匯出包含已儲存的投影機，Epson Web Control 密碼也在內。
支援電子郵件的內容
意見回饋與錯誤報告僅在您選擇時才傳送，會送至 admin@miyarahub.com。其中包含您的訊息、應用程式版本、作業系統、所選投影機的名稱與品牌，以及應用程式內記錄，該記錄會保留 IP 位址與投影機名稱。錯誤報告還包含投影機的序號與韌體。
已知限制
當機報告沒有開關，且未經遮蔽。Epson Web Control 密碼未加密儲存，並包含在備份與匯出檔案中。支援記錄會保留 IP 位址。

Projector Pilot D-ILA

名稱與平台
Projector Pilot D-ILA，一款適用於 JVC D-ILA 投影機的控制應用程式，支援 Android、iOS、macOS 與 Windows。尚未發行。
資料模型
應用程式在您的區域網路上與您的投影機通訊。沒有帳號，也沒有 MiyaraHub 伺服器。當機報告，以及在您選擇加入後的分析資料，僅在 Android 與 iOS 上傳送至 Google Firebase。
網路目的地
您的投影機，透過 TCP 連接埠 20554。為了尋找投影機，應用程式會連線至您的裝置所回報的每個私人 /24 網路中的每個位址。此外還有 Google Firebase、商店計費與評論，以及您點選的連結；沒有更新檢查。
當機報告
預設值：開啟。開關：Settings > About，「Send crash reports」；關閉後會刪除尚未傳送的報告。傳送的內容：錯誤文字、情境與堆疊、Crashlytics 安裝 ID、裝置型號、作業系統版本、應用程式版本以及記憶體與磁碟狀態，且 Google 會看到您的 IP 位址。資料遮蔽：在當機報告離開您的裝置之前，應用程式會從其攜帶的錯誤文字中移除 IP、MAC 與網址、已儲存的投影機主機名稱與存取權杖。投影機名稱、型號名稱與序號不會被移除。
分析
在您選擇加入之前保持關閉。首次啟動的提示提供「No thanks」或「Share analytics」，開關位於 Settings > About。識別碼：應用程式執行個體 ID 與 Firebase 安裝 ID；不蒐集廣告 ID。事件：app_open、scan_started、scan_finished、connection_tested、device_added、projector_connected、command_sent、paywall_view、paywall_unlock_tap、purchase_result 與 restore_tap，以及包含 in_app_purchase 在內的 Firebase 自動事件。
權限
Android：網際網路與通知（本機維護提醒）。iOS：區域網路；相片、相機與位置的字串僅因外掛程式引用而存在，且它們已如此說明。不要求位置權限。
購買項目
三項選用的一次性購買項目：Pro、Home Automation，以及兩者合一的組合包，透過 App Store、Google Play 或 Microsoft Store 提供。購買項目僅在您的裝置上檢查。在 Android 上，包含訂單 ID 與購買權杖的 Google Play 購買記錄保存在應用程式儲存空間中。
本機儲存與解除安裝
已儲存的投影機（名稱、IP 位址、連接埠、型號、MAC 位址）與設定位於應用程式儲存空間中，而投影機密碼、Home Assistant 與 Hubitat 連結以及自動化觸發器位於安全儲存空間中。Android 自動備份包含應用程式儲存空間，以及 Google Play 購買記錄（訂單 ID、購買權杖）。在 iOS 與 macOS 上，Keychain 項目在解除安裝後可能仍然存在，且下次安裝時會於首次啟動時將其刪除。Reset All App Data 會刪除密碼、中樞連結、觸發器與小工具資料，並將當機報告恢復為預設值（開啟）。免費方向鍵使用計數器是三個數字（累計使用的按壓次數、最後使用的日期以及該日的次數），不含個人資料，在 iOS 與 macOS 上保存在系統 Keychain 中，使重新安裝不會重新補滿免費額度。它絕不會傳送給我們，在您解除安裝應用程式後仍保留在 Keychain 中，且不會被 Reset All App Data 移除。在 Android 上，該計數器保存在應用程式儲存空間中，Android 自動備份包含該空間。
傳送至您所選服務的資料
您輸入的位址上的 Home Assistant 會將每台投影機視為一個裝置，收到其名稱、型號與作業系統詳細資料，接著是其狀態（電源、輸入、MAC 位址、光源使用時數、設定），以及您在該處新增時的位址、連接埠與密碼。Hubitat 會收到電源與輸入指令。您輸入的任何位址上的 Webhook 會收到事件、投影機名稱、輸入、場景與時間。
支援電子郵件的內容
意見回饋與錯誤報告僅在您透過郵件應用程式或分享選單選擇時才傳送，會送至 admin@miyarahub.com。其中包含應用程式版本、裝置製造商與型號、作業系統、地區設定、已儲存的投影機名稱與型號，以及經遮蔽的診斷記錄。
已知限制
當機報告在徵詢您之前即已開啟。當機報告中不會移除投影機名稱與型號。Android 的購買記錄會由 Android 自動備份複製到 Google Drive。

NexusDeck

名稱與平台
NexusDeck，一款適用於 Denon 與 Marantz 接收器的校正檔案管理應用程式，支援 Android、iOS、macOS 與 Windows。商店上架情況在本政策中尚未確認。
資料模型
應用程式在您的裝置上保存校正資料庫，並在您的區域網路上與您的接收器通訊。沒有帳號，也沒有 MiyaraHub 伺服器。當機報告僅在 Android 與 iOS 上傳送至 Google Firebase。
網路目的地
您區域網路上的接收器，透過 HTTP，以及本機探索。此外還有 Google Firebase、商店購買與評論，以及您點選的連結。不會呼叫其他網際網路服務。
當機報告
預設值：開啟。開關：位於 About；一旦關閉便保持關閉。傳送的內容：錯誤訊息與堆疊、Crashlytics 安裝 ID、Firebase 安裝 ID、裝置型號與作業系統版本，且 Google 會看到您的 IP 位址。資料遮蔽：IP 位址、網址主機與私人主機名稱在上傳前會從錯誤文字中移除；堆疊追蹤則原樣傳送。
分析
不傳送分析資料。應用程式沒有分析程式庫，儘管本政策的舊版本曾有不同的說法。
權限
Android：網際網路、網路與 Wi-Fi 狀態以及多點傳送（探索）。iOS：區域網路。沒有位置、相機或麥克風。
購買項目
一項選用的一次性 Pro 解鎖，透過商店提供。
本機儲存與解除安裝
校正資料庫、設定，以及已配對接收器的主機與名稱保存在您的裝置上。Android 自動備份包含資料庫與設定。沒有單一的全部刪除動作。
傳送至您所選服務的資料
在 Android 上，NexusDeck 會讀取同一裝置上由 AVR Maestro 儲存的接收器（名稱、IP 位址、型號、序號、MAC 位址與校正）。備份匯出會隨您分享的對象而流傳。
支援電子郵件的內容
「Send debug report」會開啟您的郵件應用程式，收件人為 admin@miyarahub.com，並附有應用程式版本、套件、建置模式、裝置製造商與型號、Android 建置 ID 與建置指紋，以及最多 1000 行未經遮蔽且包含接收器位址的記錄行。接收器診斷畫面會以電子郵件寄出帶有接收器名稱的探測傾印。您可以在傳送前編輯這兩封電子郵件。
已知限制
偵錯電子郵件記錄未經遮蔽。校正資料庫由 Android 自動備份複製到 Google Drive。

Network Deck

名稱與平台
Network Deck，一款適用於 Android 的 UniFi 網路管理應用程式。商店上架情況在本政策中尚未確認。
資料模型
應用程式以您的 UniFi 帳號登入您的 UniFi 控制器。沒有 MiyaraHub 帳號，也沒有 MiyaraHub 伺服器。當機報告會傳送至 Google Firebase。
網路目的地
您的 UniFi 控制器與 UniFi Protect，透過 HTTPS，且憑證驗證已關閉，因此當應用程式傳送您的控制器使用者名稱與密碼時，會接受任何憑證。Site Survey 速度測試在您啟動時，會將測試資料傳送至 Cloudflare（speed.cloudflare.com），該服務會看到您的 IP 位址。
當機報告
預設值：開啟。開關：設定中有一個開關，但正式版本會在每次啟動時將當機回報重新開啟，且關閉期間儲存的報告隨後會被傳送。傳送的內容：錯誤訊息與堆疊、Crashlytics 安裝 ID、Firebase 安裝 ID、裝置型號與作業系統版本，且 Google 會看到您的 IP 位址。資料遮蔽：無；錯誤文字可能包含控制器位址、API 路徑以及用戶端或裝置名稱。
分析
不傳送分析資料。沒有分析程式庫。
權限
網際網路、Wi-Fi 狀態、變更 Wi-Fi 狀態、精確與大致位置，以及附近的 Wi-Fi 裝置，用於 Site Survey 中的 Wi-Fi 掃描。生物辨識鎖為選用。
購買項目
應用程式沒有購買項目。
本機儲存與解除安裝
控制器主機、連接埠、使用者名稱、密碼與站台保存在安全儲存空間中，並在您登出時刪除。工作階段 Cookie 與設定保存在裝置上。Android 自動備份包含設定，但不包含安全儲存空間。
傳送至您所選服務的資料
在您啟動時的 Cloudflare 速度測試。應用程式會顯示帶有名稱、MAC 與 IP 位址（來自您的網路）的用戶端清單，且除了在當機文字或您分享的記錄中之外，不會將其傳送到任何地方。
支援電子郵件的內容
「Debug info」會透過分享選單分享應用程式版本、套件、作業系統、Dart 版本，以及控制器主機與站台。記錄匯出會分享完整且未經遮蔽的應用程式記錄。
已知限制
當機回報無法保持關閉，且未經遮蔽。控制器連線的憑證驗證已關閉。
