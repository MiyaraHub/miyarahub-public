MiyaraHub / Projector Pilot D-ILA

Projector Pilot D-ILA · 適用於 JVC D-ILA 投影機您的 D-ILA，盡在掌握。✦

從您的手機、平板或電腦，透過區域網路遙控 JVC D-ILA 投影機。

Projector Pilot D-ILA 直接透過投影機的網路控制連接埠 (TCP 20554)，並使用您在投影機上設定的網路密碼與其通訊。支援電源、輸入、選單導覽、畫面模式、HDR 等級、色彩、動態、鏡頭、安裝與畫面比例，並加上情境、維護與居家自動化。中間沒有帳號，也沒有雲端服務。

運作方式

直接網路連線。中間沒有雲端。

Projector Pilot D-ILA 直接連線到您區域網路上的投影機。沒有 MiyaraHub 伺服器，也不需要帳號。

1

尋找您的投影機

掃描您的網路（會在子網路的每個位址上嘗試連接埠 20554），或以 IP 位址新增投影機。

2

使用密碼登入

輸入您在投影機上設定的網路密碼。應用程式會在 TCP 20554 上登入、讀取機型，並將密碼保存在您裝置的安全儲存空間中。

3

掌控一切

使用您的機型所支援的遙控、畫面、鏡頭與設定畫面，儲存情境，並在需要時連結居家自動化。

安全與隱私

本機優先。無需帳號。無廣告。

應用程式只與您區域網路上的投影機以及商店（用於應用程式內購買）通訊。其他傳送的內容與時機都列在這裡。

◉

直接傳送到投影機

指令與狀態讀取都直接在您的裝置與區域網路上的投影機之間進行，中間沒有任何雲端服務。

◎

不需要帳號

無需註冊，也沒有 MiyaraHub 帳號。掃描或輸入投影機位址即可連線。

▣

當機報告與分析

當機報告在 Android、iPhone 與 iPad 上預設為開啟，以便修復錯誤，您可以在「設定」中關閉。當機報告可能包含導致應用程式停止的錯誤訊息文字，在少數情況下會出現網路位址。macOS 與 Windows 版應用程式不會傳送。匿名使用情況分析在您選擇加入前保持關閉，且只包含次數與結果，絕不包含投影機名稱、位址、密碼或中樞位址。

◆

密碼存放於安全儲存空間

每台投影機的網路密碼都保存在您裝置的安全儲存空間中。除了您加入投影機的 Home Assistant 之外，它不會傳送到其他地方，也不會進入記錄檔或備份。

▢

未購買居家自動化就不傳送任何資料

購買居家自動化後，應用程式只會將您的觸發傳送到您輸入的網址，只將電源與輸入傳送到您連結的 Hubitat 中樞，並將投影機狀態傳送到您登入的 Home Assistant。未購買時，示範投影機則始終如此，不會傳送任何資料。

☼

透過商店購買

Pro、居家自動化與組合包皆為由商店處理的一次性購買。MiyaraHub 不會看到您的付款資料。

FAQ

常見問題。

關於 Projector Pilot D-ILA，您需要知道的一切。

Projector Pilot D-ILA 與 JVC 有關聯嗎？ +
沒有。Projector Pilot D-ILA 是由 MiyaraHub Technologies LLC 開發的獨立應用程式，與 JVCKENWOOD Corporation 沒有關聯，也未獲其認可。JVC 與 D-ILA 是其各自所有者的商標，在此僅用於說明相容性。
何時可以使用？ +
Projector Pilot D-ILA 的 iPhone 與 iPad、Android、macOS 和 Windows 版本正在商店審核中。位於 projectorpilot.com/jvc 的手冊現在即可閱讀。
它支援哪些 JVC 投影機？ +
支援已連網的 JVC D-ILA 投影機：DLA-NZ900 與 NZ800、NZ700 與 NZ500 世代、NZ9、NZ8、NZ7 與 NP5 世代、NX9、NX7 與 NX5 世代，以及較早的 X7、X9、X30、X70R 與 X90R 系列，包含各地區名稱的機型。較舊的 HD 與 RS10 至 RS40 機型以及 X3 沒有網路控制。
它如何連線到我的投影機？ +
直接在您的區域網路上，透過投影機的網路控制連接埠 TCP 20554 連線。您可以掃描網路或輸入 IP 位址，然後使用您在投影機上設定的網路密碼登入。沒有雲端服務，也不需要帳號。
哪些功能免費，哪些需要購買？ +
不購買的情況下，您可使用電源開啟與待機、HDMI 1，以及 20 次選單導覽按鍵，之後每天 3 次。Pro 可解鎖 HDMI 2、無限次導覽、其他所有遙控按鍵、情境、維護、測試圖樣與小工具。居家自動化則加入網路請求觸發、Hubitat 與 Home Assistant。組合包涵蓋兩者，且每項都是一次性購買，無訂閱。
應用程式會傳送什麼資料，又傳送到哪裡？ +
指令會直接傳送到您的投影機。當機報告在 Android、iPhone 與 iPad 上預設為開啟，可在「設定」中關閉；macOS 與 Windows 版應用程式不會傳送。匿名使用情況分析在您選擇加入前保持關閉。購買居家自動化後，應用程式只會傳送到您輸入的網址、您連結的 Hubitat 中樞，以及您登入的 Home Assistant。
我有 Epson 投影機，有適用的版本嗎？ +
有。Projector Pilot PJLink & VP21 可控制 Epson 投影機，現已上架 App Store、Google Play、Mac App Store 與 Microsoft Store。
