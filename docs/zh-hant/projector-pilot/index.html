功能

完整的投影機控制，盡在手中。

Projector Pilot 透過 Wi-Fi 連線到您的 Epson 投影機，讓您完整掌控每一項設定，從電源、畫面到鏡頭與幾何校正，不必碰投影機，也不必到處找實體遙控器。

No. 01

◉ 電源 & 輸入控制

從待機開機、即時切換 HDMI 輸入、切換 A/V 靜音，並以虛擬方向鍵導覽 OSD，天花板吊掛的投影機還會自動反向。

電源開 / 關HDMI 切換A/V 靜音OSD 方向鍵
No. 02

▣ 畫面設定

完整控制色彩模式、亮度、對比、飽和度、色調、銳利度、伽瑪、色溫、降噪、超解析度與影像處理模式。

色彩模式亮度伽瑪銳利度
No. 03

◆ HDR & 色彩空間

動態範圍選擇（Auto、HDR10、HLG、SDR）、色彩空間控制（Auto、BT.709、BT.2020），以及逐通道的 RGB 增益與偏移調整，以進行精準校正。

HDR10HLGBT.2020RGB 增益 / 偏移
No. 04

◎ 鏡頭控制 & 記憶

電動鏡頭偏移、對焦與縮放調整，並即時顯示位置。可針對不同的畫面比例或螢幕位置，儲存並叫出鏡頭記憶預設。

鏡頭偏移對焦縮放記憶預設
No. 05

▢ 幾何 & 梯形校正

水平與垂直梯形校正，並支援 QuickCorner、Point Correction、Curved Surface、Corner Wall 與 FreeForm 等校正方式。

水平 / 垂直梯形校正QuickCornerCurved Surface
No. 06

⚙ 狀態 & 監控

即時追蹤燈泡與雷射時數並提供更換提醒。監控錯誤與警告狀態，並提供裝置資訊、序號、韌體版本與連線診斷。

燈泡時數錯誤監控裝置資訊
No. 07

☼ 動態 & 影像處理

補幀控制（關、低、一般、高）、降噪、超解析度增強，以及 Fine/Fast 影像處理模式選擇。

補幀降噪超解析度
No. 08

✦ 主題 & 自訂

AMOLED 深色主題帶來純黑畫面，另有淺色主題，並支援 Material You（裝置主題）。可調整顯示比例以適應任何螢幕尺寸，包括 Samsung Galaxy S25+ 的精簡版面。

AMOLED 深色Material You顯示比例

運作方式

直接網路連線，不需要雲端。

Projector Pilot 使用標準網路協定，透過 Wi-Fi 直接與您的投影機通訊。您的資料絕不會經過外部伺服器。

1

新增您的投影機

輸入 Epson 投影機的 IP 位址。Projector Pilot 會測試 PJLink 與 Web Control 的連線、偵測機種，並自動找出所有可用的功能。

2

透過 Wi-Fi 連線

Projector Pilot 使用 PJLink 偵測待機並控制電源，開機後再透過 Epson Web Control API 完整控制畫面、鏡頭與各項設定。一切都留在您的區域網路內。

3

完全掌控

調整畫面設定、切換輸入、控制電動鏡頭、管理梯形校正、監控燈泡時數並導覽 OSD，全都在一個優雅的應用程式中完成。

安全與隱私

僅限本機。沒有帳號。沒有雲端。

Projector Pilot 採用隱私優先的純本機架構設計。不依賴雲端、不需要使用者帳號，除了當機報告外不收集任何資料。

◉

沒有雲端中繼

所有指令與狀態輪詢都只在您的手機與投影機之間，透過本機 Wi-Fi 直接進行。沒有任何內容會離開您的網路。

◎

不需要帳號

不需註冊、不需電子郵件、不需 MiyaraHub 帳號。開啟應用程式、輸入投影機的 IP 位址，就能開始掌控。

▣

最低限度的分析

僅使用 Firebase Crashlytics 回報錯誤。沒有個人資料、沒有使用追蹤、沒有廣告。您的投影機資料絕不會離開手機。

◆

僅限本機儲存

投影機 IP 位址、憑證與應用程式偏好設定，使用 SharedPreferences 儲存在您的裝置本機。不會同步到任何伺服器。

▢

僅限使用者主動操作

應用程式只會在您明確操作時才對投影機發送指令。不會有任何動作在您不知情的情況下自動或在背景執行。

☼

僅需網路權限

Projector Pilot 唯一需要的裝置權限是網際網路 / 網路存取，僅用於連線到您本機 Wi-Fi 上的投影機。

FAQ

常見問題。

關於 Projector Pilot，您需要知道的一切。

Projector Pilot 與 Epson 有關係嗎？ +
沒有。Projector Pilot 是由 MiyaraHub Technologies LLC 開發的獨立第三方應用程式，與 Seiko Epson Corporation 或其任何子公司、關係企業沒有任何開發、背書、贊助或隸屬關係。「Epson」是 Seiko Epson Corporation 的註冊商標。我們使用此名稱純粹是為了說明相容性（指示性合理使用）。
支援哪些投影機？ +
Projector Pilot 支援所有支援 PJLink 和 / 或 Web Control 的連網 Epson 投影機，涵蓋過去 10 多年的大多數機種，從旗艦 QB1000 與 LS12000，到中階 Home Cinema 與專業安裝機種。應用程式在連線時會自動偵測可用功能，讓每位使用者看到的都是自己投影機實際支援的內容。基礎的 PJLink 控制也適用於 NEC、Panasonic、Sony 等非 Epson 投影機。
Projector Pilot 如何與我的投影機通訊？ +
Projector Pilot 使用兩種協定：PJLink（連接埠 4352）用於通用投影機控制，包括待機開機、輸入切換與燈泡狀態；以及採用 Digest 驗證的 Epson Web Control API（連接埠 80），用於豐富的設定控制，包括畫面、鏡頭、梯形校正、HDR 等。所有通訊都直接在您的本機 Wi-Fi 網路上進行。
我可以控制電動鏡頭嗎？ +
可以，適用於配備電動鏡頭系統的投影機。Projector Pilot 提供完整的鏡頭偏移（水平與垂直）、對焦與縮放控制，並即時回饋位置。您也可以針對不同的畫面比例、螢幕位置或觀賞情境，儲存並叫出鏡頭記憶預設。沒有電動鏡頭的機種會自動隱藏鏡頭控制。
支援 HDR 與廣色域嗎？ +
支援。Projector Pilot 可讓您控制動態範圍設定（Auto、HDR10、HLG、SDR）、色彩空間（Auto、BT.709、BT.2020），並提供逐通道的 RGB 增益與偏移調整，以進行精準的色彩校正。HDR 功能僅會顯示在支援的機種上。
我可以從待機狀態開啟投影機嗎？ +
可以。Projector Pilot 使用 PJLink，即使投影機處於待機模式也能開機。只要您的投影機已連上網路（待機喚醒建議使用有線區域網路），您就能用手機開關機。
Projector Pilot 的價格是多少？ +
Projector Pilot 可免費下載，並包含基本控制功能。Pro 為 $9.99 一次性解鎖，居家自動化為 $2.99，兩者合購套組則為 $11.99。沒有訂閱、沒有廣告。一次購買，永久擁有。正式推出前價格可能會調整。
需要哪個 Android 版本？ +
Projector Pilot 需要 Android 5.0（API 21）或更高版本。目前僅提供 Android 版本，未來版本可能會新增 iOS 支援。
