完整的投影機控制，盡在手中。

運作方式

直接網路連線，不需要雲端。

Projector Pilot PJLink & VP21 直接與您區域網路上的投影機通訊。沒有 MiyaraHub 伺服器，也不需要帳號。

1

尋找您的投影機

掃描您的網路，找出在 PJLink (4352) 與 ESC/VP.net (3629) 連接埠上回應的投影機，或直接輸入 IP 位址。應用程式會偵測機型及其支援的功能。

2

在您的網路上連線

應用程式使用 ESC/VP.net 上的 ESC/VP21 (TCP 3629) 與 PJLink (TCP 4352) 來控制電源、輸入與設定，並在投影機提供時使用 Epson Web Control (HTTP 80，Digest 登入)。一切都留在您的區域網路內。

3

完全掌控

調整畫面設定、切換輸入、控制電動鏡頭、管理梯形校正、監控燈泡時數並導覽 OSD，全都在一個優雅的應用程式中完成。

FAQ

常見問題。

關於 Projector Pilot PJLink & VP21，您需要知道的一切。

Projector Pilot PJLink & VP21 與 Epson 有關聯嗎？ +
沒有。Projector Pilot PJLink & VP21 是由 MiyaraHub Technologies LLC 開發的獨立第三方應用程式，並非由 Seiko Epson Corporation 或其任何子公司或關係企業所建立、認可或贊助，也與其沒有任何關聯。「Epson」是 Seiko Epson Corporation 的註冊商標。我們使用此名稱純粹是為了說明相容性（指示性合理使用）。
有適用於 iPhone 和 Android 的 Epson 投影機應用程式嗎？ +
有。Projector Pilot PJLink & VP21 可在 iPhone 與 iPad（iOS 15 或更新版本）、Android、Mac（macOS 12 或更新版本）以及 Windows 上執行，可從 App Store、Google Play、Mac App Store 與 Microsoft Store 取得。它用於控制您區域網路上的 Epson 投影機。
它支援 Home Cinema 5050UB、LS12000 或 QB1000 嗎？ +
支援。EH-QB1000 已在實機上確認，應用程式也內建 EH-LS12000 / Pro Cinema LS12000 與 EH-TW8400 / Home Cinema 5050UB 的設定檔，以及相容性中列出的其他機型。應用程式在連線時會讀取機型，並只顯示該機型支援的控制項目。
它可以取代 Epson iProjection 嗎？ +
兩者的用途不同。Epson iProjection 是將您的螢幕或照片傳送到投影機。Projector Pilot PJLink & VP21 不會投影內容；它是用於電源、輸入、畫面、HDR、鏡頭、梯形校正與維護的遙控與設定控制器，並提供情境與居家自動化。
支援哪些投影機？ +
支援已連網的 Epson 家庭劇院投影機，從 EH-QB1000，以及 LS12000、LS11000、LS800 與 LS500 雷射機型，到 6050UB、5050UB、4010 與 3800 燈泡機型，以及較早的 6040UB、5040UB 與 5030UB 世代。較小型的 Home Cinema、LS300、LS650 與 EF 機型提供電源與輸入控制。Home Cinema 3200 不支援網路控制。基本的 PJLink 控制也適用於其他廠商的投影機。
它如何與我的投影機通訊？ +
共有三種方式，全都在您的區域網路上進行：透過 ESC/VP.net 在 TCP 連接埠 3629 上使用 ESC/VP21（若您設定了投影機密碼，則會使用該密碼）；在 TCP 連接埠 4352 上使用 PJLink 控制電源、輸入與狀態；以及在 HTTP 連接埠 80 上使用 Epson Web Control 介面，並以 Digest 登入來存取其開放的設定。
我可以控制電動鏡頭嗎？ +
可以，適用於配備電動鏡頭的投影機。您可以調整鏡頭位移、對焦與變焦，並為不同的畫面比例或螢幕位置儲存及叫出鏡頭記憶預設。沒有電動鏡頭的機型不會顯示鏡頭控制項目。
支援 HDR 與廣色域嗎？ +
可以，適用於提供這些功能的機型。您可以選擇動態範圍（Auto、SDR、HDR PQ 與 HLG，視機型列出的項目而定）與色彩空間，並可調整各色版 RGB 增益與偏移以進行校準。
我可以從待機狀態開啟投影機嗎？ +
可以，前提是投影機在待機時保持網路運作。使用有線區域網路並搭配投影機的待機網路設定，可讓待機喚醒更穩定可靠。
Projector Pilot PJLink & VP21 的價格是多少？ +
可免費下載，內含一台投影機與基本控制功能。Pro 為 $9.99 一次性解鎖，居家自動化為 $2.99，或以 $11.99 購買兩者的組合包。無訂閱、無廣告。一次購買，永久擁有。
