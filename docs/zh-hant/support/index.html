來信時請提供哪些資訊

事先提供這些細節，可以省下一來一往的時間，更快為您解決問題：

  • 應用程式名稱與版本 - 可在應用程式的「設定」或「關於」畫面中查看（例如「AVR Maestro v2.9.6+131」）
  • 裝置與作業系統 - 手機 / 平板的型號與作業系統版本（例如「iPhone 15 Pro, iOS 18.2」或「Samsung Galaxy S24, Android 15」）
  • 您預期會發生什麼與實際發生了什麼
  • 重現步驟 - 讓我們能在自己這邊看到同樣的問題
  • 如果問題與畫面有關，請附上截圖或簡短的螢幕錄影
  • 裝置控制類應用程式請提供硬體環境 - 接收器 / NAS / UPS / 投影機的型號，若知道的話請一併提供韌體版本

我們的大多數應用程式都內建「傳送意見回饋」選項，會自動為您填入這些資訊，請在「關於」或「設定」畫面中尋找。

常見問題

應用程式無法連線到我區域網路上的裝置

我們的裝置控制類應用程式（AVR Maestro、UPSight、Syno Manager、FuryPath、Projector Pilot）必須透過 Wi-Fi 或乙太網路連上您的硬體。如果裝置沒有出現：

  • 確認您的手機與目標裝置位於同一個網路（相同的 SSID、相同的 VLAN）
  • 檢查裝置本身的設定選單中，是否已啟用網路控制或 API 功能
  • 在 iOS 上，首次執行應用程式時請接受「尋找並連線到區域網路上的裝置」的權限提示；如果您已拒絕，請在 Settings → [App Name] → Local Network 中重新啟用
  • 在 Android 上，應用程式需要 Wi-Fi 與網際網路權限（安裝時預設會授予）
  • 部分路由器會讓裝置彼此隔離（「AP 隔離」或「訪客網路」），請針對您裝置所在的子網路停用隔離

應用程式內跳出了評分提示，是必須的嗎？

不是。您可以直接關閉、選擇「稍後」延後，或點選「不再詢問」永久停止提示。要不要為我們評分或提供意見回饋完全是自願的，並不影響應用程式的功能。

我買了這款應用程式，要如何申請退款？

所有付費應用程式都是透過 Apple App Store 或 Google Play Store 購買。退款申請由這些平台直接處理：

  • Apple：reportaproblem.apple.com
  • Google：Google Play 的訂單記錄

如果您在任一平台遇到困難，請寄信給我們，我們會協助您爭取退款。

韌體更新後，我的硬體行為改變了

第三方製造商有時會在不同韌體版本之間更動其網路 API。如果您更新裝置後應用程式的行為突然不同，請將裝置型號、先前的韌體版本、目前的韌體版本，以及改變的內容寄給我們，我們會進行調查，若是我們能夠適應的情況，就會推出修正。

在哪裡可以看到最新版本更新了什麼？

請開啟應用程式的「關於」或「設定」畫面，我們的大多數應用程式都內建更新記錄。版本說明也會顯示在各商店的上架頁面。

你們有公開的產品藍圖嗎？

我們不公布固定的產品藍圖，因為我們是程式碼準備好才發布，而不是照著日曆走。話雖如此，如果您有想看到的功能，請寄信告訴我們，使用者的意見回饋會直接影響我們接下來要做什麼。
