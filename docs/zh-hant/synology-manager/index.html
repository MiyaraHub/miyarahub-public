整台 NAS，一眼掌握。

來自 Syno Manager 的真實截圖：儀表板、系統監控、儲存空間、工作排程、檔案、主題等。輕點任一張即可放大。

功能

完整的 NAS 控制，盡在手中。

DSM 能顯示的一切，都能在行動裝置上使用，並且會優雅地隱藏您的帳號無法查看的內容。

No. 01

◉ 即時儀表板

一眼查看即時 CPU、RAM、溫度與運作時間。可自訂的卡片讓您精準掌握重要資訊：系統健康狀態、儲存空間用量、網路吞吐量等。

No. 02

▣ Docker 管理

查看所有執行中的容器及其即時 CPU 與記憶體用量。啟動、停止、重新啟動容器並存取記錄，在手機上完整掌控 Docker。

No. 03

◎ 監視攝影機

以簡潔的格狀版面顯示即時攝影機畫面。輕點即可全螢幕檢視、查看錄影狀態，並在同一處監控所有 Surveillance Station 攝影機。

No. 04

▢ 儲存空間 & 硬碟健康

每顆硬碟的磁碟區用量、RAID 狀態、個別硬碟溫度與 SMART 健康資料。隨時掌握儲存空間的狀態。

No. 05

╿ 網路監控

每個網路介面的即時頻寬圖表。追蹤下載 / 上傳速度、作用中連線、綁定介面與 DNS 設定。

No. 06

⚙ 套件管理

查看所有已安裝的 DSM 套件及其狀態。監控執行中的服務、排程工作、UPS 電池狀態、記錄項目與共用資料夾。

No. 07

☼ 高度可自訂

設定儀表板類別、自訂導覽列、選擇主題並設定輪詢間隔。讓應用程式依您的習慣運作。

No. 08

✦ 主畫面小工具

快速動作、儲存空間總覽與系統狀態小工具，直接放在主畫面上。不必開啟應用程式，就能瞄一眼 NAS 的健康狀態。

運作方式

直接連線 DSM，沒有雲端。

1

新增您的 NAS

輸入 NAS 的 IP 或主機名稱與連接埠。不需要 MiyaraHub 帳號，也不需註冊。

2

使用 DSM 登入

使用您現有的 DSM 憑證進行驗證，憑證只會傳送給您的 NAS，採用與 DSM 網頁入口相同的機制。

3

監控 & 管理

儀表板、Docker、攝影機、儲存空間、網路、套件與工作，直接在您的手機、平板或桌面上完成。

安全與隱私

您的 NAS、您的資料、由您掌控。

Syno Manager 採用隱私優先的架構設計。最少的資料收集、沒有使用者追蹤、不依賴雲端。

◉

沒有雲端中繼

所有通訊都只在您的裝置與 NAS 之間，透過區域網路直接進行。不會經過任何外部伺服器。

▣

標準 DSM 驗證

採用與 DSM 網頁介面相同的驗證機制。您的憑證只會傳送給您的 NAS，絕不會傳給我們。

◎

最低限度的分析

使用 Firebase Crashlytics 找出錯誤並提升穩定性，沒有個人資料、沒有使用追蹤、沒有廣告。應用程式不會在您的裝置之外收集 NAS 資料或憑證。

◆

安全的本機儲存

連線資訊使用平台安全儲存機制（iOS Keychain 與 Android Keystore）儲存在裝置上。

FAQ

常見問題。

應用程式如何連線到我的 NAS？ +
Syno Manager 使用 Synology DSM 公開記載的 API 端點，透過您的區域網路與 NAS 通訊。應用程式會直接向您的 NAS 發送請求，沒有任何中介伺服器、代理伺服器或雲端中繼。您只要提供 NAS 的 IP / 主機名稱與連接埠，並使用 DSM 憑證登入，應用程式就會直接與 DSM 通訊。
應用程式需要我 NAS 上的哪些權限？ +
應用程式只會在您的 DSM 使用者帳號所擁有的權限範圍內運作。若要使用完整的儀表板功能，建議使用管理員帳號。不過應用程式會優雅降級：如果您的帳號沒有 Docker 權限，Docker 區塊就不會顯示資料，Surveillance Station、共用資料夾等也一樣。不需要安裝任何特殊的 DSM 套件。
應用程式會儲存我的 NAS 憑證嗎？ +
連線資訊會使用平台安全儲存機制（iOS Keychain / Android Keystore）儲存在您的裝置本機。憑證絕不會傳送給 MiyaraHub Technologies 或任何第三方，僅用於向您的 NAS 進行驗證。
支援哪些 Synology 機種？ +
Syno Manager 適用於任何執行 DSM 7.0 或更新版本的 Synology NAS，包括目前所有的 DiskStation (DS)、RackStation (RS) 與 FlashStation (FS) 機種。執行 DSM 6.x 的較舊機種，可能因 API 差異而功能有限。
我可以遠端管理 Docker 容器嗎？ +
可以。您可以直接在應用程式中查看容器狀態、CPU / 記憶體使用量、存取記錄，並執行停止 / 重新啟動操作。目前尚不支援建立容器與變更設定，重點在於監控與快速管理操作。
Syno Manager 的價格是多少？ +
Syno Manager 為 $9.99 一次買斷。沒有訂閱、沒有廣告、沒有應用程式內購買。只要在 App Store 或 Google Play 購買一次，就永久擁有。
我可以遠端存取我的 NAS 嗎（不在家中網路時）？ +
Syno Manager 會連線到您設定的任何 IP / 主機名稱。只要您的 NAS 能透過 VPN、Tailscale 或轉發的連接埠連上，應用程式就能遠端使用。我們建議使用 VPN 或 Tailscale，而不要將 DSM 直接暴露在網際網路上。
