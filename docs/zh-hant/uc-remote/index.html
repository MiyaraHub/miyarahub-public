功能

整支遙控器，盡在您手中。

UC Remote 透過 Wi-Fi 連線到您的 Unfolded Circle Remote Two 或 Remote 3，並以專為手機設計、流暢的原生介面，呈現遙控器能做的一切：活動、頁面、實體與媒體。

No. 01

◉ 一鍵啟動活動

從簡潔的清單中啟動與停止完整活動，例如觀看 Shield TV、Xbox、PS5。遙控器會開啟正確的設備並切換輸入，應用程式則直接帶您進入該活動的控制畫面。

啟動 / 停止活動群組一鍵操作
No. 02

▣ 精美的活動頁面

每個活動都有自己的自訂頁面。在媒體播放畫面、按鍵遙控器與量身打造的控制磚之間滑動切換，版面與您在遙控器上的設定完全一致。

可滑動的頁面自訂版面按鍵磚
No. 03

♫ 即時播放資訊

專輯封面、曲名與演出者、播放控制（上一首、播放 / 暫停、下一首），以及媒體播放器的訊號源與音效模式選擇器，全都隨狀態變化即時更新。

專輯封面播放控制即時狀態
No. 04

◎ 每種實體都有專屬設計

帶有亮度與色彩的燈光、含設定溫度的空調、窗簾、開關、感測器與媒體播放器，每一種都有專為它設計的控制畫面，搭配合適的圖示與動作，而不是千篇一律的開關。

燈光空調窗簾感測器
No. 05

☰ 完整實體瀏覽器

依類型搜尋並篩選您整個設定中的數百個實體，不論是燈光、媒體播放器、開關或空調，並可直接跳進其中任何一個。

搜尋依類型篩選快速開啟
No. 06

▤ 多支遙控器

配對多支 Unfolded Circle 遙控器並即時切換。每支遙控器都會記住各自的設定檔、頁面與實體，因此劇院遙控器與辦公室遙控器可以完全分開。

多遙控器快速切換各遙控器設定檔
No. 07

▦ 主畫面小工具

直接在主畫面放置活動、媒體播放器或裝置小工具，每個都可指向所選的遙控器，不必開啟應用程式就能一鍵控制並查看即時播放資訊。

運作方式

直接連線到您的遙控器，不需要雲端。

UC Remote 在您自己的 Wi-Fi 上與 Unfolded Circle 遙控器配對，並使用遙控器本身的整合介面直接與其通訊。您的設定絕不會經過外部伺服器。

1

配對您的遙控器

輸入 Unfolded Circle Remote Two 或 Remote 3 的 IP 位址，以及它顯示的 PIN。UC Remote 會安全地完成配對，並載入您的設定檔、頁面、活動與實體。

2

保持同步

即時雙向連線會串流遙控器的狀態，例如什麼設備開著、什麼正在播放，而您的每次輕點則會直接以指令回傳。沒有輪詢延遲，也不必繞道雲端。

3

掌控一切

執行活動、操作自訂頁面、控制每個實體與媒體播放器、在多支遙控器之間切換，並將小工具釘選到主畫面，全都在同一個應用程式中完成。

安全與隱私

僅限本機。沒有帳號。沒有雲端。

UC Remote 以隱私優先、純本機的理念打造：不依賴雲端、不需要使用者帳號，除了當機報告外不收集任何資料。

◉

沒有雲端中繼

每個指令與即時狀態串流，都只在您的手機與遙控器之間，透過本機 Wi-Fi 直接進行。沒有任何內容會離開您的網路。

◎

不需要帳號

不需註冊、不需電子郵件、不需 MiyaraHub 帳號。以遙控器的 PIN 完成配對，就能開始掌控。

▣

PIN 配對存取

配對時會交換一組安全的存取權杖，僅儲存在您的裝置本機，並只用於與您的遙控器通訊。

◆

僅限本機儲存

遙控器位址與應用程式偏好設定儲存在您的裝置上。不會同步到任何伺服器。

▢

只執行您的操作

只有在您操作時才會發送指令。不會有任何動作在您不知情的情況下自動或在背景執行。

☰

僅需網路權限

UC Remote 唯一需要的權限是區域網路存取，僅用於連上您 Wi-Fi 上的遙控器。

FAQ

常見問題。

關於 UC Remote，您需要知道的一切。

UC Remote 與 Unfolded Circle 有關係嗎？ +
沒有。UC Remote 是由 MiyaraHub Technologies LLC 開發的獨立第三方隨行應用程式，與 Unfolded Circle 沒有任何開發、背書、贊助或隸屬關係。「Unfolded Circle」、「Remote Two」與「Remote 3」為其各自所有者的商標；我們使用這些名稱僅為說明相容性。
支援哪些裝置？ +
UC Remote 適用於您區域網路上的 Unfolded Circle Remote Two 與 Remote 3。只要您的遙控器與手機位於同一個 Wi-Fi，UC Remote 就能與其配對，並同步呈現其活動、頁面與實體。
它如何連線到我的遙控器？ +
透過您的本機 Wi-Fi。完成一次性的 PIN 配對後，UC Remote 會保持即時事件通道開啟，與遙控器的狀態同步，並將您的指令直接送出。沒有雲端中繼，也不需要帳號，一切都留在您的網路內。
我需要帳號或網際網路連線嗎？ +
永遠不需要帳號。UC Remote 只需要您的區域網路來連上遙控器，沒有任何內容會離開您的 Wi-Fi，也沒有需要註冊的雲端服務。
我可以控制多支遙控器嗎？ +
可以。您可以配對任意數量的 Unfolded Circle 遙控器，並輕點一下就能切換。每支遙控器都會保留各自的設定檔、頁面與實體。
UC Remote 支援哪些平台？ +
UC Remote 是適用於 Android 手機與平板的原生應用程式，可在 Google Play 下載。
