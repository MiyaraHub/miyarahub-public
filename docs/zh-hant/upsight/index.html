功能

UPS 回報的一切，清楚呈現。

從家用實驗室到整櫃機架，監控並管理您網路上的每一台 UPS。

No. 01

◉ 即時儀表板

所有 UPS 裝置的狀態一目了然。電池百分比、負載、電壓與剩餘運轉時間。可設定輪詢間隔，即時且永遠保持最新。

No. 02

▣ 電力指標

詳細的輸入與輸出電力資料。監控電壓、頻率、電流、瓦數、視在功率與線路品質。了解您的供電環境所需的一切。

No. 03

◎ 電池健康

動畫電池量表，顯示充電百分比、電壓、溫度與預估剩餘運轉時間。可直接在應用程式中執行自我測試，確認電池是否就緒。

No. 04

▢ 插座控制

查看並管理個別 UPS 插座。查看哪些插座處於作用中、重新命名以便辨識，並開關可控制的插座。

No. 05

⚠ 智慧警報

可設定停電、低電量、裝置離線與電力恢復事件的通知。設定自訂門檻，並選擇聲音與震動偏好。

No. 06

╿ 事件記錄

UPS 事件的完整記錄：連線變更、狀態輪詢、電力事件與警報。每台裝置都有附帶時間戳記的項目，讓您掌握何時發生了什麼事。

No. 07

☼ 高度可自訂

深色、淺色與跟隨系統的主題。攝氏或華氏。可調整的顯示大小、可自訂的底部導覽，以及可設定的輪詢間隔。打造專屬於您的介面。

No. 08

✦ 匯出 & 匯入

匯出裝置設定以供備份或轉移。在新裝置上匯入設定，立即上手，不必重新輸入連線資訊。

直接使用 SNMP / NUT，沒有雲端。

1

新增您的 UPS

輸入 IP 位址，並選擇 SNMP (v1/v2c/v3) 或 NUT。不需要帳號，也不需註冊。

2

透過您的網路輪詢

UPSight 直接在區域網路上與您的 UPS 通訊，不會經過任何外部伺服器。

3

監控 & 接收警報

電池、負載、剩餘運轉時間、插座與事件，並在電力中斷或電池電量偏低時發出智慧通知。

您需要準備的東西

您網路上的 UPS。

UPSight 透過網路與 UPS 通訊，可經由其網路卡或 NUT 伺服器。

◉

配備網路卡的 UPS

APC Network Management Card、CyberPower RMCARD、Eaton Network-M2 與 Network-M3、Tripp Lite WEBCARDLX、Vertiv Liebert IntelliSlot，以及任何其他支援 SNMP 的 UPS 網路卡。請先在網路卡的網頁中開啟 SNMP，再於 UPSight 中新增其 IP 位址。

▣

或透過 NUT 共用的 UPS

如果您的 UPS 以 USB 接到伺服器、NAS 或 Raspberry Pi，且該機器執行 Network UPS Tools (NUT) 伺服器，只要在 UPSight 中新增該 NUT 伺服器，就能在網路上的任何地方監控這台 UPS。

◎

不適用僅有 USB 的設定

如果 UPS 只透過 USB 連接到一台電腦，沒有網路卡也沒有 NUT 伺服器，就無法透過網路連上，因此 UPSight 無法看到它。

FAQ

常見問題。

我的 UPS 需要連上網際網路嗎？ +
不需要。UPSight 僅透過您的區域網路通訊。您的 UPS 只要與手機位於同一個網路（或能透過 VPN/Tailscale 連上）即可，UPS 本身不需要網際網路存取。
我可以監控多台 UPS 嗎？ +
可以！UPSight 支援無限台 UPS 裝置。儀表板會以一目了然的狀態卡片顯示所有設備。輕點任一裝置，即可在六個分頁中查看完整詳細資料：概覽、電力、電池、插座、事件與資訊。
我可以在應用程式中控制 UPS 插座嗎？ +
可以，適用於支援透過 SNMP 控制插座的 UPS 機種（例如具備可控制插座的 CyberPower PR 系列）。您可以個別開關插座，並重新命名以便辨識。唯讀插座只會顯示狀態，不提供開關控制。
UPSight 的價格是多少？ +
UPSight 為 $4.99 一次買斷。沒有訂閱、沒有應用程式內購買、沒有廣告。買一次，永久使用，並包含所有未來更新。
支援哪些 SNMP 版本？ +
UPSight 支援 SNMP v1、v2c 與 v3。您可以在設定時為每台裝置選擇版本。大多數消費級與進階消費級 UPS 使用 v2c，community string 為「public」。v3 則適用於需要驗證與加密的企業環境。
我可以遠端使用 UPSight 嗎（不在家中網路時）？ +
可以，只要您的 UPS 能透過 VPN、Tailscale、WireGuard 或類似方式連上即可。UPSight 會連線到您設定的任何 IP 位址。我們建議透過 VPN 存取，而不要將 SNMP 連接埠直接暴露在網際網路上。
UPSight 支援我的 UPS 網路卡嗎？ +
支援，只要網路卡支援 SNMP。涵蓋 APC Network Management Card、CyberPower RMCARD、Eaton Network-M2 與 Network-M3、Tripp Lite WEBCARDLX，以及 Vertiv Liebert IntelliSlot 網路卡。請先在網路卡's 網頁介面中啟用 SNMP，再於 UPSight 中新增網路卡's IP 位址。
我的 UPS 只有 USB 連接埠，可以使用 UPSight 嗎？ +
可以，透過 NUT。將 UPS 接到執行 Network UPS Tools (NUT) 伺服器的伺服器、NAS 或 Raspberry Pi，再於 UPSight 中新增該伺服器。如果 UPS 只透過 USB 連接到一台電腦，且沒有 NUT，就無法透過網路連上。
我的 UPS 品牌沒有列在清單上，能用嗎？ +
很可能可以！只要您的 UPS 支援 SNMP 並實作標準的 RFC 1628 UPS-MIB，UPSight 的通用驅動程式就能運作。大多數具備網路功能的 UPS 都符合此標準。如果您遇到問題，請與我們聯絡，我們可以評估為您的品牌新增專用驅動程式。
